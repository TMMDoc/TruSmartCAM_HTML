Requisitos de puertos

Servidor TruSmartCAM: 7371

El servidor espera las solicitudes del cliente en este puerto TCP. Deben permitirse las conexiones entrantes a este puerto en el equipo del servidor.

Servidor de licencias flotantes: 5776

El servidor de licencias flotantes espera las solicitudes de licencia en este puerto. Deben permitirse las conexiones entrantes a este puerto en el equipo del servidor de licencias flotantes (servidor TruSmartCAM).

Conexión de licencia a la nube: 7567

Este puerto lo utilizan TecZone (software de plegado) y el servidor de licencias flotantes para enviar solicitudes de licencia a Metamation Cloud. Por lo tanto, debe permitirse la conexión saliente en este puerto para las activaciones y renovaciones de licencias.

Requisitos de instalación y soporte

  • Se requieren privilegios administrativos para instalar la aplicación TruSmartCAM.

  • Herramientas de diagnóstico remoto a través de la VPN del contratista o de una conexión segura.
