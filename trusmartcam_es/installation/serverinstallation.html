Instalación del servidor

Instalación del servidor

Siga las instrucciones para instalar el servidor TruSmartCAM junto con SQL.

Administrator Rights

Para ejecutar esta instalación, el usuario debe tener privilegios administrativos.

  • Ejecute Setup.TruSmartCAM.<version>.exe para comenzar la instalación.

La versión es un número.

  • Lea el acuerdo de licencia, elija I accept the agreement y, a continuación, haga clic en Next.

Paso 1: Ubicación de la instalación

  • Indique el directorio de instalación o acepte el valor predeterminado C:\Program Files\TRUMPF\TMM\Praxis y haga clic en Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - La carpeta de instalación tendrá las siguientes carpetas: Bin, MetaCAM, Samples y Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - La carpeta de datos tendrá las siguientes carpetas: TruSmartCAM, TecZone y MetaCAM.

Paso 2: Selección de componentes

Tipo de instalación Componentes

Full

Servidor + Cliente de escritorio + Motor

Client

Cliente de escritorio

Server

Servidor + Cliente de escritorio

Station

Selecciona todos los terminales de estación como TecZone, MetaCAM, RightAngle(controlador de plegado), Vulcan(controlador de máquina láser)

Custom

Selecciona según la elección del usuario.

  • Elija la instalación Full. Seleccione Code Senders y Bend Code Senders de las herramientas TruSmartCAM. Ahora el tipo de instalación cambia a Custom. Haga clic en Next.

Paso 3: Elegir instalar SQL Server

La instalación de SQL Express 2022 solo es necesaria para el servidor TruSmartCAM. Esta opción no está disponible para las instalaciones de cliente y sincronización. Además, esta opción está activada e instalada la primera vez y puede omitirse posteriormente. Si SQL ya está instalado en el servidor TruSmartCAM, el usuario puede omitir el paso 3.

  • En Seleccionar tareas adicionales: Haga clic en Install SQL Express y haga clic en Next.

  • En Listo para instalar: Se resumen todas las funciones de instalación y se hace clic en Install.

Paso 4: Instalación de SQL Server

Una vez instalados los componentes de TruSmartCAM, el instalador continúa con la instalación del servidor SQL. Acepte el acuerdo de licencia para continuar e instale SQL Express con las opciones predeterminadas.

Una vez completada la instalación, haga clic en Close y complete la instalación.

Según la versión de Windows, al cerrar la instalación de SQL es posible que se solicite un reinicio.

Paso 5: Accesos directos del escritorio de Windows

  • Después de instalar SQL, si el sistema no se reinicia, seleccione la casilla Launch TruSmartCAM y haga clic en Finish.

  • Si el sistema se reinicia, inicie el icono de acceso directo Launch TruSmartCAM en el escritorio o escriba TruSmartCAM en el menú Inicio de Windows y Run as administrator.

Instalación del servidor: Los iconos de acceso directo TruSmartCAM y TruSmartCAM License están disponibles en el escritorio.
Instalación de cliente/SYNC: Solo el icono de acceso directo TruSmartCAM está disponible en el escritorio.

Paso 6: Registro de la licencia

  • En el campo Serial Number, escriba la clave de serie de TruSmartCAM proporcionada por el equipo de servicio de Trumpf Metamation. Escriba <Company Name> en el campo "Registered to" y el correo electrónico. Haga clic en OK.

En caso de que el firewall de la red bloquee el registro de la licencia o de que no haya internet en el PC del servidor TruSmartCAM, entonces la licencia de TruSmartCAM se realiza mediante activación sin conexión. Envíe por correo electrónico el archivo Prax.request desde la carpeta C:\ProgramData\TRUMPF\TMM\Praxis al equipo de servicio de Trumpf Metamation. El equipo de Trumpf Metamation proporcionará el archivo Prax.lock que debe colocarse en esta carpeta.

Paso 7: Configuración inicial única

  • Escriba el nombre de la base de datos y establezca la ubicación de almacenamiento de datos. Seleccione la casilla Use SQL Server y seleccione el nombre del servidor SQL al que conectarse para la base de datos. Haga clic en OK.

  • El cliente de escritorio TruSmartCAM se abre mostrando Database Connection Succeeded en la parte inferior.

  • Los archivos de configuración de TruSmartCAM, TecZone y MetaCAM se crearon con las máquinas de configuración predeterminadas o con las máquinas de licencia de TruSmartCAM. La misma configuración se compartirá entre todos los clientes TruSmartCAM.

La pantalla de bienvenida se muestra con el nombre de inicio de sesión del usuario de Windows como nombre e inicio de sesión de TruSmartCAM. El primer usuario de TruSmartCAM se considera Site Admin. Proporcione el correo electrónico y la contraseña. Haga clic en OK .

Seleccione la casilla Remember me para guardar las credenciales de inicio de sesión para la próxima vez. Al desmarcar la casilla Remember me, se solicitará el diálogo de inicio de sesión y contraseña cada vez que se inicie la aplicación TruSmartCAM.

Paso 8: Inicio de sesión en TruSmartCAM

  • Cierre TruSmartCAM y ábralo de nuevo. El sistema le solicita que introduzca las credenciales de inicio de sesión de TruSmartCAM.

  • El nombre de usuario con el que se ha iniciado sesión se muestra junto al icono de usuario en el encabezado de la aplicación TruSmartCAM.

  • Al pasar el cursor sobre el icono de usuario, el sistema muestra:

    • El rol del usuario (por ejemplo: Programador, Administrador).

    • Un acceso directo para cerrar sesión: Ctrl+L.

  • Al hacer clic en el icono de usuario se abre un menú que le permite:

    • Edit information…​ - Actualizar los datos de su perfil.

    • Change password…​ - Cambiar la contraseña de su cuenta.

    • Sign out - Cerrar la sesión de la aplicación.

    • Cancel - Cerrar el menú sin realizar ningún cambio.

Paso 9: Configuración de la máquina de la fábrica

  • Licencia de TruSmartCAM [bit de licencia que habilita todas las máquinas]: La máquina y el material TruSmartCAM predeterminados se consideran la configuración de fábrica.

  • Licencia de TruSmartCAM [sin demostración y con pocos bits de máquina habilitados]: Esas pocas máquinas y el material predeterminado se consideran la configuración de fábrica.

  • (Open → Import) una nueva pieza desde C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts y compruebe si la pieza se ha importado correctamente.

Note 1: TruSmartCAM Monitor

  • TruSmartCAM Monitor con instalación del motor (derechos de administrador del sitio):

    • TruSmartCAM Monitor con motor junto con los derechos de administrador del sitio de TruSmartCAM tendrá las siguientes opciones:

      1. Enviar la configuración de TruSmartCAM, TecZone, MetaCAM a todos los clientes TruSmartCAM. También tiene derechos para crear un nuevo inicio de sesión de usuario de TruSmartCAM.

      2. Show Agents mostrará el total de motores disponibles para realizar tareas de automatización, según la licencia de TruSmartCAM.

  • TruSmartCAM Monitor sin instalación del motor (derechos de administrador del sitio):

  • TruSmartCAM Monitor sin instalación del motor (sin derechos de administrador del sitio):

El PC que ejecuta la aplicación TruSmartCAM debe tener instalado el componente Engine TruSmartCAM [PC del servidor o en cualquier instalación de cliente]. El PC con el componente Engine TruSmartCAM instalado debe estar funcionando las 24 horas del día, los 7 días de la semana, para realizar todas las tareas de automatización.
Note 2: OpenGL

  • La aplicación TruSmartCAM al abrirse se cierra inmediatamente y además pmonitor no se muestra en la barra de tareas.

  • Esto representa un problema de OpenGL.

  • Otra forma de confirmarlo: Abra C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts que muestra un diálogo de error sobre el problema de OpenGL.

  • Actualice C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , la sección de opciones con GLVersion=1 para que la aplicación TruSmartCAM se abra correctamente.

[Options]
GLVersion=1.0
