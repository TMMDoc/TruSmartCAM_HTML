Import assemblies

Los montajes son grupos de piezas relacionadas combinadas en una sola unidad, lo que le permite gestionar varias piezas juntas como una sola entidad.

Puede importar montajes mediante los siguientes métodos:

  1. Importar mediante archivo

  2. Arrastrar y soltar

  3. Importar desde hoja de cálculo

Importar mediante archivo

Un montaje se puede importar en la biblioteca de piezas mediante la opción Import Assemblies…​.

  • Haga clic en el icono Open de la barra de comandos y seleccione Import Assemblies…​, o utilice File → Open → Import Assemblies…​.

  • Aparece el cuadro de diálogo Open. Seleccione los archivos de montaje requeridos.

  • Se muestra una vista previa del montaje seleccionado.

  • Haga clic en Open para importar el montaje.

  • Los montajes importados se enumeran en la vista Assemblies de la biblioteca de piezas.

Arrastrar y soltar

  • Arrastre y suelte un montaje directamente en la biblioteca de piezas de TruSmartCAM.

Importar desde hoja de cálculo

  • Utilice File → Open → Import Assemblies…​ y seleccione un archivo CSV, XLSX o XML, o arrastre y suelte el archivo.

  • Revise y actualice los detalles y las cantidades del montaje antes de importar. Utilice Add…​ o Remove…​ para modificar.

  • Tras la importación, los montajes se pueden preparar y asignar a nestings estáticos.
