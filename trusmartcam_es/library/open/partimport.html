Import parts

Antes de importar piezas, asegúrese de que los formatos de archivo sean compatibles con TruSmartCAM. Consulte supported file formats para obtener más detalles.

Si el material y el espesor no se asignan a la pieza tras la importación, asigne el material mediante el panel de piezas.

Métodos de importación

Existen tres métodos para importar piezas en la biblioteca de piezas:

  1. Importar mediante archivo

  2. Arrastrar y soltar

  3. Carpeta de visualización

Importar mediante archivo

Un archivo de pieza 2D o 3D se puede importar en la biblioteca de piezas mediante la opción Import parts…​.

  • Haga clic en los iconos open de la barra de comandos y seleccione la opción Import parts…​.

  • Aparece el cuadro de diálogo Open: seleccione cualquier archivo CAD (2D o 3D).

  • Se muestra una vista previa del archivo CAD seleccionado.

  • Seleccione la pieza requerida y haga clic en Open.

  • El sistema aplica el utillaje automáticamente a la pieza para todas las máquinas disponibles con el estado de utillaje actualizado.

Arrastrar y soltar

  • Arrastre y suelte un archivo de pieza directamente en la biblioteca de piezas de TruSmartCAM.

Carpeta de visualización

Los ajustes de visualización le permiten supervisar una carpeta en busca de archivos nuevos e importarlos automáticamente en la biblioteca de piezas.

Para configurarlos, consulte la página Watch settings.

  • Utilice una ruta UNC (Universal Naming Convention) \\192.168.1.11\<Folder path> o una unidad asignada M:\<Folder Path>.

  • El PC que ejecuta el Engine debe tener acceso de lectura/escritura a esta carpeta.

  • No utilice una ruta local como C:\<Folder Path>, ya que el servicio de visualización busca los archivos en el PC del Engine, no en el PC local.

Configuración de importación

Use geometry comparison on same CAD revision

Al importar una pieza con la misma revisión CAD, TruSmartCAM puede comparar la geometría del archivo CAD con la pieza existente.

  • Para habilitarlo, configure las Revision lookup keys (por ejemplo, REV) en factory → settings →Import. A continuación, habilite la opción Use geometry comparison on same CAD revision.

La comparación de geometría en la misma revisión CAD solo funciona cuando se han configurado las Revision lookup keys.

  • Ahora, importe una pieza en la biblioteca de piezas con una revisión específica (por ejemplo, Revisión 1).

  • La misma pieza se vuelve a importar con el mismo valor de revisión.

  • TruSmartCAM compara la geometría del archivo CAD recién importado con la pieza existente.

  • Si se detecta una diferencia de geometría, TruSmartCAM muestra un mensaje preguntando si desea:

    • Replace la pieza existente con la nueva geometría, manteniendo el mismo valor de revisión.

    • Skip la importación, conservando la pieza existente y su geometría.

Esto permite a los usuarios actualizar la geometría de la pieza sin cambiar el valor de revisión, manteniendo al mismo tiempo el control sobre si se reemplazan las piezas existentes.

Las piezas importadas se añaden automáticamente a la biblioteca para su uso posterior. Para obtener más información, consulte Library.
