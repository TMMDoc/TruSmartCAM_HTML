Import jobs

Importar desde csv o xlsx

También puede importar tareas en formatos de texto comunes

  • Haga clic en File → Open → Import Jobs, aparece el cuadro de diálogo Open Folder. Seleccione C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Si todas las piezas existen en la ubicación del csv o en los directorios de la carpeta de búsqueda, aparece la ventana new job mostrando todas las piezas que coinciden con los campos del csv.

  • Las piezas que faltan se ignoran y no aparecen en la ventana new job.

  • Inicialmente el estado de la pieza es Nascent.

  • Haga clic en OK; ahora las piezas se importan en la biblioteca de piezas.

Create a blank part for the missing CAD files

Al importar tareas mediante una hoja de cálculo (.csv o .xlsx), es posible que a veces tenga filas que hagan referencia a archivos CAD que no están disponibles en el sistema.

  • Para gestionar esto, vaya a Factory → Settings → Job, en Spreadsheet import settings habilite Create a blank part for the missing CAD files

Cuando se selecciona esta opción:

  • Si falta un archivo CAD para alguna fila durante la importación de la tarea, el sistema creará automáticamente una pieza en blanco en lugar del archivo CAD que falta.

  • En la ventana new job, estas piezas que faltan se resaltan visualmente en amarillo para indicar que falta el archivo CAD asociado.

  • La pieza que falta conservará sus campos asignados (como nombre de pieza, material, espesor, cantidad, etc.) del CSV. Sin embargo, su estado de pieza se mostrará como Nascent, lo que significa que es solo un marcador de posición vacío sin geometría real todavía.

Esto garantiza que la importación de la tarea pueda continuar sin errores debido a archivos CAD que faltan: podrá actualizar o reemplazar posteriormente la pieza en blanco con el archivo CAD correcto cuando esté disponible.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Cuando esta casilla está seleccionada, el sistema crea automáticamente la nueva tarea sin mostrar el cuadro de diálogo New Job si la hoja de cálculo no tiene errores (sin piezas que falten, fechas que falten o datos no válidos).

  • Cuando esta casilla está desactivada, el cuadro de diálogo New Job siempre aparece para la revisión y confirmación del usuario, incluso si la hoja de cálculo no tiene errores.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Cuando esta casilla está seleccionada, el sistema espera que la hoja de cálculo utilice la columna Raw-Material (por ejemplo, Steel-20). Esto significa que el tipo de material y el espesor deben combinarse en un solo valor en una columna.

  • Cuando esta casilla está desactivada, el sistema espera que la hoja de cálculo tenga columnas separadas para Material y Espesor (por ejemplo, Steel y 2.00). El sistema los combina internamente durante la importación.

Carpeta de visualización con CSV/XLSX

  • En factory → Settings→ Watch settings marque Enable 'Live Folder' y Watch sub-folders also.

  • Establezca la ruta de la carpeta de visualización (UNC o unidad asignada).

  • En Spreadsheet import settings, marque Import spreadsheet from 'Live Folder'.

  • Seleccione Import Jobs en las opciones de importación de hoja de cálculo.

  • Copie C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv y péguelo en la carpeta de visualización.

  • El sistema comprueba el CSV e intenta crear la tarea automáticamente.

  • Si falta el archivo CAD, no se crea ninguna tarea porque no se encuentran los datos CAD requeridos.

Directorio de búsqueda CAD y búsqueda CAD recursiva - no configurados

  • En factory → Settings → Job → Spreadsheet import settings, si no se establece ningún CAD lookup directories y no se utiliza Use recursive CAD search, el sistema no busca archivos CAD automáticamente.

  • Si la casilla Create a blank part for the missing CAD files está seleccionada, la tarea se creará igualmente aunque falten archivos CAD.

  • En este caso, todas las piezas de la tarea se crearán como piezas nascent (en blanco), lo que significa que no tienen geometría porque no se pudieron encontrar los archivos CAD.

Directorio de búsqueda CAD y búsqueda CAD recursiva - configurados

Cuando CAD lookup directories se establece en (C:\Program Files\TRUMPF\TMM\Praxis\Samples) y Use recursive CAD search está habilitado en factory → Settings → Job → Spreadsheet import settings:

  • El sistema busca automáticamente en la carpeta especificada y en todas sus subcarpetas los archivos CAD requeridos mencionados en la hoja de cálculo.

  • Create a blank part for the missing CAD files también está habilitado, por lo que si aún no se encuentra algún archivo CAD, el sistema creará una pieza en blanco como marcador de posición.
