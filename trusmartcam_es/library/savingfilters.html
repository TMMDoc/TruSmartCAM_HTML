Guardar filtros

Los filtros guardados le permiten reutilizar criterios aplicados con frecuencia en Piezas, Tareas y Diseños, agilizando su flujo de trabajo. Cada módulo incluye filtros predeterminados, pero los administradores del sitio o los programadores pueden crear listas de filtros adicionales según sea necesario. Reutilizar los filtros guardados ahorra tiempo y ayuda a mantener la coherencia entre las búsquedas.

  • Haga clic en el icono para ver los filtros predeterminados.

Pasos para guardar filtros

  • Haga clic en el icono y seleccione cualquier elemento de filtro.

  • En el menú desplegable del elemento de filtro seleccionado, elija una opción. Aparecerá una marca de verificación junto a la condición seleccionada.

  • Para aplicar la condición, haga clic en el icono y luego seleccione Add Condition Ctrl++. Puede repetir este paso para añadir varias condiciones.

  • Para guardar estos filtros seleccionados con condiciones, haga clic en Save Filter…​ Ctrl+S.

  • Introduzca el nombre y luego haga clic en Save.

  • Desde el cuadro de diálogo Save Filter, también puede eliminar cualquier filtro guardado previamente.

  • Estos filtros se guardarán en la lista de filtros predeterminada. Aquí, Material se guarda en la lista predeterminada.

Los filtros creados por SiteAdmin y Admin se comparten con todos los usuarios. Los filtros creados por Programmer y Operator se comparten únicamente con los roles de usuario Programadores y Operadores.

Comandos de filtro

Comando Icono Atajos Descripción

Clear Selection

Ctrl+X

Deselecciona todas las opciones seleccionadas y actualiza la vista de elementos de filtro.

Select Highlighted

Ctrl+A

Selecciona todas las opciones resaltadas. Este comando permanece deshabilitado si el resaltado de elementos no es aplicable al campo seleccionado.

Match All

&

Muestra solo los elementos que cumplen todas las condiciones seleccionadas.

Pin In/Out Menu

Ctrl+Down/Up

Cuando está fijado, el menú desplegable permanece abierto incluso cuando el foco actual se mueve a otra ventana.

Close Menu

Esc

Cierra el menú desplegable.
