La interfaz de usuario

La interfaz de usuario

La interfaz de usuario de TruSmartCAM proporciona acceso a todas las funciones principales a través de la barra de comandos y la barra de menús, lo que permite una navegación y operación eficientes.

Barra de comandos

Open - Importa piezas, tareas, pedidos y montajes a la biblioteca. Para más detalles, consulte Open.

Language - Cambia el idioma de la interfaz de usuario. Para más detalles, consulte Language.

Library - Abre la página de inicio de la biblioteca, donde las piezas y los montajes se muestran por separado. Para más detalles, consulte Library.

Jobs - Muestra las tareas importadas o creadas. Para más detalles, consulte Jobs.

Factory - Abre la ubicación central para configurar y administrar rutas, materiales, usuarios y datos de clientes para la configuración de producción. Para más detalles, consulte Factory.

Info - Muestra información sobre el software.

Barra de menús

File - Proporciona opciones para abrir piezas, tareas, pedidos y montajes, y para salir de la aplicación.

View - Permite cambiar entre pantallas y acceder a diferentes vistas.

Help - Proporciona acceso al manual de ayuda y a las opciones de actualización del software.

Admin - Contiene ajustes administrativos y opciones de configuración.

Subcomandos

Parts - Muestra los elementos de la Part Library.

Assys - Cambia a los elementos de montaje en la vista Library.

Export - Exporta el informe actual de piezas o utillaje como CSV.
