Bend

Se puede acceder a los ajustes de plegado haciendo clic en el icono Factory y seleccionando después Settings, donde verá una lista de todos los ajustes ambientales disponibles del software.

Output settings

Save bend NC and reports- Los resultados del utillaje se guardan solo si el utillaje es correcto y estos ajustes de exportación están habilitados y configurados. Habilite esta opción para que se conserven el NC de plegado y los informes.

Show Raw Material name in bend reports - Hace que TruSmartCAM imprima los nombres de la materia prima en los informes de plegado.

Save bend tool setup CSV report - Exporta los detalles de configuración de la herramienta de plegado a un archivo CSV.

Save bend FX along with NC - Si esta opción está habilitada, cuando se realiza el plegado dentro de TruSmartCAM la salida de la pieza se guardará en el directorio junto con los archivos NC y el informe de cada configuración.

Bend output destination - Este es el destino donde se guardarán los archivos NC, los informes y los archivos FX.

Process settings

Apply flat correction during bending - Cuando se selecciona esta opción, TruSmartCAM comprueba si las dimensiones del desarrollo plano se actualizaron durante el utillaje de plegado y vuelve a actualizar la copia maestra utilizada para el proceso de corte.

Retain the legacy bend tooling when a FX file is imported - Habilite esta opción para conservar el utillaje existente cuando se importe un archivo FX heredado en TruSmartCAM.
