Import

Output settings

Save flat pattern - Habilite esta opción para que se guarde el desarrollo plano de una pieza importada.

Format for flat pattern - Esta opción se utiliza para elegir entre los formatos de archivo DXF o GEO.

Flat pattern destination - Esta es la ubicación donde se guardará el desarrollo plano.

Import settings

Units for DXF files - Esta es la unidad de medida con la que se importará un archivo DXF; el usuario puede elegir entre mm o pulgada.

Material lookup keys - Se pueden asignar varias entradas de búsqueda utilizando una coma como separador entre ellas. Cuando se importa una pieza, TruSmartCAM utiliza estas claves para buscar los valores de material. Los valores buscados se utilizan después para resolver la materia prima. Los valores originales se almacenan en las propiedades varias de la pieza.

Revision lookup keys - Cuando se importa una pieza, el valor de revisión del archivo de pieza en bruto (el archivo de pieza que se está importando) se compara con el valor de revisión existente en el repositorio. La importación se cancela si la revisión es la misma. El mapeo de campos personalizados también es compatible ahora con los archivos DXF. Para los archivos DXF, los datos del campo personalizado se extraen de la capa de texto del dibujo o de un adjunto PPI.

Use geometry comparison on same CAD revision - Compara la geometría al importar una pieza con la misma revisión CAD y solicita al usuario que reemplace u omita la importación si se detectan diferencias. Consulte Import configuration para obtener más detalles.

Part name keys - Esta opción funciona de forma similar a las Revision lookup keys y de material. Establezca una o más Part name keys para utilizar el Part name del PPI en lugar del nombre del archivo como nombre de la pieza.

Thickness lookup keys - Se pueden asignar varias entradas de búsqueda utilizando una coma como separador entre ellas. Cuando se importa una pieza, TruSmartCAM utiliza estas claves para buscar los valores de espesor. Los valores buscados se utilizan después para resolver el espesor. Los valores originales se almacenan en las propiedades varias de la pieza.

Thickness comparison fudge - Se utiliza para buscar la materia prima cuando se importa una pieza. TruSmartCAM intenta resolver la materia prima después de analizar el nombre del material y el espesor. Para obtener más información, consulte el tema Thickness fudge más abajo.

Identify shapes after a flat is imported - Cuando se importa una pieza, las formas interiores dentro de la pieza pueden reconocerse e identificarse automáticamente.

Shape identification fudge - El valor de tolerancia de identificación de formas se puede establecer en:

  1. Nivel global - Este valor se utiliza como predeterminado para todas las formas.

  2. Nivel de forma individual - El valor predeterminado se puede anular estableciendo el valor de tolerancia a nivel de forma individual. Al seleccionar la forma en el diálogo Shape Library se muestra el valor de tolerancia. De forma predeterminada, este valor es 0, y se utiliza el valor global predeterminado para dichas formas.

Rotate flat horizontally - Generalmente, las mesas de las máquinas de corte son rectangulares y más anchas. Para mejorar la viabilidad del utillaje, gire la pieza a lo largo de su ancho después de importarla.

Part rotation threshold - Establezca este valor como el número mínimo para permitir la rotación. Cualquier pieza menor que el valor establecido no se girará.

Misc settings

Enable pre-import external tools - Habilite la opción de importación de herramientas externas previas a la importación para activar Creo Reader. TruSmartCAM carga las instancias de familia preextraídas de la pieza soltada. Tenga en cuenta que la extracción de instancias se realiza durante la carga de la pieza (como operación previa a la importación), por lo que el software Creo debe estar instalado en el equipo desde el que se carga la pieza.

Ignore drawing colors in Flat thumbnails for clarity - Habilite esta opción para generar miniaturas más nítidas en escala de grises. Los colores de las capas y las entidades de texto se ignoran para mayor claridad de la imagen.

Use only one Engine for all import tasks - Cuando está habilitada, solo se utiliza un núcleo de motor para las tareas de importación.

Thickness fudge

La opción Thickness comparison fudge elige el valor de espesor de chapa más cercano cuando el espesor de chapa deseado no está disponible en el inventario, comparando el valor de espesor de las chapas del inventario.

Por ejemplo, supongamos lo siguiente:

  1. Tenemos una pieza con un espesor de chapa de 1,6 mm y material de acero.

  2. El valor de Thickness comparison fudge es 0,1 mm.

  3. El inventario tiene chapas de acero con espesores de 1,5 mm, 1,55 mm y 1,7 mm.

TruSmartCAM elige una chapa con el valor de espesor más cercano tras comparar el valor de Thickness comparison fudge (0,1 mm) con el elemento importado (que mide 1,6 mm). En este caso, la selección será de 1,55 mm.
