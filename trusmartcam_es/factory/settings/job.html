Output settings

Save layout NC and reports - Habilite esta opción para que se guarden el NC de diseño y los informes.

Save layout file - Habilite esta opción para que se guarde el archivo de diseño.

Output simulation preview in reports - Habilite esta opción para generar la vista previa de simulación del utillaje junto con las demás salidas. Se trata de una breve animación GIF del utillaje de láser/punzón.

Do not delete program outputs on layout/job completion - Al habilitar esta opción se omitirá la operación de eliminación de las salidas del programa cuando una tarea/diseño se marque como completado.

Nest settings

Mix parts from multiple Jobs - Admite el nesting en modo mixto. Las piezas de varias tareas deben anidarse juntas para una mejor eficiencia de empaquetado.

Do not auto-release layouts - Esto evitará que los diseños estén disponibles para producción hasta que todos los diseños estén en estado liberado.

Re-nesting packing cut-off - Este valor se utiliza para decidir si un diseño anidado se mantiene en la cola de aprobación y se vuelve a anidar cuando se planifican nuevas piezas o cuando se liberan para producción y las salidas relacionadas se exportan a la carpeta de salida.

Interactive sheet-name prefix - Esta sección se utiliza para admitir el nesting interactivo, donde el usuario tiene más control sobre las piezas que se anidan y el resultado del nesting. Utilice un esquema de nombres, diferente del nesting automático, para los diseños anidados de forma interactiva.

Update sheet inventory on nest (un)release - Si esta opción está habilitada, el inventario de chapas se actualizará al enviar un nesting a una máquina. Además, al recuperar el nesting de la máquina se devolverá la chapa al inventario.

Automate remnant inventory management - Cuando se selecciona este conmutador, el software automatiza la gestión del inventario de restos. Si no se selecciona, la gestión de restos se vuelve interactiva.

Auto-refresh Out-of-date layouts - Cuando se marca, el software actualiza todos los ui:EGTag.SelectOutOfDate[Out-of-date Layouts] vinculados a una pieza después de que se calculen sus soluciones de corte.

Automate twin-line nesting - Marque esta opción para habilitar la automatización de twin-line.

Pull workflow settings

Use 'Pull workflow' - Esta opción resulta útil para los usuarios que necesitan un sistema de planificación y nesting altamente autónomo. Cuando está habilitada, TruSmartCAM planifica el nesting bajo demanda.

Nests per station - Este valor sirve para establecer cuántos diseños por estación se deben crear.

Maximum sheets per nest - Este valor se utiliza para controlar el número máximo de chapas por nesting único. Así, por ejemplo, si hay un pedido con una pieza grande (que ocupa toda la chapa), necesaria en grandes cantidades (por ejemplo, 500), TruSmartCAM ya no crea un solo nesting con 500 copias en modo pull. En su lugar, crea 10 copias por nesting, donde 10 es el máximo.

Bend programs per station - Este valor sirve para establecer cuántos programas de plegado por estación se deben crear.

Mark the task completed, when the program outputs are removed - Habilite esta opción para que un diseño se marque como Done cuando las salidas se eliminen del destino de salida objetivo.

Spreadsheet import settings

CAD lookup directories - TruSmartCAM intentará cargar la entrada de pieza mencionada en el CSV importado desde la biblioteca de piezas. Sin embargo, si la pieza no está disponible en la biblioteca de piezas, intentará obtener las piezas de los directorios de búsqueda según el orden de directorios establecido en este diálogo.

Use recursive CAD search - Habilite esta opción para que la búsqueda se repita en resultados sucesivos.

Create a blank part for the missing CAD files - Si las piezas no existen en la biblioteca de TruSmartCAM ni en los directorios de búsqueda, TruSmartCAM creará una pieza en blanco para esas piezas no disponibles.

Do not show New Job dialog if the spreadsheet has no error - Si las entradas del CSV son correctas, es decir, no hay ninguna discrepancia de datos con la base de datos o todos los campos están indicados correctamente, TruSmartCAM no mostrará la ventana de resumen de la tarea y procesará la tarea en cuanto se importe o suelte el CSV.

Prefer Raw-Material column over Material + Thickness - Tipos de hoja de cálculo admitidos:

  1. Patrón 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Patrón 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Patrón 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Si esta opción no está marcada, el Patrón 1 se considerará el tipo de hoja de cálculo predeterminado. También admitimos el Patrón 3 en caso de que el formato CSV sea de tipo Patrón 3.

Si esta opción está marcada y el CSV es de tipo Patrón 2, entonces TruSmartCAM resolverá la materia prima a partir de los campos Material y Thickness del CSV.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Marque esta opción para habilitar la exportación a CSV cuando se completa un diseño o una tarea. Los informes completados se guardan en el destino de Reports especificado en los ajustes de Factory → Settings → Reports.
