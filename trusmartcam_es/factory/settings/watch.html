Watch

Los ajustes de Watch permiten a TruSmartCAM supervisar una carpeta designada e importar automáticamente archivos al sistema. Esto ayuda a automatizar la importación de piezas, tareas, montajes y pedidos sin intervención manual.

Watch settings

Enable 'Live Folder' - Habilita la supervisión automática de la carpeta especificada.

Watch this folder - Especifica la carpeta que se supervisará en busca de archivos entrantes.

Watch sub-folders also - Incluye todas las subcarpetas en el proceso de supervisión.

After file import

After import - Después de importar el archivo, el usuario tiene dos opciones. El archivo se puede eliminar de la ubicación o mover a otra ubicación.

  • Delete imported file - Elimina el archivo de origen tras una importación correcta.

  • Move imported file - Mueve el archivo de origen a la carpeta especificada en Move files to this folder tras una importación correcta.

Move files to this folder - Especifica la carpeta de destino donde se deben mover los archivos importados correctamente cuando After import está configurado en Move imported file.

Move spreadsheets with errors to this folder - Mueve las importaciones fallidas a la carpeta de errores especificada.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Importa automáticamente los archivos de hoja de cálculo detectados en la carpeta de visualización.

Do not import spreadsheet with errors - Impide que se importen los archivos que contienen errores de validación.

Spreadsheet import option - Selecciona el tipo de datos que se importarán de la lista desplegable. Los formatos de hoja de cálculo admitidos pueden incluir CSV, XLSX o XML. Las opciones disponibles son:

  • Import Jobs - Importa datos de tareas desde la hoja de cálculo.

  • Import Orders - Importa datos de pedidos desde la hoja de cálculo.

  • Import Assemblies - Importa datos de montajes desde la hoja de cálculo.

  • Import Parts - Importa datos de piezas desde la hoja de cálculo.

Información adicional

  • Utilice una ruta UNC (\\ServerName\FolderPath) o una unidad asignada (M:\FolderPath) al configurar la carpeta de visualización. No utilice rutas locales como C:\FolderPath.

  • El equipo que ejecuta el servicio TruSmartCAM Engine debe tener acceso de lectura y escritura a la carpeta de visualización configurada. Sin los permisos suficientes, es posible que los archivos no se detecten, importen, muevan o eliminen correctamente.

  • El mapeo de la hoja de cálculo debe configurarse antes de habilitar los ajustes de Watch. De lo contrario, TruSmartCAM no podrá procesar los archivos de hoja de cálculo detectados en la carpeta de visualización.
