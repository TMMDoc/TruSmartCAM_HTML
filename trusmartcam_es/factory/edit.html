Edit

Las opciones Edit le permiten modificar diversos ajustes relacionados con máquinas, materiales, herramientas y preferencias del sistema dentro de TecZone. Al seleccionarlas, será redirigido a la sección de configuración correspondiente en TecZone para realizar los ajustes necesarios.

Se pueden editar los siguientes ajustes:

  • Machines

  • CAM Materials - Consulte el tema Database → Materials en la documentación de TecZone.

  • Bend-tool Inventory - Consulte el tema Database → Bend Tools en la documentación de TecZone.

  • Custom Bend Deductions - Consulte el tema Database → Bend Deductions en la documentación de TecZone.

  • TecZone Settings - Consulte el tema Settings en la documentación de TecZone.
