Export/Import material

Using text format

Vie varastomateriaalit siirtymällä kohtaan Factory → Sheets, napsauta Export/Import, valitse Export sheets, valitse .txt ja tallenna se kohdekansioon.

Avaa viety .csv -tiedosto, lisää uusi raakamateriaali ja levy tarvittavilla tiedoilla ja tallenna sitten tiedosto.

Tuodaksesi päivitetyn tiedoston siirry kohtaan Factory → Sheets → Export/Import, valitse Import, valitse muokattu TXT-tiedosto, ja äsken lisätyt materiaalit ja levyt tulevat näkyviin TruSmartCAM-ohjelmaan.

Using CSV format

  • Napsauta Factory → Sheets → Export/Import…​ → Export sheets. Valitse CSV-tiedosto ja tallenna kohdekansioon.

  • Lisää levyt ja levyn parametrit, tallenna .csv -tiedosto.

  • Käyttämällä Import sheets valitse muokattu .csv -tiedosto.

  • Äsken lisätyt materiaalit ja levyt tulevat näkyviin TruSmartCAM-ohjelmaan.

Materiaalin tuonnin on oltava erityisesti muodostettu tekstipohjainen tiedosto, joka kattaa seuraavan muodon.

Material-Name=[BendMaterial],[Density],[FName];
RawMaterial-Thickness,[Name]=[Film],[Treatment],[Surface];
Sheet-Width,Height,Grain,Desc,HeatNumber=Qty,[Factory],[Shelf],[Cost],[Comments]

Example: Aluminum0.5,Aluminum-051500,1500,None,=112,,,22,2500,1250,Horizontal,=105,,,7,2500,1500,None,=100

Tuontitiedoston helppoon luomiseen vie ensin materiaalit ja tee sitten niihin muutoksia tai tarkastele rakennetta.
