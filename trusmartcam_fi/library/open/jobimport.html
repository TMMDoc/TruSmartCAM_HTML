Import jobs

Tuonti CSV- tai XLSX-tiedostosta

Voit my\u00f6s tuoda t\u00f6it\u00e4 yleisiss\u00e4 tekstimuodoissa

  • Napsauta File → Open → Import Jobs, jolloin Open Folder -valintaikkuna tulee n\u00e4kyviin. Valitse C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Jos kaikki osat ovat olemassa CSV-sijainnissa tai hakukansioissa, new job -ikkuna tulee n\u00e4kyviin ja luettelee kaikki osat, jotka vastaavat CSV-kentti\u00e4.

  • Puuttuvat osat ohitetaan eiv\u00e4tk\u00e4 ne n\u00e4y new job -ikkunassa.

  • Aluksi osan tila on Nascent.

  • Napsauta OK , jolloin osat tuodaan osakirjastoon.

Create a blank part for the missing CAD files

Kun t\u00f6it\u00e4 tuodaan taulukkotiedostolla (.csv tai .xlsx), sinulla voi joskus olla rivej\u00e4, jotka viittaavat CAD-tiedostoihin, jotka eiv\u00e4t ole k\u00e4ytett\u00e4viss\u00e4 j\u00e4rjestelm\u00e4ss\u00e4.

  • K\u00e4sittele t\u00e4m\u00e4 siirtym\u00e4ll\u00e4 kohtaan Factory → Settings → Job ja ota Spreadsheet import settings -kohdassa k\u00e4ytt\u00f6\u00f6n Create a blank part for the missing CAD files

Kun t\u00e4m\u00e4 vaihtoehto on valittu:

  • Jos jonkin rivin CAD-tiedosto puuttuu ty\u00f6n tuonnin aikana, j\u00e4rjestelm\u00e4 luo automaattisesti tyhj\u00e4n osan puuttuvan CAD-tiedoston tilalle.

  • new job -ikkunassa n\u00e4m\u00e4 puuttuvat osat korostetaan visuaalisesti keltaisella osoittamaan, ett\u00e4 liittyv\u00e4 CAD-tiedosto puuttuu.

  • Puuttuvalla osalla on edelleen sen m\u00e4\u00e4ritetyt kent\u00e4t (kuten osan nimi, materiaali, paksuus, m\u00e4\u00e4r\u00e4 jne.) CSV-tiedostosta. Sen osan tila n\u00e4ytet\u00e4\u00e4n kuitenkin nimell\u00e4 Nascent, mik\u00e4 tarkoittaa, ett\u00e4 se on vain tyhj\u00e4 paikkamerkki ilman todellista geometriaa.

T\u00e4m\u00e4 varmistaa, ett\u00e4 ty\u00f6n tuonti voi silti jatkua ilman virheit\u00e4 puuttuvien CAD-tiedostojen vuoksi \u2014 voit my\u00f6hemmin p\u00e4ivitt\u00e4\u00e4 tai korvata tyhj\u00e4n osan oikealla CAD-tiedostolla, kun se tulee saataville.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job \u2192 Spreadsheet import settings\u2192 Do not show the New Job dialog if the spreadsheet has no error

  • Kun t\u00e4m\u00e4 valintaruutu on valittu, j\u00e4rjestelm\u00e4 luo uuden ty\u00f6n automaattisesti n\u00e4ytt\u00e4m\u00e4tt\u00e4 New Job -valintaikkunaa, jos taulukkotiedostossa ei ole virheit\u00e4 (ei puuttuvia osia, puuttuvia p\u00e4iv\u00e4m\u00e4\u00e4ri\u00e4 tai virheellisi\u00e4 tietoja).

  • Kun t\u00e4m\u00e4 valintaruutu on tyhj\u00e4, New Job -valintaikkuna tulee aina n\u00e4kyviin k\u00e4ytt\u00e4j\u00e4n tarkistusta ja vahvistusta varten, vaikka taulukkotiedostossa ei olisi virheit\u00e4.

Prefer raw-material column over material + thickness

factory → Settings → Job\u2192*Prefer Raw-Material column over Material + Thickness*

  • Kun t\u00e4m\u00e4 valintaruutu on valittu, j\u00e4rjestelm\u00e4 olettaa, ett\u00e4 taulukkotiedostossa k\u00e4ytet\u00e4\u00e4n Raw-Material-saraketta (esimerkiksi Steel-20). T\u00e4m\u00e4 tarkoittaa, ett\u00e4 materiaalityyppi ja paksuus tulee yhdist\u00e4\u00e4 yhteen arvoon yhdess\u00e4 sarakkeessa.

  • Kun t\u00e4m\u00e4 valintaruutu on tyhj\u00e4, j\u00e4rjestelm\u00e4 olettaa, ett\u00e4 taulukkotiedostossa on erilliset sarakkeet materiaalille ja paksuudelle (esimerkiksi Steel ja 2.00). J\u00e4rjestelm\u00e4 yhdist\u00e4\u00e4 ne sis\u00e4isesti tuonnin aikana.

Valvottava kansio CSV/XLSX-tiedostoilla

  • Kohdassa factory → Settings→ Watch settings valitse Enable 'Live Folder' ja Watch sub-folders also.

  • Aseta valvottavan kansion polku (UNC tai yhdistetty asema).

  • Valitse Spreadsheet import settings -kohdassa Import spreadsheet from 'Live Folder'.

  • Valitse Import Jobs Spreadsheet Import -vaihtoehdoista.

  • Kopioi C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv ja liit\u00e4 se valvottavaan kansioon.

  • J\u00e4rjestelm\u00e4 tarkistaa CSV-tiedoston ja yritt\u00e4\u00e4 luoda ty\u00f6n automaattisesti.

  • Jos CAD-tiedosto puuttuu, ty\u00f6t\u00e4 ei luoda, koska tarvittavia CAD-tietoja ei l\u00f6ydy.

CAD-hakukansio ja rekursiivinen CAD-haku \u2013 ei m\u00e4\u00e4ritetty

  • Kohdassa factory → Settings → Job → Spreadsheet import settings, jos CAD lookup directories -kohtaa ei ole asetettu eik\u00e4 Use recursive CAD search -kohtaa k\u00e4ytet\u00e4, j\u00e4rjestelm\u00e4 ei etsi CAD-tiedostoja automaattisesti.

  • Jos Create a blank part for the missing CAD files -valintaruutu on valittu, ty\u00f6 luodaan silti, vaikka CAD-tiedostot puuttuisivat.

  • T\u00e4ss\u00e4 tapauksessa kaikki ty\u00f6n osat luodaan alustavina (tyhjin\u00e4) osina \u2014 mik\u00e4 tarkoittaa, ett\u00e4 niill\u00e4 ei ole geometriaa, koska CAD-tiedostoja ei l\u00f6ytynyt.

CAD-hakukansio ja rekursiivinen CAD-haku \u2013 m\u00e4\u00e4ritetty

Kun CAD lookup directories on asetettu arvoon (C:\Program Files\TRUMPF\TMM\Praxis\Samples) ja Use recursive CAD search on otettu k\u00e4ytt\u00f6\u00f6n kohdassa factory → Settings → Job → Spreadsheet import settings:

  • J\u00e4rjestelm\u00e4 etsii automaattisesti m\u00e4\u00e4ritetyst\u00e4 kansiosta ja kaikista sen alikansioista taulukkotiedostossa mainitut tarvittavat CAD-tiedostot.

  • Create a blank part for the missing CAD files on my\u00f6s otettu k\u00e4ytt\u00f6\u00f6n, joten jos jokin CAD-tiedosto ei viel\u00e4\u00e4n l\u00f6ydy, j\u00e4rjestelm\u00e4 luo tyhj\u00e4n osan paikkamerkiksi.
