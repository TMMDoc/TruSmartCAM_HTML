Import orders

Ty\u00f6teht\u00e4vi\u00e4 voidaan luoda tai tuoda seuraavilla menetelmill\u00e4:

  1. Ty\u00f6teht\u00e4vien tuonti taulukkotiedostoista.

  2. Ty\u00f6teht\u00e4vien automaattinen tuonti valvonta-asetusten kautta.

  3. Ty\u00f6teht\u00e4vien luonti osakirjaston olemassa olevista osista.

  4. Ty\u00f6teht\u00e4vien luonti rakenneryhmien staattisista nestauksista.

Ty\u00f6teht\u00e4vien tuonti taulukkotiedostosta

  • Siirry kohtaan Open → Import Orders…​.

  • Tuetut taulukkotiedostomuodot ovat CSV, XLSX ja XML.

  • Valitse haluttu taulukkotiedosto ja napsauta Open.

  • Tuontiprosessi on samanlainen kuin ty\u00f6n/rakenneryhm\u00e4n tuonnin ty\u00f6nkulku.

Voit my\u00f6s ved\u00e4t\u00e4 ja pudottaa taulukkotiedoston suoraan Ty\u00f6teht\u00e4v\u00e4t-sivulle tuodaksesi ty\u00f6teht\u00e4vi\u00e4.

Ty\u00f6teht\u00e4vien tuonti valvonta-asetuksilla

  • Ota k\u00e4ytt\u00f6\u00f6n Import spreadsheet from 'Live Folder' -vaihtoehto kohdassa Watch settings.

  • Valitse Import Orders kohdassa Spreadsheet import option.

  • M\u00e4\u00e4rit\u00e4 kansion sijainti, josta ty\u00f6teht\u00e4v\u00e4t tuodaan.

  • J\u00e4rjestelm\u00e4 valvoo m\u00e4\u00e4ritetty\u00e4 kansiota jatkuvasti.

  • Uudet lis\u00e4tyt taulukkotiedostot tuodaan automaattisesti ty\u00f6teht\u00e4viin.

Yksityiskohtaiset m\u00e4\u00e4ritysvaiheet ovat Watch settings -dokumentaatiossa.

Ty\u00f6teht\u00e4vien luonti osakirjastosta

  • Valitse halutut osat osakirjastosta.

  • Napsauta hiiren kakkospainikkeella ja valitse New…​ → Order avataksesi New Orders -valintaikkunan.

  • Anna tarvittavat tiedot, kuten m\u00e4\u00e4r\u00e4, m\u00e4\u00e4r\u00e4p\u00e4iv\u00e4 ja prioriteetti.

  • Napsauta OK luodaksesi ty\u00f6teht\u00e4v\u00e4t.

  • J\u00e4rjestelm\u00e4 siirtyy automaattisesti Ty\u00f6teht\u00e4v\u00e4t-sivulle.

  • Luodut ty\u00f6teht\u00e4v\u00e4t n\u00e4ytet\u00e4\u00e4n Orders Ready -sivulla ty\u00f6n luontia varten.

Ty\u00f6teht\u00e4vien luonti rakenneryhm\u00e4st\u00e4

  • Napsauta haluttua rakenneryhm\u00e4\u00e4 hiiren kakkospainikkeella.

  • Valitse New…​ → Order avataksesi New Orders -valintaikkunan.

  • Anna tarvittava Assembly count.

  • Napsauta OK luodaksesi ty\u00f6teht\u00e4v\u00e4t.
