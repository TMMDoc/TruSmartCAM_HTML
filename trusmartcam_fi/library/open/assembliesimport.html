Import assemblies

Rakenneryhm\u00e4t ovat toisiinsa liittyvien osien ryhmi\u00e4, jotka on yhdistetty yhdeksi kokonaisuudeksi, jolloin voit hallita useita osia yhten\u00e4 kokonaisuutena.

Voit tuoda rakenneryhmi\u00e4 seuraavilla menetelmill\u00e4:

  1. Tuonti tiedoston kautta

  2. Ved\u00e4 ja pudota

  3. Tuonti taulukkotiedostosta

Tuonti tiedoston kautta

Rakenneryhm\u00e4 voidaan tuoda osakirjastoon Import Assemblies…​ -vaihtoehdolla.

  • Napsauta komentopalkin Open-kuvaketta ja valitse Import Assemblies…​, tai k\u00e4yt\u00e4 File \u2192 Open \u2192 Import Assemblies…​.

  • Open-valintaikkuna tulee n\u00e4kyviin. Valitse haluttu rakenneryhm\u00e4tiedosto(t).

  • Valitusta rakenneryhm\u00e4st\u00e4 n\u00e4ytet\u00e4\u00e4n esikatselu.

  • Napsauta Open tuodaksesi rakenneryhm\u00e4n.

  • Tuodut rakenneryhm\u00e4t luetellaan osakirjaston Assemblies-n\u00e4kym\u00e4ss\u00e4.

Ved\u00e4 ja pudota

  • Ved\u00e4 ja pudota rakenneryhm\u00e4 suoraan TruSmartCAM-osakirjastoon.

Tuonti taulukkotiedostosta

  • K\u00e4yt\u00e4 File \u2192 Open \u2192 Import Assemblies…​ ja valitse CSV-, XLSX- tai XML-tiedosto, tai ved\u00e4 ja pudota tiedosto.

  • Tarkista ja p\u00e4ivit\u00e4 rakenneryhm\u00e4n tiedot ja m\u00e4\u00e4r\u00e4t ennen tuontia. K\u00e4yt\u00e4 Add…​ tai Remove…​ muokataksesi.

  • Tuonnin j\u00e4lkeen rakenneryhm\u00e4t voidaan valmistella ja niille voidaan m\u00e4\u00e4ritt\u00e4\u00e4 staattisia nestauksia.
