Palvelimen asennus

Seuraa ohjeita asentaaksesi TruSmartCAM-palvelimen yhdessä SQL:n kanssa.

Järjestelmänvalvojan oikeudet

Tämän asennuksen suorittamiseen käyttäjällä on oltava järjestelmänvalvojan oikeudet.

  • Suorita Setup.TruSmartCAM.<version>.exe aloittaaksesi asennuksen.

Versio on numero.

  • Lue lisenssisopimus, valitse I accept the agreement ja napsauta sitten Next.

Vaihe 1 : Asennussijainti

  • Määritä asennushakemisto tai hyväksy oletusasennussijainti C:\Program Files\TRUMPF\TMM\Praxis ja napsauta Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Asennuskansio sisältää seuraavat kansiot : Bin, MetaCAM, Samples ja Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Datakansio sisältää seuraavat kansiot : TruSmartCAM, TecZone ja MetaCAM.

Vaihe 2 : Komponenttien valinta

Asennustyyppi Komponentit

Full

Palvelin + työpöytäasiakasohjelma + moottori

Client

Työpöytäasiakasohjelma

Server

Palvelin + työpöytäasiakasohjelma

Station

Valitsee kaikki asematerminaalit, kuten TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Valitsee käyttäjän valinnan mukaan.

  • Valitse Full-asennus. Valitse Code Senders ja Bend Code Senders TruSmartCAM-työkaluista. Nyt asennustyyppi muuttuu muotoon Custom. Napsauta Next.

Vaihe 3 : Valitse SQL Serverin asennus

SQL Express 2022 -asennus tarvitaan vain TruSmartCAM-palvelimelle. Tämä vaihtoehto ei ole käytettävissä asiakasohjelma- ja synkronointiasennuksissa. Lisäksi tämä on valittuna päällä ja asennetaan ensimmäisellä kerralla, ja sen voi jättää huomiotta sen jälkeen. Jos SQL on jo asennettu TruSmartCAM-palvelimeen, käyttäjä voi ohittaa vaiheen 3.

  • Kohdassa Select Additional Tasks : Napsauta Install SQL Express ja napsauta Next.

  • Kohdassa Ready to Install : Tarkista kaikki asennettavat ominaisuudet ja napsauta Install.

Vaihe 4 : SQL Serverin asennus

Kun TruSmartCAM-komponentit on asennettu, asennusohjelma jatkaa SQL-palvelimen asennuksella. Hyväksy lisenssisopimus jatkaaksesi ja asenna SQL Express oletusvaihtoehdoilla.

Kun asennus on valmis, napsauta Close ja viimeistele asennus.

Windows-versiosta riippuen SQL-asennuksen sulkeminen saattaa pyytää uudelleenkäynnistystä.

Vaihe 5 : Windowsin työpöytäpikakuvakkeet

  • SQL-asennuksen jälkeen, jos järjestelmä ei käynnisty uudelleen, valitse Launch TruSmartCAM -valintaruutu ja napsauta Finish.

  • Jos järjestelmä käynnistyy uudelleen, käynnistä TruSmartCAM-pikakuvake työpöydältä tai kirjoita TruSmartCAM Windowsin Käynnistä-valikkoon ja valitse Run as administrator.

Palvelimen asennus : TruSmartCAM- ja TruSmartCAM License -pikakuvakkeet ovat käytettävissä työpöydällä.
Asiakasohjelman/SYNC-asennus : Vain TruSmartCAM-pikakuvake on käytettävissä työpöydällä.

Vaihe 6 : Lisenssin rekisteröinti

  • Serial Number -kenttään kirjoita Trumpf Metamation -palvelutiimin toimittama TruSmartCAM-sarja-avain. Kirjoita <Company Name> "Registered to" -kenttään ja sähköposti. Napsauta OK.

Jos verkon palomuuri estää lisenssin rekisteröinnin tai TruSmartCAM-palvelin-PC:ssä ei ole internetyhteyttä, TruSmartCAM-lisenssi aktivoidaan offline-tilassa. Lähetä sähköpostitse Prax.request kansiosta C:\ProgramData\TRUMPF\TMM\Praxis Trumpf Metamation -palvelutiimille. Trumpf Metamation -tiimi toimittaa Prax.lock -tiedoston, joka tulee sijoittaa tähän kansioon.

Vaihe 7 : Ensimmäinen kertaluonteinen määritys

  • Kirjoita tietokannan nimi ja aseta tietojen tallennussijainti. Valitse Use SQL Server -valintaruutu ja valitse SQL-palvelimen nimi yhdistääksesi tietokantaan. Napsauta OK.

  • TruSmartCAM-työpöytäasiakasohjelma avautuu ja näyttää Database Connection Succeeded alareunassa.

  • TruSmartCAM-, TecZone- ja MetaCAM-määritystiedostot luotiin oletusmäärityskoneilla tai TruSmartCAM-lisenssikoneita vastaan. Sama määritys jaetaan kaikkien TruSmartCAM-asiakasohjelmien kesken.

Tervetuloa-näyttö näkyy Windows-käyttäjän kirjautumisnimellä TruSmartCAM-kirjautumis- ja nimenä. Ensimmäinen TruSmartCAM-käyttäjä katsotaan Site Admin -käyttäjäksi. Anna sähköposti ja salasana. Napsauta OK .

Valitse Remember me -valintaruutu tallentaaksesi kirjautumistiedot seuraavaa kertaa varten. Jos poistat Remember me -valintaruudun valinnan, kirjautumis- ja salasanavalintaikkuna kysytään aina, kun TruSmartCAM-sovellus käynnistetään.

Vaihe 8 : TruSmartCAM-sisäänkirjautuminen

  • Sulje TruSmartCAM ja avaa se uudelleen. Järjestelmä pyytää sinua syöttämään TruSmartCAM -kirjautumistiedot.

  • Sisäänkirjautuneen käyttäjän nimi näytetään käyttäjäkuvakkeen vieressä TruSmartCAM -sovelluksen otsikkorivillä.

  • Kun viet hiiren käyttäjäkuvakkeen päälle, järjestelmä näyttää:

    • Käyttäjäroolin (esimerkiksi: Programmer, Admin).

    • Pikakuvakkeen uloskirjautumiseen: Ctrl+L.

  • Käyttäjäkuvakkeen napsauttaminen avaa valikon, jonka avulla voit:

    • Edit information…​ - Päivitä profiilitietosi.

    • Change password…​ - Vaihda tilisi salasana.

    • Sign out - Kirjaudu ulos sovelluksesta.

    • Cancel - Sulje valikko tekemättä muutoksia.

Vaihe 9 : Tehtaan koneiden määritys

  • TruSmartCAM-lisenssi [Kaikki koneet mahdollistava lisenssibitti] : Oletusarvoiset TruSmartCAM-kone ja materiaali katsotaan tehdasmääritykseksi.

  • TruSmartCAM-lisenssi [Ei demoa ja muutama konebitti käytössä] : Nämä muutamat koneet ja oletusmateriaali katsotaan tehdasmääritykseksi.

  • (Open → Import) uusi osa sijainnista C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts ja tarkista, tuotiinko osa onnistuneesti.

Huomautus 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor moottoriasennuksella (Site admin -oikeudet):

    • TruSmartCAM Monitor moottorilla ja Site Admin TruSmartCAM -oikeuksilla sisältää seuraavat vaihtoehdot:

      1. Push TruSmartCAM -määritys, TecZone-, MetaCAM-määritys kaikkiin TruSmartCAM -asiakasohjelmiin. Lisäksi oikeus luoda uusi TruSmartCAM-käyttäjäkirjautuminen.

      2. Show Agents näyttää kaikki automaatiotehtävien suorittamiseen käytettävissä olevat moottorit, jotka ovat TruSmartCAM-lisenssiä vastaan.

  • TruSmartCAM Monitor ilman moottoriasennusta (Site admin -oikeudet):

  • TruSmartCAM Monitor ilman moottoriasennusta (ei Site Admin -oikeuksia):

TruSmartCAM-sovellusta suorittavaan PC:hen on asennettava Engine TruSmartCAM -komponentti [palvelin-PC tai mikä tahansa asiakasohjelma-asennus]. Engine TruSmartCAM -komponentin sisältävän PC:n tulee olla käynnissä 24x7 kaikkien automaatiotehtävien suorittamiseksi.
Huomautus 2 : OpenGL

  • TruSmartCAM-sovellus, joka avattaessa sulkeutuu välittömästi ja myös pmonitoria ei näytetä tehtäväpalkissa.

  • Tämä edustaa OpenGL-ongelmaa.

  • Toinen tapa varmistaa tämä: Avaa C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts joka näyttää virhevalintaikkunan OpenGL-ongelmasta.

  • Päivitä C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , options-osioon GLVersion=1 saa TruSmartCAM-sovelluksen avautumaan onnistuneesti.

[Options]
GLVersion=1.0
