Nastavenia sledovania

Nastavenia sledovania umožňujú aplikácii TruSmartCAM monitorovať určený priečinok a automaticky importovať súbory do systému. Toto pomáha automatizovať import dielov, jobov, zostav a objednávok bez manuálneho zásahu.

Watch settings

Enable 'Live Folder' - Umožňuje automatické monitorovanie špecifikovaného priečinka.

Watch this folder - Určuje priečinok, ktorý sa má monitorovať na prichádzajúce súbory.

Watch sub-folders also - Zahŕňa do procesu monitorovania všetky podpriečinky.

After file import

After import - Po importe súboru má používateľ dve možnosti. Súbor možno z umiestnenia odstrániť alebo presunúť do iného umiestnenia.

  • Delete imported file - Odstráni zdrojový súbor po úspešnom importe.

  • Move imported file - Presunie zdrojový súbor do priečinka špecifikovaného v Move files to this folder po úspešnom importe.

Move files to this folder - Určuje cieľový priečinok, do ktorého sa majú presunúť úspešne importované súbory, keď je After import nastavené na Move imported file.

Move spreadsheets with errors to this folder - Presunie neúspešné importy do špecifikovaného priečinka chýb.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Automaticky importuje súbory tabuliek zistené v sledovanom priečinku.

Do not import spreadsheet with errors - Zabraňuje importu súborov obsahujúcich validačné chyby.

Spreadsheet import option - Vyberie typ údajov na import z rozbaľovacieho zoznamu. Podporované formáty tabuliek môžu zahŕňať CSV, XLSX alebo XML. Dostupné možnosti sú:

  • Import Jobs - Importuje údaje jobov z tabuľky.

  • Import Orders - Importuje údaje objednávok z tabuľky.

  • Import Assemblies - Importuje údaje zostáv z tabuľky.

  • Import Parts - Importuje údaje dielov z tabuľky.

Ďalšie informácie

  • Pri konfigurácii sledovaného priečinka použite cestu UNC (\\ServerName\FolderPath) alebo mapovaný disk (M:\FolderPath). Nepoužívajte lokálne cesty ako C:\FolderPath.

  • Počítač, na ktorom beží služba TruSmartCAM Engine, musí mať práva na čítanie a zápis do nakonfigurovaného sledovaného priečinka. Bez dostatočných oprávnení nemusia byť súbory úspešne zistené, importované, presunuté ani odstránené.

  • Mapovanie tabuliek musí byť nakonfigurované ešte pred zapnutím nastavení sledovania. V opačnom prípade TruSmartCAM nebude schopný spracovať súbory tabuliek zistené v sledovanom priečinku.
