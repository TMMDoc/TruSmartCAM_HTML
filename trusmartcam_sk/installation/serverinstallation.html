Inštalácia servera

Postupujte podľa pokynov na inštaláciu servera TruSmartCAM spolu so SQL.

Administrátorské práva

Na vykonanie tejto inštalácie musí mať používateľ administrátorské oprávnenia.

  • Spustite Setup.TruSmartCAM.<version>.exe pre začatie inštalácie.

Verzia je číslo.

  • Prečítajte si licenčnú zmluvu a zvoľte I accept the agreement a potom kliknite na Next.

Krok 1 : Umiestnenie inštalácie

  • Uveďte inštalačný adresár alebo akceptujte predvolené umiestnenie inštalácie C:\Program Files\TRUMPF\TMM\Praxis a kliknite na Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Inštalačný priečinok bude obsahovať nasledujúce priečinky : Bin, MetaCAM, Samples a Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Dátový priečinok bude obsahovať nasledujúce priečinky : TruSmartCAM, TecZone a MetaCAM.

Krok 2 : Výber komponentov

Typ inštalácie Komponenty

Full

Server + desktopový klient + Engine

Client

Desktopový klient

Server

Server + desktopový klient

Station

Vyberá všetky terminály staníc ako TecZone, MetaCAM, RightAngle (ovládač ohýbania), Vulcan (ovládač laserového stroja)

Custom

Vyberá sa podľa voľby používateľa.

  • Zvoľte Full inštaláciu. Vyberte Code Senders a Bend Code Senders z nástrojov TruSmartCAM. Teraz sa typ inštalácie zmení na Custom. Kliknite na Next.

Krok 3 : Výber inštalácie SQL Servera

Inštalácia SQL Express 2022 je potrebná iba pre server TruSmartCAM. Táto možnosť nie je dostupná pre inštalácie klienta a synchronizácie. Okrem toho je táto možnosť začiarknutá a inštalovaná pri prvom raze a potom ju možno ignorovať. Ak je SQL na serveri TruSmartCAM už nainštalovaný, používateľ môže ignorovať Krok 3.

  • V Select Additional Tasks : Kliknite na Install SQL Express a kliknite na Next.

  • V Ready to Install : Zhŕňte všetky inštalačné funkcie a kliknite na Install.

Krok 4 : Inštalácia SQL Servera

Po nainštalovaní komponentov TruSmartCAM pokračuje inštalátor s inštaláciou SQL servera. Akceptujte licenčnú zmluvu pre pokračovanie a nainštalujte SQL express s predvolenými možnosťami.

Po dokončení inštalácie kliknite na Close a dokončite inštaláciu.

V závislosti od verzie Windows môže zatvorenie inštalácie SQL vyžadovať reštart.

Krok 5 : Odkazy na pracovnej ploche Windows

  • Po inštalácii SQL, ak sa systém nereštartuje, začiarknite políčko Launch TruSmartCAM a kliknite na Finish.

  • Ak sa systém reštartuje, spustite odkaz TruSmartCAM na pracovnej ploche alebo zadajte TruSmartCAM v ponuke Windows Start Program a Run as administrator.

Inštalácia servera : Odkazy TruSmartCAM a TruSmartCAM License sú dostupné na pracovnej ploche.
Inštalácia klienta/SYNC : Na pracovnej ploche je dostupný iba odkaz TruSmartCAM.

Krok 6 : Registrácia licencie

  • Do poľa Serial Number zadajte sériový kľúč TruSmartCAM poskytnutý tímom Trumpf Metamation Service. Do poľa "Registered to" zadajte <Company Name> a E-Mail. Kliknite na OK.

V prípade, že sieťový firewall blokuje registráciu licencie alebo na počítači servera TruSmartCAM nie je internet, licencia TruSmartCAM sa aktivuje offline. Pošlite e-mailom súbor Prax.request z priečinka C:\ProgramData\TRUMPF\TMM\Praxis tímu Trumpf Metamation Service. Tím Trumpf Metamation poskytne súbor Prax.lock, ktorý je potrebné vložiť do tohto priečinka.

Krok 7 : Prvá jednorazová konfigurácia

  • Zadajte názov databázy a nastavte umiestnenie úložiska údajov. Začiarknite políčko Use SQL Server a vyberte názov SQL servera na pripojenie k databáze. Kliknite na OK.

  • Otvorí sa desktopový klient TruSmartCAM so zobrazením Database Connection Succeeded v dolnej časti.

  • Konfiguračné súbory TruSmartCAM, TecZone a MetaCAM boli vytvorené s predvolenými konfiguračnými strojmi alebo podľa licenčných strojov TruSmartCAM. Rovnaká konfigurácia bude zdieľaná vo všetkých klientoch TruSmartCAM.

Uvítacia obrazovka sa zobrazí s prihlasovacím menom používateľa Windows ako prihlasovacie meno a názov TruSmartCAM. Prvý používateľ TruSmartCAM sa považuje za Site Admin. Zadajte Email a Heslo. Kliknite na OK .

Začiarknite políčko Remember me pre uloženie prihlasovacích údajov na nasledujúci raz. Zrušením začiarknutia políčka Remember me sa pri každom spustení aplikácie TruSmartCAM zobrazí dialóg na prihlásenie a heslo.

Krok 8 : Prihlásenie do TruSmartCAM

  • Zatvorte TruSmartCAM a znova ho otvorte. Systém vás vyzve na zadanie prihlasovacích údajov TruSmartCAM.

  • Prihlásené používateľské meno sa zobrazí vedľa ikony používateľa v záhlaví aplikácie TruSmartCAM.

  • Keď prejdete kurzorom nad ikonu používateľa, systém zobrazí:

    • Rolu používateľa (napríklad: Programmer, Admin).

    • Odkaz na odhlásenie: Ctrl+L.

  • Kliknutím na ikonu používateľa sa otvorí ponuka, ktorá vám umožní:

    • Edit information…​ - Aktualizovať údaje vášho profilu.

    • Change password…​ - Zmeniť heslo vášho konta.

    • Sign out - Odhlásiť sa z aplikácie.

    • Cancel - Zatvoriť ponuku bez vykonania akýchkoľvek zmien.

Krok 9 : Konfigurácia továrenského stroja

  • Licencia TruSmartCAM [licenčný bit povoľujúci všetky stroje] : Predvolený stroj TruSmartCAM a materiál sa považujú za továrenskú konfiguráciu.

  • Licencia TruSmartCAM [žiadne demo a povolených niekoľko bitov strojov] : Tieto niekoľko strojov a predvolený materiál sa považujú za továrenskú konfiguráciu.

  • (Open → Import) nový diel z C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts a overte, či bol diel úspešne importovaný.

Počítač, na ktorom beží aplikácia TruSmartCAM, musí mať nainštalovaný komponent Engine TruSmartCAM [na počítači servera alebo v akéjkoľvek inštalácii klienta]. Počítač s nainštalovaným komponentom Engine TruSmartCAM by mal bežať 24x7, aby mohol vykonávať všetky automatizačné úlohy.
Poznámka 2 : OpenGL

  • Aplikácia TruSmartCAM sa pri otváraní okamžite zatvorí a tiež pmonitor sa nezobrazí na paneli úloh.

  • To predstavuje problém s OpenGL.

  • Iný spôsob, ako to potvrdiť: Otvorte C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts ktorý zobrazí chybový dialóg o probléme s OpenGL.

  • Aktualizujte C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , sekciu options s GLVersion=1, čím sa aplikácia TruSmartCAM úspešne otvorí.

[Options]
GLVersion=1.0
