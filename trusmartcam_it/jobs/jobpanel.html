Pannello lavoro

Questa sezione illustra le azioni relative al lavoro come Export outputs, Reset job…​, Mark complete…​, Export job…​ e altre opzioni utilizzate per gestire le istanze del lavoro.

Open in read-only mode for viewing
Apre il lavoro selezionato in modalità di sola lettura.

Check-out the document for editing
Abilita la modifica del lavoro selezionato.

Delete
Elimina il lavoro selezionato.

View Report
Apre il report di produzione per il lavoro selezionato.

Export Outputs

Esporta i file di output pronti per la macchina (file NC e report) generati per il lavoro selezionato.

Plan Job…​

Genera i layout annidati per i componenti del lavoro selezionato.

Reset Job…​

Rimuove tutti i layout generati per il lavoro e reimposta i relativi componenti allo stato pianificabile.

Mark Complete…​

Contrassegna il lavoro e tutti i suoi nest come completati dopo la produzione.

Export Job…​

Esporta il lavoro completo come pacchetto che può essere riutilizzato o importato in un altro sistema.

Prev / Next / Layout

Consente di passare al layout precedente o successivo all’interno del lavoro selezionato.

Sort and filter

Utilizzare questi filtri per visualizzare altri lavori che condividono lo Same Customer, Same Part.

Export outputs

  • Selezionare il lavoro desiderato.

  • Fare clic su Export outputs.

  • Questa operazione esporta i file di output pronti per la macchina generati per il lavoro selezionato.

  • Export Outputs può essere salvato nella posizione predefinita configurata in Factory Settings oppure in una posizione personalizzata utilizzando Browse…​.

  • Esporta solo i file di output della macchina (come NC e report) per il lavoro.

  • Questi file vengono utilizzati direttamente per la produzione e possono essere inviati alla macchina.

Reset job…​

Reimposta il lavoro selezionato rimuovendo tutti i layout generati e rendendo i componenti nuovamente disponibili per la pianificazione.

Per reimpostare un lavoro:

  • Fare clic con il pulsante destro del mouse sul lavoro e selezionare Reset job…​.

  • Questa operazione elimina tutti i layout annidati esistenti per il lavoro selezionato e reimposta tutti i relativi componenti allo stato pianificabile.

  • Se i layout contengono componenti di altri lavori, anche tali componenti vengono reimpostati.

Export job…​

  • Selezionare il lavoro desiderato.

  • Fare clic su Export job…​.

  • Questa opzione esporta il lavoro completo come pacchetto che può essere riutilizzato o importato in un altro sistema.

  • I dati esportati includono tutte le informazioni necessarie per ricreare il lavoro:

    • Dettagli e quantità dei componenti (file CSV).

    • Dati di layout e nesting (file CSV / FXYLT).

  • I file esportati vengono salvati come cartella del lavoro nella posizione di esportazione configurata.

  • Questa opzione viene utilizzata per trasferire, condividere o eseguire il backup dell’intero lavoro.

Mark complete…​

  • Una volta elaborato il lavoro sulla macchina, aprire il Pannello lavoro e selezionare Mark complete…​.

  • Quando un lavoro viene contrassegnato come completato:

    • Tutti i nest del lavoro vengono contrassegnati come completati.

    • Il lavoro viene disattivato, spostato alla fine dell’elenco e mostrato con un segno di spunta verde.

    • Tutti i layout del lavoro vengono rimossi dall’elenco dei layout attivi.

    • Gli stati del componente e del lavoro vengono aggiornati e le quantità elaborate passano allo stato completato.

    • I file di output di tutti i layout del lavoro vengono rimossi dalla posizione di output della macchina per evitarne l’uso duplicato.
