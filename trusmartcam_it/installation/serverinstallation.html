Installazione del server

Seguire le istruzioni per installare il Server TruSmartCAM insieme a SQL.

Diritti di amministratore

Per eseguire questa installazione, l’utente deve disporre di privilegi amministrativi.

  • Eseguire Setup.TruSmartCAM.<version>.exe per avviare l’installazione.

La versione è un numero.

  • Leggere il contratto di licenza, scegliere I accept the agreement e quindi fare clic su Next.

Passaggio 1: Percorso di installazione

  • Indicare la directory di installazione o accettare il valore predefinito C:\Program Files\TRUMPF\TMM\Praxis e fare clic su Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - La cartella di installazione conterrà le seguenti cartelle: Bin, MetaCAM, Samples e Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - La cartella dati conterrà le seguenti cartelle: TruSmartCAM, TecZone e MetaCAM.

Passaggio 2: Selezione dei componenti

Tipo di installazione Componenti

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Seleziona tutti i terminali delle stazioni, come TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Seleziona in base alla scelta dell’utente.

  • Scegliere l’installazione Full. Selezionare Code Senders e Bend Code Senders dagli strumenti TruSmartCAM. Ora il tipo di installazione cambia in Custom. Fare clic su Next.

Passaggio 3: Scelta dell’installazione di SQL Server

L’installazione di SQL Express 2022 è necessaria solo per il Server TruSmartCAM. Questa opzione non è disponibile per le installazioni Client e Sync. Inoltre, questa opzione è selezionata e installata la prima volta e può essere ignorata in seguito. Se SQL è già installato nel server TruSmartCAM, l’utente può ignorare il Passaggio 3.

  • In Select Additional Tasks: fare clic su Install SQL Express e fare clic su Next.

  • In Ready to Install: riepilogare tutte le funzionalità di installazione e fare clic su Install.

Passaggio 4: Installazione di SQL Server

Una volta installati i componenti TruSmartCAM, il programma di installazione procede con l’installazione del server SQL. Accettare il contratto di licenza per procedere e installare SQL express con le opzioni predefinite.

Al termine dell’installazione, fare clic su Close e completare l’installazione.

A seconda della versione di Windows, la chiusura dell’installazione di SQL potrebbe richiedere un riavvio.

Passaggio 5: Collegamenti sul desktop di Windows

  • Dopo l’installazione di SQL, se il sistema non si riavvia, selezionare la casella di controllo Launch TruSmartCAM e fare clic su Finish.

  • Se il sistema si riavvia, avviare l’icona di collegamento TruSmartCAM sul desktop oppure digitare TruSmartCAM in Programmi del menu Start di Windows e scegliere Run as administrator.

Installazione del server : le icone di collegamento TruSmartCAM e TruSmartCAM License sono disponibili sul desktop.
Installazione Client/SYNC : sul desktop è disponibile solo l’icona di collegamento TruSmartCAM.

Passaggio 6: Registrazione della licenza

  • Nel campo Serial Number, digitare la TruSmartCAM Serial key fornita dal team di assistenza Trumpf Metamation. Digitare <Company Name> nel campo "Registered to" e l’indirizzo e-mail. Fare clic su OK.

Nel caso in cui il firewall di rete blocchi la registrazione della licenza o non sia disponibile una connessione a Internet nel PC Server TruSmartCAM, la licenza TruSmartCAM viene attivata tramite attivazione offline. Inviare tramite e-mail il file Prax.request dalla cartella C:\ProgramData\TRUMPF\TMM\Praxis al team di assistenza Trumpf Metamation. Il team Trumpf Metamation fornirà il file Prax.lock che dovrà essere inserito in questa cartella.

Passaggio 7: Configurazione iniziale una tantum

  • Digitare il nome del database e impostare il percorso di archiviazione dei dati. Selezionare la casella di controllo Use SQL Server e selezionare il nome del server SQL a cui connettersi per il database. Fare clic su OK.

  • Il Desktop Client TruSmartCAM si apre mostrando Database Connection Succeeded nella parte inferiore.

  • I file di configurazione TruSmartCAM, TecZone e MetaCAM sono stati creati con le macchine di configurazione predefinite o in base alle macchine della licenza TruSmartCAM. La stessa configurazione verrà condivisa tra tutti i client TruSmartCAM.

La schermata di benvenuto mostra il LoginName dell’utente Windows come login e nome TruSmartCAM. Il primo utente TruSmartCAM è considerato Site Admin. Indicare l’indirizzo e-mail e la password. Fare clic su OK .

Selezionare la casella di controllo Remember me per salvare le credenziali di accesso per la volta successiva. Deselezionando la casella di controllo Remember me verrà richiesta la finestra di dialogo di accesso e password ogni volta che viene avviata l’applicazione TruSmartCAM.

Passaggio 8: Accesso a TruSmartCAM

  • Chiudere TruSmartCAM e riaprirlo. Il sistema richiede di immettere le credenziali di accesso TruSmartCAM.

  • Il nome utente con cui è stato effettuato l’accesso viene visualizzato accanto all’icona dell’utente nell’intestazione dell’applicazione TruSmartCAM.

  • Passando il puntatore sull’icona dell’utente, il sistema visualizza:

    • Il ruolo dell’utente (ad esempio: Programmer, Admin).

    • Un collegamento per disconnettersi: Ctrl+L.

  • Facendo clic sull’icona dell’utente si apre un menu che consente di:

    • Edit information…​ - Aggiornare i dettagli del profilo.

    • Change password…​ - Modificare la password dell’account.

    • Sign out - Disconnettersi dall’applicazione.

    • Cancel - Chiudere il menu senza apportare modifiche.

Passaggio 9: Configurazione delle macchine della fabbrica

  • Licenza TruSmartCAM [bit della licenza che abilita tutte le macchine] : la macchina e il materiale predefiniti TruSmartCAM sono considerati come configurazione della fabbrica.

  • Licenza TruSmartCAM [nessuna demo e alcuni bit macchina abilitati] : quelle poche macchine e il materiale predefinito sono considerati come configurazione della fabbrica.

  • (Open → Import) un nuovo componente dalla cartella C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts e verificare se il componente è stato importato correttamente.

Nota 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor con installazione dell’Engine (diritti di Site admin):

    • TruSmartCAM Monitor con Engine insieme ai diritti TruSmartCAM di Site Admin disporrà delle seguenti opzioni:

      1. Distribuire la configurazione TruSmartCAM, TecZone, MetaCAM su tutti i client TruSmartCAM. Dispone inoltre dei diritti per creare un nuovo login utente TruSmartCAM.

      2. Show Agents mostrerà il totale degli engine disponibili per eseguire le attività di automazione in base alla licenza TruSmartCAM.

  • TruSmartCAM Monitor senza installazione dell’Engine (diritti di Site admin):

  • TruSmartCAM Monitor senza installazione dell’Engine (diritti diversi da Site Admin):

Il PC che esegue l’applicazione TruSmartCAM deve avere installato il componente Engine TruSmartCAM [PC Server o in qualsiasi installazione Client]. Il PC su cui è installato il componente Engine TruSmartCAM deve essere in esecuzione 24 ore su 24, 7 giorni su 7, per eseguire tutte le attività di automazione.
Nota 2 : OpenGL

  • L’applicazione TruSmartCAM durante l’apertura si chiude immediatamente e inoltre pmonitor non viene visualizzato nella barra delle applicazioni.

  • Questo rappresenta un problema di OpenGl.

  • Un altro modo per confermarlo: aprire C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts che visualizza una finestra di dialogo di errore relativa al problema di OpenGL.

  • Aggiornare C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , la sezione options con GLVersion=1 consente l’apertura corretta dell’applicazione TruSmartCAM.

[Options]
GLVersion=1.0
