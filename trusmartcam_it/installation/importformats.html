Formati di file supportati

TruSmartCAM supporta l’importazione diretta CAD. La disponibilità dei formati di importazione dipende dalla configurazione della licenza. I formati supportati sono classificati come segue.

L’elenco dei formati CAD supportati e la compatibilità con le versioni dei file dipendono dal livello di licenza attivo. Le versioni supportate vengono aggiornate periodicamente nel corso dell’anno. Prima di aggiornare il software CAD a una versione più recente, si consiglia di verificare l’elenco di compatibilità per garantire il supporto continuativo.
