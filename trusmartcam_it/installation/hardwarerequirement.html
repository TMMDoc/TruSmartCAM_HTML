Requisiti delle porte

Server TruSmartCAM : 7371

Il server attende le richieste dei client su questa porta TCP. Le connessioni in ingresso devono essere consentite su questa porta nel computer Server.

Server delle licenze fluttuanti : 5776

Il server delle licenze fluttuanti attende le richieste di licenza su questa porta. Le connessioni in ingresso devono essere consentite su questa porta nel computer del server delle licenze fluttuanti (Server TruSmartCAM).

Connessione delle licenze al Cloud : 7567

Questa porta è utilizzata da TecZone (software di piegatura) e dal server delle licenze fluttuanti per inviare le richieste di licenza a Metamation Cloud. Pertanto, la connessione in uscita deve essere consentita su questa porta per le attivazioni e i rinnovi delle licenze.

Requisiti di installazione e supporto

  • Sono richiesti privilegi amministrativi per installare l’applicazione TruSmartCAM.

  • Strumenti di diagnostica remota tramite VPN del contraente o una connessione sicura.
