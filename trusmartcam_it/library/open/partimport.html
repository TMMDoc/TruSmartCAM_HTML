Importa componenti

Prima di importare i componenti, assicurarsi che i formati di file siano compatibili con TruSmartCAM. Per ulteriori dettagli, vedere supported file formats.

Se il materiale e lo spessore non vengono mappati sul componente dopo l’importazione, assegnare il materiale utilizzando il pannello componente.

Metodi di importazione

Esistono tre metodi per importare i componenti nella Libreria componenti:

  1. Importazione tramite file

  2. Trascinamento della selezione

  3. Cartella monitorata

Importazione tramite file

Un file di componente 2D o 3D può essere importato nella Libreria componenti utilizzando l’opzione Import parts…​.

  • Fare clic sulle icone open nella barra dei comandi e selezionare l’opzione Import parts…​.

  • Viene visualizzata la finestra di dialogo Open — selezionare un file CAD qualsiasi (2D o 3D).

  • Viene visualizzata un’anteprima del file CAD selezionato.

  • Selezionare il componente richiesto e fare clic su Open.

  • Il sistema esegue l’attrezzaggio automatico del componente per tutte le macchine disponibili con lo stato di attrezzaggio aggiornato.

Trascinamento della selezione

  • Trascinare e rilasciare un file di componente direttamente nella Libreria componenti di TruSmartCAM.

Cartella monitorata

Le impostazioni di monitoraggio consentono di monitorare una cartella per i nuovi file e di importarli automaticamente nella Libreria componenti.

Per la configurazione, vedere la pagina Watch settings.

  • Utilizzare un percorso UNC (Universal Naming Convention) \\192.168.1.11\<Folder path> o un’unità mappata M:\<Folder Path>.

  • Il PC su cui è in esecuzione l’Engine deve disporre dell’accesso in lettura/scrittura a questa cartella.

  • Non utilizzare un percorso locale come C:\<Folder Path> poiché il servizio Watch cerca i file sul PC dell’Engine, non sul PC locale.

Configurazione dell’importazione

Use geometry comparison on same CAD revision

Quando si importa un componente con la stessa revisione CAD, TruSmartCAM può confrontare la geometria del file CAD con il componente esistente.

  • Per abilitare questa funzione, configurare Revision lookup keys (ad esempio, REV) in factory → settings →Import. Quindi, abilitare l’opzione Use geometry comparison on same CAD revision.

Il confronto della geometria sulla stessa revisione CAD funziona solo quando sono configurate le Revision lookup keys.

  • Ora, importare un componente nella libreria componenti con una revisione specifica (ad esempio, Revisione 1).

  • Lo stesso componente viene importato di nuovo con lo stesso valore di revisione.

  • TruSmartCAM confronta la geometria del file CAD appena importato con il componente esistente.

  • Se viene rilevata una differenza geometrica, TruSmartCAM visualizza una richiesta che chiede se:

    • Replace il componente esistente con la nuova geometria, mantenendo lo stesso valore di revisione.

    • Skip l’importazione, conservando il componente esistente e la sua geometria.

Questo consente agli utenti di aggiornare la geometria del componente senza modificare il valore di revisione, mantenendo comunque il controllo sulla sostituzione o meno dei componenti esistenti.

I componenti importati vengono aggiunti automaticamente alla libreria per un ulteriore utilizzo. Per ulteriori informazioni, vedere Library.
