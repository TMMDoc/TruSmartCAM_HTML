Importa ordini

Gli ordini possono essere creati o importati utilizzando i seguenti metodi:

  1. Importazione di ordini da file di foglio di calcolo.

  2. Importazione automatica di ordini tramite le impostazioni di monitoraggio.

  3. Creazione di ordini da componenti esistenti nella libreria componenti.

  4. Creazione di ordini da nest statici di assieme.

Importa ordini da foglio di calcolo

  • Passare a Open → Import Orders…​.

  • I formati di foglio di calcolo supportati includono CSV, XLSX e XML.

  • Selezionare il file di foglio di calcolo richiesto e fare clic su Open.

  • Il processo di importazione è simile al flusso di lavoro di importazione di lavori/assiemi.

È inoltre possibile trascinare e rilasciare direttamente il foglio di calcolo nella pagina Ordini per importare gli ordini.

Importa ordini utilizzando le impostazioni di monitoraggio

  • Abilitare l’opzione Import spreadsheet from 'Live Folder' in Watch settings.

  • Selezionare Import Orders in Spreadsheet import option.

  • Configurare la posizione della cartella da cui importare gli ordini.

  • Il sistema monitora continuamente la cartella configurata.

  • I file di foglio di calcolo appena aggiunti vengono importati automaticamente in Ordini.

Per i passaggi di configurazione dettagliati, fare riferimento alla documentazione Watch settings.

Crea ordini dalla libreria componenti

  • Selezionare i componenti richiesti dalla Libreria componenti.

  • Fare clic con il pulsante destro del mouse e scegliere New…​ → Order per aprire la finestra di dialogo New Orders.

  • Immettere i dettagli richiesti come quantità, data di scadenza e priorità.

  • Fare clic su OK per creare gli ordini.

  • Il sistema passa automaticamente alla pagina Ordini.

  • Gli ordini creati vengono visualizzati nella pagina Ordini pronti per la creazione del lavoro.

Crea ordini da assieme

  • Fare clic con il pulsante destro del mouse sull’assieme richiesto.

  • Selezionare New…​ → Order per aprire la New Orders finestra di dialogo.

  • Immettere il Assembly count richiesto.

  • Fare clic su OK per creare gli ordini.
