Importa lavori

Importazione da csv o xlsx

È inoltre possibile importare i lavori nei comuni formati di testo

  • Fare clic su File → Open → Import Jobs, viene visualizzata la finestra di dialogo Open Folder. Selezionare C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Se tutti i componenti esistono nella posizione del csv o nelle directory della cartella di ricerca, viene visualizzata la finestra new job che elenca tutti i componenti corrispondenti ai campi del csv.

  • I componenti mancanti vengono ignorati e non compaiono nella finestra new job.

  • Inizialmente lo stato del componente è Nascent.

  • Fare clic su OK, ora i componenti vengono importati nella Libreria componenti.

Create a blank part for the missing CAD files

Quando si importano i lavori utilizzando un foglio di calcolo (.csv o .xlsx), talvolta possono esservi righe che fanno riferimento a file CAD non disponibili nel sistema.

  • Per gestire questa situazione, andare in Factory → Settings → Job, in Spreadsheet import settings abilitare Create a blank part for the missing CAD files

Quando questa opzione è selezionata:

  • Se manca un file CAD per una riga qualsiasi durante l’importazione del lavoro, il sistema creerà automaticamente un componente vuoto al posto del file CAD mancante.

  • Nella finestra new job, questi componenti mancanti vengono evidenziati visivamente in giallo per indicare che il file CAD associato è mancante.

  • Il componente mancante avrà comunque i suoi campi mappati (come nome componente, materiale, spessore, quantità, ecc.) dal CSV. Tuttavia, il suo stato del componente verrà mostrato come Nascent, il che significa che si tratta solo di un segnaposto vuoto senza geometria effettiva.

Ciò garantisce che l’importazione del lavoro possa comunque procedere senza errori dovuti a file CAD mancanti — è possibile aggiornare o sostituire in seguito il componente vuoto con il file CAD corretto quando diventa disponibile.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Quando questa casella di controllo è selezionata, il sistema crea automaticamente il nuovo lavoro senza mostrare la finestra di dialogo New Job se il foglio di calcolo non presenta errori (nessun componente mancante, date mancanti o dati non validi).

  • Quando questa casella di controllo è deselezionata, la finestra di dialogo New Job viene sempre visualizzata per la revisione e la conferma da parte dell’utente, anche se il foglio di calcolo non presenta errori.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Quando questa casella di controllo è selezionata, il sistema si aspetta che il foglio di calcolo utilizzi la colonna Raw-Material (ad esempio, Steel-20). Ciò significa che il tipo di materiale e lo spessore devono essere combinati in un unico valore in una sola colonna.

  • Quando questa casella di controllo è deselezionata, il sistema si aspetta che il foglio di calcolo abbia colonne separate per Material e Thickness (ad esempio, Steel e 2.00). Il sistema le combina internamente durante l’importazione.

Cartella monitorata tramite CSV/XLSX

  • In factory → Settings→ Watch settings selezionare Enable 'Live Folder' e Watch sub-folders also.

  • Impostare il percorso della cartella monitorata (UNC o unità mappata).

  • In Spreadsheet import settings, selezionare Import spreadsheet from 'Live Folder'.

  • Selezionare Import Jobs dalle opzioni di importazione del foglio di calcolo.

  • Copiare C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv e incollarlo nella cartella monitorata.

  • Il sistema controlla il CSV e prova a creare automaticamente il lavoro.

  • Se manca il file CAD, non viene creato alcun lavoro perché i dati CAD richiesti non vengono trovati.

Directory di ricerca CAD e ricerca CAD ricorsiva - non configurate

  • In factory → Settings → Job → Spreadsheet import settings, se non è impostata alcuna CAD lookup directories e non viene utilizzata Use recursive CAD search, il sistema non cerca automaticamente i file CAD.

  • Se la casella di controllo Create a blank part for the missing CAD files è selezionata, il lavoro verrà comunque creato anche quando i file CAD sono mancanti.

  • In questo caso, tutti i componenti nel lavoro verranno creati come componenti nascent (vuoti) — il che significa che non hanno geometria perché i file CAD non è stato possibile trovarli.

Directory di ricerca CAD e ricerca CAD ricorsiva - configurate

Quando CAD lookup directories è impostata su (C:\Program Files\TRUMPF\TMM\Praxis\Samples) e Use recursive CAD search è abilitata in factory → Settings → Job → Spreadsheet import settings:

  • Il sistema cerca automaticamente nella cartella specificata e in tutte le sue sottocartelle i file CAD richiesti indicati nel foglio di calcolo.

  • Anche Create a blank part for the missing CAD files è abilitata, quindi se un file CAD non viene ancora trovato, il sistema creerà un componente vuoto come segnaposto.
