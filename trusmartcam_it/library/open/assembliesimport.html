Importa assiemi

Gli assiemi sono gruppi di componenti correlati combinati in una singola unità, che consentono di gestire più componenti insieme come un’unica entità.

È possibile importare gli assiemi utilizzando i seguenti metodi:

  1. Importazione tramite file

  2. Trascinamento della selezione

  3. Importazione da foglio di calcolo

Importazione tramite file

Un assieme può essere importato nella Libreria componenti utilizzando l’opzione Import Assemblies…​.

  • Fare clic sull’icona Open nella barra dei comandi e selezionare Import Assemblies…​, oppure utilizzare File → Open → Import Assemblies…​.

  • Viene visualizzata la finestra di dialogo Open. Selezionare il file o i file di assieme richiesti.

  • Viene visualizzata un’anteprima dell’assieme selezionato.

  • Fare clic su Open per importare l’assieme.

  • Gli assiemi importati sono elencati nella vista Assiemi della Libreria componenti.

Trascinamento della selezione

  • Trascinare e rilasciare un assieme direttamente nella Libreria componenti di TruSmartCAM.

Importazione da foglio di calcolo

  • Utilizzare File → Open → Import Assemblies…​ e selezionare un file CSV, XLSX o XML, oppure trascinare e rilasciare il file.

  • Rivedere e aggiornare i dettagli e le quantità dell’assieme prima dell’importazione. Utilizzare Add…​ o Remove…​ per apportare modifiche.

  • Dopo l’importazione, gli assiemi possono essere preparati e a cui possono essere assegnati Static Nests.
