Monitoraggio

Le impostazioni di monitoraggio consentono a TruSmartCAM di monitorare una cartella designata e importare automaticamente i file nel sistema. Questo aiuta ad automatizzare l’importazione di Componenti, Lavori, Assiemi e Ordini senza intervento manuale.

Watch settings

Enable 'Live Folder' - Abilita il monitoraggio automatico della cartella specificata.

Watch this folder - Specifica la cartella da monitorare per i file in arrivo.

Watch sub-folders also - Include tutte le sottocartelle nel processo di monitoraggio.

After file import

After import - Dopo l’importazione del file, l’utente ha due opzioni. Il file può essere eliminato dalla posizione o spostato in una posizione diversa.

  • Delete imported file - Rimuove il file di origine dopo un’importazione riuscita.

  • Move imported file - Sposta il file di origine nella cartella specificata in Move files to this folder dopo un’importazione riuscita.

Move files to this folder - Specifica la cartella di destinazione in cui devono essere spostati i file importati correttamente quando After import è impostato su Move imported file.

Move spreadsheets with errors to this folder - Sposta le importazioni non riuscite nella cartella degli errori specificata.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Importa automaticamente i file dei fogli di calcolo rilevati nella cartella monitorata.

Do not import spreadsheet with errors - Impedisce l’importazione dei file contenenti errori di validazione.

Spreadsheet import option - Seleziona il tipo di dati da importare dall’elenco a discesa. I formati di fogli di calcolo supportati possono includere CSV, XLSX o XML. Le opzioni disponibili sono:

  • Import Jobs - Importa i dati dei lavori dal foglio di calcolo.

  • Import Orders - Importa i dati degli ordini dal foglio di calcolo.

  • Import Assemblies - Importa i dati degli assiemi dal foglio di calcolo.

  • Import Parts - Importa i dati dei componenti dal foglio di calcolo.

Informazioni aggiuntive

  • Utilizzare un percorso UNC (\\ServerName\FolderPath) o un’unità mappata (M:\FolderPath) durante la configurazione della cartella monitorata. Non utilizzare percorsi locali come C:\FolderPath.

  • Il computer che esegue il servizio TruSmartCAM Engine deve disporre dell’accesso in lettura e scrittura alla cartella monitorata configurata. Senza autorizzazioni sufficienti, i file potrebbero non essere rilevati, importati, spostati o eliminati correttamente.

  • La mappatura dei fogli di calcolo deve essere configurata prima di abilitare le impostazioni di monitoraggio. In caso contrario, TruSmartCAM non sarà in grado di elaborare i file dei fogli di calcolo rilevati nella cartella monitorata.
