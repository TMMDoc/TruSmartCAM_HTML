Importazione

Importazione

Output settings

Save flat pattern - Abilitare questa opzione affinché lo sviluppo di un componente importato venga salvato.

Format for flat pattern - Questa opzione viene utilizzata per scegliere il formato di file DXF o GEO.

Flat pattern destination - Questa è la posizione in cui verrà salvato lo sviluppo.

Import settings

Units for DXF files - Questa è l’unità di misura con cui verrà importato un file DXF; l’utente può scegliere tra mm o pollici.

Material lookup keys - È possibile assegnare più voci di ricerca utilizzando una virgola come separatore. Quando un componente viene importato, TruSmartCAM utilizza queste chiavi per cercare i valori del materiale. I valori cercati vengono quindi utilizzati per risolvere la materia prima. I valori originali vengono memorizzati nelle Proprietà varie del componente.

Revision lookup keys - Quando un componente viene importato, il valore di revisione del file del componente grezzo (il file del componente in fase di importazione) viene confrontato con il valore di revisione esistente nel repository. L’importazione viene abbandonata se la revisione è la stessa. La mappatura dei campi personalizzati è ora supportata anche per i file DXF. Per i file DXF, i dati del campo personalizzato vengono estratti dal livello di testo nel disegno o da un allegato PPI.

Use geometry comparison on same CAD revision - Confronta la geometria quando si importa un componente con la stessa revisione CAD e richiede all’utente di sostituire o saltare l’importazione se vengono rilevate differenze. Vedere Import configuration per maggiori dettagli.

Part name keys - Questa opzione funziona in modo simile alle Revision lookup keys e del materiale. Impostare una o più Part name keys per utilizzare il Part name PPI anziché il nome del file come nome del componente.

Thickness lookup keys - È possibile assegnare più voci di ricerca utilizzando una virgola come separatore. Quando un componente viene importato, TruSmartCAM utilizza queste chiavi per cercare i valori dello spessore. I valori cercati vengono quindi utilizzati per risolvere lo spessore. I valori originali vengono memorizzati nelle Proprietà varie del componente.

Thickness comparison fudge - Viene utilizzato nella ricerca della materia prima quando un componente viene importato. TruSmartCAM cerca di risolvere la materia prima dopo aver analizzato il nome del materiale e lo spessore. Per ulteriori informazioni, fare riferimento all’argomento Thickness fudge riportato di seguito.

Identify shapes after a flat is imported - Quando un componente viene importato, le forme interne al componente possono essere riconosciute e identificate automaticamente.

Shape identification fudge - Il valore di tolleranza per l’identificazione delle forme può essere impostato a:

  1. Livello globale - Questo valore viene utilizzato come predefinito per tutte le forme.

  2. Livello della singola forma - Il valore predefinito può essere sovrascritto impostando il valore di tolleranza a livello della singola forma. La selezione della forma nella finestra di dialogo Libreria forme visualizza il valore di tolleranza. Per impostazione predefinita, è impostato su 0 e per tali forme viene utilizzato il valore globale predefinito.

Rotate flat horizontally - Generalmente i tavoli delle macchine da taglio sono rettangolari e più larghi. Per migliorare la fattibilità dell’attrezzaggio, ruotare il componente lungo la larghezza dopo l’importazione.

Part rotation threshold - Impostare questo valore come numero minimo per consentire la rotazione. Qualsiasi componente più piccolo del valore impostato non verrà ruotato.

Misc settings

Enable pre-import external tools - Abilitare l’opzione di importazione degli strumenti esterni di pre-importazione per abilitare Creo Reader. TruSmartCAM carica le istanze di famiglia pre-estratte del componente rilasciato. Si noti che l’estrazione delle istanze viene eseguita durante il caricamento del componente (come operazione di pre-importazione), quindi il software Creo deve essere installato sul computer da cui viene caricato il componente.

Ignore drawing colors in Flat thumbnails for clarity - Abilitare questa opzione per generare miniature in scala di grigi più nitide. I colori dei livelli e le entità di testo vengono ignorati per garantire la chiarezza dell’immagine.

Use only one Engine for all import tasks - Quando abilitata, viene utilizzato un solo core del motore per le attività di importazione.

Thickness fudge

La Thickness comparison fudge sceglie il valore di spessore della lamiera più vicino quando uno spessore della lamiera desiderato non è disponibile nell’inventario, confrontando il valore di spessore delle lamiere nell’inventario.

Ad esempio, supponiamo quanto segue:

  1. Abbiamo un componente con spessore della lamiera di 1,6 mm e materiale acciaio.

  2. Il valore Thickness comparison fudge è 0,1 mm.

  3. L’inventario contiene lamiere di acciaio con spessore 1,5 mm, 1,55 mm e 1,7 mm.

TruSmartCAM sceglie una lamiera con il valore di spessore più vicino dopo aver confrontato il valore Thickness comparison fudge (0,1 mm) con l’elemento importato (che misura 1,6 mm). In questo caso, la selezione sarà 1,55 mm.
