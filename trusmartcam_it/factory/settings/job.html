Lavoro

Output settings

Save layout NC and reports - Abilitare questa opzione affinché il programma NC del layout e i report vengano salvati.

Save layout file - Abilitare questa opzione affinché il file di layout venga salvato.

Output simulation preview in reports - Abilitare questa opzione per generare l’anteprima della simulazione dell’attrezzaggio insieme agli altri output. Si tratta di una breve animazione GIF per l’attrezzaggio laser/punzonatura.

Do not delete program outputs on layout/job completion - Abilitando questa opzione verrà saltata l’operazione di eliminazione degli output del programma quando un lavoro/layout viene contrassegnato come completato.

Nest settings

Mix parts from multiple Jobs - Supporta il nesting in modalità mista. I componenti di più lavori dovrebbero essere annidati insieme per una migliore efficienza di riempimento.

Do not auto-release layouts - Impedirà che i layout siano disponibili per la produzione fino a quando tutti i layout non sono in stato rilasciato.

Re-nesting packing cut-off - Questo valore viene utilizzato per decidere se un layout annidato viene mantenuto nella coda di approvazione e viene rinnidato quando nuovi componenti vengono pianificati oppure vengono rilasciati per la produzione e i relativi output vengono esportati nella cartella di output.

Interactive sheet-name prefix - Questa sezione viene utilizzata per supportare il nesting interattivo, in cui l’utente ha un maggiore controllo sui componenti annidati e sul risultato del nesting. Utilizzare uno schema di denominazione, diverso dal nesting automatico, per i layout annidati in modo interattivo.

Update sheet inventory on nest (un)release - Se questa opzione è abilitata, l’inventario delle lamiere si aggiornerà quando si invia un nest a una macchina. Anche il richiamo del nest dalla macchina restituirà la lamiera all’inventario.

Automate remnant inventory management - Quando questo interruttore è selezionato, il software automatizza la gestione dell’inventario degli avanzi. Se non selezionato, la gestione degli avanzi diventa interattiva.

Auto-refresh Out-of-date layouts - Quando selezionato, il software aggiorna tutti i ui:EGTag.SelectOutOfDate[Out-of-date Layouts] collegati a un componente dopo che le sue soluzioni di taglio sono state calcolate.

Automate twin-line nesting - Selezionare questa opzione per abilitare l’automazione twin-line.

Pull workflow settings

Use 'Pull workflow' - Questa opzione è utile per gli utenti che necessitano di un sistema di pianificazione e nesting altamente autonomo. Quando abilitata, TruSmartCAM pianifica il nesting su richiesta.

Nests per station - Questo valore serve a impostare quanti layout per stazione devono essere creati.

Maximum sheets per nest - Questo valore viene utilizzato per controllare il numero massimo di lamiere rispetto al nest univoco. Ad esempio, se c’è un ordine con un componente grande (che riempie l’intera lamiera), necessario in grandi quantità (ad esempio 500), TruSmartCAM non crea più un singolo nest con 500 copie in modalità pull. Crea invece 10 copie per nest, dove 10 è il massimo.

Bend programs per station - Questo valore serve a impostare quanti programmi di piegatura per stazione devono essere creati.

Mark the task completed, when the program outputs are removed - Abilitare questa opzione affinché un layout venga contrassegnato come Fatto quando gli output vengono rimossi dalla destinazione di output di destinazione.

Spreadsheet import settings

CAD lookup directories - TruSmartCAM tenterà di caricare la voce del componente indicata nel CSV importato dalla libreria dei componenti. Tuttavia, se il componente non è disponibile nella libreria dei componenti, tenterà di recuperare i componenti dalle directory di ricerca in base all’ordine delle directory impostato in questa finestra di dialogo.

Use recursive CAD search - Abilitare questa opzione affinché la ricerca venga ripetuta per i risultati successivi.

Create a blank part for the missing CAD files - Se i componenti non esistono nella libreria di TruSmartCAM o nelle directory di ricerca, TruSmartCAM creerà un componente vuoto per quei componenti non disponibili.

Do not show New Job dialog if the spreadsheet has no error - Se le voci CSV sono corrette, ovvero non ci sono discrepanze di dati dal DB o tutti i campi sono elencati correttamente, TruSmartCAM non mostrerà la finestra di panoramica del lavoro ed elaborerà il lavoro non appena il CSV viene importato o rilasciato.

Prefer Raw-Material column over Material + Thickness - Tipi di fogli di calcolo supportati:

  1. Pattern 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Pattern 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Pattern 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Se questa opzione non è selezionata, il Pattern 1 sarà considerato il tipo di foglio di calcolo predefinito. Supportiamo anche il Pattern 3 nel caso in cui il formato CSV sia di tipo Pattern 3.

Se questa opzione è selezionata e il CSV è di tipo Pattern 2, allora TruSmartCAM risolverà la Materia prima dai campi Materiale e Spessore del CSV.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Selezionare questa opzione per abilitare l’esportazione CSV quando un Layout o un Lavoro è completo. I report completati vengono salvati nella destinazione dei report specificata nelle impostazioni Factory → Settings → Reports.
