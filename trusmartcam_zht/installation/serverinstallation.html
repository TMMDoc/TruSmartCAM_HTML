伺服器安裝

請依照說明安裝 TruSmartCAM 伺服器以及 SQL。

管理員權限

要執行此安裝，使用者必須具有管理員權限。

  • 執行 Setup.TruSmartCAM.<version>.exe 以開始安裝。

版本為數字。

  • 閱讀授權協議並選取 I accept the agreement，然後點選 Next。

步驟 1：安裝位置

  • 指定安裝目錄或接受安裝預設值 C:\Program Files\TRUMPF\TMM\Praxis，並點選 Next。

    • C:\Program Files\TRUMPF\TMM\Praxis - 安裝資料夾將包含以下資料夾：Bin、MetaCAM、Samples 和 Tracker。

    • C:\ProgramData\TRUMPF\TMM\Praxis - 資料資料夾將包含以下資料夾：TruSmartCAM、TecZone 和 MetaCAM。

步驟 2：元件選取

安裝類型 元件

Full

伺服器 + 桌面用戶端 + 引擎

Client

桌面用戶端

Server

伺服器 + 桌面用戶端

Station

選取所有 Station 終端，例如 TecZone、MetaCAM、RightAngle（折彎控制器）、 Vulcan（雷射機控制器）

Custom

依使用者選擇選取。

  • 選擇 Full 安裝。從 TruSmartCAM 工具中選取 Code Senders 和 Bend Code Senders。此時安裝類型變更為 Custom。點選 Next。

步驟 3：選擇安裝 SQL Server

SQL Express 2022 僅 TruSmartCAM 伺服器需要安裝。此選項不適用於用戶端和同步安裝。此選項也會在首次勾選並安裝，之後可忽略。如果 TruSmartCAM 伺服器已安裝 SQL，使用者可忽略步驟 3。

  • 在「選取其他任務」中：點選 Install SQL Express 並點選 Next。

  • 在「準備安裝」中：摘要所有安裝功能並點選 Install。

步驟 4：SQL Server 安裝

安裝 TruSmartCAM 元件後，安裝程式會繼續進行 SQL 伺服器安裝。接受授權協議以繼續，並使用預設選項安裝 SQL Express。

安裝完成後，點選 Close 並完成安裝。

視 Windows 版本而定，關閉 SQL 安裝可能會提示重新啟動。

步驟 5：Windows 桌面捷徑

  • SQL 安裝後，如果系統未重新啟動，則選取 Launch TruSmartCAM 核取方塊並點選 Finish。

  • 如果系統重新啟動，則啟動桌面上的 TruSmartCAM 捷徑圖示，或在 Windows 開始程式中輸入 TruSmartCAM，並 以管理員身分執行。

伺服器安裝：桌面上提供 TruSmartCAM 和 TruSmartCAM License 捷徑圖示。
用戶端/SYNC 安裝：桌面上僅提供 TruSmartCAM 捷徑圖示。

步驟 6：授權註冊

  • 在 序號 欄位中，輸入 Trumpf Metamation 服務團隊提供的 TruSmartCAM 序號金鑰。在 "Registered to" 欄位中輸入 <Company Name> 和電子郵件。點選 OK。

如果網路防火牆封鎖授權註冊，或 TruSmartCAM 伺服器 PC 無網際網路，則透過離線啟用完成 TruSmartCAM 授權。將 C:\ProgramData\TRUMPF\TMM\Praxis 資料夾中的 Prax.request 電郵給 Trumpf Metamation 服務團隊。Trumpf Metamation 團隊將提供 Prax.lock，需將其放入此資料夾。

步驟 7：首次一次性組態

  • 輸入資料庫名稱並設定資料儲存位置。選取 Use SQL Server 核取方塊並選取 SQL 伺服器名稱以連接至資料庫。點選 OK。

  • TruSmartCAM 桌面用戶端開啟，並在下方顯示 Database Connection Succeeded。

  • TruSmartCAM、TecZone 和 MetaCAM 組態檔案會使用預設組態機器或針對 TruSmartCAM 授權機器建立。相同的組態將在所有 TruSmartCAM 用戶端間共用。

歡迎畫面顯示 Windows 使用者登入名稱作為 TruSmartCAM 登入和名稱。第一位 TruSmartCAM 使用者被視為 Site Admin。提供電子郵件和密碼。點選 OK .

選取 Remember me 核取方塊可保存登入憑證以供下次使用。 清除 Remember me 核取方塊，則每次啟動 TruSmartCAM 應用程式時都會提示登入和密碼對話方塊。

步驟 8：TruSmartCAM 登入

  • 關閉 TruSmartCAM 並重新開啟。系統會提示您輸入 TruSmartCAM 登入憑證。

  • 登入的使用者名稱顯示在 TruSmartCAM 應用程式標頭中的使用者圖示旁邊。

  • 當您將滑鼠懸停在使用者圖示上時，系統會顯示：

    • 使用者角色（例如：編程者、管理員）。

    • 登出的捷徑：Ctrl+L。

  • 點選使用者圖示會開啟一個選單，允許您：

    • Edit information…​ - 更新您的個人資料詳細資訊。

    • Change password…​ - 變更您的帳戶密碼。

    • Sign out - 登出應用程式。

    • Cancel - 關閉選單而不進行任何變更。

步驟 9：工廠機器組態

  • TruSmartCAM 授權（所有機器啟用授權位）：預設 TruSmartCAM 機器和材料被視為工廠組態。

  • TruSmartCAM 授權（無試用並啟用少數機器位）：那些少數機器和預設材料被視為工廠組態。

  • 從 C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts （Open → Import）一個新零件，並驗證零件是否成功匯入。

備註 1：TruSmartCAM Monitor

  • 具引擎安裝的 TruSmartCAM Monitor（站台管理員權限）：

    • 具引擎及站台管理員 TruSmartCAM 權限的 TruSmartCAM Monitor 將具有以下選項：

      1. 將 TruSmartCAM 組態、TecZone、MetaCAM 組態推送至所有 TruSmartCAM 用戶端。也有權限建立新的 TruSmartCAM 使用者登入。

      2. Show Agents 將顯示可用於執行自動化任務的總引擎數，這取決於 TruSmartCAM 授權。

  • 無引擎安裝的 TruSmartCAM Monitor（站台管理員權限）：

  • 無引擎安裝的 TruSmartCAM Monitor（非站台管理員權限）：

執行 TruSmartCAM 應用程式的 PC 必須安裝引擎 TruSmartCAM 元件（伺服器 PC 或任何用戶端安裝）。安裝引擎 TruSmartCAM 元件的 PC 應全年無休執行，以執行所有自動化任務。
備註 2：OpenGL

  • TruSmartCAM 應用程式在開啟時立即關閉，且工作列上未顯示 pmonitor。

  • 這代表 OpenGL 問題。

  • 確認此問題的另一種方式：開啟 C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts ，它會顯示關於 OpenGL 問題的錯誤對話方塊。

  • 更新 C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini 的 options 區段，設定 GLVersion=1 可使 TruSmartCAM 應用程式成功開啟。

[Options]
GLVersion=1.0
