新增材料和板材

可透過點擊 Factory 圖示並選取 sheets 來存取板材管理。這會提供已設定材料的概覽。選取左側列出的任何材料，會顯示可用的板材、厚度、尺寸和數量。

若要新增材料，請從 factory 中的 sheets 頁面點擊 Add new → New Material…​。

輸入 Material、Raw Material、 Thickness 和材料參數。點擊 OK。

檢視材料

factory → Sheets 中的 View…​ 選項具有以下選項：

  • Expand All：展開所有材料類別。

  • Collapse All：摺疊所有材料類別。

  • Show All Materials：列出所有原材料，不論板材庫存為何。

  • Show Inventory Materials：僅列出具有板材庫存的原材料。

以粗體顯示的原材料厚度代表板材可用性。

新增板材

若要新增板材，請從 factory 中的 Sheets 頁面點擊 Add new → New Sheet。修改板材參數。

  • Search Sheets (Ctrl + F)…​：依尺寸、軋制方向、註解、爐號、餘料和汽化篩選板材。

  • Slider (+ / –)：調整板材預覽的縮放級別。

  • Filter by：依選取的選項控制板材預覽（Width、Height、 Area、Quantity、 Grain 或 Type）。

只有在零件尚未指派給該材料或尚未在該板材上 nest layout 之前，才能編輯或刪除材料或板材。

在此階段無法變更材料名稱。因此，必須建立新材料。
