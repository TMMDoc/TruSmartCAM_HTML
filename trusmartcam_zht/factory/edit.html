編輯

Edit 選項讓您可以修改與機床、 材料、刀具及 TecZone 中系統偏好相關的各項設定。選取後，您 將被重新導向到 TecZone 中適當的設定區段，以 進行必要的調整。

下列設定可供編輯：

  • Machines

  • CAM Materials - 請參閱 TecZone 文件中的 Database → Materials 主題。

  • Bend-tool Inventory - 請參閱 TecZone 文件中的 Database → Bend Tools 主題。

  • Custom Bend Deductions - 請參閱 TecZone 文件中的 Database → Bend Deductions 主題。

  • TecZone Settings - 請參閱 TecZone 文件中的 Settings 主題。
