通知

通知會告知使用者系統內發生的 CAD 和 tooling 錯誤。它們確保問題能及時傳達，以便採取適當的措施。

電子郵件通知

電子郵件通知功能允許使用者設定並接收 CAD 和 tooling 錯誤的自動電子郵件警報。設定完成後，每當發生相關事件時，系統會自動向指定收件人發送電子郵件，確保問題能及時處理。

若要設定電子郵件通知，請前往： factory > settings > Notifications

Notifications 頁面包含以下區段：

通知設定

Notification settings 區段控制如何產生電子郵件警報並傳送給收件人。

  • Enable email notifications - 啟用系統依所設定的條件發送通知。

  • Notification recipients - 指定收件人的電子郵件地址。可以用逗號（,）或空格分隔以新增多個收件人。

  • Send messages in batch - 將多個通知合併為單一電子郵件。在指定時間間隔內產生的訊息會被群組在一起，這有助於減少電子郵件數量並避免雜亂。

  • Attach tooling simulation preview where applicable - 在可用時將 tooling 模擬預覽附加到通知電子郵件。這有助於直接從電子郵件檢視 tooling 相關問題。

包含模擬預覽可能會大幅增加電子郵件的大小。

Mail settings

Mail settings 區段定義系統用來傳送電子郵件通知的外發郵件伺服器組態。這些設定必須正確設定，通知才能成功發送。

  • SMTP server - 指定用來發送外發電子郵件的 SMTP 伺服器地址（例如 smtp.gmail.com）。此資訊通常可在使用者郵件用戶端的帳戶或設定區段中找到。

  • SMTP port - 定義郵件伺服器用來透過網際網路發送電子郵件的埠號。常見值包括 465（SSL）和 587（TLS）。

  • Transport protocol - 指定用來從應用程式安全地向郵件伺服器發送電子郵件的協定（例如 SSL 或 TLS）。

  • Server needs authentication - 啟用 SMTP 伺服器的驗證。啟用後，伺服器會在發送電子郵件前驗證使用者名稱和密碼。

  • User-name - 指定用來與 SMTP 伺服器驗證並發送通知的電子郵件帳戶。

  • Password - 指定用於驗證的電子郵件帳戶相關聯的密碼。

  • Sender address - 指定收件人接收通知時所顯示的發件人電子郵件地址。

  • Test…​ - 發送測試電子郵件以驗證郵件伺服器組態。

點選 Test…​ 以驗證設定。若測試成功，會顯示確認訊息；否則會顯示錯誤訊息，指出失敗原因。

  • 在互動模式下（例如編輯或手動儲存零件時）不會觸發電子郵件通知。

  • 電子郵件傳送在背景中處理，可能會延遲。

  • 若系統或引擎在處理完成前停止，通知可能無法傳送。
