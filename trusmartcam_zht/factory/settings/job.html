Output settings

Save layout NC and reports - 啟用此選項以儲存 layout NC 和報告。

Save layout file - 啟用此選項以儲存 layout 檔案。

Output simulation preview in reports - 啟用此選項以在其他輸出之外產生 tooling 模擬預覽。這是雷射/歖孔 tooling 的一段短 GIF 動畫。

Do not delete program outputs on layout/job completion - 啟用此選項後，當 job/layout 被標記為完成時，會跳過程式輸出的刪除作業。

Nest settings

Mix parts from multiple Jobs - 支援混合模式 nesting。來自多個 job 的零件應一同 nesting，以獲得更佳的排樣效率。

Do not auto-release layouts - 這將阻止 layout 可供生產使用，直到所有 layout 都處於已發佈狀態。

Re-nesting packing cut-off - 此值用於決定 nested layout 是否保留在核准佇列中，並在規劃新零件時重新 nesting，或是否發佈至生產並將相關輸出匯出至輸出資料夾。

Interactive sheet-name prefix - 此區段用於支援互動式 nesting，讓使用者對所 nesting 的零件及 nest 結果有更多控制權。為互動式 nested 的 layout 使用與自動 nesting 不同的命名方案。

Update sheet inventory on nest (un)release - 若啟用此選項，將 nest 傳送至機台時會更新板材庫存。同樣地，從機台召回 nest 時會將板材退回庫存。

Automate remnant inventory management - 選擇此切換時，軟體會自動化餘料庫存管理。若未選擇，餘料管理則變為互動式。

Auto-refresh Out-of-date layouts - 勾選時，軟體會在零件的切割解決方案計算完成後，重新整理與該零件連結的所有 ui:EGTag.SelectOutOfDate[Out-of-date Layouts]。

Automate twin-line nesting - 勾選此選項以啟用 twin-line 自動化。

Pull workflow settings

Use 'Pull workflow' - 此選項適用於需要高度自主規劃和 nesting 系統的使用者。啟用後，TruSmartCAM 會依需求規劃 nesting。

Nests per station - 此值用於設定每個工作站應建立多少個 layout。

Maximum sheets per nest - 此值用於控制同一 nest 的最大板材數量。例如，若有一張包含大零件（填滿整張板材）的訂單，需求量很大（例如 500）- TruSmartCAM 在 pull 模式下不再建立含 500 個副本的單一 nest。而是建立每個 nest 10 個副本，其中 10 為上限。

Bend programs per station - 此值用於設定每個工作站應建立多少個折彎程式。

Mark the task completed, when the program outputs are removed - 啟用此選項後，當輸出從目標輸出目的地移除時，layout 會被標記為 Done。

Spreadsheet import settings

CAD lookup directories - TruSmartCAM 會嘗試從零件庫載入所匯入 CSV 中提到的零件項目。不過，若零件庫中沒有該零件，則會依此對話方塊中設定的目錄順序，嘗試從查找目錄擷取零件。

Use recursive CAD search - 啟用此選項以針對後續結果重複執行搜尋。

Create a blank part for the missing CAD files - 若零件不存在於 TruSmartCAM 庫或查找目錄中，TruSmartCAM 會為這些無法取得的零件建立空白零件。

Do not show New Job dialog if the spreadsheet has no error - 若 CSV 項目干淨（即與資料庫無資料不符，或所有欄位都正確列出），TruSmartCAM 將不會顯示 job 概覽視窗，並會在 CSV 匯入或拖放後立即處理該 job。

Prefer Raw-Material column over Material + Thickness - 支援的試算表類型：

  1. Pattern 1：PartName, Quantity, DueDate, Priority, RawMaterial

  2. Pattern 2：PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Pattern 3：PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

若未勾選此選項，Pattern 1 將被視為預設的試算表類型。若 CSV 格式為 Pattern 3 類型，我們也支援 Pattern 3。

若勾選此選項且 CSV 為 Pattern 2 類型，則 TruSmartCAM 會從 CSV 的 Material 和 Thickness 欄位解析原材料。

Spreadsheet output settings

Export Job/Layout completion report (.csv) - 勾選此選項以在 Layout 或 Job 完成時啟用 CSV 匯出。完成的報告會儲存在 Factory → Settings → Reports 設定所指定的 Reports 目的地。
