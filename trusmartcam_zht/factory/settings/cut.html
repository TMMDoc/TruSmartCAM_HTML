Output settings

Save cut outputs - 只有當 tooling 正常且啟用並設定了這些匯出設定時，tooling 結果才會被儲存。啟用此選項以儲存切割 NC。

Output tooling simulation preview - 啟用此選項以在其他輸出之外產生 tooling 模擬預覽。這是雷射/歖孔 tooling 的一段短 GIF 動畫。

Cut output destination - 這是 NC 和報告將被儲存的目的地。

MetaCAM settings

Lookup MetaCAM materials by raw-material names （針對類似 DMM 的整合啟用此選項）- 啟用此樣式後，TruSmartCAM 會依原材料名稱產生頁面，並在自動 tooling 時將其指派給零件。

MetaCAM sync folders - 此切割設定用於新增額外的 MetaCAM 資料夾，這些資料夾應在使用 config-push 監視命令時與 config.dat 一同同步。config-push 會將本地檔案儲存到 TruSmartCAM 資料庫，當 MetaCAM（重新）啟動時，其他電腦會下載該檔案。當 MetaCAM 機台完成自動 tooling 時，引擎電腦應自動同步。除了 Tools 之外，其他一些安裝特定的候選項目還有 Etc、Reports 和 Machines 資料夾。

DMM config sync location - 這是 Dynamic Machine Management 組態同步的設定位置。

TecZone Settings

Enable multi-pass nesting - 這將啟用雷射在同一輪廓上切割多次（適用於較厚的材料）。
