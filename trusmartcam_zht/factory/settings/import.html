匯入

匯入

Output settings

Save flat pattern - 啟用此選項以儲存所匯入零件的展開圖。

Format for flat pattern - 此選項用於選擇 DXF 或 GEO 檔案格式。

Flat pattern destination - 這是展開圖將被儲存的位置。

Import settings

Units for DXF files - 這是匯入 DXF 檔案時所使用的量測單位，使用者可以在 mm 或 inch 之間選擇。

Material lookup keys - 可以使用逗號分隔符指定多個查找項目。匯入零件時，TruSmartCAM 會使用這些鍵來搜尋材料值。搜尋到的值隨後用於解析原材料。原始值則儲存在零件的 Misc Properties 中。

Revision lookup keys - 匯入零件時，會將原始零件檔案（正在匯入的零件檔案）中的修訂值與資料庫中現有的修訂值進行比較。若修訂相同，則放棄匯入。現在 DXF 檔案也支援自訂欄位對應。對於 DXF 檔案，自訂欄位資料會從圖面中的文字圖層或 PPI 附件中擷取。

Use geometry comparison on same CAD revision - 在匯入具有相同 CAD 修訂的零件時比較幾何圖形，並在偵測到差異時提示使用者取代或跳過匯入，詳見 Import configuration 以了解更多詳情。

Part name keys - 此選項的運作方式與材料及 Revision lookup keys 類似。設定一個或多個 Part name keys，以使用 PPI 的 Part name 而非檔名作為零件名稱。

Thickness lookup keys - 可以使用逗號分隔符指定多個查找項目。匯入零件時，TruSmartCAM 會使用這些鍵來搜尋厚度值。搜尋到的值隨後用於解析厚度。原始值則儲存在零件的 Misc Properties 中。

Thickness comparison fudge - 這用於匯入零件時查找原材料。在解析出材料名稱和厚度後，TruSmartCAM 會嘗試解析原材料。更多資訊請參閱下方的 Thickness fudge 主題。

Identify shapes after a flat is imported - 匯入零件時，可以自動識別並確認零件內部的形狀。

Shape identification fudge - 形狀識別 fudge 值可在以下層級設定：

  1. Global level - 此值作為所有形狀的預設值。

  2. Individual Shape Level - 可以在個別形狀層級設定 fudge 值來覆寫預設值。在 Shape Library 對話方塊中選取形狀時會顯示 fudge 值。預設情況下，此值設為 0，這類形狀將使用預設的全域值。

Rotate flat horizontally - 一般來說，切割機台面為矩形且較寬。為了提升 tooling 可行性，在零件匯入後沿零件寬度旋轉零件。

Part rotation threshold - 將此設為允許旋轉的最小數值。任何小於所設值的零件都不會被旋轉。

Misc settings

Enable pre-import external tools - 啟用匯入前外部工具匯入選項以啟用 Creo Reader。TruSmartCAM 會上傳所拖放零件的預先擷取家族實例。請注意，實例擷取是在零件上傳期間執行（作為匯入前作業），因此上傳零件的電腦上必須安裝 Creo 軟體。

Ignore drawing colors in Flat thumbnails for clarity - 啟用此選項以產生灰階更锐利的縮圖。為了圖像清晰度，會忽略圖層顏色和文字實體。

Use only one Engine for all import tasks - 啟用後，所有匯入作業僅使用一個引擎核心。

Thickness fudge

Thickness comparison fudge 會在庫存中沒有所需的板材厚度時，藉由比較庫存中板材的厚度值來選擇最接近的板材厚度值。

例如，假設如下：

  1. 我們有一個板材厚度為 1.6 mm、材料為 steel 的零件。

  2. Thickness comparison fudge 值為 0.1 mm。

  3. 庫存中有厚度為 1.5 mm、1.55 mm 和 1.7 mm 的 steel 板材。

TruSmartCAM 會在比較 Thickness comparison fudge 值（0.1 mm）與所匯入項目（量測為 1.6 mm）後，選擇厚度值最接近的板材。在此情況下，會選擇 1.55 mm。
