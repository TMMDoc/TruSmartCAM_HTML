監視

監視設定允許 TruSmartCAM 監控指定的資料夾，並自動將檔案匯入系統。這有助於自動化 Parts、Jobs、Assemblies 和 Orders 的匯入，而無需手動介入。

Watch settings

Enable 'Live Folder' - 啟用對指定資料夾的自動監控。

Watch this folder - 指定要監控入傳檔案的資料夾。

Watch sub-folders also - 將所有子資料夾納入監控流程。

After file import

After import - 檔案匯入後，使用者有兩個選項。可以從位置刪除檔案，或將其移至不同位置。

  • Delete imported file - 在成功匯入後移除來源檔案。

  • Move imported file - 在成功匯入後，將來源檔案移至 Move files to this folder 中指定的資料夾。

Move files to this folder - 指定目的資料夾，當 After import 設為 Move imported file 時，成功匯入的檔案將被移至此處。

Move spreadsheets with errors to this folder - 將匯入失敗的檔案移至指定的錯誤資料夾。

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - 自動匯入在監視資料夾中偵測到的試算表檔案。

Do not import spreadsheet with errors - 防止匯入包含驗證錯誤的檔案。

Spreadsheet import option - 從下拉清單選擇要匯入的資料類型。支援的試算表格式可能包括 CSV、XLSX 或 XML。可用選項包括：

  • Import Jobs - 從試算表匯入 job 資料。

  • Import Orders - 從試算表匯入訂單資料。

  • Import Assemblies - 從試算表匯入組件資料。

  • Import Parts - 從試算表匯入零件資料。

其他資訊

  • 設定監視資料夾時，請使用 UNC 路徑 (\\ServerName\FolderPath) 或對應磁碟機 (M:\FolderPath)。請勿使用本地路徑，例如 C:\FolderPath。

  • 執行 TruSmartCAM Engine 服務的電腦必須對所設定的監視資料夾具有讀寫存取權。若權限不足，檔案可能無法成功地被偵測、匯入、移動或刪除。

  • 必須先設定試算表對應，才能啟用監視設定。否則，TruSmartCAM 將無法處理在監視資料夾中偵測到的試算表檔案。
