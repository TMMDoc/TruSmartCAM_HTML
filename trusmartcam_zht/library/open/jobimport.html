匯入 job

從 csv 或 xlsx 匯入

您也可以以常見的文字格式匯入 job

  • 點選 File → Open → Import Jobs，會出現 Open Folder 對話方塊。選取 C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • 若所有零件存在於 csv 位置或查詢資料夾目錄中，則會出現 new job 視窗，列出所有符合 csv 欄位的零件。

  • 遺漏的零件會被忽略，且不會出現在 new job 視窗中。

  • 初始時零件狀態為 Nascent。

  • 點選 OK，現在零件已匯入零件庫。

Create a blank part for the missing CAD files

當使用試算表（.csv 或 .xlsx）匯入 job 時，有時您可能會有 參照到系統中不可用的 CAD 檔案的列。

  • 若要處理此情況，請前往 Factory → Settings → Job， 在 Spreadsheet import settings 下啟用 Create a blank part for the missing CAD files

選取此選項時：

  • 若在 job 匯入期間任何列遺漏 CAD 檔案，系統會自動建立空白 零件以取代遺漏的 CAD 檔案。

  • 在 new job 視窗中，這些遺漏的零件會以黃色 反白顯示，以指示相關的 CAD 檔案遺漏。

  • 遺漏的零件仍會保有其從 CSV 對映的欄位（如零件名稱、材料、 厚度、數量等）。不過，其零件狀態會顯示為 Nascent，意味著它只 是一個尚無實際幾何圖形的空佔位符。

這確保 job 匯入仍可進行，而不會因遺漏 CAD 檔案而發生錯誤— 您之後可在正確的 CAD 檔案可用時更新或取代空白零件。

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • 選取此勾選方塊時，若試算表沒有錯誤（沒有遺漏零件、 遺漏日期或無效資料），系統會自動建立新 job，而不顯示 New Job 對話方塊。

  • 清除此勾選方塊時，即使試算表沒有錯誤，New Job 對話方塊也始 終會出現，供使用者審閱和確認。

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • 選取此勾選方塊時，系統預期試算表使用 Raw-Material 欄（例如 Steel-20）。這意味著材料類型和厚度應合併在一個欄的單一值中。

  • 清除此勾選方塊時，系統預期試算表具有分開的 Material 和 Thickness 欄（例如 Steel 和 2.00）。系統會在匯入期間在內部將它們 合併。

使用 CSV/XLSX 監視資料夾

  • 在 factory → Settings→ Watch settings 中勾選 Enable 'Live Folder' 和 Watch sub-folders also。

  • 設定監視資料夾路徑（UNC 或對映磁碟機）。

  • 在 Spreadsheet import settings 中，勾選 Import spreadsheet from 'Live Folder'。

  • 從 Spreadsheet Import 選項中選取 Import Jobs。

  • 複製 C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv 並將其貼入監視資料夾。

  • 系統會檢查 CSV 並嘗試自動建立 job。

  • 若 CAD 檔案遺漏，則不會建立 job，因為找不到所需的 CAD 資料。

CAD 查詢目錄與遞迴 CAD 搜尋 - 未設定

  • 在 factory → Settings → Job → Spreadsheet import settings 中， 若未設定 CAD lookup directories 且未使用 Use recursive CAD search，則系統不會自動搜尋 CAD 檔案。

  • 若選取 Create a blank part for the missing CAD files 勾選方塊，則即使 CAD 檔案遺漏仍會建立 job。

  • 在這種情況下，job 中的所有零件都會建立為 nascent（空白）零件— 意味著它們沒有幾何圖形，因為找不到 CAD 檔案。

CAD 查詢目錄與遞迴 CAD 搜尋 - 已設定

當 CAD lookup directories 設定為 (C:\Program Files\TRUMPF\TMM\Praxis\Samples) 且在 factory → Settings → Job → Spreadsheet import settings 下啟用 Use recursive CAD search 時：

  • 系統會自動搜尋所指定的資料夾及其所有子資料夾，以尋找試算表中 提到的所需 CAD 檔案。

  • 也已啟用 Create a blank part for the missing CAD files， 因此若仍找不到任何 CAD 檔案，系統會建立空白零件作為佔位符。
