匯入零件

匯入零件

在匯入零件之前，請確保檔案格式與 TruSmartCAM 相容。 詳見 支援的檔案格式。

若匯入後材料和厚度未對映到零件，請使用零件面板指派 材料。

匯入方法

將零件匯入零件庫有三種方法：

  1. 透過檔案匯入

  2. 拖放

  3. 監視資料夾

透過檔案匯入

可使用 Import parts…​ 選項將 2D 或 3D 零件檔案 匯入零件庫。

  • 從命令列點選 open 圖示，並選取 Import parts…​ 選項。

  • 出現 Open 對話方塊—選取任何 CAD 檔案（2D 或 3D）。

  • 顯示所選 CAD 檔案的預覽。

  • 選取所需零件並點選 Open。

  • 系統會為所有可用機床自動建置零件的 tooling，並更新 tooling 狀態。

拖放

  • 將零件檔案直接拖放到 TruSmartCAM 零件庫中。

監視資料夾

監視設定讓您可以監視資料夾中的新檔案，並自動將它們匯入 零件庫。

若要設定，請參閱 監視設定頁面。

  • 使用 UNC（Universal Naming Convention）路徑 \\192.168.1.11\<Folder path> 或 對映的磁碟機 M:\<Folder Path>。

  • 執行 Engine 的 PC 必須對此資料夾具有讀/寫存取權限。

  • 請勿使用像 C:\<Folder Path> 這樣的本機路徑，因為監視服務 會在 Engine PC 上尋找檔案—而非本機 PC。

匯入設定

Use geometry comparison on same CAD revision

當匯入具有相同 CAD 修訂版本的零件時，TruSmartCAM 可以將 CAD 檔案的 幾何圖形與現有零件進行比較。

  • 若要啟用此功能，請在 factory → settings → Import 中設定 Revision lookup keys（例如 REV）。然後啟用 Use geometry comparison on same CAD revision 選項。

只有在設定 Revision lookup keys 時，相同 CAD 修訂版本的幾何圖形比較才能運作。

  • 現在，將具有特定修訂版本（例如 Revision 1）的零件匯入零件庫。

  • 使用相同的修訂版本值再次匯入同一零件。

  • TruSmartCAM 會將新匯入的 CAD 檔案的幾何圖形與現有零件進行比較。

  • 若偵測到幾何圖形差異，TruSmartCAM 會顯示提示，詢問是否要：

    • Replace 以新幾何圖形取代現有零件，並保留相同的修訂 版本值。

    • Skip 此次匯入，保留現有零件及其幾何圖形。

這讓使用者可以在不變更修訂版本值的情況下更新零件幾何圖形， 同時仍可控制是否取代現有零件。

匯入的零件會自動新增到庫中供進一步使用。更多資訊請參閱 庫。
