匯入訂單

可使用以下方法建立或匯入訂單：

  1. 從試算表檔案匯入訂單。

  2. 透過監視設定自動匯入訂單。

  3. 從零件庫中現有的零件建立訂單。

  4. 從組件靜態 nest 建立訂單。

從試算表匯入訂單

  • 導覽至 Open → Import Orders…​。

  • 支援的試算表格式包括 CSV、XLSX 和 XML。

  • 選取所需的試算表檔案並點選 Open。

  • 匯入流程與 Job/Assembly 匯入工作流程類似。

您也可以直接將試算表拖放到訂單頁面以匯入訂單。

使用監視設定匯入訂單

  • 在 Watch settings 中啟用 Import spreadsheet from 'Live Folder' 選項。

  • 在 Spreadsheet import option 中選取 Import Orders。

  • 設定應匯入訂單的資料夾位置。

  • 系統會持續監視所設定的資料夾。

  • 新增的試算表檔案會自動匯入訂單。

有關詳細的設定步驟，請參閱 監視設定 文件。

從零件庫建立訂單

  • 從零件庫中選取所需零件。

  • 按右鍵並選擇 New…​ → Order 以開啟 New Orders 對話方塊。

  • 輸入所需詳細資料，例如數量、交付日期和優先順序。

  • 點選 OK 以建立訂單。

  • 系統會自動切換到訂單頁面。

  • 已建立的訂單會顯示在 Orders Ready 頁面以供建立 job。

從組件建立訂單

  • 按右鍵所需的組件。

  • 選取 New…​ → Order 以開啟 New Orders 對話方塊。

  • 輸入所需的 Assembly count。

  • 點選 OK 以建立訂單。
