tooling 驗證

本節說明如何存取和修改 TruSmartCAM 中零件的 tooling 資訊。

  • 在任何零件圖磚上按一下滑鼠右鍵，即可開啟零件面板並存取 tooling 選項。

  • 按一下 Toolings，即可切換至第一個可用的 tooling 實例。

  • 或者，直接按一下 tooling 實例，即可檢視機床詳細資訊和 tooling 選項。

  • 使用 來 Open in read-only mode for viewing。

  • 使用 來 Check-out the document for editing。

  • 所選的 tooling 實例會在 TecZone 或 MetaCAM 中開啟。

  • 執行手動 tooling 檢查並進行必要的變更。

  • 當您嘗試儲存時，會出現 Unsaved Changes 對話方塊，提示您確認編輯內容。

  • 按一下 Yes 以繼續儲存。

  • 儲存後，系統會再次執行 tooling 驗證。

  • 如果沒有錯誤，就會出現將變更儲存至 TruSmartCAM 的選項。

  • 如果發現 tooling 錯誤，就會顯示錯誤訊息：

  • 儲存後，零件的 tooling 狀態會在零件庫中更新。

  • tooling 實例上的綠色表示它已簽入。

  • tooling 實例作者會更新為最後編輯它的人員。

  • User-edited 欄位會指出 tooling 實例是否經過手動 修改。當使用者簽出實例並進行任何變更時，此欄位會在儲存時自動設定為 Yes。

  • 如果零件目前正在編輯中，其圖磚上會出現使用者圖示。

  • 將滑鼠停留在圖磚上，會顯示簽出它的人員以及簽出的時間。

  • 當零件處於簽出狀態時，同一 tooling 實例的 Check-out the document for editing 選項會停用，而 Cancel Check-out 選項會啟用。
