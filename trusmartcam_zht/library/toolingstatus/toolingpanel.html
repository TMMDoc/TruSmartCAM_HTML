Tooling 面板

本節說明與 tooling 相關的動作，例如 Export outputs、 Check Tooling、Suppress Tooling、 Set as Base-Flat…​、Copy Tooling， 以及其他用於管理 tooling 實例的選項。

Open in read-only mode for viewing
以唯讀模式開啟所選的 tooling。

Check-out the document for editing
啟用所選 tooling 的編輯。

Export Outputs

將所選的 tooling 輸出匯出到所設定的目的地。

Check Tooling

驗證現有的 tooling 而不做任何變更，並在驗證失敗時更新其狀態。

Copy Tooling…​

從所選的參考 tooling 複製沖頭、順序和背規設定，並在可行的情況下將其套用到其他解決方案。

Set as Base-Flat…​

將所選的折彎或折疊 tooling 標記為產生切割解決方案的參考展開尺寸。

Re-tool…​

重新處理零件所選的 tooling，而不影響其他 tooling。

Suppress Tooling

隱藏所選的 tooling，使其排除在後續處理和輸出產生之外。

Prev / Next / Part

導覽至上一個或下一個 tooling，或返回上層零件。

排序和篩選

顯示與所選 tooling 具有類似特性的其他 tooling，以供快速參考。

Export Outputs

此選項會將零件輸出匯出到 Factory Settings 中所設定的目的地。(請參閱 折彎設定 和 切割設定)

只會匯出與所選 tooling 操作相關聯的 tooling，而不是整個零件。

匯出的檔案取決於操作類型。對於 Bend 和 Fold 操作，會產生 NC 檔案和報告。對於 Cut 和 Punch 操作，則只會匯出零件檔案。

Check Tooling

  • 如果 CAM 設定有變更或折彎刀具遺失，您不需要重新 tooling 零件。

  • 相反地，請使用 Check Tooling 來驗證現有的 tooling，而不做任何變更。

  • 如果驗證失敗，該實例的 tooling 狀態會更新，且相關的輸出檔案會移除。

  • Check Tooling 也會偵測先前使用 Ignore Errors 手動覆寫錯誤的零件，並在需要時將其狀態更新為錯誤。

Copy tooling

複製 tooling 可讓您快速將折彎 tooling 從一個解決方案套用到其他解決方案， 節省時間和精力。

這會從所選的參考 tooling (解決方案) 複製沖頭、順序和背規設定，並嘗試將相同的 設定套用到所有其他解決方案。

  • 如果複製的設定對目標機床可行，就會加以儲存和使用。

  • 如果設定不可行，該機床的原始 tooling 會保持不變。

例如，您可能針對不同的機床有不同的 tooling：

  • 這裡，機床 5230X 4A 使用 Gooseneck 沖頭，機床 5230SX 6A 使用 Pointed 沖頭。

當您在機床 5230X 4A 上使用 Copy Tooling…​ 時，它會 嘗試將 Gooseneck 設定複製到所有其他機床。

系統會盡可能套用相同的沖頭、順序和背規設定。如果無法使用複製的設定， 原始的 tooling 會保持不變。

套用複製 tooling 後，Gooseneck 設定已成功套用到所有可行的其他機床。

Set as Base-Flat…​

Set as Base-Flat…​ 功能會定義使用哪個折彎或折疊 tooling 作為產生切割解決方案的參考展開尺寸。當 tooling 標記為 Base-Flat 時， TruSmartCAM 會根據該機床更新零件的展開尺寸，並據此重新產生切割解決方案。 Base-Flat tooling 在 UI 中會以藍色邊框顯示。

不同的折彎機床對於相同的零件可能會產生略有不同的展開尺寸。當您將 tooling 設定為 Base-Flat 時，TruSmartCAM 會使用該機床的展開尺寸作為主要參考，並自動 重新計算切割解決方案。

自動 base flat 選擇

當啟用工廠設定 Apply flat correction during bending 時：

  • TruSmartCAM 會在零件匯入期間，自動將折彎 tooling (包含最大折彎長度表格) 設定為 Base-Flat。

  • 如果所選的折彎 tooling 遇到錯誤或不可行，TruSmartCAM 會智慧地切換並將另一個 有效的折彎 tooling 設定為 Base-Flat。這可確保展開尺寸參考和切割解決方案始終 保持一致且有效，無需手動介入。

增強的 base flat 管理

TruSmartCAM 在儲存折彎或折疊 tooling 編輯時，會在 Save to Praxis 對話方塊中提供 Base-Flat 選項。這些選項僅會針對處於 OK 狀態的 tooling 出現，並 確保展開尺寸和切割解決方案保持準確。

Set as Base-Flat and calculate cutting solution

此選項用於首次將 tooling 標記為 Base-Flat，並自動產生對應的切割解決方案。

出現時機：

  • tooling 目前未標記為 Base-Flat。

  • 使用者已簽出 tooling 進行編輯，並正在儲存變更。

若要使用此選項，請簽出折彎或折疊 tooling 並進行所需的修改，例如變更折彎 參數或展開尺寸。按 Ctrl+S 儲存變更。在 Save to Praxis 對話方塊中，選擇 Set as Base-Flat and calculate cutting solution 並 按一下 OK。TruSmartCAM 會將 tooling 設定為 Base-Flat，並使用更新後的展開尺寸產生 切割解決方案。

Update the base-flat and re-calculate cutting solution

當 tooling 已標記為 Base-Flat 且已經過編輯，需要重新產生展開尺寸和切割解決方案時， 就會使用此選項。

出現時機：

  • tooling 已標記為 Base-Flat。

  • 使用者已簽出、編輯它，並正在儲存變更。

編輯現有的 Base-Flat tooling 時，請視需要更新折彎參數或展開尺寸幾何形狀。在 Save to Praxis 對話方塊中，選擇 Update the base-flat and re-calculate cutting solution。 接著，TruSmartCAM 會更新 Base-Flat tooling，並重新產生所有相關的 切割解決方案，以反映最新的變更。

一次只能將一個折彎 tooling 設定為 Base-Flat。

當變更 Base-Flat 時，現有的切割解決方案會自動重新處理。

此功能在 TruSmartCAM 中適用於折彎和折疊 tooling。

Re-tool

此選項會重新處理零件所選的 tooling。

在 tooling 面板中所需的 tooling 上按一下滑鼠右鍵，然後按一下 Re-tool…​

繼續之前會顯示確認對話方塊。

按一下 Yes 以繼續重新 tooling，或按一下 No 以 取消操作。

只會重新 tooling 所選的 tooling。與零件相關聯的其他 tooling 不會受到 影響。與所選 tooling 相關的現有輸出會在重新 tooling 過程中移除並重新產生。

當 tooling 資料過時、不正確，或對機床或 tooling 組態進行變更時，請使用 此選項。

Ignore errors

  • 如果 tooling 實例顯示警告，而您仍想要繼續使用它，可以按一下 Ignore errors 覆寫警告。

  • 這會允許系統為該實例匯出輸出檔案，即使有 tooling 問題也一樣。

只有在您確定可以安全忽略警告時，才使用 Ignore Errors。覆寫實際 的錯誤可能會導致機床損壞或安全風險。

隱藏/取消隱藏 tooling

  • 當機床處於非作用中狀態，或您不想讓特定零件由 特定機床處理時，請使用 Suppress Tooling 將 該零件排除在該機床的 nesting 之外。

  • 隱藏後，將滑鼠停留在 tooling 實例上會顯示類似「Tooling suppressed by <User name> on <Date Time>」的訊息。

  • 隱藏 tooling 會移除該機床和零件的輸出檔案。

  • 使用 Unsuppress tooling 可還原該機床上零件的 tooling 狀態。

  • 取消隱藏後，會再次產生相應的輸出檔案。
