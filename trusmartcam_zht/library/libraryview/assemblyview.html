組件

從組件建立靜態 nest

可使用互動 nesting 精靈為組件產生靜態 nest。 這些 nest 是僅與所選組件相關聯的固定 layout。

  • 切換至 assys 檢視。

  • 按右鍵所需的組件並選取 Create Nests…​。

  • 開啟互動 Nesting 精靈。

  • 預設情況下，互動 nesting 精靈會切換至 Select Machine & Material 頁面。

  • 機床會以色條顯示，指示可用的生產負載：

    • 綠色條：已排程小時

    • 灰色條：可用小時（在8 小時班中）

  • 在每台機床下，所選零件會依其 Raw-Material 分組 （零件/總數量）。

  • 若某零件對所屬機床沒有有效的 tooling 解決方案，則該零件和材料 會在該機床上被忽略而不處理。

  • 若某原材料已為一台機床選取，則它將不可用於其他機床。

  • 一旦設定了機床 nest 計畫，請選取偏好的板材並覆寫板材參數， 如 Priority、 Quantity、Margins 等。

  • 您可以篩選板材以顯示 All Sheets、 Standard Sheets 或 Remnant Sheets。點選 next。

在此階段無法增加數量。您可以保持與板材庫存數量相同， 或減少它並檢查 nesting 結果。

  • Update Qty 會出現在互動 nesting 計畫視窗中。

  • 預設情況下，Pick All (F5) 會包含所有零件進行 nesting，或您可以手動選取優先零件並調整零件數量。 點選 next。

  • nesting 開始，已 nest 到板材中的零件會以藍色狀態更新。

  • 機床的生產負載會依據 nest 結果更新。

  • 若部分零件仍未 nest，會出現訊息 Some parts remain unnested — 這些零件會留在 原始 job 中。

    • 若沒有合適的板材可用，零件可能仍未 nest。

  • 可以編輯靜態 nest 以包含未 nest 的零件：

    • 選取您要插入未 nest 零件的 layout，並將其簽出以供編輯。

  • TecZone 開啟。點選 Pick 或 Pick All 以從父組件中選取未 nest 的零件。

  • 依需要在 layout 中排列零件。

  • 產生的 nest 會自動以父組件命名，以便於識別。

靜態 nest 不能包含來自其他組件的零件。允許混合組件 nest 會阻止在不釋放其他組件的情況下釋放一個組件，因此設計上禁止 混合。

非鱈金元件

  • 當匯入組件時，會提取鱈金零件並新增到零件庫中的組件。

  • 非鱈金元件會被分離並新增到 Components 中。

  • 組件會新增到組件庫，其 BOM （物料清單）包含零件和元件。

  • 若某零件已作為鱈金零件匯入，系統會更新現有項目並從零件庫中 移除重複項目。

  • 選取組件會同時顯示零件和元件，元件數量顯示在元件圖片下方 （所選組件元件數和總元件數）。

  • 元件工具提示會顯示名稱、材料和尺寸。 元件在生產期間會被排除—它們不會 nest，也不會為元件產生板材。

  • 範例組件和元件可在以下位置取得： C:\Program Files\TRUMPF\TMM\Praxis\Samples\Assys\Components, 可用於測試元件匯入和組件工作流程。

從組件建立 job

  • 按右鍵組件，點選 New…​，然後點選 Job。

  • 在 New Job 對話方塊中，設定組件數量，點選 OK， 然後依需更新 job 詳細資料（如交付日期和優先順序）。

  • 系統會從組件建立 job，並將靜態 nest 複製為 job nest， 更新板材數量。複製的 nest 會以 job ID 作為前綴。

  • 可以編輯或刪除 job nest，而不影響原始靜態 nest。

  • 可使用 Adapt/Compact…​ 或 Add parts…​ 重新排列 job nest。

  • 有關詳細步驟，請參閱 Adapt/Compact 和 Add parts。

若某零件未出現在 nest 中，請檢查 nest 編輯對話方塊—您可以 手動插入未 nest 的零件。

使用已儲存的搜尋和篩選器，可快速在多個組件中尋找零件。

使用清晰、具描述性的組件和 nest 名稱，以避免在將 nest 複製到 job 時混淆。
