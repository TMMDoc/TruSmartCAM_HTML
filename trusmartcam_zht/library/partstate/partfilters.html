零件篩選器

零件庫篩選器可讓您透過套用特定條件，快速在庫中搜尋和尋找零件。這些篩選器 會將結果縮小到僅符合您條件的零件，讓您更容易有效率地管理和存取相關零件。

State

  • 使用 State 篩選器，根據零件目前的狀態搜尋零件。

  • 下拉式清單會根據可用的庫零件顯示所有適用的狀態。

  • 狀態清單會根據所選的零件及其狀態動態變更。

  • 例如，選取 Material Missing 即可檢視處於未解決材料狀態的零件。

Status

  • 使用 Status 篩選器，根據 tooling 狀態搜尋零件。

  • 下拉式清單會以彩色方塊顯示 tooling 狀態，以及所有可用的機床及其適用的 錯誤。

  • 彩色方塊代表下列狀態：

    • 白色：tooling 正常

    • 橙色：tooling 有錯誤

    • 黃色：tooling 有警告

    • 灰色：tooling 已隱藏

  • 如果零件有窄凸緣或未指派 tooling 的錯誤，選取這些項目會顯示相應的零件。

  • 按一下灰色方塊，即可顯示在所選機床上已隱藏 tooling 的零件。

Bend mounts

  • 使用 Bend mounts 篩選器，根據使用的折彎刀具搜尋零件。

  • 下拉式清單會顯示所有可用的折彎刀具，並可依刀具名稱、 類型 (沖頭、鵝頸、圓弧等) 或說明進行篩選。

  • 選取多個刀具並按一下 Match all，即可排序同時使用 所選兩個刀具的刀具。
