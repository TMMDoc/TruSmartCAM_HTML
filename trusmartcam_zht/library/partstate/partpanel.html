零件面板

本節說明與零件相關的動作，例如 Re-import、Re-tool、 Rename、Export outputs 等， 用於管理零件實例。

Open in read-only mode for viewing
以唯讀模式開啟所選的零件。

Check-out the document for editing
啟用所選零件的編輯。

Delete
刪除所選的零件。

New…​

所選的零件可以轉換為新的訂單、job 或組件。

Export Outputs

將零件輸出匯出到所設定的目的地。

Re-import…​

可讓您再次匯入所選的零件。

Re-tool…​

可讓您重新處理所選的零件。

Rename…​

變更所選零件的名稱。

Assign Material…​

指定與所選零件相關聯的材料。

Assign Customer…​

指定與所選零件相關聯的客戶。

Rolling direction

定義材料軋制的方向。可用的選項有 None、Horizontal 和 Vertical。

Prev / Next / Toolings

導覽至上一個或下一個零件或 tooling。

排序和篩選

使用這些篩選器可檢視與所選零件共用相同屬性的其他零件：Same Material、Same Customer、Same Bend count 或 Same State。

Re-import

  • 在任何零件上按一下滑鼠右鍵，然後按一下 Re-import…​。

  • 所有機床上所選零件的 tooling 實例都會清除，包括自動 tooling 和手動 tooling 的實例。

  • 現有的輸出檔案 (CAD、Bend 和 Cut) 會移除。

  • 零件會重新匯入，並針對所有機床套用全新的 CAD 驗證和 tooling。

  • 系統會根據更新後的 tooling 結果建立新的輸出檔案。

Re-tool

  • 在任何零件上按一下滑鼠右鍵，然後按一下 Re-tool…​。

  • 所有機床預設都會勾選，並分組為 Laser、Punch、Panel 和 Press brake。

  • 按一下 OK 以繼續。這會移除所選機床的自動 tooling 和手動 tooling 實例，並刪除相關的輸出檔案。

  • 當勾選 Retain existing outputs 核取方塊時， 只有先前移除輸出的零件才會重新 tooling，其他輸出則保持不變。如果未勾選， 所選機床的所有輸出檔案都會在重新 tooling 期間移除並重新產生。

  • 如果任何機床的 CAM 設定有變更，請選取該機床並重新 tooling 零件。

  • 如果刀具 (LTT、punch 或 bend) 有變更或遺失，請更新機床並僅重新 tooling 受影響的零件。

Rename

本節說明如何在 TruSmartCAM 中重新命名一個或多個零件。

  • 在零件上按一下滑鼠右鍵，然後按一下 Rename…​。

  • 會出現重新命名確認對話方塊，顯示目前的零件名稱。

  • 輸入新名稱並按一下勾號 ✓ 圖示以確認，或按一下叉號 ✗ 圖示以取消重新命名操作。

  • 若要重新命名多個零件，請選取所有需要的零件，然後在其中任何一個上按一下滑鼠右鍵， 並按一下 Rename…​。

  • 會出現確認對話方塊，顯示所選零件的總數。

  • 針對每個零件，輸入新名稱並按一下勾號 ✓ 圖示逐一確認。

  • 如果誤選了任何零件，請按一下叉號 ✗ 圖示以取消。或者，您可以在零件上按一下滑鼠右鍵，然後按一下 Cancel Rename 以略過重新命名。

Export outputs

此選項會將零件輸出匯出到 Factory Settings 中所設定的目的地。(請參閱 折彎設定 和 切割設定)

輸出位置會在 Bend、Fold 和 Cut 各自的輸出設定中分別定義。與折彎、 折疊和切割操作相關聯的所有 tooling 都會針對整個零件匯出。

匯出的檔案取決於操作類型。對於 Bend 和 Fold 操作，會產生 NC 檔案和報告。對於 Cut 和 Punch 操作，則只會匯出零件檔案。

零件指派材料

狀態為 Material not assigned 的零件需要先 更新才能進一步處理。以下步驟說明如何指派材料。

  • 在顯示 Material not assigned 狀態的零件上按一下滑鼠右鍵，然後選取 Assign Material…​。

  • 會開啟 Assign Material 視窗。

  • 此對話方塊有四個區段：

    • Suggestions - 根據匯入零件的厚度自動建議原 材料。

    • All Materials - 列出 TruSmartCAM 中定義的所有材料類型。

    • All Raw-Materials - 顯示系統中所有可用的原材料。

    • Used Raw-Materials - 顯示最近使用的原材料，以供快速存取。

  • 您可以使用頂端的 Search 欄位快速尋找材料。例如，輸入「steel」即可在 三個區段中顯示所有相符的材料。

  • 從篩選後的清單中，從原材料清單選取所需的材料 (例如 Steel-25)。

  • 所選的材料將指派給零件。

Rolling direction

Rolling direction 是指零件中紋理的方向，這可能會影響零件的 切割和處理方式。此選項可讓您為零件庫中的零件指定 Rolling direction。系統會根據所選的 方向，將零件放置在正確的方向，以便在可用的機床上進行切割。

  • 在零件庫或 Job 視窗中的任何零件圖磚上按一下滑鼠右鍵。

  • 選取偏好的軋制方向：

    • None

    • Horizontal

    • Vertical

  • 零件會根據所選的軋制方向，針對所有可用的切割機床自動重新 tooling。
