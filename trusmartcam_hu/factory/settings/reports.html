Jelentések

Report settings

Report destination - Használja ezt a lehetőséget a jelentések mentési helyének megadásához.

Report Output Format - Megadja a jelentés formátumát az exportálás során (PDF vagy HTML).

Job report settings

Include layout images in the report - Engedélyezze ezt a beállítást, hogy az elrendezések képei belefoglalódjanak egy jelentésbe.

Include part images in the report - Engedélyezze ezt a beállítást, hogy az alkatrészek képei belefoglalódjanak egy jelentésbe.

Include layout reports in the job report - Engedélyezze ezt a beállítást, hogy egy feladatjelentésen belül hivatkozás legyen az elrendezés-jelentésekre.

Label report settings

Enable label reports - Engedélyezze ezt a beállítást, hogy címkék generálását tegye lehetővé vagy a feladatból, vagy egy elrendezésből, ahol a jobb gombbal kattintás és az Export Layouts, illetve a Send to Machine kiválasztása lehetőséget kínál a címkejelentés megjelenítésére.

Label size (W x H) - Megadja a címke szélességét és magasságát milliméterben. Ezek az értékek határozzák meg a generált címke fizikai méreteit.

QR code field - Meghatározza a címkén lévő QR-kódba kódolandó adatmezőt. A legördülő lista tartalmazza a Part Name, Part Order és None elemeket. A kiválasztott mezőérték QR-kódként jelenik meg.

Barcode field - Meghatározza a címkén lévő vonalkódba kódolandó adatmezőt. A legördülő lista tartalmazza a Part Name, Part Order és None elemeket. A kiválasztott mezőérték vonalkódként jelenik meg.

Show part image - Ha engedélyezve van, belefoglalja az alkatrész képét a generált címkejelentésbe.
