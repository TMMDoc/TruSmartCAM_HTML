Megtekintés

A Megtekintési beállítások lehetővé teszik a TruSmartCAM számára, hogy egy kijelölt mappát figyeljen, és automatikusan importálja a fájlokat a rendszerbe. Ez segít automatizálni az alkatrészek, feladatok, részegységek és megrendelések importálását kézi beavatkozás nélkül.

Watch settings

Enable 'Live Folder' - Engedélyezi a megadott mappa automatikus figyelését.

Watch this folder - Megadja a beérkező fájlok szempontjából figyelendő mappát.

Watch sub-folders also - Az összes almappát belefoglalja a figyelési folyamatba.

After file import

After import - A fájl importálása után a felhasználónak két lehetősége van. A fájl törölhető a helyéről, vagy áthelyezhető egy másik helyre.

  • Delete imported file - Eltávolítja a forrásfájlt sikeres importálás után.

  • Move imported file - Sikeres importálás után áthelyezi a forrásfájlt a Move files to this folder mezőben megadott mappába.

Move files to this folder - Megadja azt a célmappát, ahová a sikeresen importált fájlokat át kell helyezni, amikor az After import beállítás Move imported file értékre van állítva.

Move spreadsheets with errors to this folder - A sikertelen importálásokat a megadott hibamappába helyezi.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Automatikusan importálja a figyelt mappában észlelt táblázatfájlokat.

Do not import spreadsheet with errors - Megakadályozza az érvényesítési hibákat tartalmazó fájlok importálását.

Spreadsheet import option - Kiválasztja a legördülő listából importálandó adatok típusát. A támogatott táblázatformátumok közé tartozhat a CSV, XLSX vagy XML. Az elérhető lehetőségek a következők:

  • Import Jobs - Feladatadatokat importál a táblázatból.

  • Import Orders - Megrendelési adatokat importál a táblázatból.

  • Import Assemblies - Részegység-adatokat importál a táblázatból.

  • Import Parts - Alkatrészadatokat importál a táblázatból.

További információk

  • Használjon UNC-elérési utat (\\ServerName\FolderPath) vagy leképezett meghajtót (M:\FolderPath) a figyelt mappa konfigurálásakor. Ne használjon helyi elérési utakat, például C:\FolderPath.

  • A TruSmartCAM Engine szolgáltatást futtató számítógépnek olvasási és írási hozzáféréssel kell rendelkeznie a konfigurált figyelt mappához. Elegendő engedélyek nélkül a fájlok észlelése, importálása, áthelyezése vagy törlése nem történhet meg sikeresen.

  • A táblázatleképezést a Megtekintési beállítások engedélyezése előtt kell konfigurálni. Ellenkező esetben a TruSmartCAM nem lesz képes feldolgozni a figyelt mappában észlelt táblázatfájlokat.
