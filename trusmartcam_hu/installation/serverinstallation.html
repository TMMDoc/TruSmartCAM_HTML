Kiszolgálótelepítés

Kövesse az utasításokat a TruSmartCAM kiszolgáló SQL-lel együtt történő telepítéséhez.

Rendszergazdai jogosultságok

A telepítés végrehajtásához a felhasználónak rendszergazdai jogosultságokkal kell rendelkeznie.

  • Futtassa a Setup.TruSmartCAM.<version>.exe fájlt a telepítés megkezdéséhez.

A verzió egy szám.

  • Olvassa el a licencszerződést, válassza az I accept the agreement lehetőséget, majd kattintson a Next gombra.

1. lépés: Telepítési hely

  • Adja meg a telepítési könyvtárat, vagy fogadja el az alapértelmezett telepítési helyet (C:\Program Files\TRUMPF\TMM\Praxis), majd kattintson a Next gombra.

    • C:\Program Files\TRUMPF\TMM\Praxis - A telepítési mappa a következő mappákat tartalmazza: Bin, MetaCAM, Samples és Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Az adatmappa a következő mappákat tartalmazza: TruSmartCAM, TecZone és MetaCAM.

2. lépés: Összetevők kiválasztása

Telepítés típusa Összetevők

Full

Kiszolgáló + Asztali kliens + Engine

Client

Asztali kliens

Server

Kiszolgáló + Asztali kliens

Station

Az összes állomásterminált kiválasztja, például: TecZone, MetaCAM, RightAngle (hajlításvezérlő), Vulcan (lézergép-vezérlő)

Custom

A felhasználó választása szerint választ.

  • Válassza a Full telepítést. Válassza ki a Code Senders és Bend Code Senders elemeket a TruSmartCAM Tools közül. A telepítés típusa most Custom értékre változik. Kattintson a Next gombra.

3. lépés: Az SQL Server telepítésének kiválasztása

Az SQL Express 2022 telepítésére csak a TruSmartCAM kiszolgálóhoz van szükség. Ez a lehetőség a kliens- és szinkronizálási telepítéseknél nem érhető el. Ez az első alkalommal be van kapcsolva és telepítésre kerül, azt követően figyelmen kívül hagyható. Ha az SQL már telepítve van a TruSmartCAM kiszolgálón, a felhasználó kihagyhatja a 3. lépést.

  • A Select Additional Tasks lapon: kattintson az Install SQL Express lehetőségre, majd kattintson a Next gombra.

  • A Ready to Install lapon: összegzi az összes telepítési funkciót, majd kattintson az Install gombra.

4. lépés: Az SQL Server telepítése

A TruSmartCAM összetevők telepítése után a telepítő folytatja az SQL Server telepítését. Fogadja el a licencszerződést a folytatáshoz, és telepítse az SQL Expresst az alapértelmezett beállításokkal.

A telepítés befejezése után kattintson a Close gombra, és fejezze be a telepítést.

A Windows verziójától függően az SQL telepítés bezárása újraindítást kérhet.

5. lépés: Windows asztali parancsikonok

  • Az SQL telepítése után, ha a rendszer nem indul újra, jelölje be a Launch TruSmartCAM jelölőnégyzetet, majd kattintson a Finish gombra.

  • Ha a rendszer újraindul, indítsa el a TruSmartCAM parancsikont az asztalon, vagy írja be a TruSmartCAM nevet a Windows Start menübe, és válassza a Run as administrator lehetőséget.

Kiszolgálótelepítés: a TruSmartCAM és a TruSmartCAM License parancsikonok elérhetők az asztalon.
Kliens/SYNC telepítés: csak a TruSmartCAM parancsikon érhető el az asztalon.

6. lépés: Licencregisztráció

  • A Serial Number mezőbe írja be a Trumpf Metamation szervizcsapata által megadott TruSmartCAM sorozatkulcsot. Írja be a <Company Name> értéket a "Registered to" mezőbe és az e-mail címet. Kattintson az OK gombra.

Ha a hálózati tűzfal blokkolja a licencregisztrációt, vagy nincs internet a TruSmartCAM kiszolgáló PC-n, akkor a TruSmartCAM licenc offline aktiválással történik. Küldje el e-mailben a Prax.request fájlt a C:\ProgramData\TRUMPF\TMM\Praxis mappából a Trumpf Metamation szervizcsapatának. A Trumpf Metamation csapata biztosítja a Prax.lock fájlt, amelyet ebbe a mappába kell helyezni.

7. lépés: Kezdeti egyszeri konfiguráció

  • Írja be az adatbázis nevét, és állítsa be az adattárolási helyet. Jelölje be a Use SQL Server jelölőnégyzetet, és válassza ki az SQL Server nevét az adatbázishoz való csatlakozáshoz. Kattintson az OK gombra.

  • A TruSmartCAM asztali kliens megnyílik, és az alsó részen a Database Connection Succeeded üzenetet jeleníti meg.

  • A TruSmartCAM, TecZone és MetaCAM konfigurációs fájlok az alapértelmezett konfigurációs gépekkel vagy a TruSmartCAM licencgépekkel jöttek létre. Ugyanaz a konfiguráció lesz megosztva az összes TruSmartCAM kliens között.

Az üdvözlőképernyő a Windows felhasználói bejelentkezési nevet jeleníti meg a TruSmartCAM bejelentkezési neveként és neveként. Az első TruSmartCAM felhasználó Site Admin jogosultságúnak számít. Adja meg az e-mail címet és a jelszót. Kattintson az OK gombra .

Jelölje be az Remember me jelölőnégyzetet a bejelentkezési adatok legközelebbi mentéséhez. Az Remember me jelölőnégyzet törlése esetén a TruSmartCAM alkalmazás minden indításakor megjelenik a bejelentkezési és jelszó párbeszédpanel.

8. lépés: Bejelentkezés a TruSmartCAM alkalmazásba

  • Zárja be a TruSmartCAM alkalmazást, majd nyissa meg újra. A rendszer kéri a TruSmartCAM bejelentkezési adatainak megadását.

  • A bejelentkezett felhasználónév a TruSmartCAM alkalmazás fejlécében a felhasználó ikon mellett jelenik meg.

  • Amikor a felhasználó ikon fölé viszi az egérmutatót, a rendszer a következőket jeleníti meg:

    • A felhasználó szerepköre (például: Programmer, Admin).

    • Kijelentkezési gyorsbillentyű: Ctrl+L.

  • A felhasználó ikonra kattintva megnyílik egy menü, amely lehetővé teszi a következőket:

    • Edit information…​ - A profiladatok frissítése.

    • Change password…​ - A fiók jelszavának módosítása.

    • Sign out - Kijelentkezés az alkalmazásból.

    • Cancel - A menü bezárása módosítások nélkül.

9. lépés: Gyári gépkonfiguráció

  • TruSmartCAM licenc [Az összes gépet engedélyező licencbit]: az alapértelmezett TruSmartCAM gép és anyag számít gyári konfigurációnak.

  • TruSmartCAM licenc [Nincs demó, és csak néhány gépbit engedélyezve]: az a néhány gép és az alapértelmezett anyag számít gyári konfigurációnak.

  • (Open → Import) importáljon egy új alkatrészt a C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts mappából, és ellenőrizze, hogy az alkatrész sikeresen importálódott-e.

  • TruSmartCAM Monitor Engine-telepítéssel (Site admin jogosultságok):

    • A TruSmartCAM Monitor Engine-nel és Site Admin TruSmartCAM jogosultságokkal a következő lehetőségekkel rendelkezik:

      1. A TruSmartCAM, TecZone, MetaCAM konfiguráció leküldése az összes TruSmartCAM kliensre. Jogosultsága van új TruSmartCAM felhasználói bejelentkezés létrehozására is.

      2. A Show Agents megjeleníti az automatizálási feladatokhoz rendelkezésre álló összes engine-t, amely a TruSmartCAM licenchez tartozik.

  • TruSmartCAM Monitor Engine-telepítés nélkül (Site admin jogosultságok):

  • TruSmartCAM Monitor Engine-telepítés nélkül (nem Site Admin jogosultságok):

A TruSmartCAM alkalmazást futtató PC-n telepítve kell lennie az Engine TruSmartCAM összetevőnek [a kiszolgáló PC-n vagy bármely kliens telepítésében]. Az Engine TruSmartCAM összetevővel telepített PC-nek a nap 24 órájában, a hét minden napján futnia kell az összes automatizálási feladat elvégzéséhez.
2. megjegyzés: OpenGL

  • A TruSmartCAM alkalmazás megnyitáskor azonnal bezárul, és a pmonitor sem jelenik meg a tálcán.

  • Ez OpenGL-problémát jelez.

  • Ennek ellenőrzésének másik módja: nyissa meg a C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts fájlt, amely hibaüzenetet jelenít meg az OpenGL-problémáról.

  • Frissítse a C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini fájl options szakaszát a GLVersion=1 beállítással, hogy a TruSmartCAM alkalmazás sikeresen megnyíljon.

[Options]
GLVersion=1.0
