Portkövetelmények

TruSmartCAM Server : 7371

A kiszolgáló ezen a TCP-porton várja a kliens kéréseit. A bejövő kapcsolatokat engedélyezni kell erre a portra a kiszolgálógépen.

Floating License Server : 5776

A Floating License Server ezen a porton várja a licenckéréseket. A bejövő kapcsolatokat engedélyezni kell erre a portra a floating license server gépen (a TruSmartCAM Server).

Licenckapcsolat a felhőhöz : 7567

Ezt a portot a TecZone (hajlítószoftver) és a Floating License Server használja a licenckérések Metamation Cloudba küldéséhez. Ezért a kimenő kapcsolatot engedélyezni kell ezen a porton a licencaktiválásokhoz és -megújításokhoz.

Telepítési és támogatási követelmények

  • A TruSmartCAM alkalmazás telepítéséhez rendszergazdai jogosultságok szükségesek.

  • Távoli diagnosztikai eszközök a vállalkozói VPN-en vagy biztonságos kapcsolaton keresztül.
