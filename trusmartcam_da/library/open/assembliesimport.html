Importer monteringer

Monteringer er grupper af relaterede dele kombineret til en enkelt enhed, hvilket giver dig mulighed for at håndtere flere dele sammen som én enhed.

Du kan importere monteringer ved hjælp af følgende metoder:

  1. Importer via fil

  2. Træk og slip

  3. Importer fra regneark

Importer via fil

En montering kan importeres til Part Library ved hjælp af Import Assemblies…​-muligheden.

  • Klik på Open-ikonet i kommandolinjen og vælg Import Assemblies…​, eller brug File → Open → Import Assemblies…​.

  • Open-dialogen vises. Vælg den eller de ønskede monteringsfil(er).

  • Et eksempel på den valgte montering vises.

  • Klik på Open for at importere monteringen.

  • Importerede monteringer vises under Assemblies-visningen i Part Library.

Træk og slip

  • Træk og slip en montering direkte ind i TruSmartCAM Part Library.

Importer fra regneark

  • Brug File → Open → Import Assemblies…​ og vælg en CSV-, XLSX- eller XML-fil, eller træk og slip filen.

  • Gennemgå og opdater monteringsdetaljer og -mængder før import. Brug Add…​ eller Remove…​ til at ændre.

  • Efter import kan monteringer forberedes og tildeles Static Nests.
