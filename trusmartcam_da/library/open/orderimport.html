Importer opgaver

Opgaver kan oprettes eller importeres ved hjælp af følgende metoder:

  1. Importere opgaver fra regnearksfiler.

  2. Importere opgaver automatisk via overvågningsindstillinger.

  3. Oprette opgaver fra eksisterende dele i delbiblioteket.

  4. Oprette opgaver fra statiske monteringsindlejringer.

Importer opgaver fra regneark

  • Naviger til Open → Import Orders…​.

  • Understøttede regnearksformater omfatter CSV, XLSX og XML.

  • Vælg den ønskede regnearksfil og klik på Open.

  • Importprocessen ligner arbejdsgangen for job-/monteringsimport.

Du kan også direkte trække og slippe regnearket ind på Orders-siden for at importere opgaver.

Importer opgaver ved hjælp af overvågningsindstillinger

  • Aktiver Import spreadsheet from 'Live Folder'-muligheden i Watch settings.

  • Vælg Import Orders i Spreadsheet import option.

  • Konfigurer mappeplaceringen, hvorfra opgaver skal importeres.

  • Systemet overvåger løbende den konfigurerede mappe.

  • Nyligt tilføjede regnearksfiler importeres automatisk til Orders.

For detaljerede konfigurationstrin, se Overvågningsindstillinger- dokumentationen.

Opret opgaver fra delbiblioteket

  • Vælg de ønskede dele fra Part Library.

  • Højreklik og vælg New…​ → Order for at åbne New Orders-dialogen.

  • Angiv de nødvendige detaljer såsom mængde, afleveringsdato og prioritet.

  • Klik på OK for at oprette opgaverne.

  • Systemet skifter automatisk til Orders-siden.

  • Oprettede opgaver vises på Orders Ready-siden til joboprettelse.

Opret opgaver fra montering

  • Højreklik på den ønskede montering.

  • Vælg New…​ → Order for at åbne New Orders-dialogen.

  • Angiv det nødvendige Assembly count.

  • Klik på OK for at oprette opgaverne.
