Kræver en standardbrugerkonto
En standardbrugerkonto er nødvendig for at TruSmartCAM Server kan køre som tjeneste i Task Manager, og for at Monitor kan køre. Den skal indstilles til auto-login- tilstand.

Portkrav

TruSmartCAM Server : 7371

Serveren venter på klientanmodninger på denne TCP-port. Indkommende forbindelser bør tillades til denne port på servercomputeren.

Floating License Server : 5776

Floating License Server venter på licensanmodninger på denne port. Indkommende forbindelser bør tillades til denne port på floating license server- computeren (TruSmartCAM Server).

Licensforbindelse til Cloud : 7567

Denne port bruges af TecZone (Bending Software) og Floating License Server til at sende licensanmodninger til Metamation Cloud. Så udgående forbindelse bør tillades på denne port til licensaktiveringer og -fornyelser.

Installations- og supportkrav

  • Administratorrettigheder kræves for at installere TruSmartCAM-applikationen.

  • Fjerndiagnosticeringsværktøjer via Contractor VPN eller en sikker forbindelse.
