Serverinstallation

Følg instruktionerne for at installere TruSmartCAM Server-installation sammen med SQL.

Administratorrettigheder

For at udføre denne installation skal brugeren have administratorrettigheder.

  • Kør Setup.TruSmartCAM.<version>.exe for at begynde installationen.

Version er et tal.

  • Læs licensaftalen, vælg I accept the agreement, og klik derefter på Next.

Trin 1 : Installationsplacering

  • Angiv installationsmappen, eller acceptér installationens standard C:\Program Files\TRUMPF\TMM\Praxis, og klik på Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Installationsmappen vil indeholde følgende mapper: Bin, MetaCAM, Samples og Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Datamappen vil indeholde følgende mapper: TruSmartCAM, TecZone og MetaCAM.

Trin 2 : Komponentvalg

Installationstype Komponenter

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Vælger alle Stations Terminal som TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Vælger efter brugerens valg.

  • Vælg Full Installation. Vælg Code Senders og Bend Code Senders fra TruSmartCAM Tools. Nu ændres installationstypen til Custom. Klik på Next.

Trin 3 : Vælg installation af SQL Server

Installation af SQL Express 2022 er kun nødvendig for TruSmartCAM Server. Denne mulighed er ikke tilgængelig for Client- og Sync-installationer. Desuden er dette sat til ON og installeres første gang og kan ignoreres derefter. Hvis SQL allerede er installeret på TruSmartCAM-serveren, kan brugeren ignorere Step 3.

  • I Select Additional Tasks: Klik på Install SQL Express, og klik på Next.

  • I Ready to Install: Opsummer alle installationsfunktioner, og klik på Install.

Trin 4 : SQL Server-installation

Når TruSmartCAM-komponenterne er installeret, fortsætter installationsprogrammet med SQL- serverinstallationen. Acceptér licensaftalen for at fortsætte, og installer SQL express med standardindstillingerne.

Når installationen er fuldført, klik på Close, og fuldfør installationen.

Afhængigt af Windows-versionen kan lukning af SQL-installationen kræve en genstart.

Trin 5 : Windows skrivebordsgenveje

  • Hvis systemet ikke genstarter efter SQL-installationen, så vælg Launch TruSmartCAM- afkrydsningsfeltet, og klik på Finish.

  • Hvis systemet genstarter, så start TruSmartCAM via genvejsikonet på skrivebordet, eller skriv TruSmartCAM i Windows Start Program, og Run as administrator.

Server installation : Genvejsikoner for TruSmartCAM og TruSmartCAM License er tilgængelige på skrivebordet.
Client/SYNC Installation : Kun TruSmartCAM-genvejsikonet er tilgængeligt på skrivebordet.

Trin 6 : Licensregistrering

  • I feltet Serial Number skal du skrive den TruSmartCAM Serial key, der er leveret af Trumpf Metamation Service Team. Skriv <Company Name> i feltet "Registered to" og E-Mail. Klik på OK.

Hvis netværksfirewallen blokerer licensregistreringen, eller der ikke er internet på TruSmartCAM-server-pc’en, så udføres TruSmartCAM-licensen via offline-aktivering. E-mail Prax.request fra mappen C:\ProgramData\TRUMPF\TMM\Praxis til Trumpf Metamation Service Team. Trumpf Metamation-teamet vil levere Prax.lock, som skal lægges i denne mappe.

Trin 7 : Indledende engangskonfiguration

  • Skriv Database Name, og angiv Data Storage Location. Vælg Use SQL Server-afkrydsningsfeltet, og vælg SQL-servernavnet for at oprette forbindelse til databasen. Klik på OK.

  • TruSmartCAM Desktop Client åbnes og viser Database Connection Succeeded i nederste hjørne.

  • Konfigurationsfiler for TruSmartCAM, TecZone og MetaCAM blev oprettet med standard-konfigurations- maskiner eller mod TruSmartCAM-licensmaskiner. Den samme konfiguration deles på tværs af alle TruSmartCAM-klienter.

Velkomstskærmen vises med Windows-brugerens LoginName som TruSmartCAM-login og navn. Den første TruSmartCAM-bruger betragtes som Site Admin. Angiv Email og Password. Klik på OK .

Vælg Remember me- afkrydsningsfeltet for at gemme login-oplysningerne til næste gang. Rydning af Remember me-afkrydsningsfeltet vil bede om login- og password-dialog, hver gang TruSmartCAM-applikationen startes.

Trin 8 : TruSmartCAM-login

  • Luk TruSmartCAM, og genåbn det. Systemet beder dig om at indtaste TruSmartCAM- loginoplysningerne.

  • Det indloggede brugernavn vises ved siden af brugerikonet i TruSmartCAM- applikationens header.

  • Når du holder musen over brugerikonet, viser systemet:

    • Brugerrollen (for eksempel: Programmer, Admin).

    • En genvej til at logge ud: Ctrl+L.

  • Klik på brugerikonet åbner en menu, der giver dig mulighed for at:

    • Edit information…​ - Opdater dine profiloplysninger.

    • Change password…​ - Ændr dit konto- password.

    • Sign out - Log ud af applikationen.

    • Cancel - Luk menuen uden at foretage ændringer.

Trin 9 : Fabriksmaskinkonfiguration

  • TruSmartCAM License [All machines enables license bit]: Standard-TruSmartCAM-maskine og -materiale betragtes som Factory Configuration.

  • TruSmartCAM License [No demo and few machine bit enabled]: Disse få maskiner og standardmateriale betragtes som Factory Configuration.

  • (Open → Import) en ny del fra C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts og verificér, om delen er importeret med succes.

Bemærkning 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor med Engine-installation (Site admin-rettigheder):

    • TruSmartCAM Monitor med Engine sammen med Site Admin-TruSmartCAM-rettigheder vil have følgende muligheder:

      1. Push TruSmartCAM-konfiguration, TecZone-, MetaCAM-konfiguration på tværs af alle TruSmartCAM- klienter. Har også rettigheder til at oprette New TruSmartCAM User Login.

      2. Show Agents viser den samlede engine, der er tilgængelig til at udføre automatiseringsopgaver, som er mod TruSmartCAM-licensen.

  • TruSmartCAM Monitor uden Engine-installation (Site admin-rettigheder):

  • TruSmartCAM Monitor uden Engine-installation (ikke Site Admin-rettigheder):

PC’en, der kører TruSmartCAM-applikationen, skal have Engine-TruSmartCAM-komponenten installeret [Server-pc eller i en Client-installation]. Pc’en med Engine-TruSmartCAM-komponenten installeret bør køre 24x7 for at udføre alle automatiseringsopgaver.
Note 2 : OpenGL

  • TruSmartCAM-applikationen lukker straks under åbning, og desuden vises pmonitor ikke på proceslinjen.

  • Dette repræsenterer et OpenGl-problem.

  • En anden måde at bekræfte dette på: Åbn C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts som viser en fejldialog om OpenGL-problemet.

  • Opdater C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , options-sektionen med GLVersion=1 gør, at TruSmartCAM-applikationen åbner med succes.

[Options]
GLVersion=1.0
