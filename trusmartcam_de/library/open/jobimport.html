Jobs importieren

Import aus CSV oder XLSX

Sie können Jobs auch in gängigen Textformaten importieren.

  • Klicken Sie auf File → Open → Import Jobs. Der Dialog Open Folder wird angezeigt. Wählen Sie C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Wenn alle Teile am CSV-Speicherort oder in den Nachschlage-Ordnerverzeichnissen vorhanden sind, wird das Fenster new job angezeigt, in dem alle Teile aufgelistet sind, die mit den CSV-Feldern übereinstimmen.

  • Fehlende Teile werden ignoriert und erscheinen nicht im Fenster new job.

  • Anfänglich lautet der Teilestatus Nascent.

  • Klicken Sie auf OK; nun werden die Teile in die Teilebibliothek importiert.

Create a blank part for the missing CAD files

Beim Importieren von Jobs mithilfe einer Tabellenkalkulation (.csv oder .xlsx) kann es vorkommen, dass Zeilen auf CAD-Dateien verweisen, die im System nicht verfügbar sind.

  • Um dies zu handhaben, gehen Sie zu Factory → Settings → Job und aktivieren Sie unter Spreadsheet import settings die Option Create a blank part for the missing CAD files.

Wenn diese Option ausgewählt ist:

  • Wenn für eine Zeile während des Jobimports eine CAD-Datei fehlt, erstellt das System automatisch ein leeres Teil anstelle der fehlenden CAD-Datei.

  • Im Fenster new job werden diese fehlenden Teile visuell gelb hervorgehoben, um anzuzeigen, dass die zugehörige CAD-Datei fehlt.

  • Das fehlende Teil verfügt weiterhin über seine zugeordneten Felder (wie Teilename, Material, Dicke, Menge usw.) aus der CSV. Sein Teilestatus wird jedoch als Nascent angezeigt, was bedeutet, dass es sich lediglich um einen leeren Platzhalter ohne tatsächliche Geometrie handelt.

Dies stellt sicher, dass der Jobimport trotz fehlender CAD-Dateien fehlerfrei fortgesetzt werden kann – Sie können das leere Teil später aktualisieren oder durch die korrekte CAD-Datei ersetzen, sobald diese verfügbar ist.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Wenn dieses Kontrollkästchen aktiviert ist, erstellt das System den neuen Job automatisch, ohne den Dialog New Job anzuzeigen, sofern die Tabellenkalkulation keine Fehler aufweist (keine fehlenden Teile, fehlenden Datumsangaben oder ungültigen Daten).

  • Wenn dieses Kontrollkästchen deaktiviert ist, wird der Dialog New Job immer zur Überprüfung und Bestätigung durch den Benutzer angezeigt, auch wenn die Tabellenkalkulation keine Fehler aufweist.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Wenn dieses Kontrollkästchen aktiviert ist, erwartet das System, dass die Tabellenkalkulation die Spalte Raw-Material verwendet (zum Beispiel Steel-20). Dies bedeutet, dass Materialtyp und Dicke in einem einzigen Wert in einer Spalte kombiniert werden sollten.

  • Wenn dieses Kontrollkästchen deaktiviert ist, erwartet das System, dass die Tabellenkalkulation separate Spalten für Material und Dicke enthält (zum Beispiel Steel und 2.00). Das System kombiniert sie intern während des Imports.

Überwachungsordner mit CSV/XLSX

  • Aktivieren Sie in factory → Settings→ Watch settings die Optionen Enable 'Live Folder' und Watch sub-folders also.

  • Legen Sie den Pfad des Überwachungsordners fest (UNC oder zugeordnetes Laufwerk).

  • Aktivieren Sie in Spreadsheet import settings die Option Import spreadsheet from 'Live Folder'.

  • Wählen Sie Import Jobs aus den Spreadsheet-Import-Optionen aus.

  • Kopieren Sie C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv und fügen Sie es in den Überwachungsordner ein.

  • Das System überprüft die CSV und versucht, den Job automatisch zu erstellen.

  • Wenn die CAD-Datei fehlt, wird kein Job erstellt, da die erforderlichen CAD-Daten nicht gefunden werden.

CAD-Nachschlageverzeichnis & rekursive CAD-Suche – nicht konfiguriert

  • Wenn in factory → Settings → Job → Spreadsheet import settings kein CAD lookup directories festgelegt ist und Use recursive CAD search nicht verwendet wird, sucht das System nicht automatisch nach CAD-Dateien.

  • Wenn das Kontrollkästchen Create a blank part for the missing CAD files aktiviert ist, wird der Job auch dann erstellt, wenn CAD-Dateien fehlen.

  • In diesem Fall werden alle Teile im Job als nascent (leere) Teile erstellt – das heißt, sie haben keine Geometrie, da die CAD-Dateien nicht gefunden werden konnten.

CAD-Nachschlageverzeichnis & rekursive CAD-Suche – konfiguriert

Wenn CAD lookup directories auf (C:\Program Files\TRUMPF\TMM\Praxis\Samples) festgelegt ist und Use recursive CAD search unter factory → Settings → Job → Spreadsheet import settings aktiviert ist:

  • Das System durchsucht den angegebenen Ordner und alle seine Unterordner automatisch nach den in der Tabellenkalkulation genannten erforderlichen CAD-Dateien.

  • Create a blank part for the missing CAD files ist ebenfalls aktiviert, sodass das System, falls eine CAD-Datei weiterhin nicht gefunden wird, ein leeres Teil als Platzhalter erstellt.
