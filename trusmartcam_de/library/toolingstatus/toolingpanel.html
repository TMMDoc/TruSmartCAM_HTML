Werkzeugpanel

Dieser Abschnitt erläutert werkzeugbezogene Aktionen wie Export outputs, Check Tooling, Suppress Tooling, Set as Base-Flat…​, Copy Tooling und andere Optionen zur Verwaltung von Werkzeuginstanzen.

Open in read-only mode for viewing
Öffnet das ausgewählte Werkzeug im schreibgeschützten Modus.

Check-out the document for editing
Ermöglicht die Bearbeitung des ausgewählten Werkzeugs.

Export Outputs

Exportiert die ausgewählte Werkzeugausgabe an das konfigurierte Ziel.

Check Tooling

Validiert die vorhandene Bewerkzeugung, ohne Änderungen vorzunehmen, und aktualisiert ihren Status, wenn die Validierung fehlschlägt.

Copy Tooling…​

Kopiert die Stempel-, Sequenz- und Hinteranschlageinrichtung aus der ausgewählten Referenzbewerkzeugung und wendet sie nach Möglichkeit auf andere Lösungen an.

Set as Base-Flat…​

Markiert die ausgewählte Biege- oder Faltbewerkzeugung als Referenz-Abwicklungsgröße zur Generierung von Schneidlösungen.

Re-tool…​

Verarbeitet die ausgewählte Bewerkzeugung für das Teil erneut, ohne andere Bewerkzeugungen zu beeinflussen.

Suppress Tooling

Unterdrückt die ausgewählte Bewerkzeugung, sodass sie von der weiteren Verarbeitung und Ausgabegenerierung ausgeschlossen wird.

Prev / Next / Part

Navigiert zur vorherigen oder nächsten Bewerkzeugung oder zurück zum übergeordneten Teil.

Sortieren und filtern

Zeigt andere Bewerkzeugungen an, die ähnliche Eigenschaften wie die ausgewählte Bewerkzeugung aufweisen, zur schnellen Referenz.

Export Outputs

Diese Option exportiert die Teileausgabe an das in Factory Settings konfigurierte Ziel. (Siehe Biegeeinstellungen und Schneideinstellungen)

Es werden nur die mit dem ausgewählten Bewerkzeugungsvorgang verbundenen Werkzeuge exportiert, nicht das gesamte Teil.

Die exportierten Dateien hängen vom Vorgangstyp ab. Für Biege- und Faltvorgänge werden NC-Dateien und Berichte generiert. Für Schneid- und Stanzvorgänge werden nur die Teiledateien exportiert.

Check Tooling

  • Wenn sich die CAM-Einstellungen ändern oder ein Biegewerkzeug verloren geht, müssen Sie das Teil nicht erneut bewerkzeugen.

  • Verwenden Sie stattdessen Check Tooling, um die vorhandene Bewerkzeugung zu validieren, ohne Änderungen vorzunehmen.

  • Wenn die Validierung fehlschlägt, wird der Werkzeugstatus dieser Instanz aktualisiert und die zugehörigen Ausgabedateien werden entfernt.

  • Check Tooling erkennt auch Teile, bei denen Fehler zuvor manuell mit Ignore Errors überschrieben wurden, und aktualisiert bei Bedarf ihren Status auf Fehler.

Copy tooling

Mit Copy Tooling können Sie die Biegebewerkzeugung schnell von einer Lösung auf andere anwenden, was Zeit und Aufwand spart.

Dies kopiert die Stempel-, Sequenz- und Hinteranschlageinrichtung aus einer ausgewählten Referenzbewerkzeugung (Lösung) und versucht, dieselben Einstellungen auf alle anderen Lösungen anzuwenden.

  • Wenn die kopierte Einrichtung für eine Zielmaschine machbar ist, wird sie gespeichert und verwendet.

  • Wenn die Einrichtung nicht machbar ist, bleibt die ursprüngliche Bewerkzeugung für diese Maschine unverändert.

Zum Beispiel können Sie für verschiedene Maschinen unterschiedliche Bewerkzeugungen haben:

  • Hier verwendet Maschine 5230X 4A einen Schwanenhals-Stempel, Maschine 5230SX 6A verwendet einen spitzen Stempel.

Wenn Sie Copy Tooling…​ auf Maschine 5230X 4A verwenden, versucht es, die Schwanenhals-Einrichtung auf alle anderen Maschinen zu kopieren.

Dieselben Stempel-, Sequenz- und Hinteranschlageinstellungen werden nach Möglichkeit angewendet. Wenn die kopierte Einrichtung nicht verwendet werden kann, bleibt die ursprüngliche Bewerkzeugung unverändert.

Nach dem Anwenden von Copy Tooling wurde die Schwanenhals-Einrichtung erfolgreich auf alle anderen Maschinen angewendet, wo dies machbar ist.

Set as Base-Flat…​

Die Funktion Set as Base-Flat…​ definiert, welche Biege- oder Faltbewerkzeugung als Referenz-Abwicklungsgröße zur Generierung von Schneidlösungen verwendet wird. Wenn eine Bewerkzeugung als Base-Flat markiert ist, aktualisiert TruSmartCAM die Abwicklungsgröße des Teils basierend auf dieser Maschine und generiert die Schneidlösungen entsprechend neu. Base-Flat- Bewerkzeugungen werden in der Benutzeroberfläche mit einem blauen Rahmen dargestellt.

Unterschiedliche Biegemaschinen können für dasselbe Teil geringfügige Abweichungen in der Abwicklungsgröße erzeugen. Wenn Sie eine Bewerkzeugung als Base-Flat festlegen, verwendet TruSmartCAM die Abwicklungsgröße dieser Maschine als Masterreferenz und berechnet die Schneidlösungen automatisch neu.

Automatische Base-Flat-Auswahl

Wenn die Werkseinstellung Apply flat correction during bending aktiviert ist:

  • Legt TruSmartCAM automatisch die Biegebewerkzeugung (die die Tabelle der maximalen Biegelänge enthält) während des Teileimports als Base-Flat fest.

  • Wenn die ausgewählte Biegebewerkzeugung auf einen Fehler stößt oder nicht machbar ist, wechselt TruSmartCAM intelligent und legt eine andere gültige Biegebewerkzeugung als Base-Flat fest. Dadurch bleiben die Abwicklungsgrößen- Referenz und die Schneidlösungen ohne manuellen Eingriff stets konsistent und gültig.

Erweiterte Base-Flat-Verwaltung

TruSmartCAM bietet Base-Flat-Optionen im Dialog Save to Praxis, wenn Bearbeitungen der Biege- oder Faltbewerkzeugung gespeichert werden. Diese Optionen erscheinen nur für Bewerkzeugungen im Status OK und stellen sicher, dass Abwicklungsgröße und Schneidlösungen korrekt bleiben.

Set as Base-Flat and calculate cutting solution

Diese Option wird verwendet, um eine Bewerkzeugung zum ersten Mal als Base-Flat zu markieren und automatisch die entsprechende Schneidlösung zu generieren.

Erscheint, wenn:

  • Die Bewerkzeugung derzeit nicht als Base-Flat markiert ist.

  • Der Benutzer die Bewerkzeugung zur Bearbeitung ausgecheckt hat und die Änderungen speichert.

Um diese Option zu verwenden, checken Sie die Biege- oder Faltbewerkzeugung aus und nehmen Sie die erforderlichen Änderungen vor, z. B. Änderungen an Biegeparametern oder der Abwicklungsgröße. Drücken Sie Ctrl+S, um die Änderungen zu speichern. Wählen Sie im Dialog Save to Praxis die Option Set as Base-Flat and calculate cutting solution und klicken Sie auf OK. TruSmartCAM legt die Bewerkzeugung als Base-Flat fest und generiert die Schneidlösung anhand der aktualisierten Abwicklungsgröße.

Update the base-flat and re-calculate cutting solution

Diese Option wird verwendet, wenn die Bewerkzeugung bereits als Base-Flat markiert ist und bearbeitet wurde, sodass die Abwicklungsgröße und die Schneidlösungen neu generiert werden müssen.

Erscheint, wenn:

  • Die Bewerkzeugung bereits als Base-Flat markiert ist.

  • Der Benutzer sie ausgecheckt, bearbeitet und die Änderungen speichert.

Aktualisieren Sie beim Bearbeiten der vorhandenen Base-Flat-Bewerkzeugung die Biegeparameter oder die Abwicklungsgrößengeometrie nach Bedarf. Wählen Sie im Dialog Save to Praxis die Option Update the base-flat and re-calculate cutting solution. TruSmartCAM aktualisiert dann die Base-Flat-Bewerkzeugung und generiert alle zugehörigen Schneidlösungen neu, um die neuesten Änderungen widerzuspiegeln.

Es kann jeweils nur eine Biegebewerkzeugung als Base-Flat festgelegt werden.

Wenn die Base-Flat geändert wird, werden vorhandene Schneidlösungen automatisch neu verarbeitet.

Diese Funktion ist für Biege- und Faltbewerkzeugungen innerhalb von TruSmartCAM verfügbar.

Re-tool

Diese Option verarbeitet die ausgewählte Bewerkzeugung für das Teil erneut.

Klicken Sie mit der rechten Maustaste auf die erforderliche Bewerkzeugung im Werkzeugpanel und klicken Sie auf Re-tool…​

Vor dem Fortfahren wird ein Bestätigungsdialog angezeigt.

Klicken Sie auf Yes, um mit der erneuten Bewerkzeugung fortzufahren, oder auf No, um den Vorgang abzubrechen.

Nur die ausgewählte Bewerkzeugung wird erneut bewerkzeugt. Andere mit dem Teil verbundene Bewerkzeugungen sind nicht betroffen. Die vorhandenen Ausgaben, die sich auf die ausgewählte Bewerkzeugung beziehen, werden während des erneuten Bewerkzeugungsprozesses entfernt und neu generiert.

Verwenden Sie diese Option, wenn Werkzeugdaten veraltet oder falsch sind oder wenn Änderungen an Maschinen- oder Werkzeugkonfigurationen vorgenommen werden.

Ignore errors

  • Wenn eine bewerkzeugte Instanz eine Warnung anzeigt und Sie dennoch damit fortfahren möchten, können Sie die Warnung überschreiben, indem Sie auf Ignore errors klicken.

  • Dadurch kann das System Ausgabedateien für diese Instanz exportieren, auch wenn es Bewerkzeugungsprobleme gab.

Verwenden Sie Ignore Errors nur, wenn Sie sicher sind, dass die Warnung gefahrlos ignoriert werden kann. Das Überschreiben tatsächlicher Fehler kann zu Maschinenschäden oder Sicherheitsrisiken führen.

Bewerkzeugung unterdrücken/aufheben

  • Wenn eine Maschine inaktiv ist oder Sie nicht möchten, dass ein bestimmtes Teil von einer bestimmten Maschine verarbeitet wird, verwenden Sie Suppress Tooling, um dieses Teil vom Schachteln auf dieser Maschine auszuschließen.

  • Nach dem Unterdrücken zeigt das Bewegen der Maus über die bewerkzeugte Instanz eine Meldung wie: „Tooling suppressed by <User name> on <Date Time>“.

  • Das Unterdrücken der Bewerkzeugung entfernt die Ausgabedatei für diese Maschine und dieses Teil.

  • Verwenden Sie Unsuppress tooling, um den Werkzeugstatus für das Teil auf dieser Maschine wiederherzustellen.

  • Beim Aufheben der Unterdrückung wird die entsprechende Ausgabedatei erneut generiert.
