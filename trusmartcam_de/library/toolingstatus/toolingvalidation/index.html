Werkzeugvalidierung

Dieser Abschnitt beschreibt, wie Sie in TruSmartCAM auf die Werkzeuginformationen für Teile zugreifen und diese ändern.

  • Klicken Sie mit der rechten Maustaste auf eine beliebige Teilekachel, um das Teilepanel zu öffnen und auf die Werkzeugoptionen zuzugreifen.

  • Klicken Sie auf Toolings, um zur ersten verfügbaren bewerkzeugten Instanz zu wechseln.

  • Alternativ können Sie direkt auf eine bewerkzeugte Instanz klicken, um Maschinendetails und Werkzeugoptionen anzuzeigen.

  • Verwenden Sie , um Open in read-only mode for viewing.

  • Verwenden Sie , um Check-out the document for editing.

  • Die ausgewählte bewerkzeugte Instanz wird in TecZone oder MetaCAM geöffnet.

  • Führen Sie manuelle Werkzeugprüfungen durch und nehmen Sie die notwendigen Änderungen vor.

  • Wenn Sie versuchen zu speichern, fordert ein Dialog Unsaved Changes Sie auf, Ihre Bearbeitungen zu bestätigen.

  • Klicken Sie auf Yes, um mit dem Speichern fortzufahren.

  • Das System führt nach dem Speichern erneut eine Werkzeugvalidierung durch.

  • Wenn keine Fehler vorliegen, erscheint die Option, Änderungen in TruSmartCAM zu speichern.

  • Wenn Werkzeugfehler gefunden werden, wird eine Fehlermeldung angezeigt:

  • Nach dem Speichern wird der Werkzeugstatus des Teils in der Teilebibliothek aktualisiert.

  • Eine grüne Farbe auf der bewerkzeugten Instanz zeigt an, dass sie eingecheckt ist.

  • Der Autor der bewerkzeugten Instanz wird auf die letzte Person aktualisiert, die sie bearbeitet hat.

  • Das Feld User-edited gibt an, ob die bewerkzeugte Instanz manuell geändert wurde. Wenn ein Benutzer die Instanz auscheckt und Änderungen vornimmt, wird dieses Feld beim Speichern automatisch auf Yes gesetzt.

  • Wenn ein Teil gerade bearbeitet wird, erscheint ein Benutzersymbol auf seiner Kachel.

  • Das Bewegen der Maus über die Kachel zeigt an, wer sie ausgecheckt hat und wann sie ausgecheckt wurde.

  • Während das Teil ausgecheckt ist, ist die Option Check-out the document for editing für dieselbe bewerkzeugte Instanz deaktiviert, und die Option Cancel Check-out wird aktiviert.
