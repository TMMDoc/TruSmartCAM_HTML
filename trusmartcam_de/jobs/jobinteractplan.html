Interaktives Schachteln

Interactive nesting kann verwendet werden, um einen Schachtelplan für ein einzelnes Teil, einige Teile aus einem Job, einen einzelnen Job oder mehrere Jobs zu erstellen. Es ermöglicht Ihnen, Maschinen und Materialien auszuwählen, Tafelparameter festzulegen und die Schachtelergebnisse interaktiv zu überprüfen.

Klicken Sie mit der rechten Maustaste auf ein Teil oder einen Job und wählen Sie die Option Plan Part…​/Plan Job…​ → Run Interactive Nesting…​.

  • Das Fenster Interactive Nesting wird geöffnet.

  • Standardmäßig wechselt das Interactive-Nesting-Fenster zur Seite Select Machine & Material.

  • Maschinen werden mit Farbbalken angezeigt, die die verfügbare Produktionslast anzeigen:

    • Grüner Balken: Geplante Stunden

    • Grauer Balken: Verfügbare Stunden (aus einer 8-Stunden-Schicht)

  • Unter jeder Maschine werden ausgewählte Teile mit ihrem Rohmaterial gruppiert (Teile/Gesamtmenge).

  • Wenn ein Teil keine gültige Werkzeuglösung für eine Maschine hat, werden dieses Teil und Material für die Verarbeitung auf einer bestimmten Maschine ignoriert.

  • Wenn ein Rohmaterial für eine Maschine ausgewählt ist, steht es für andere Maschinen nicht zur Verfügung.

  • Sobald der Maschinenschachtelplan festgelegt ist, wählen Sie die bevorzugte Tafel aus und überschreiben Sie Tafelparameter wie Priority, Quantity, Margins usw.

  • Sie können Tafeln filtern, um All Sheets, Standard Sheets oder Remnant Sheets anzuzeigen. Klicken Sie auf Next.

Es ist nicht möglich, die Mengen in dieser Phase zu erhöhen. Sie können sie entweder gleich der Tafelbestandsmenge halten oder verringern und die Schachtelergebnisse prüfen.

  • Update Qty erscheint im Interactive-Nesting-Planfenster.

  • Standardmäßig schließt Pick All (F5) alle Teile für das Schachteln ein, oder Sie können manuell Prioritätsteile auswählen und Teilemengen anpassen. Klicken Sie auf Next.

  • Das Schachteln beginnt, und in der Tafel geschachtelte Teile werden mit blauem Farbstatus aktualisiert.

  • Die Produktionslast der Maschine wird basierend auf dem Schachtelergebnis aktualisiert.

  • Die geschachtelten Layouts werden maßstabsgetreu gezeichnet und im Register Nest Results angezeigt.

  • Wenn einige Teile ungeschachtelt bleiben, erscheint die Meldung Some parts remain unnested – diese Teile verbleiben im ursprünglichen Job.

    • Der Grund für das Nichtschachteln kann sein, dass keine Tafel zum Schachteln verfügbar ist

  • Interaktive Schachtelergebnisse werden präfigiert unter: factory → settings → Job→ Nest settings, Interactive sheet-name prefix.

  • Die interaktiven Schachtellayouts werden mit dem Buchstaben L präfigiert.
