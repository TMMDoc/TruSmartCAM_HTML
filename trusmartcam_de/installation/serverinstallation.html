Serverinstallation

Befolgen Sie die Anweisungen, um die TruSmartCAM-Serverinstallation zusammen mit SQL zu installieren.

Administratorrechte

Zur Ausführung dieser Installation muss der Benutzer über Administratorrechte verfügen.

  • Führen Sie Setup.TruSmartCAM.<version>.exe aus, um die Installation zu starten.

Die Version ist eine Nummer.

  • Lesen Sie die Lizenzvereinbarung, wählen Sie I accept the agreement und klicken Sie dann auf Next.

Schritt 1: Installationsort

  • Geben Sie das Installationsverzeichnis an oder übernehmen Sie den Standardpfad C:\Program Files\TRUMPF\TMM\Praxis und klicken Sie auf Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Der Installationsordner enthält folgende Ordner: Bin, MetaCAM, Samples und Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Der Datenordner enthält folgende Ordner: TruSmartCAM, TecZone und MetaCAM.

Schritt 2: Komponentenauswahl

Installationstyp Komponenten

Full

Server + Desktop-Client + Engine

Client

Desktop-Client

Server

Server + Desktop-Client

Station

Wählt alle Stationsterminals wie TecZone, MetaCAM, RightAngle (Biegesteuerung), Vulcan (Lasermaschinensteuerung)

Custom

Auswahl nach Benutzerwunsch.

  • Wählen Sie die Vollinstallation. Wählen Sie Code Senders und Bend Code Senders aus den TruSmartCAM-Tools. Der Installationstyp ändert sich nun zu Custom. Klicken Sie auf Next.

Schritt 3: SQL Server-Installation auswählen

Die Installation von SQL Express 2022 ist nur für den TruSmartCAM-Server erforderlich. Diese Option ist für Client- und Sync-Installationen nicht verfügbar. Außerdem ist diese Option beim ersten Mal aktiviert und wird installiert und kann danach ignoriert werden. Wenn SQL bereits auf dem TruSmartCAM-Server installiert ist, kann der Benutzer Schritt 3 ignorieren.

  • Unter "Select Additional Tasks": Klicken Sie auf Install SQL Express und klicken Sie auf Next.

  • Unter "Ready to Install": Fassen Sie alle Installationsfunktionen zusammen und klicken Sie auf Install.

Schritt 4: SQL Server-Installation

Sobald die TruSmartCAM-Komponenten installiert sind, fährt das Installationsprogramm mit der SQL Server-Installation fort. Akzeptieren Sie die Lizenzvereinbarung, um fortzufahren, und installieren Sie SQL Express mit den Standardoptionen.

Sobald die Installation abgeschlossen ist, klicken Sie auf Close und schließen Sie die Installation ab.

Je nach Windows-Version kann das Schließen der SQL-Installation einen Neustart erfordern.

Schritt 5: Windows-Desktopverknüpfungen

  • Wenn das System nach der SQL-Installation nicht neu startet, aktivieren Sie das Kontrollkästchen Launch TruSmartCAM und klicken Sie auf Finish.

  • Wenn das System neu startet, starten Sie TruSmartCAM über das Verknüpfungssymbol auf dem Desktop oder geben Sie TruSmartCAM im Windows-Startmenü ein und wählen Sie Als Administrator ausführen.

Serverinstallation: Die Verknüpfungssymbole TruSmartCAM und TruSmartCAM License sind auf dem Desktop verfügbar.
Client-/SYNC-Installation: Nur das TruSmartCAM-Verknüpfungssymbol ist auf dem Desktop verfügbar.

Schritt 6: Lizenzregistrierung

  • Geben Sie im Feld Serial Number den von Trumpf Metamation Service Team bereitgestellten TruSmartCAM Serial key ein. Geben Sie <Company Name> im Feld "Registered to" sowie die E-Mail-Adresse ein. Klicken Sie auf OK.

Falls eine Netzwerk-Firewall die Lizenzregistrierung blockiert oder auf dem TruSmartCAM-Server-PC kein Internet verfügbar ist, wird die TruSmartCAM-Lizenz durch Offline-Aktivierung erstellt. Senden Sie die Datei Prax.request aus dem Ordner C:\ProgramData\TRUMPF\TMM\Praxis per E-Mail an das Trumpf Metamation Service Team. Das Trumpf Metamation Team stellt die Datei Prax.lock bereit, die in diesen Ordner abgelegt werden muss.

Schritt 7: Einmalige Erstkonfiguration

  • Geben Sie den Datenbanknamen ein und legen Sie den Speicherort für die Daten fest. Aktivieren Sie das Kontrollkästchen Use SQL Server und wählen Sie den Namen des SQL-Servers aus, um eine Verbindung zur Datenbank herzustellen. Klicken Sie auf OK.

  • Der TruSmartCAM-Desktop-Client wird geöffnet und zeigt unten Database Connection Succeeded an.

  • Die Konfigurationsdateien von TruSmartCAM, TecZone und MetaCAM wurden mit den Standardkonfigurationsmaschinen oder anhand der TruSmartCAM-Lizenzmaschinen erstellt. Dieselbe Konfiguration wird von allen TruSmartCAM-Clients gemeinsam genutzt.

Der Begrüßungsbildschirm zeigt den Windows-Benutzeranmeldenamen als TruSmartCAM-Anmeldung und -Name an. Der erste TruSmartCAM-Benutzer wird als Site Admin betrachtet. Geben Sie E-Mail und Passwort an. Klicken Sie auf OK .

Aktivieren Sie das Kontrollkästchen Remember me, um die Anmeldedaten für das nächste Mal zu speichern. Wenn Sie das Kontrollkästchen Remember me deaktivieren, wird bei jedem Start der TruSmartCAM-Anwendung der Dialog für Anmeldung und Passwort angezeigt.

Schritt 8: TruSmartCAM-Anmeldung

  • Schließen Sie TruSmartCAM und öffnen Sie es erneut. Das System fordert Sie auf, die TruSmartCAM-Anmeldedaten einzugeben.

  • Der angemeldete Benutzername wird neben dem Benutzersymbol in der Kopfzeile der TruSmartCAM-Anwendung angezeigt.

  • Wenn Sie den Mauszeiger über das Benutzersymbol bewegen, zeigt das System Folgendes an:

    • Die Benutzerrolle (zum Beispiel: Programmer, Admin).

    • Eine Verknüpfung zum Abmelden: Ctrl+L.

  • Durch Klicken auf das Benutzersymbol wird ein Menü geöffnet, in dem Sie Folgendes tun können:

    • Edit information…​ - Aktualisieren Sie Ihre Profildetails.

    • Change password…​ - Ändern Sie Ihr Kontopasswort.

    • Sign out - Melden Sie sich von der Anwendung ab.

    • Cancel - Schließen Sie das Menü, ohne Änderungen vorzunehmen.

Schritt 9: Werksmaschinenkonfiguration

  • TruSmartCAM-Lizenz [Lizenzbit für alle Maschinen aktiviert]: Die Standard-TruSmartCAM-Maschine und das Standardmaterial werden als Werkskonfiguration betrachtet.

  • TruSmartCAM-Lizenz [keine Demo und wenige Maschinenbits aktiviert]: Diese wenigen Maschinen und das Standardmaterial werden als Werkskonfiguration betrachtet.

  • Importieren Sie ein neues Teil (Open → Import) aus C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts und prüfen Sie, ob das Teil erfolgreich importiert wurde.

Hinweis 1: TruSmartCAM Monitor

  • TruSmartCAM Monitor mit Engine-Installation (Site-Admin-Rechte):

    • TruSmartCAM Monitor mit Engine und Site-Admin-TruSmartCAM-Rechten verfügt über folgende Optionen:

      1. Übertragen der TruSmartCAM-, TecZone- und MetaCAM-Konfiguration auf alle TruSmartCAM-Clients. Außerdem besteht das Recht, eine neue TruSmartCAM-Benutzeranmeldung zu erstellen.

      2. Show Agents zeigt die insgesamt verfügbaren Engines zur Ausführung von Automatisierungsaufgaben gemäß der TruSmartCAM-Lizenz an.

  • TruSmartCAM Monitor ohne Engine-Installation (Site-Admin-Rechte):

  • TruSmartCAM Monitor ohne Engine-Installation (ohne Site-Admin-Rechte):

Der PC, auf dem die TruSmartCAM-Anwendung ausgeführt wird, muss die Engine-TruSmartCAM-Komponente installiert haben [Server-PC oder in einer beliebigen Client-Installation]. Der PC mit installierter Engine-TruSmartCAM-Komponente sollte rund um die Uhr (24x7) laufen, um alle Automatisierungsaufgaben auszuführen.
Hinweis 2: OpenGL

  • Die TruSmartCAM-Anwendung wird beim Öffnen sofort wieder geschlossen und pmonitor wird nicht in der Taskleiste angezeigt.

  • Dies weist auf ein OpenGL-Problem hin.

  • Eine weitere Möglichkeit, dies zu bestätigen: Öffnen Sie C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts , wodurch ein Fehlerdialog zum OpenGL-Problem angezeigt wird.

  • Aktualisieren Sie in C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini den Abschnitt "options" mit GLVersion=1, damit die TruSmartCAM-Anwendung erfolgreich geöffnet wird.

[Options]
GLVersion=1.0
