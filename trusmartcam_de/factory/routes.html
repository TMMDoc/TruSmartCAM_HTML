Routen

Basierend auf Ihrer Lizenz verfügt TruSmartCAM über einen Standardsatz von CAM-Maschinen und Routing-Konfigurationen. Sie können diese Konfigurationen an Ihre spezifischen Fertigungsworkflows anpassen.

Auf der Routes-Seite werden Maschinen als Bearbeitungsstationen dargestellt, die jeweils durch ein Bild und einen Namen gekennzeichnet sind.

Routen verbinden die Stationen und zeigen die möglichen Workflow-Pfade an, denen ein Teil von Anfang bis Ende folgen kann. Sie können die Stationseigenschaften anzeigen, indem Sie mit der Maus über eine Station fahren.

Ein Klick auf eine Station öffnet ein Panel mit detaillierten Informationen zu dieser Station, einschließlich ihres Namens, Typs und Verfügbarkeitsstatus.

  • Um die Stationsverfügbarkeit zu bearbeiten, klicken Sie auf die Station und schalten Sie das Kontrollkästchen Enabled im Panel um.

Routing-Konfigurationen exportieren/importieren

Mit der Funktion Export/Import können Benutzer ihre aktuellen Routing-Konfigurationen speichern und auf andere Projekte oder Instanzen anwenden.

CAD-Routen exportieren

Klicken Sie auf Export CAD routes…​, um alle aktuellen Routenbedingungsregeln in einer CSV-Datei zu speichern.

Die CSV listet Materialien und ihre Routing-Bedingungen auf. Spalten stellen Maschinennamen und Bedingungen dar (z. B. Material, SpecialTool, HasBend, MaxBendLength). Ein Wert von 1 zeigt das Routing zu einer Maschine an; eine leere Zelle bedeutet kein Routing.

Sie können diese CSV ändern und erneut in das System importieren.

CAD-Routen importieren

Verwenden Sie Import CAD routes…​, um eine geänderte CSV-Datei anzuwenden.

Führen Sie vor dem Import Reset CAD routes aus, um vorhandene Konfigurationen zu löschen.

Das System liest die Datei und aktualisiert die Routenbedingungen. Regeln können Bedingungen wie HasBend und MaxBendLength enthalten.

Wenn HasBend = 1, gilt die Regel für Teile mit Biegungen.
Wenn MaxBendLength =1, schränkt die Regel weiter basierend auf der längsten Biegelänge des Teils ein.

Beispiel 1

Teil 00.13 hat eine längste Biegung von 500 mm. Es entspricht der ersten Regel, sodass TBC-5030-V2 ausgeschlossen wird.

CAD-Routen zurücksetzen

Verwenden Sie Reset CAD routes, um alle vorhandenen Konfigurationen zu löschen, bevor Sie eine neue CSV importieren.

Wenn Sie ohne Zurücksetzen importieren, können alte Regeln mit neuen in Konflikt geraten.
