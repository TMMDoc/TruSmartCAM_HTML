Environment settings

Program default units - Der Benutzer kann wählen, ob die Standardeinheit mm oder Zoll ist.

Decimal places to display - Mit diesem Wert wird festgelegt, wie viele Dezimalstellen angezeigt werden sollen.

Decimal accuracy in export/import - Mit diesem Wert wird festgelegt, wie viele Dezimalstellen beim Import oder Export exakt sein sollen.

Display part toolings in groups - Verwenden Sie diese Option, um die Werkzeuggruppe zur Anzeige des Werkzeugstatus in der Teilebibliothek auszuwählen.

Captions for command-bar icons - Wenn Sie diese Option aktivieren, wird unter jedem Symbol eine Beschriftung angezeigt, die angibt, worauf sich die Seite bezieht. Wenn diese Option deaktiviert ist, werden alle Beschriftungen für die Schalter entfernt und nur das Symbol für jede unterschiedliche Seite angezeigt.

Display Job status labels - Wenn Sie diese Option aktivieren, wird die Anzahl der Teile innerhalb eines Jobs am Ende der Job-Statusleiste angezeigt. Wenn diese Option deaktiviert ist, wird die Teileanzahl entfernt und die Farbe zur Anzeige des Prozesses bleibt erhalten.

Display nested parts by job-order color - Diese Option zeigt jedes unterschiedliche Teil innerhalb eines Jobs in einer anderen Farbe an. Wenn Sie diese Option deaktivieren, werden alle Teile in derselben grauen Farbe angezeigt.

Display the duration in time-span format(HH:MM:SS) - Aktivieren Sie diese Option, um die Dauer im Format HH:MM:SS anzuzeigen. Wenn diese Option aktiviert ist, wird die Dauer in den Layout-Details und den Job-/Layout-Berichten im ausgewählten Format angezeigt. Aufgrund der Platzbeschränkungen wird die Dauer auf den Layout-Kacheln in einem kompakteren Sekundenformat angezeigt.
