Benachrichtigungen

Benachrichtigungen informieren Benutzer über CAD- und Werkzeugfehler, die innerhalb des Systems auftreten. Sie stellen sicher, dass Probleme umgehend kommuniziert werden, damit geeignete Maßnahmen ergriffen werden können.

E-Mail-Benachrichtigung

Mit der E-Mail-Benachrichtigungsfunktion können Benutzer automatisierte E-Mail-Warnungen für CAD- und Werkzeugfehler konfigurieren und empfangen. Nach der Konfiguration sendet das System automatisch E-Mails an die angegebenen Empfänger, sobald ein relevantes Ereignis auftritt, um sicherzustellen, dass Probleme umgehend behoben werden.

Um E-Mail-Benachrichtigungen zu konfigurieren, navigieren Sie zu: factory > settings > Notifications

Die Seite Notifications besteht aus den folgenden Abschnitten:

Benachrichtigungseinstellungen

Der Abschnitt Notification settings steuert, wie E-Mail-Warnungen generiert und an Empfänger zugestellt werden.

  • Enable email notifications - Ermöglicht dem System, Benachrichtigungen basierend auf den konfigurierten Bedingungen zu senden.

  • Notification recipients - Gibt die E-Mail-Adresse(n) der Empfänger an. Mehrere Empfänger können hinzugefügt werden, indem sie durch ein Komma (,) oder ein Leerzeichen getrennt werden.

  • Send messages in batch - Fasst mehrere Benachrichtigungen in einer einzigen E-Mail zusammen. Nachrichten, die innerhalb eines definierten Zeitintervalls generiert werden, werden gruppiert, was dazu beiträgt, das E-Mail-Volumen zu reduzieren und Unordnung zu vermeiden.

  • Attach tooling simulation preview where applicable - Fügt der Benachrichtigungs-E-Mail eine Vorschau der Werkzeugsimulation bei, wenn verfügbar. Dies ist nützlich, um werkzeugbezogene Probleme direkt aus der E-Mail zu überprüfen.

Das Einbeziehen der Simulationsvorschau kann die E-Mail-Größe erheblich vergrößern.

Mail settings

Der Abschnitt Mail settings definiert die Konfiguration des Postausgangsservers, den das System zur Zustellung von E-Mail-Benachrichtigungen verwendet. Diese Einstellungen müssen korrekt konfiguriert sein, damit Benachrichtigungen erfolgreich gesendet werden.

  • SMTP server - Gibt die SMTP-Serveradresse an, die zum Senden ausgehender E-Mails verwendet wird (zum Beispiel smtp.gmail.com). Diese Information ist normalerweise im Konto- oder Einstellungsbereich des E-Mail-Clients des Benutzers verfügbar.

  • SMTP port - Definiert die Portnummer, die der Mailserver zum Senden von E-Mails über das Internet verwendet. Übliche Werte sind 465 (SSL) und 587 (TLS).

  • Transport protocol - Gibt das Protokoll an, das zum sicheren Senden von E-Mails von der Anwendung an den Mailserver verwendet wird (zum Beispiel SSL oder TLS).

  • Server needs authentication - Aktiviert die Authentifizierung für den SMTP-Server. Wenn diese Option aktiviert ist, werden Benutzername und Passwort vom Server validiert, bevor E-Mails gesendet werden.

  • User-name - Gibt das E-Mail-Konto an, das zur Authentifizierung beim SMTP-Server und zum Senden von Benachrichtigungen verwendet wird.

  • Password - Gibt das mit dem E-Mail-Konto verknüpfte Passwort an, das für die Authentifizierung verwendet wird.

  • Sender address - Gibt die Absender-E-Mail-Adresse an, die den Empfängern angezeigt wird, wenn Benachrichtigungen empfangen werden.

  • Test…​ - Sendet eine Test-E-Mail, um die Mailserverkonfiguration zu überprüfen.

Klicken Sie auf Test…​, um die Einrichtung zu validieren. Bei erfolgreichem Test wird eine Bestätigungsmeldung angezeigt; andernfalls wird eine Fehlermeldung angezeigt, die die Ursache des Fehlers angibt.

  • E-Mail-Benachrichtigungen werden im interaktiven Modus nicht ausgelöst (zum Beispiel beim Bearbeiten oder manuellen Speichern eines Teils).

  • Die E-Mail-Zustellung wird im Hintergrund abgewickelt und kann verzögert sein.

  • Benachrichtigungen werden möglicherweise nicht zugestellt, wenn das System oder die Engine gestoppt wird, bevor die Verarbeitung abgeschlossen ist.
