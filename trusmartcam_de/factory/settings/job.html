Output settings

Save layout NC and reports - Aktivieren Sie diese Option, damit Layout-NC und -Berichte gespeichert werden.

Save layout file - Aktivieren Sie diese Option, damit die Layout-Datei gespeichert wird.

Output simulation preview in reports - Aktivieren Sie diese Option, um die Vorschau der Werkzeugsimulation zusammen mit den anderen Ausgaben zu erzeugen. Dies ist eine kurze GIF-Animation für die Laser-/Stanzwerkzeugbestückung.

Do not delete program outputs on layout/job completion - Wenn Sie diese Option aktivieren, wird der Löschvorgang für die Programmausgaben übersprungen, wenn ein Job/Layout als abgeschlossen markiert wird.

Nest settings

Mix parts from multiple Jobs - Unterstützt das Schachteln im gemischten Modus. Teile aus mehreren Jobs sollten zusammen geschachtelt werden, um eine bessere Packungseffizienz zu erzielen.

Do not auto-release layouts - Dies verhindert, dass Layouts für die Produktion verfügbar sind, bis sich alle Layouts im freigegebenen Zustand befinden.

Re-nesting packing cut-off - Dieser Wert wird verwendet, um zu entscheiden, ob ein geschachteltes Layout in der Genehmigungswarteschlange gehalten und erneut geschachtelt wird, wenn neue Teile geplant werden, oder ob es für die Produktion freigegeben und die zugehörigen Ausgaben in den Ausgabeordner exportiert werden.

Interactive sheet-name prefix - Dieser Abschnitt wird verwendet, um interaktives Schachteln zu unterstützen, bei dem der Benutzer mehr Kontrolle über die geschachtelten Teile und das Schachtelergebnis hat. Verwenden Sie für die interaktiv geschachtelten Layouts ein Benennungsschema, das sich vom automatischen Schachteln unterscheidet.

Update sheet inventory on nest (un)release - Wenn diese Option aktiviert ist, wird der Blechbestand aktualisiert, wenn eine Schachtelung an eine Maschine gesendet wird. Auch das Zurückrufen der Schachtelung von der Maschine gibt das Blech an den Bestand zurück.

Automate remnant inventory management - Wenn dieser Schalter ausgewählt ist, automatisiert die Software die Verwaltung des Reststückbestands. Wenn er nicht ausgewählt ist, wird die Reststückverwaltung interaktiv.

Auto-refresh Out-of-date layouts - Wenn diese Option aktiviert ist, aktualisiert die Software alle mit einem Teil verknüpften Out-of-date Layouts, nachdem dessen Schneidlösungen berechnet wurden.

Automate twin-line nesting - Aktivieren Sie diese Option, um die Twin-Line-Automatisierung zu ermöglichen.

Pull workflow settings

Use 'Pull workflow' - Diese Option ist nützlich für Benutzer, die ein hochgradig autonomes Planungs- und Schachtelungssystem benötigen. Wenn diese Option aktiviert ist, plant TruSmartCAM das Schachteln bei Bedarf.

Nests per station - Mit diesem Wert wird festgelegt, wie viele Layouts pro Station erstellt werden sollen.

Maximum sheets per nest - Dieser Wert wird verwendet, um die maximale Blechanzahl gegenüber der eindeutigen Schachtelung zu steuern. Wenn es also beispielsweise einen Auftrag mit einem großen Teil gibt (das das gesamte Blech ausfüllt), das in großen Mengen benötigt wird (z. B. 500), erstellt TruSmartCAM im Pull-Modus nicht mehr eine einzige Schachtelung mit 500 Kopien. Stattdessen erstellt es 10 Kopien pro Schachtelung, wobei 10 das Maximum ist.

Bend programs per station - Mit diesem Wert wird festgelegt, wie viele Biegeprogramme pro Station erstellt werden sollen.

Mark the task completed, when the program outputs are removed - Aktivieren Sie diese Option, damit ein Layout als Done markiert wird, wenn die Ausgaben aus dem Ziel-Ausgabeverzeichnis entfernt werden.

Spreadsheet import settings

CAD lookup directories - TruSmartCAM versucht, den in der importierten CSV genannten Teileeintrag aus der Teilebibliothek zu laden. Wenn das Teil jedoch nicht in der Teilebibliothek verfügbar ist, versucht es, die Teile aus Suchverzeichnissen abzurufen, basierend auf der Reihenfolge der in diesem Dialog festgelegten Verzeichnisse.

Use recursive CAD search - Aktivieren Sie diese Option, damit die Suche für aufeinanderfolgende Ergebnisse wiederholt wird.

Create a blank part for the missing CAD files - Wenn Teile nicht in der TruSmartCAM-Bibliothek oder in den Suchverzeichnissen vorhanden sind, erstellt TruSmartCAM ein leeres Teil für diese nicht verfügbaren Teile.

Do not show New Job dialog if the spreadsheet has no error - Wenn die CSV-Einträge sauber sind, d. h. keine Datenabweichung von der DB vorliegt oder alle Felder ordnungsgemäß aufgeführt sind, zeigt TruSmartCAM das Job-Übersichtsfenster nicht an und verarbeitet den Job, sobald die CSV importiert oder abgelegt wird.

Prefer Raw-Material column over Material + Thickness - Unterstützte Tabellentypen:

  1. Muster 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Muster 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Muster 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Wenn diese Option nicht aktiviert ist, wird Muster 1 als Standardtabellentyp betrachtet. Wir unterstützen auch Muster 3, falls das CSV-Format vom Typ Muster 3 ist.

Wenn diese Option aktiviert ist und die CSV vom Typ Muster 2 ist, löst TruSmartCAM das Rohmaterial aus den Feldern Material und Thickness der CSV auf.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Aktivieren Sie diese Option, um den CSV-Export zu ermöglichen, wenn ein Layout oder Job abgeschlossen ist. Die abgeschlossenen Berichte werden am Reports-Zielverzeichnis gespeichert, das unter Factory → Settings → Reports festgelegt ist.
