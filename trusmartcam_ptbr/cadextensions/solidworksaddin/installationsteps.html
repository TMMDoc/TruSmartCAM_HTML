Installation

Requisitos obrigatórios

Fazer login no TruSmartCAM desktop é obrigatório ao iniciar o SolidWorks pela primeira vez.

Certifique-se de que o TruSmartCAM monitor esteja em execução na área de notificação do Windows.

Se o TruSmartCAM desktop não estiver aberto, verifique se o serviço do TruSmartCAM server está em execução para permitir que o Add-in do SolidWorks funcione. Se ambos estiverem inativos, o SolidWorks exibirá uma mensagem de erro ao ser iniciado.

Siga estas etapas para instalar e configurar o Add-in do TruSmartCAM para SolidWorks:

  1. Execute o TruSmartCAM Setup e, na página de seleção de Components, habilite SolidWorks Extension. (Ignore a opção Server se o SolidWorks estiver instalado em um cliente TruSmartCAM.)

  2. Conclua a instalação e, em seguida, inicie o TruSmartCAM desktop e faça login com credenciais de usuário válidas.

  3. Inicie o SolidWorks.

  4. No SolidWorks, vá para Tools → TruSmartCAM → About TruSmartCAM, para verificar a versão e os detalhes do add-in.

  5. Para habilitar ou desabilitar o add-in na inicialização, vá para Tools → Add-ins e localize TruSmartCAM em Other Add-ins.
