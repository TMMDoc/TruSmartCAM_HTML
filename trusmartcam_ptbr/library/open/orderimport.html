Importar pedidos

Os pedidos podem ser criados ou importados usando os seguintes métodos:

  1. Importar pedidos de arquivos de planilha.

  2. Importar pedidos automaticamente por meio das configurações de watch.

  3. Criar pedidos a partir de peças existentes na biblioteca de peças.

  4. Criar pedidos a partir de static nests de montagem.

Importar pedidos de planilha

  • Navegue até abrir → Importar _Pedidos…​.

  • Os formatos de planilha suportados incluem CSV, XLSX e XML.

  • Selecione o arquivo de planilha necessário e clique em abrir.

  • O processo de importação é semelhante ao workflow de importação de Job/Montagem.

Você também pode arrastar e soltar a planilha diretamente na página Orders para importar pedidos.

Importar pedidos usando as configurações de watch

  • Habilite a opção Importar planilha da "Pasta ao vivo" em Configurações de monitoramento.

  • Selecione Importar pedidos na Opção de importação de planilha.

  • Configure o local da pasta a partir da qual os pedidos devem ser importados.

  • O sistema monitora continuamente a pasta configurada.

  • Os arquivos de planilha recém-adicionados são importados automaticamente para Orders.

Para etapas detalhadas de configuração, consulte a documentação Watch settings.

Criar pedidos a partir da biblioteca de peças

  • Selecione as peças necessárias na Biblioteca de Peças.

  • Clique com o botão direito e escolha Novo…​ → Pedido para abrir o diálogo Novos pedidos.

  • Insira os detalhes necessários, como quantidade, data de vencimento e prioridade.

  • Clique em OK para criar os pedidos.

  • O sistema alterna automaticamente para a página Orders.

  • Os pedidos criados são exibidos na página Orders Ready para a criação de jobs.

Criar pedidos a partir de montagem

  • Clique com o botão direito na Montagem necessária.

  • Selecione Novo…​ → Pedido para abrir o diálogo Novos pedidos.

  • Insira a Contagem de conjunto necessária.

  • Clique em OK para criar os pedidos.
