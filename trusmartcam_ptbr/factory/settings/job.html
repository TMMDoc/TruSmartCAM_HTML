Ajustes de saída

Salvar layout NC - Habilite esta opção para que o NC de layout e os relatórios sejam salvos.

Salvar arquivo de layout e relatórios - Habilite esta opção para que o arquivo de layout seja salvo.

Pré-visualização de simulação de saída em relatórios - Habilite esta opção para gerar a prévia de simulação de ferramental junto com as outras saídas. Esta é uma curta animação GIF para o ferramental de laser/punção.

Não excluir saídas do programa ao concluir layout/tarefa - Habilitar esta opção ignorará a operação de exclusão das saídas do programa quando um job/layout for marcado como concluído.

Ajustes de nesting

Misturar peças de múltiplas tarefas - Oferece suporte ao nesting em modo misto. As peças de vários jobs devem ser aninhadas juntas para melhor eficiência de empacotamento.

Não liberar layouts automaticamente - Isso impedirá que os layouts fiquem disponíveis para produção até que todos os layouts estejam em um estado liberado.

Limite de corte para re-nesting do agrupamento - Este valor é usado para decidir se um layout aninhado é mantido na fila de aprovação e é aninhado novamente quando novas peças são planejadas ou se são liberados para produção e as saídas relacionadas são exportadas para a pasta de saída.

Prefixo interativo para o nome da chapa - Esta seção é usada para dar suporte ao nesting interativo, onde o usuário tem mais controle sobre as peças que estão sendo aninhadas e o resultado do nest. Use um esquema de nomenclatura, diferente do auto-nesting, para os layouts aninhados interativamente.

Atualizar o inventário de chapas ao liberar ou cancelar um nesting - Se esta opção estiver habilitada, o inventário de chapas será atualizado ao enviar um nest para uma máquina. Além disso, recall do nest da máquina retornará a chapa ao inventário.

Automatizar a gestão de remanescentes no inventário - Quando este botão está selecionado, o software automatiza o gerenciamento do inventário de retalhos. Se não selecionado, o gerenciamento de retalhos torna-se interativo.

Atualizar automaticamente layouts desatualizados - Quando marcado, o software atualiza todos os ui:EGTag.SelectOutOfDate[Out-of-date Layouts] vinculados a uma peça após suas soluções de corte serem calculadas.

Automatizar nesting de linha dupla - Marque esta opção para habilitar a automação de twin-line.

Ajustes do fluxograma por demanda

Usar "Fluxograma por demanda" - Esta opção é útil para usuários que precisam de um sistema de planejamento e nesting altamente autônomo. Quando habilitado, o TruSmartCAM planeja o nesting sob demanda.

Nestings por estação - Este valor define quantos layouts por estação devem ser criados.

Máximo de chapas por nesting - Este valor é usado para controlar a contagem máxima de chapas em relação ao nest único. Assim, por exemplo, se houver um pedido com uma peça grande (que preenche a chapa inteira), necessária em grandes quantidades (digamos 500) - o TruSmartCAM não cria mais um único nest com 500 cópias no modo pull. Em vez disso, ele cria 10 cópias por nest, onde 10 é o máximo.

Programas de dobra por estação - Este valor define quantos programas de bend por estação devem ser criados.

Marque a tarefa como concluída quando as saídas do programa forem removidas - Habilite esta opção para que um layout seja marcado como Done quando as saídas são removidas do destino de saída de destino.

Ajustes de importação da planilha

Diretórios de pesquisa CAD - O TruSmartCAM tentará carregar a entrada de peça mencionada no CSV importado a partir da biblioteca de peças. No entanto, se a peça não estiver disponível na biblioteca de peças, ele tentará buscar as peças nos diretórios de pesquisa com base na ordem dos diretórios definida neste diálogo.

Usar pesquisa recursiva em CAD - Habilite esta opção para que a pesquisa seja repetida para resultados sucessivos.

Criar uma peça em branco para os arquivos CAD em falta - Se as peças não existirem na biblioteca do TruSmartCAM ou nos diretórios de pesquisa, o TruSmartCAM criará uma peça em branco para essas peças indisponíveis.

Não mostrar a caixa de diálogo Nova tarefa se a planilha não tiver erros - Se as entradas do CSV estiverem limpas, ou seja, sem incompatibilidade de dados do DB ou todos os campos listados corretamente, o TruSmartCAM não mostrará a janela de visão geral do job e processará o job assim que o CSV for importado ou inserido.

Preferir a coluna Material em bruto em vez de Material + Espessura - Tipos de planilha suportados:

  1. Pattern 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Pattern 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Pattern 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Se esta opção não estiver marcada, o Pattern 1 será considerado o tipo de planilha padrão. Também oferecemos suporte ao Pattern 3 caso o formato CSV seja do tipo Pattern 3.

Se esta opção estiver marcada e o CSV for do tipo Pattern 2, o TruSmartCAM resolverá o Raw Material a partir dos campos Material e Thickness do CSV.

Ajustes de saída da planilha

Exportar relatório de conclusão da tarefa/layout (.csv)* - Marque esta opção para habilitar a exportação de CSV quando um Layout ou Job for concluído. Os relatórios concluídos são salvos no destino Reports especificado nas configurações Factory → Settings → Reports.
