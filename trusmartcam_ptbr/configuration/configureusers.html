Configurar usuários

  • Os clientes TruSmartCAM com diferentes funções são usados para controlar a configuração da factory.

    • Adicionar novas máquinas, materiais e chapas.

    • Editar configurações de máquinas.

    • Editar peças, jobs e montagens.

    • Editar / Atualizar chapas de nesting, planejar job.

    • Adicionar/Editar os usuários.

  • O PC de instalação do Pserver é considerado como o primeiro usuário do TruSmartCAM.

  • O TruSmartCAM usa a credencial do Windows como nome de usuário do TruSmartCAM, que é Administrador do site.

  • A instalação seguinte, ou seja, o nome de usuário do computador de instalação do Cliente TruSmartCAM, é considerado como Programador.

Apenas o Administrador do site pode editar informações de outros usuários e alterar a senha.
