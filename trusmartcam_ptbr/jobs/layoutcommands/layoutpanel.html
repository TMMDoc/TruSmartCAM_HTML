Painel de layout

Esta seção explica as ações relacionadas a layout, como Enviar para a máquina…​, Recuperar da máquina…​, Exportar saídas, Marcar como concluído…​, Adicionar peças…​, Adaptar/compactar…​, Dividir layouts…​, e outras opções usadas para gerenciar instâncias de layout.

Abrir em modo somente leitura para visualização
Abre o layout selecionado no modo somente leitura.

Check-out the document for editing
Habilita a edição do layout selecionado.

Excluir
Exclui o layout selecionado.

Ver relatório
Abre o relatório de layout padrão e o relatório específico de etiquetas para o layout selecionado.

Enviar para a máquina…​

Envia o layout selecionado para a máquina e exporta os arquivos de saída (fxlyt, NC, report, csv) para o local de saída do job.

Adicionar peças…​

Adiciona mais peças a um layout mal empacotado usando o assistente de repack de layout.

Adaptar/compactar…​

Refaz o nesting do layout selecionado para compactar as peças e liberar área utilizável.

Alterar TTL…​

Altera a chapa atribuída ao layout selecionado.

Dividir layouts…​

Divide o layout selecionado em dois ou mais layouts separados.

Rename…​

Renomeia o layout selecionado.

Tarefa / Anterior / Próximo / Peças

Navega para o job pai, para o layout anterior ou seguinte dentro do job selecionado, ou para as peças contidas no layout.

Sort and filter

Use esses filtros para ver outros layouts que compartilham o mesmo atributo do layout selecionado: Mesma máquina, Mesmo material, Mesma TTL, Mesma prioridade, Mesmo estado, Mesma chapa, Same Part, Same Remnant State ou Same Rolling Direction.

Enviar para a máquina…​

  • Quando um nest está pronto (preenchido ou urgentemente necessário), você pode enviá-lo para a máquina.

  • Clique com o botão direito no nest e selecione Enviar para a máquina…​.

  • Uma pasta é criada automaticamente, com o nome do nest.

  • Os arquivos de saída (fxlyt, NC, report, csv) são exportados para o local de saída do JOB.

  • Os nests enviados para a máquina são exibidos com uma marca de verificação azul.

Depois de liberados, esses nests não são mais retentados para repacking.

Recuperar da máquina…​

  • Se a saída precisar de validação ou atualização (por exemplo, adicionar mais peças):

    • Clique com o botão direito no layout exportado.

    • Selecione Recuperar da máquina…​.

  • Os arquivos de saída e a pasta (fxlyt, NC, report, csv) são excluídos.

  • O nest torna-se editável novamente.

  • Você pode fazer alterações e enviá-lo para a máquina novamente.

Exportar saídas

  • Clique com o botão direito em qualquer layout (nest) que tenha sido enviado para a máquina e clique em Exportar saídas.

  • A opção Export Outputs exporta os arquivos NC, Report e Layout para as respectivas pastas de saída da máquina.

  • Esta opção regenera o arquivo NC com as configurações de unidade atuais do layout.

Export Outputs não está disponível para layouts que estão Completed e layouts que estão aguardando na fila para repacking.

Mark complete

  • Depois que o nest é processado na máquina, clique com o botão direito no nest e selecione Marcar como concluído…​.

  • Você pode selecionar vários nests e marcá-los como concluídos ao mesmo tempo.

  • Quando um nest é marcado como concluído:

    • Ele fica esmaecido, é movido para o final da lista e exibido com uma marca de verificação verde.

    • O layout é removido da lista de layouts ativos.

    • Os status da peça e do job são atualizados, e as quantidades processadas passam para o estado concluído.

    • Os arquivos de saída desse layout são removidos do local de saída da máquina para evitar o uso duplicado.

Adicionar peças…​

  • Use esta opção para adicionar mais peças a um layout relativamente mal empacotado. Assim como o Interactive Nesting, esta é uma opção baseada em assistente e pode ser usada em um único ou em vários layouts ao mesmo tempo.

  • O TruSmartCAM monta o assistente de repack de layout na área de trabalho principal quando esta opção é usada. Mantenha pressionada a tecla Ctrl e selecione uma ou mais peças a serem empacotadas no(s) layout(s) e pressione Próximo.

  • As peças selecionadas são exibidas na próxima etapa com uma coluna de quantidade editável. Atualize as quantidades das peças, se necessário, no campo Update Qty. Clique em Próximo para prosseguir para o nesting. Observe que as quantidades só podem ser aumentadas, não diminuídas.

  • Todos os layouts são aninhados separadamente, e os resultados aninhados são exibidos com as peças recém-empacotadas colocadas neles. Selecionar o layout exibe todas as peças existentes do layout. O resultado é descartado automaticamente se nenhuma nova peça for colocada durante o repacking. Um layout com várias cópias pode resultar em padrões diferentes após o repacking.

Adaptar/compactar…​

  • Este comando baseado em assistente pode ser usado para adaptar um layout de uma máquina para outra quando a máquina original está fora de serviço ou quando a carga de trabalho da máquina precisa ser equilibrada.

  • Ele pode ser usado quando a chapa planejada está fora de estoque e o layout precisa ser replanejado em outra chapa disponível.

  • Você pode mesclar layouts empacotados em chapas menores em chapas maiores para usar o material de forma mais eficiente.

  • Você pode dividir layouts empacotados em chapas maiores em chapas menores se grandes estoques de chapas não estiverem disponíveis.

  • Você pode aumentar a eficiência de empacotamento de vários layouts (mesmo de máquinas diferentes) mesclando-os.

  • Para usá-lo, selecione um ou mais layouts e clique em Adaptar/compactar…​ para abrir o assistente na área de trabalho.

  • O painel esquerdo mostra todos os layouts selecionados e o painel Parts mostra as peças do layout.

  • Selecione a máquina de destino e o material da chapa e, em seguida, clique em Próximo para executar o renesting.

  • Os novos resultados do nest são exibidos no painel de resultados.

  • Clique em Próximo para salvar o layout adaptado ou compactado.

Dividir um layout

A opção Dividir layouts…​ permite dividir um layout existente em vários layouts modificando as quantidades, sem a necessidade de refazer o ferramental ou o nesting.

Este recurso é particularmente útil nos seguintes cenários:

  1. Quando você precisa produzir uma parte da quantidade total imediatamente enquanto agenda a quantidade restante para produção posterior.

  2. Quando os requisitos de produção precisam ser distribuídos por vários turnos ou dias para otimizar o fluxo de trabalho e a utilização de recursos.

  3. Quando uma máquina específica está temporariamente indisponível ou ocupada, e você precisa ajustar o layout para acomodar as restrições de produção atuais.

Para dividir um layout, execute as seguintes etapas:

  • Na visualização Layouts, selecione o layout necessário.

  • Clique em Dividir layouts…​.

  • Insira o valor necessário em Novas cópias.

  • Clique em OK.

O layout selecionado agora está dividido em dois layouts com quantidades ajustadas.
