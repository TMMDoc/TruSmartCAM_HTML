Instalação do servidor

Siga as instruções para instalar o Servidor TruSmartCAM juntamente com o SQL.

Direitos de administrador

Para executar esta instalação, o usuário deve ter privilégios administrativos.

  • Execute Setup.TruSmartCAM.<version>.exe para iniciar a instalação.

A versão é um número.

  • Leia o contrato de licença, escolha I accept the agreement e, em seguida, clique em Próximo.

Etapa 1 : Local de instalação

  • Informe o diretório de instalação ou aceite o padrão de instalação C:\Program Files\TRUMPF\TMM\Praxis e clique em Próximo.

    • C:\Program Files\TRUMPF\TMM\Praxis - A pasta de instalação terá as seguintes pastas : Bin, MetaCAM, Samples e Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - A pasta de dados terá as seguintes pastas : TruSmartCAM, TecZone e MetaCAM.

Etapa 2 : Seleção de componentes

Tipo de instalação Componentes

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Seleciona todos os terminais de estação como TecZone, MetaCAM, RightAngle (Controlador de Dobra), Vulcan (Controlador de Máquina a Laser)

Custom

Seleciona conforme a escolha do usuário.

  • Escolha Full Installation. Selecione Code Senders e Bend Code Senders nas ferramentas do TruSmartCAM. Agora o tipo de instalação muda para Personalizado. Clique em Próximo.

Etapa 3 : Escolher instalar o SQL Server

A instalação do SQL Express 2022 é necessária apenas para o Servidor TruSmartCAM. Esta opção não está disponível para as instalações Client e Sync. Além disso, ela é marcada e instalada na primeira vez e pode ser ignorada posteriormente. Se o SQL já estiver instalado no servidor TruSmartCAM, o usuário pode ignorar a Etapa 3.

  • Em Select Additional Tasks : Clique em Install SQL Express e clique em Próximo.

  • Em Ready to Install : Resume todos os recursos de instalação e clique em Install.

Etapa 4 : Instalação do SQL Server

Assim que os componentes do TruSmartCAM forem instalados, o instalador prossegue com a instalação do SQL server. Aceite o contrato de licença para prosseguir e instale o SQL express com as opções padrão.

Após a conclusão da instalação, clique em Close e finalize a instalação.

Dependendo da versão do Windows, o fechamento da instalação do SQL pode solicitar uma reinicialização.

Etapa 5 : Atalhos da área de trabalho do Windows

  • Após a instalação do SQL, se o sistema não reiniciar, selecione a caixa de seleção Launch TruSmartCAM e clique em Finish.

  • Se o sistema reiniciar, inicie o ícone de atalho Launch TruSmartCAM na área de trabalho ou digite TruSmartCAM no menu Iniciar do Windows e selecione Run as administrator.

Instalação do servidor : Os ícones de atalho TruSmartCAM e TruSmartCAM License estão disponíveis na área de trabalho.
Instalação Client/SYNC : Apenas o ícone de atalho TruSmartCAM está disponível na área de trabalho.

Etapa 6 : Registro da licença

  • No campo Serial Number, digite a chave serial do TruSmartCAM fornecida pela equipe de serviço da Trumpf Metamation. Digite <Company Name> no campo "Registered to" e o e-mail. Clique em OK.

Caso o firewall de rede bloqueie o registro da licença ou não haja internet no PC do Servidor TruSmartCAM, o licenciamento do TruSmartCAM é feito por ativação offline. Envie por e-mail o Prax.request da pasta C:\ProgramData\TRUMPF\TMM\Praxis para a equipe de serviço da Trumpf Metamation. A equipe da Trumpf Metamation fornecerá o Prax.lock que deve ser colocado nesta pasta.

Etapa 7 : Configuração inicial única

  • Digite o nome do banco de dados e defina o local de armazenamento de dados. Selecione a caixa de seleção Usar Servidor SQL e selecione o nome do servidor SQL para conectar ao banco de dados. Clique em OK.

  • O Desktop Client do TruSmartCAM abre exibindo Database Connection Succeeded na parte inferior.

  • Os arquivos de configuração TruSmartCAM, TecZone e MetaCAM foram criados com as máquinas de configuração padrão ou de acordo com as máquinas licenciadas do TruSmartCAM. A mesma configuração será compartilhada entre todos os clientes TruSmartCAM.

A tela de boas-vindas é exibida com o LoginName do usuário do Windows como Login e Nome do TruSmartCAM. O primeiro usuário do TruSmartCAM é considerado como Administrador do site. Forneça o e-mail e a senha. Clique em OK .

Selecione a caixa de seleção Lembrar de mim para salvar as credenciais de login para a próxima vez. Desmarcar a caixa de seleção Lembrar de mim solicitará o diálogo de login e senha sempre que o aplicativo TruSmartCAM for iniciado.

Etapa 8 : Login no TruSmartCAM

  • Feche o TruSmartCAM e reabra-o. O sistema solicita que você insira as credenciais de login do TruSmartCAM.

  • O nome de usuário conectado é exibido ao lado do ícone de usuário no cabeçalho do aplicativo TruSmartCAM.

  • Ao passar o cursor sobre o ícone de usuário, o sistema exibe:

    • A função do usuário (por exemplo: Programmer, Admin).

    • Um atalho para sair: Ctrl+L.

  • Ao clicar no ícone de usuário, abre-se um menu que permite:

    • Editar informações…​ - Atualizar os detalhes do seu perfil.

    • Alterar senha…​ - Alterar a senha da sua conta.

    • Fazer logout - Sair do aplicativo.

    • Cancelar - Fechar o menu sem fazer nenhuma alteração.

Etapa 9 : Configuração da máquina Factory

  • Licença TruSmartCAM [todas as máquinas habilitam o bit de licença] : As máquinas e materiais padrão do TruSmartCAM são considerados como Configuração da Factory.

  • Licença TruSmartCAM [sem demo e com poucos bits de máquina habilitados] : Essas poucas máquinas e o material padrão são considerados como Configuração da Factory.

  • (Open → Import) de uma nova peça a partir de C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts e verifique se a peça foi importada com sucesso.

Nota 1 : Monitor do TruSmartCAM

  • Monitor do TruSmartCAM com instalação do Engine (direitos de site admin):

    • O Monitor do TruSmartCAM com Engine juntamente com os direitos de Site Admin do TruSmartCAM terá as seguintes opções:

      1. Enviar a configuração do TruSmartCAM, TecZone, MetaCAM para todos os clientes TruSmartCAM. Também tem direitos para criar um novo login de usuário do TruSmartCAM.

      2. Show Agents mostrará o total de engines disponíveis para realizar tarefas de automação, o que está de acordo com a licença do TruSmartCAM.

  • Monitor do TruSmartCAM sem instalação do Engine (direitos de site admin):

  • Monitor do TruSmartCAM sem instalação do Engine (direitos não site admin):

O PC que executa o aplicativo TruSmartCAM deve ter o componente Engine TruSmartCAM instalado [PC do servidor ou em qualquer instalação de cliente]. O PC com o componente Engine TruSmartCAM instalado deve estar em execução 24x7 para realizar todas as tarefas de automação.
Nota 2 : OpenGL

  • O aplicativo TruSmartCAM, ao abrir, é fechado imediatamente e também o pmonitor não é exibido na barra de tarefas.

  • Isso representa um problema de OpenGL.

  • Outra maneira de confirmar isso: Abra C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts que exibe um diálogo de erro sobre o problema de OpenGL.

  • Atualize C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , a seção options com GLVersion=1 faz com que o aplicativo TruSmartCAM abra com sucesso.

[Options]
GLVersion=1.0
