Requisitos de porta

Servidor TruSmartCAM : 7371

O servidor aguarda as solicitações do cliente nesta porta TCP. As conexões de entrada devem ser permitidas nesta porta no computador do servidor.

Servidor de licença flutuante : 5776

O servidor de licença flutuante aguarda as solicitações de licenciamento nesta porta. As conexões de entrada devem ser permitidas nesta porta no computador do servidor de licença flutuante (Servidor TruSmartCAM).

Conexão de licença com a nuvem : 7567

Esta porta é usada pelo TecZone (Software de Dobra) e pelo servidor de licença flutuante para enviar solicitações de licenciamento para a Metamation Cloud. Portanto, a conexão de saída deve ser permitida nesta porta para ativações e renovações de licença.
