Sunucu kurulumu

TruSmartCAM Sunucu kurulumunu SQL ile birlikte kurmak için talimatları izleyin.

Yönetici Hakları

Bu kurulumu çalıştırmak için kullanıcının yönetici ayrıcalıklarına sahip olması gerekir.

  • Kurulumu başlatmak için Setup.TruSmartCAM.<version>.exe dosyasını çalıştırın.

Sürüm bir sayıdır.

  • Lisans sözleşmesini okuyun ve I accept the agreement seçeneğini seçin, ardından Next öğesine tıklayın.

Adım 1 : Kurulum Konumu

  • Kurulum dizinini belirtin veya varsayılan kurulum konumu olan C:\Program Files\TRUMPF\TMM\Praxis konumunu kabul edin ve Next öğesine tıklayın.

    • C:\Program Files\TRUMPF\TMM\Praxis - Kurulum klasörü şu klasörleri içerir: Bin, MetaCAM, Samples ve Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Veri Klasörü şu klasörleri içerir: TruSmartCAM, TecZone ve MetaCAM.

Adım 2 : Bileşen Seçimi

Installation Type Components

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Picks all Stations Terminal like TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Picks by user choice.

  • Full Installation’ı seçin. TruSmartCAM Araçlarından Code Senders ve Bend Code Senders öğelerini seçin. Artık Kurulum türü Custom olarak değişir. Next öğesine tıklayın.

Adım 3 : SQL Server Kurulumunu Seçme

SQL Express 2022 kurulumu yalnızca TruSmartCAM Sunucusu için gereklidir. Bu seçenek İstemci ve Sync Kurulumlarında kullanılamaz. Ayrıca bu seçenek ilk kez açık (Checked ON) olarak işaretlenir ve kurulur, sonrasında göz ardı edilebilir. TruSmartCAM sunucusunda SQL zaten kuruluysa, kullanıcı Adım 3’ü göz ardı edebilir.

  • Select Additional Tasks içinde: Install SQL Express öğesine tıklayın ve Next öğesine tıklayın.

  • Ready to Install içinde: Tüm kurulum özelliklerini özetleyin ve Install öğesine tıklayın.

Adım 4 : SQL Server Kurulumu

TruSmartCAM bileşenleri kurulduktan sonra, yükleyici SQL server kurulumuyla devam eder. Devam etmek için Lisans Sözleşmesini kabul edin ve SQL express’i varsayılan seçeneklerle kurun.

Kurulum tamamlandıktan sonra Close öğesine tıklayın ve kurulumu tamamlayın.

Windows sürümüne bağlı olarak, SQL kurulumunu kapatmak yeniden başlatma istemi görüntüleyebilir.

Adım 5 : Windows Masaüstü kısayolları

  • SQL kurulumundan sonra, Sistem yeniden başlatılmazsa, Launch TruSmartCAM onay kutusunu seçin ve Finish öğesine tıklayın.

  • Sistem yeniden başlatılırsa, Masaüstündeki TruSmartCAM kısayol simgesini başlatın veya Windows Başlat Programı’nda TruSmartCAM yazın ve Run as administrator ile çalıştırın.

Sunucu kurulumu : TruSmartCAM ve TruSmartCAM License Kısayol simgeleri Masaüstünde bulunur.
İstemci/SYNC Kurulumu : Masaüstünde yalnızca TruSmartCAM kısayol simgesi bulunur.

Adım 6 : Lisans Kaydı

  • Serial Number alanına, Trumpf Metamation Servis Ekibi tarafından sağlanan TruSmartCAM Seri anahtarını yazın. "Registered to" alanına <Company Name> ve E-Posta yazın. OK öğesine tıklayın.

Ağ güvenlik duvarı lisans kaydını engellerse veya TruSmartCAM Sunucu bilgisayarında İnternet yoksa, TruSmartCAM lisansı Çevrimdışı etkinleştirme ile yapılır. C:\ProgramData\TRUMPF\TMM\Praxis Klasöründeki Prax.request dosyasını Trumpf Metamation Servis Ekibine e-postayla gönderin. Trumpf Metamation Ekibi, bu klasöre bırakılması gereken Prax.lock dosyasını sağlayacaktır.

Adım 7 : İlk kez tek seferlik Yapılandırma

  • Veritabanı Adını yazın ve Veri Depolama Konumunu Ayarlayın. Use SQL Server onay kutusunu seçin ve Veritabanına bağlanmak için SQL server adını seçin. OK öğesine tıklayın.

  • TruSmartCAM Masaüstü İstemcisi açılır ve alt kısımda Database Connection Succeeded ifadesini gösterir.

  • TruSmartCAM, TecZone ve MetaCAM Yapılandırma dosyaları, varsayılan yapılandırma makineleriyle veya TruSmartCAM lisans makinelerine göre oluşturulmuştur. Aynı yapılandırma tüm TruSmartCAM İstemcileri arasında paylaşılacaktır.

Hoş geldiniz ekranı, TruSmartCAM Oturum Açma ve Adı olarak Windows Kullanıcı OturumAdı’nı gösterir. İlk TruSmartCAM Kullanıcısı Site Admin olarak kabul edilir. E-posta ve Parola girin. OK öğesine tıklayın .

Oturum açma kimlik bilgilerini bir sonraki sefere kaydetmek için Remember me onay kutusunu seçin. Remember me onay kutusunu temizlemek, TruSmartCAM uygulaması her başlatıldığında oturum açma ve parola iletişim kutusunu isteyecektir.

Adım 8 : TruSmartCAM oturum açma

  • TruSmartCAM uygulamasını kapatın ve yeniden açın. Sistem, TruSmartCAM oturum açma kimlik bilgilerini girmenizi ister.

  • Oturum açmış kullanıcı adı, TruSmartCAM uygulama başlığındaki kullanıcı simgesinin yanında görüntülenir.

  • Kullanıcı simgesinin üzerine geldiğinizde, sistem şunları görüntüler:

    • Kullanıcı rolü (örneğin: Programmer, Admin).

    • Oturumu kapatmak için bir kısayol: Ctrl+L.

  • Kullanıcı simgesine tıklamak, aşağıdakileri yapmanıza olanak tanıyan bir menü açar:

    • Edit information…​ - Profil ayrıntılarınızı güncelleyin.

    • Change password…​ - Hesap parolanızı değiştirin.

    • Sign out - Uygulamadan çıkış yapın.

    • Cancel - Herhangi bir değişiklik yapmadan menüyü kapatın.

Adım 9 : Fabrika Makine Yapılandırması

  • TruSmartCAM Lisansı [Tüm makineler lisans bitini etkinleştirir] : Varsayılan TruSmartCAM Makinesi ve Malzemesi Fabrika Yapılandırması olarak kabul edilir.

  • TruSmartCAM Lisansı [Demo yok ve birkaç makine biti etkin] : O birkaç makine ve varsayılan Malzeme Fabrika Yapılandırması olarak kabul edilir.

  • (Open → Import) yoluyla C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts konumundan yeni bir Parça açın ve Parçanın başarıyla içe aktarılıp aktarılmadığını doğrulayın.

Not 1 : TruSmartCAM Monitor

  • Engine Kurulumu ile TruSmartCAM Monitor (Site admin hakları):

    • Engine ile birlikte Site Admin TruSmartCAM Haklarına sahip TruSmartCAM Monitor şu seçeneklere sahip olacaktır:

      1. TruSmartCAM yapılandırmasını, TecZone, MetaCAM yapılandırmasını tüm TruSmartCAM İstemcilerine gönderin. Ayrıca Yeni TruSmartCAM Kullanıcı Oturumu oluşturma haklarına da sahiptir.

      2. Show Agents, TruSmartCAM Lisansına göre otomasyon görevini yapmak için mevcut toplam engine sayısını gösterir.

  • Engine Kurulumu olmadan TruSmartCAM Monitor (Site admin hakları):

  • Engine Kurulumu olmadan TruSmartCAM Monitor (Site Admin olmayan haklar):

TruSmartCAM uygulamasını çalıştıran bilgisayarda Engine TruSmartCAM bileşeni kurulu olmalıdır [Sunucu bilgisayarı veya herhangi bir İstemci kurulumunda]. Engine TruSmartCAM bileşeninin kurulu olduğu bilgisayar, tüm otomasyon görevlerini yapmak için 7x24 çalışıyor olmalıdır.
Not 2 : OpenGL

  • TruSmartCAM uygulaması açılırken hemen kapanıyor ve ayrıca pmonitor görev çubuğunda gösterilmiyor.

  • Bu, OpenGl sorununu temsil eder.

  • Bunu doğrulamanın başka bir yolu: OpenGL sorunuyla ilgili hata iletişim kutusunu görüntüleyen C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts dosyasını açın.

  • TruSmartCAM uygulamasının başarıyla açılmasını sağlamak için C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini dosyasının options bölümünü GLVersion=1 ile güncelleyin.

[Options]
GLVersion=1.0
