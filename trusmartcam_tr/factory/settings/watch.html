İzleme

Watch Settings, TruSmartCAM uygulamasının belirlenen bir klasörü izlemesine ve dosyaları otomatik olarak sisteme aktarmasına olanak tanır. Bu, Parçaların, Job’ların, Montajların ve Siparişlerin içe aktarılmasını el ile müdahale olmaksızın otomatikleştirmeye yardımcı olur.

Watch settings

Enable 'Live Folder' - Belirtilen klasörün otomatik izlenmesini etkinleştirir.

Watch this folder - Gelen dosyalar için izlenecek klasörü belirtir.

Watch sub-folders also - Tüm alt klasörleri izleme sürecine dahil eder.

After file import

After import - Dosya içe aktarıldıktan sonra kullanıcının iki seçeneği vardır. Dosya konumdan silinebilir veya farklı bir konuma taşınabilir.

  • Delete imported file - Başarılı bir içe aktarmadan sonra kaynak dosyayı kaldırır.

  • Move imported file - Başarılı bir içe aktarmadan sonra kaynak dosyayı Move files to this folder içinde belirtilen klasöre taşır.

Move files to this folder - After import, Move imported file olarak ayarlandığında başarıyla içe aktarılan dosyaların taşınacağı hedef klasörü belirtir.

Move spreadsheets with errors to this folder - Başarısız içe aktarmaları belirtilen hata klasörüne taşır.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - İzleme klasöründe algılanan elektronik tablo dosyalarını otomatik olarak içe aktarır.

Do not import spreadsheet with errors - Doğrulama hataları içeren dosyaların içe aktarılmasını engeller.

Spreadsheet import option - Açılır listeden içe aktarılacak veri türünü seçer. Desteklenen elektronik tablo biçimleri CSV, XLSX veya XML olabilir. Kullanılabilir seçenekler şunlardır:

  • Import Jobs - Elektronik tablodan job verilerini içe aktarır.

  • Import Orders - Elektronik tablodan sipariş verilerini içe aktarır.

  • Import Assemblies - Elektronik tablodan montaj verilerini içe aktarır.

  • Import Parts - Elektronik tablodan parça verilerini İçe aktarır.

Ek bilgiler

  • İzleme klasörünü yapılandırırken bir UNC yolu (\\ServerName\FolderPath) veya eşlenmiş bir sürücü (M:\FolderPath) kullanın. C:\FolderPath gibi yerel yollar kullanmayın.

  • TruSmartCAM Engine hizmetini çalıştıran bilgisayarın, yapılandırılan izleme klasörüne okuma ve yazma erişimi olmalıdır. Yeterli izinler olmadan dosyalar başarıyla algılanamayabilir, içe aktarılamayabilir, taşınamayabilir veya silinemeyebilir.

  • Elektronik tablo eşlemesi, Watch Settings etkinleştirilmeden önce yapılandırılmalıdır. Aksi takdirde, TruSmartCAM izleme klasöründe algılanan elektronik tablo dosyalarını işleyemez.
