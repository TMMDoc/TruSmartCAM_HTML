Siparişleri içe aktarma

Siparişler aşağıdaki yöntemler kullanılarak oluşturulabilir veya içe aktarılabilir:

  1. Siparişleri elektronik tablo dosyalarından içe aktarma.

  2. Siparişleri izleme ayarları aracılığıyla otomatik olarak içe aktarma.

  3. Parça kitaplığındaki mevcut parçalardan sipariş oluşturma.

  4. Montaj statik nest’lerinden sipariş oluşturma.

Siparişleri elektronik tablodan içe aktarma

  • Open → Import Orders…​ yolunu izleyin.

  • Desteklenen elektronik tablo biçimleri arasında CSV, XLSX ve XML bulunur.

  • Gerekli elektronik tablo dosyasını seçin ve Open öğesine tıklayın.

  • Içe aktarma süreci Job/Montaj içe aktarma iş akışına benzer.

Siparişleri içe aktarmak için elektronik tabloyu doğrudan Siparişler sayfasına da sürükleyip bırakabilirsiniz.

Siparişleri izleme ayarlarını kullanarak içe aktarma

  • Watch settings içinde Import spreadsheet from 'Live Folder' seçeneğini etkinleştirin.

  • Spreadsheet import option içinde Import Orders öğesini seçin.

  • Siparişlerin içe aktarılacağı klasör konumunu yapılandırın.

  • Sistem, yapılandırılan klasörü sürekli olarak izler.

  • Yeni eklenen elektronik tablo dosyaları otomatik olarak Siparişler’e içe aktarılır.

Ayrıntılı yapılandırma adımları için İzleme ayarları belgelerine bakın.

Parça kitaplığından sipariş oluşturma

  • Parça Kitaplığı’ndan gerekli parçaları seçin.

  • Sağ tıklayın ve New Orders iletişim kutusunu açmak için New…​ → Order öğesini seçin.

  • Miktar, teslim tarihi ve öncelik gibi gerekli ayrıntıları girin.

  • Siparişleri oluşturmak için OK öğesine tıklayın.

  • Sistem otomatik olarak Siparişler sayfasına geçer.

  • Oluşturulan siparişler, job oluşturmak için Siparişler Hazır sayfasında görüntülenir.

Montajdan sipariş oluşturma

  • Gerekli Montaja sağ tıklayın.

  • New Orders iletişim kutusunu açmak için New…​ → Order öğesini seçin.

  • Gerekli Assembly count değerini girin.

  • Siparişleri oluşturmak için OK öğesine tıklayın.
