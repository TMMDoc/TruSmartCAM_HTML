Persyaratan Port

TruSmartCAM Server : 7371

Server menunggu permintaan client pada port TCP ini. Koneksi masuk harus diizinkan ke port ini pada Komputer Server.

Floating License Server : 5776

Floating License Server menunggu permintaan lisensi pada port ini. Koneksi masuk harus diizinkan ke port ini pada komputer floating license server (TruSmartCAM Server).

Koneksi lisensi ke Cloud : 7567

Port ini digunakan oleh TecZone (Perangkat Lunak Tekuk) dan Floating License Server untuk mengirim permintaan lisensi ke Metamation Cloud. Jadi koneksi keluar harus diizinkan pada port ini untuk aktivasi dan pembaruan lisensi.

Persyaratan Instalasi dan Dukungan

  • Hak istimewa administratif diperlukan untuk memasang aplikasi TruSmartCAM.

  • Alat diagnostik jarak jauh melalui Contractor VPN atau koneksi aman.
