Instalasi server

Instalasi server

Ikuti instruksi untuk memasang instalasi TruSmartCAM Server beserta SQL.

Hak Administrator

Untuk menjalankan instalasi ini, pengguna harus memiliki hak istimewa administratif.

  • Jalankan Setup.TruSmartCAM.<version>.exe untuk memulai instalasi.

Version adalah sebuah angka.

  • Baca perjanjian lisensi dan pilih I accept the agreement lalu Klik Next.

Langkah 1 : Lokasi Instalasi

  • Sebutkan direktori instalasi atau terima default instalasi C:\Program Files\TRUMPF\TMM\Praxis lalu klik Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Folder Install akan memiliki folder berikut : Bin, MetaCAM, Samples dan Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Folder Data akan memiliki folder berikut : TruSmartCAM, TecZone dan MetaCAM.

Langkah 2 : Pemilihan Komponen

Installation Type Components

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Memilih semua Stations Terminal seperti TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Memilih sesuai pilihan pengguna.

  • Pilih Full Installation. Pilih Code Senders dan Bend Code Senders dari perkakas TruSmartCAM. Kini tipe Instalasi berubah menjadi Custom. Klik Next.

Langkah 3 : Pilih Instal SQL Server

Instalasi SQL Express 2022 hanya diperlukan untuk TruSmartCAM Server. Opsi ini tidak tersedia untuk instalasi Client dan Sync. Opsi ini juga Dicentang ON dan dipasang untuk pertama kali serta dapat diabaikan setelahnya. Jika SQL sudah terpasang di TruSmartCAM server, pengguna dapat mengabaikan Langkah 3.

  • Pada Select Additional Tasks : Klik Install SQL Express lalu Klik Next.

  • Pada Ready to Install : Rangkum semua fitur instalasi lalu Klik Install.

Langkah 4 : Instalasi SQL Server

Setelah komponen TruSmartCAM terpasang, installer melanjutkan dengan instalasi SQL server. Terima License Agreement untuk melanjutkan dan pasang SQL express dengan opsi default.

Setelah instalasi selesai, Klik Close dan selesaikan instalasi.

Bergantung pada versi Windows, menutup instalasi SQL dapat meminta mulai ulang.

Langkah 5 : Pintasan Desktop Windows

  • Setelah SQL terpasang, jika Sistem tidak mulai ulang, maka pilih kotak centang Launch TruSmartCAM lalu Klik Finish.

  • Jika Sistem mulai ulang, maka Luncurkan ikon pintasan TruSmartCAM di Desktop atau ketik TruSmartCAM pada Windows Start Program lalu Run as administrator.

Instalasi server : Ikon pintasan TruSmartCAM dan TruSmartCAM License tersedia di Desktop.
Instalasi Client/SYNC : Hanya ikon pintasan TruSmartCAM yang tersedia di Desktop.

Langkah 6 : Registrasi Lisensi

  • Pada bidang Serial Number, ketik TruSmartCAM Serial key yang diberikan oleh Trumpf Metamation Service Team. Ketik <Company Name> pada bidang "Registered to" dan E-Mail. Klik OK.

Jika Network firewall memblokir registrasi lisensi atau Tidak ada internet pada PC TruSmartCAM Server, maka lisensi TruSmartCAM dilakukan melalui aktivasi Offline. Kirimkan email Prax.request dari Folder C:\ProgramData\TRUMPF\TMM\Praxis ke Trumpf Metamation Service Team. Trumpf Metamation Team akan memberikan Prax.lock yang perlu diletakkan di folder ini.

Langkah 7 : Konfigurasi awal satu kali

  • Ketik Database Name dan Atur Data Storage Location. Pilih kotak centang Use SQL Server lalu pilih nama SQL server untuk tersambung ke Database. Klik OK.

  • TruSmartCAM Desktop Client terbuka menampilkan Database Connection Succeeded di bagian bawah.

  • File Konfigurasi TruSmartCAM, TecZone dan MetaCAM dibuat dengan mesin config default atau berdasarkan mesin lisensi TruSmartCAM. Konfigurasi yang sama akan dibagikan ke seluruh Client TruSmartCAM.

Layar sambutan ditampilkan dengan LoginName Pengguna Windows sebagai Login dan Name TruSmartCAM. Pengguna TruSmartCAM pertama dianggap sebagai Site Admin. Berikan Email dan Kata Sandi. Klik OK .

Pilih kotak centang Remember me untuk menyimpan kredensial login untuk lain waktu. Mengosongkan kotak centang Remember me akan meminta dialog login dan kata sandi setiap kali aplikasi TruSmartCAM diluncurkan.

Langkah 8 : Masuk ke TruSmartCAM

  • Tutup TruSmartCAM dan buka kembali. Sistem meminta Anda untuk memasukkan kredensial login TruSmartCAM.

  • Nama pengguna yang masuk ditampilkan di samping ikon pengguna pada header aplikasi TruSmartCAM.

  • Ketika Anda mengarahkan kursor ke ikon pengguna, sistem menampilkan:

    • Peran pengguna (misalnya: Programmer, Admin).

    • Pintasan untuk keluar: Ctrl+L.

  • Mengklik ikon pengguna membuka menu yang memungkinkan Anda untuk:

    • Edit information…​ - Memperbarui detail profil Anda.

    • Change password…​ - Mengubah kata sandi akun Anda.

    • Sign out - Keluar dari aplikasi.

    • Cancel - Menutup menu tanpa melakukan perubahan apa pun.

Langkah 9 : Konfigurasi Mesin Pabrik

  • Lisensi TruSmartCAM [bit lisensi semua mesin diaktifkan] : Mesin TruSmartCAM dan Material default dianggap sebagai Konfigurasi Pabrik.

  • Lisensi TruSmartCAM [Tidak ada demo dan sedikit bit mesin diaktifkan] : Sedikit mesin tersebut dan Material default dianggap sebagai Konfigurasi Pabrik.

  • (Open → Import) sebuah Komponen baru dari C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts dan verifikasi apakah Komponen berhasil diimpor.

Catatan 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor dengan Instalasi Engine (hak site admin):

    • TruSmartCAM Monitor dengan Engine beserta hak Site Admin TruSmartCAM akan memiliki opsi berikut:

      1. Mendorong konfigurasi TruSmartCAM, TecZone, MetaCAM ke seluruh Client TruSmartCAM. Juga memiliki hak untuk membuat Login Pengguna TruSmartCAM Baru.

      2. Show Agents akan menampilkan total engine yang tersedia untuk melakukan tugas otomasi yang sesuai dengan Lisensi TruSmartCAM.

  • TruSmartCAM Monitor tanpa Instalasi Engine (hak site admin):

  • TruSmartCAM Monitor tanpa Instalasi Engine (hak Non Site Admin):

PC yang menjalankan aplikasi TruSmartCAM harus memiliki komponen Engine TruSmartCAM terpasang [PC Server atau di Client mana pun]. PC yang terpasang komponen Engine TruSmartCAM harus berjalan 24x7 untuk melakukan semua tugas otomasi.
Catatan 2 : OpenGL

  • Aplikasi TruSmartCAM saat membuka langsung tertutup dan juga pmonitor tidak ditampilkan pada task bar.

  • Ini menunjukkan masalah OpenGl.

  • Cara lain untuk mengonfirmasi ini: Buka C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts yang menampilkan dialog error tentang masalah OpenGL.

  • Perbarui C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , bagian options dengan GLVersion=1 membuat aplikasi TruSmartCAM terbuka dengan sukses.

[Options]
GLVersion=1.0
