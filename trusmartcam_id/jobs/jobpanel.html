Panel pekerjaan

Bagian ini menjelaskan tindakan terkait pekerjaan seperti Export outputs, Reset job…​, Mark complete…​, Export job…​, dan opsi lain yang digunakan untuk mengelola instans pekerjaan.

Open in read-only mode for viewing
Membuka pekerjaan yang dipilih dalam mode hanya-baca.

Check-out the document for editing
Mengaktifkan pengeditan pekerjaan yang dipilih.

Delete
Menghapus pekerjaan yang dipilih.

View Report
Membuka laporan produksi untuk pekerjaan yang dipilih.

Export Outputs

Mengekspor file keluaran siap-mesin (file NC dan laporan) yang dihasilkan untuk pekerjaan yang dipilih.

Plan Job…​

Menghasilkan tata letak nest untuk komponen dalam pekerjaan yang dipilih.

Reset Job…​

Menghapus semua tata letak yang dihasilkan untuk pekerjaan dan mengatur ulang komponennya ke keadaan dapat direncanakan.

Mark Complete…​

Menandai pekerjaan dan semua nest-nya sebagai selesai setelah produksi.

Export Job…​

Mengekspor pekerjaan lengkap sebagai paket yang dapat digunakan kembali atau diimpor ke sistem lain.

Prev / Next / Layout

Menavigasi ke tata letak sebelumnya atau berikutnya dalam pekerjaan yang dipilih.

Sort and filter

Gunakan filter ini untuk melihat pekerjaan lain yang memiliki Same Customer, Same Part.

Export outputs

  • Pilih pekerjaan yang diperlukan.

  • Klik Export outputs.

  • Ini mengekspor file keluaran siap-mesin yang dihasilkan untuk pekerjaan yang dipilih.

  • Export Outputs dapat disimpan ke lokasi default yang dikonfigurasi di Factory Settings atau ke lokasi kustom menggunakan Browse…​.

  • Ini hanya mengekspor file keluaran mesin (seperti NC dan laporan) untuk pekerjaan.

  • File-file ini digunakan langsung untuk produksi dan dapat dikirim ke mesin.

Reset job…​

Mengatur ulang pekerjaan yang dipilih dengan menghapus semua tata letak yang dihasilkan dan membuat komponen tersedia untuk perencanaan kembali.

Untuk mengatur ulang pekerjaan:

  • Klik kanan pekerjaan dan pilih Reset job…​.

  • Ini menghapus semua tata letak nest yang ada untuk pekerjaan yang dipilih dan mengatur ulang semua komponennya ke keadaan dapat direncanakan.

  • Jika tata letak berisi komponen dari pekerjaan lain, komponen tersebut juga diatur ulang.

Export job…​

  • Pilih pekerjaan yang diperlukan.

  • Klik Export job…​.

  • Opsi ini mengekspor pekerjaan lengkap sebagai paket yang dapat digunakan kembali atau diimpor ke sistem lain.

  • Data yang diekspor mencakup semua informasi yang diperlukan untuk membuat ulang pekerjaan:

    • Detail dan kuantitas komponen (file CSV).

    • Data tata letak dan nesting (file CSV / FXYLT).

  • File yang diekspor disimpan sebagai folder pekerjaan di lokasi ekspor yang dikonfigurasi.

  • Opsi ini digunakan untuk mentransfer, berbagi, atau mencadangkan seluruh pekerjaan.

Mark complete…​

  • Setelah pekerjaan diproses pada mesin, buka Panel pekerjaan dan pilih Mark complete…​.

  • Saat sebuah pekerjaan ditandai sebagai selesai:

    • Semua nest di bawah pekerjaan ditandai sebagai selesai.

    • Pekerjaan diredupkan, dipindahkan ke akhir daftar, dan ditampilkan dengan tanda centang hijau.

    • Semua tata letak di bawah pekerjaan dihapus dari daftar tata letak aktif.

    • Status komponen dan pekerjaan diperbarui, dan kuantitas yang diproses berpindah ke keadaan selesai.

    • File keluaran untuk semua tata letak dalam pekerjaan dihapus dari lokasi keluaran mesin untuk menghindari penggunaan ganda.
