Impor komponen

Impor komponen

Sebelum mengimpor komponen, pastikan format file kompatibel dengan TruSmartCAM. Lihat supported file formats untuk detail lebih lanjut.

Jika material dan ketebalan tidak dipetakan ke komponen setelah impor, tetapkan material menggunakan panel komponen.

Metode impor

Ada tiga metode untuk mengimpor komponen ke Pustaka Komponen:

  1. Impor melalui file

  2. Seret dan lepas

  3. Folder pantau

Impor melalui file

File komponen 2D atau 3D dapat diimpor ke Pustaka Komponen menggunakan opsi Import parts…​.

  • Klik ikon open dari bilah perintah dan pilih opsi Import parts…​.

  • Dialog Open muncul — pilih file CAD apa pun (2D atau 3D).

  • Pratinjau file CAD yang dipilih ditampilkan.

  • Pilih komponen yang diperlukan dan klik Open.

  • Sistem secara otomatis melakukan tooling komponen untuk semua mesin yang tersedia dengan status perkakas yang diperbarui.

Seret dan lepas

  • Seret dan lepas file komponen langsung ke Pustaka Komponen TruSmartCAM.

Folder pantau

Pengaturan pantau memungkinkan Anda memantau folder untuk file baru dan secara otomatis mengimpornya ke Pustaka Komponen.

Untuk mengonfigurasi, lihat halaman Watch settings.

  • Gunakan jalur UNC (Universal Naming Convention) \\192.168.1.11\<Folder path> atau drive yang dipetakan M:\<Folder Path>.

  • PC yang menjalankan Engine harus memiliki akses baca/tulis ke folder ini.

  • Jangan gunakan jalur lokal seperti C:\<Folder Path> karena layanan Watch mencari file di PC Engine — bukan PC lokal.

Konfigurasi impor

Use geometry comparison on same CAD revision

Saat mengimpor komponen dengan revisi CAD yang sama, TruSmartCAM dapat membandingkan geometri file CAD dengan komponen yang sudah ada.

  • Untuk mengaktifkannya, konfigurasikan Revision lookup keys (misalnya, REV) di factory → settings →Import. Kemudian, aktifkan opsi Use geometry comparison on same CAD revision.

Perbandingan geometri pada revisi CAD yang sama hanya berfungsi ketika Revision lookup keys telah dikonfigurasi.

  • Sekarang, impor sebuah komponen ke pustaka komponen dengan revisi tertentu (misalnya, Revisi 1).

  • Komponen yang sama diimpor kembali dengan nilai revisi yang sama.

  • TruSmartCAM membandingkan geometri file CAD yang baru diimpor dengan komponen yang sudah ada.

  • Jika perbedaan geometri terdeteksi, TruSmartCAM menampilkan prompt yang menanyakan apakah akan:

    • Replace komponen yang sudah ada dengan geometri baru, dengan mempertahankan nilai revisi yang sama.

    • Skip impor, mempertahankan komponen yang sudah ada beserta geometrinya.

Hal ini memungkinkan pengguna memperbarui geometri komponen tanpa mengubah nilai revisi, sambil tetap mengendalikan apakah komponen yang sudah ada akan diganti.

Komponen yang diimpor secara otomatis ditambahkan ke pustaka untuk penggunaan lebih lanjut. Untuk informasi lebih lanjut, lihat Library.
