Impor pekerjaan

Impor dari csv atau xlsx

Anda juga dapat mengimpor pekerjaan dalam format teks umum

  • Klik File → Open → Import Jobs, dialog Open Folder muncul. Pilih C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Jika semua Komponen ada di lokasi csv atau di direktori folder lookup, jendela new job muncul dengan mencantumkan semua komponen yang cocok dengan field csv.

  • Komponen yang hilang diabaikan dan tidak muncul di jendela new job.

  • Awalnya status Komponen adalah Nascent.

  • Klik OK, sekarang komponen diimpor ke Pustaka Komponen.

Create a blank part for the missing CAD files

Saat mengimpor pekerjaan menggunakan spreadsheet (.csv atau .xlsx), terkadang Anda mungkin memiliki baris yang merujuk ke file CAD yang tidak tersedia di sistem.

  • Untuk menangani hal ini, buka Factory → Settings → Job, di bawah Spreadsheet import settings aktifkan Create a blank part for the missing CAD files

Ketika opsi ini dipilih:

  • Jika file CAD hilang untuk baris mana pun selama impor pekerjaan, sistem akan secara otomatis membuat komponen kosong sebagai pengganti file CAD yang hilang.

  • Di jendela new job, komponen yang hilang ini disorot secara visual dengan warna kuning untuk menunjukkan bahwa file CAD terkait hilang.

  • Komponen yang hilang tetap memiliki field yang dipetakan (seperti nama komponen, material, ketebalan, kuantitas, dll.) dari CSV. Namun, status komponennya akan ditampilkan sebagai Nascent, artinya hanya berupa placeholder kosong tanpa geometri aktual.

Hal ini memastikan impor pekerjaan tetap dapat berlanjut tanpa error akibat file CAD yang hilang — Anda dapat memperbarui atau mengganti komponen kosong dengan file CAD yang benar nanti ketika tersedia.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Ketika kotak centang ini dipilih, sistem secara otomatis membuat pekerjaan baru tanpa menampilkan dialog New Job jika spreadsheet tidak memiliki error (tidak ada komponen yang hilang, tanggal yang hilang, atau data yang tidak valid).

  • Ketika kotak centang ini dikosongkan, dialog New Job selalu muncul untuk tinjauan dan konfirmasi pengguna, meskipun spreadsheet tidak memiliki error.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Ketika kotak centang ini dipilih, sistem mengharapkan spreadsheet menggunakan kolom Raw-Material (misalnya, Steel-20). Ini berarti jenis material dan ketebalan harus digabungkan menjadi satu nilai dalam satu kolom.

  • Ketika kotak centang ini dikosongkan, sistem mengharapkan spreadsheet memiliki kolom terpisah untuk Material dan Ketebalan (misalnya, Steel dan 2.00). Sistem menggabungkannya secara internal selama impor.

Folder pantau menggunakan CSV/XLSX

  • Di factory → Settings→ Watch settings centang Enable 'Live Folder' dan Watch sub-folders also.

  • Tetapkan jalur folder pantau (UNC atau drive yang dipetakan).

  • Di Spreadsheet import settings, centang Import spreadsheet from 'Live Folder'.

  • Pilih Import Jobs dari opsi Spreadsheet Import.

  • Salin C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv dan tempelkan ke Watch Folder.

  • Sistem memeriksa CSV dan mencoba membuat pekerjaan secara otomatis.

  • Jika file CAD hilang, tidak ada pekerjaan yang dibuat karena data CAD yang diperlukan tidak ditemukan.

Direktori lookup CAD & pencarian CAD rekursif - tidak dikonfigurasi

  • Di factory → Settings → Job → Spreadsheet import settings, jika tidak ada CAD lookup directories yang ditetapkan dan Use recursive CAD search tidak digunakan, sistem tidak mencari file CAD secara otomatis.

  • Jika kotak centang Create a blank part for the missing CAD files dipilih, pekerjaan tetap akan dibuat meskipun file CAD hilang.

  • Dalam hal ini, semua komponen dalam pekerjaan akan dibuat sebagai komponen nascent (kosong) — artinya tidak memiliki geometri karena file CAD tidak dapat ditemukan.

Direktori lookup CAD & pencarian CAD rekursif - dikonfigurasi

Ketika CAD lookup directories ditetapkan ke (C:\Program Files\TRUMPF\TMM\Praxis\Samples) dan Use recursive CAD search diaktifkan di bawah factory → Settings → Job → Spreadsheet import settings:

  • Sistem secara otomatis mencari folder yang ditentukan beserta semua subfoldernya untuk file CAD yang diperlukan yang disebutkan dalam spreadsheet.

  • Create a blank part for the missing CAD files juga diaktifkan, sehingga jika ada file CAD yang masih tidak ditemukan, sistem akan membuat komponen kosong sebagai placeholder.
