Impor rakitan

Rakitan adalah kelompok komponen terkait yang digabungkan menjadi satu unit, memungkinkan Anda mengelola beberapa komponen sekaligus sebagai satu entitas.

Anda dapat mengimpor rakitan menggunakan metode berikut:

  1. Impor melalui file

  2. Seret dan lepas

  3. Impor dari spreadsheet

Impor melalui file

Sebuah rakitan dapat diimpor ke Pustaka Komponen menggunakan opsi Import Assemblies…​.

  • Klik ikon Open di bilah perintah dan pilih Import Assemblies…​, atau gunakan File → Open → Import Assemblies…​.

  • Dialog Open muncul. Pilih file rakitan yang diperlukan.

  • Pratinjau rakitan yang dipilih ditampilkan.

  • Klik Open untuk mengimpor rakitan.

  • Rakitan yang diimpor dicantumkan di bawah tampilan Assemblies di Pustaka Komponen.

Seret dan lepas

  • Seret dan lepas sebuah rakitan langsung ke Pustaka Komponen TruSmartCAM.

Impor dari spreadsheet

  • Gunakan File → Open → Import Assemblies…​ dan pilih file CSV, XLSX, atau XML, atau seret dan lepas file tersebut.

  • Tinjau dan perbarui detail rakitan serta kuantitas sebelum impor. Gunakan Add…​ atau Remove…​ untuk memodifikasi.

  • Setelah impor, rakitan dapat disiapkan dan diberi Static Nest.
