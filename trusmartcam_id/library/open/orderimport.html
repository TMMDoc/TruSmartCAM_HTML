Impor pesanan

Pesanan dapat dibuat atau diimpor menggunakan metode berikut:

  1. Mengimpor pesanan dari file spreadsheet.

  2. Mengimpor pesanan secara otomatis melalui pengaturan pantau.

  3. Membuat pesanan dari komponen yang ada di pustaka komponen.

  4. Membuat pesanan dari nest statis rakitan.

Impor pesanan dari spreadsheet

  • Navigasikan ke Open → Import Orders…​.

  • Format spreadsheet yang didukung meliputi CSV, XLSX, dan XML.

  • Pilih file spreadsheet yang diperlukan dan klik Open.

  • Proses impor serupa dengan alur kerja impor Pekerjaan/Rakitan.

Anda juga dapat langsung menyeret dan melepaskan spreadsheet ke halaman Pesanan untuk mengimpor pesanan.

Impor pesanan menggunakan pengaturan pantau

  • Aktifkan opsi Import spreadsheet from 'Live Folder' di Watch settings.

  • Pilih Import Orders pada Spreadsheet import option.

  • Konfigurasikan lokasi folder tempat pesanan akan diimpor.

  • Sistem terus memantau folder yang dikonfigurasi.

  • File spreadsheet yang baru ditambahkan secara otomatis diimpor ke Pesanan.

Untuk langkah konfigurasi terperinci, lihat dokumentasi Watch settings.

Buat pesanan dari pustaka komponen

  • Pilih komponen yang diperlukan dari Pustaka Komponen.

  • Klik kanan dan pilih New…​ → Order untuk membuka dialog New Orders.

  • Masukkan detail yang diperlukan seperti kuantitas, tanggal jatuh tempo, dan prioritas.

  • Klik OK untuk membuat pesanan.

  • Sistem secara otomatis beralih ke halaman Pesanan.

  • Pesanan yang dibuat ditampilkan di halaman Orders Ready untuk pembuatan pekerjaan.

Buat pesanan dari rakitan

  • Klik kanan Rakitan yang diperlukan.

  • Pilih New…​ → Order untuk membuka dialog New Orders.

  • Masukkan Assembly count yang diperlukan.

  • Klik OK untuk membuat pesanan.
