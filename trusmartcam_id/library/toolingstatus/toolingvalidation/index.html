Validasi perkakas

Bagian ini menjelaskan cara mengakses dan memodifikasi informasi perkakas untuk komponen di TruSmartCAM.

  • Klik kanan tile komponen mana pun untuk membuka panel komponen dan mengakses opsi perkakas.

  • Klik Toolings untuk beralih ke instance yang di-tool pertama yang tersedia.

  • Alternatifnya, klik langsung pada sebuah instance yang di-tool untuk melihat detail mesin dan opsi perkakas.

  • Gunakan untuk Open in read-only mode for viewing.

  • Gunakan untuk Check-out the document for editing.

  • Instance yang di-tool yang dipilih terbuka di TecZone atau MetaCAM.

  • Lakukan pemeriksaan tooling manual dan buat perubahan yang diperlukan.

  • Ketika Anda mencoba menyimpan, dialog Unsaved Changes meminta Anda mengonfirmasi pengeditan Anda.

  • Klik Yes untuk melanjutkan penyimpanan.

  • Sistem melakukan Validasi Perkakas lagi setelah menyimpan.

  • Jika tidak ada error, opsi untuk Menyimpan perubahan ke TruSmartCAM muncul.

  • Jika ditemukan error perkakas, pesan error ditampilkan:

  • Setelah menyimpan, status perkakas komponen diperbarui di pustaka komponen.

  • Warna hijau pada instance yang di-tool menunjukkan instance tersebut telah di-check in.

  • Tooled Instance Author diperbarui ke orang terakhir yang mengeditnya.

  • Field User-edited menunjukkan apakah instance yang di-tool telah dimodifikasi secara manual. Ketika pengguna men-check out instance dan membuat perubahan apa pun, field ini secara otomatis disetel ke Yes setelah menyimpan.

  • Jika sebuah komponen sedang diedit, ikon pengguna muncul pada tile-nya.

  • Mengarahkan mouse ke tile menampilkan siapa yang men-check out-nya dan waktu komponen tersebut di-check out.

  • Selama komponen di-check out, opsi Check-out the document for editing dinonaktifkan untuk instance yang di-tool yang sama, dan opsi Cancel Check-out menjadi aktif.
