Export Outputs

Mengekspor output tooling yang dipilih ke tujuan yang dikonfigurasi.

Check Tooling

Memvalidasi tooling yang ada tanpa membuat perubahan apa pun dan memperbarui statusnya jika validasi gagal.

Copy Tooling…​

Menyalin penyiapan punch, urutan, dan back gauge dari tooling referensi yang dipilih dan menerapkannya ke solusi lain jika memungkinkan.

Menandai bend atau fold tooling yang dipilih sebagai ukuran flat referensi untuk menghasilkan solusi pemotongan.

Memproses ulang tooling yang dipilih untuk komponen tanpa memengaruhi tooling lainnya.

Menekan tooling yang dipilih sehingga dikecualikan dari pemrosesan dan pembuatan output lebih lanjut.

Sort and filter

Export Outputs

Opsi ini mengekspor output komponen ke tujuan yang dikonfigurasi di Factory Settings. (Lihat Bend Settings dan Cut Settings)

Hanya tooling yang terkait dengan operasi tooling yang dipilih yang diekspor, bukan seluruh komponen.

File yang diekspor bergantung pada jenis operasi. Untuk operasi Bend dan Fold, file NC dan laporan dihasilkan. Untuk operasi Cut dan Punch, hanya file komponen yang diekspor.

Check Tooling

  • Jika ada perubahan pada Pengaturan CAM atau sebuah bend tool hilang, Anda tidak perlu me-Re-tool komponen.

  • Sebagai gantinya, gunakan Check Tooling untuk memvalidasi tooling yang ada tanpa membuat perubahan apa pun.

  • Jika validasi gagal, status perkakas instance tersebut diperbarui, dan file output terkait dihapus.

  • Check Tooling juga mendeteksi komponen yang errornya sebelumnya di-override secara manual menggunakan Ignore Errors, dan memperbarui statusnya menjadi error jika diperlukan.

Copy tooling

Copy tooling memungkinkan Anda dengan cepat menerapkan bend tooling dari satu solusi ke solusi lain, menghemat waktu dan tenaga.

Ini menyalin penyiapan punch, urutan, dan back gauge dari tooling (solusi) referensi yang dipilih dan mencoba menerapkan pengaturan yang sama ke semua solusi lainnya.

  • Jika penyiapan yang disalin dapat dikerjakan untuk mesin target, penyiapan tersebut disimpan dan digunakan.

  • Jika penyiapan tidak dapat dikerjakan, tooling asli untuk mesin tersebut tetap tidak berubah.

Misalnya, Anda mungkin memiliki tooling berbeda untuk mesin berbeda:

  • Di sini, Mesin 5230X 4A menggunakan punch Gooseneck, Mesin 5230SX 6A menggunakan punch Pointed.

Ketika Anda menggunakan Copy Tooling…​ pada Mesin 5230X 4A, sistem mencoba menyalin penyiapan Gooseneck ke semua mesin lainnya.

Pengaturan punch, urutan, dan back gauge yang sama diterapkan jika memungkinkan. Jika penyiapan yang disalin tidak dapat digunakan, tooling asli tetap tidak berubah.

Setelah menerapkan copy tooling, penyiapan Gooseneck berhasil diterapkan ke semua mesin lain di mana hal itu dapat dikerjakan.

Set as Base-Flat…​

Fitur Set as Base-Flat…​ mendefinisikan bend atau fold tooling mana yang digunakan sebagai ukuran flat referensi untuk menghasilkan solusi pemotongan. Ketika sebuah tooling ditandai sebagai Base-Flat, TruSmartCAM memperbarui ukuran flat komponen berdasarkan mesin tersebut dan menghasilkan ulang solusi pemotongan sesuai dengan itu. Tooling Base-Flat ditampilkan dengan border biru di UI.

Mesin bend yang berbeda mungkin menghasilkan sedikit variasi ukuran flat untuk komponen yang sama. Ketika Anda menetapkan sebuah tooling sebagai Base-Flat, TruSmartCAM menggunakan ukuran flat mesin tersebut sebagai referensi utama dan secara otomatis menghitung ulang solusi pemotongan.

Pemilihan base flat otomatis

Ketika pengaturan pabrik Apply flat correction during bending diaktifkan:

  • TruSmartCAM secara otomatis menetapkan bend tooling (yang berisi tabel max bend length) sebagai Base-Flat selama impor komponen.

  • Jika bend tooling yang dipilih mengalami error atau tidak dapat dikerjakan, TruSmartCAM secara cerdas beralih dan menetapkan bend tooling valid lainnya sebagai Base-Flat. Ini memastikan referensi ukuran flat dan solusi pemotongan selalu tetap konsisten dan valid tanpa intervensi manual.

Manajemen base flat yang ditingkatkan

TruSmartCAM menyediakan opsi Base-Flat di dialog Save to Praxis saat menyimpan pengeditan bend atau fold tooling. Opsi ini hanya muncul untuk tooling dalam status OK dan memastikan ukuran flat serta solusi pemotongan tetap akurat.

Set as Base-Flat and calculate cutting solution

Opsi ini digunakan untuk menandai sebuah tooling sebagai Base-Flat untuk pertama kali dan secara otomatis menghasilkan solusi pemotongan yang sesuai.

Muncul ketika:

  • Tooling saat ini belum ditandai sebagai Base-Flat.

  • Pengguna telah men-check out tooling untuk pengeditan dan menyimpan perubahannya.

Untuk menggunakan opsi ini, check out bend atau fold tooling dan buat modifikasi yang diperlukan, seperti perubahan pada parameter bend atau ukuran flat. Tekan Ctrl+S untuk menyimpan perubahan. Di dialog Save to Praxis, pilih Set as Base-Flat and calculate cutting solution dan klik OK. TruSmartCAM akan menetapkan tooling sebagai Base-Flat dan menghasilkan solusi pemotongan menggunakan ukuran flat yang diperbarui.

Update the base-flat and re-calculate cutting solution

Opsi ini digunakan ketika tooling sudah ditandai sebagai Base-Flat dan telah diedit, sehingga memerlukan ukuran flat dan solusi pemotongan untuk dihasilkan ulang.

Muncul ketika:

  • Tooling sudah ditandai sebagai Base-Flat.

  • Pengguna telah men-check out, mengeditnya, dan menyimpan perubahannya.

Saat mengedit tooling Base-Flat yang ada, perbarui parameter bend atau geometri ukuran flat sesuai kebutuhan. Di dialog Save to Praxis, pilih Update the base-flat and re-calculate cutting solution. TruSmartCAM kemudian akan memperbarui tooling Base-Flat dan menghasilkan ulang semua solusi pemotongan terkait untuk mencerminkan perubahan terbaru.

Hanya satu bend tooling yang dapat ditetapkan sebagai Base-Flat pada satu waktu.

Ketika Base-Flat diubah, solusi pemotongan yang ada secara otomatis diproses ulang.

Fitur ini tersedia untuk bend maupun fold tooling di dalam TruSmartCAM.

Re-tool

Opsi ini memproses ulang tooling yang dipilih untuk komponen.

Klik kanan tooling yang diperlukan di panel Tooling dan klik Re-tool…​

Dialog konfirmasi ditampilkan sebelum melanjutkan.

Klik Yes untuk melanjutkan re-tooling, atau No untuk membatalkan operasi.

Hanya tooling yang dipilih yang di-retool. Tooling lain yang terkait dengan komponen tidak terpengaruh. Output yang ada terkait dengan tooling yang dipilih dihapus dan dibuat ulang selama proses re-tooling.

Gunakan opsi ini ketika data tooling sudah usang, salah, atau ketika perubahan dibuat pada konfigurasi mesin atau tooling.

Ignore errors

  • Jika sebuah instance yang di-tool menampilkan peringatan, dan Anda tetap ingin melanjutkannya, Anda dapat meng-override peringatan tersebut dengan mengklik Ignore errors.

  • Ini akan memungkinkan sistem mengekspor file output untuk instance tersebut, meskipun ada masalah tooling.

Gunakan Ignore Errors hanya jika Anda yakin peringatan tersebut dapat diabaikan dengan aman. Meng-override error yang sebenarnya dapat mengakibatkan kerusakan mesin atau risiko keselamatan.

Menekan/Membatalkan penekanan perkakas

  • Ketika sebuah mesin tidak aktif atau Anda tidak ingin komponen tertentu diproses oleh mesin tertentu, gunakan Suppress Tooling untuk mengecualikan komponen tersebut dari nesting pada mesin itu.

  • Setelah ditekan, mengarahkan mouse ke instance yang di-tool menampilkan pesan seperti: “Perkakas ditekan oleh <User name> pada <Date Time>”.

  • Penekanan perkakas menghapus file output untuk mesin dan komponen tersebut.

  • Gunakan Unsuppress tooling untuk memulihkan status perkakas komponen pada mesin tersebut.

  • Ketika penekanan dibatalkan, file output yang bersangkutan dihasilkan kembali.
