Tekuk

Pengaturan Tekuk dapat diakses dengan mengeklik ikon Pabrik lalu memilih Pengaturan, di mana Anda akan melihat daftar semua pengaturan lingkungan perangkat lunak yang tersedia.

Output settings

Save bend NC and reports- Hasil perkakas disimpan hanya jika perkakas OK dan pengaturan ekspor ini diaktifkan serta dikonfigurasi. Aktifkan opsi ini agar NC dan laporan Tekuk disimpan.

Show Raw Material name in bend reports - TruSmartCAM untuk mencetak nama material mentah dalam laporan tekuk.

Save bend tool setup CSV report - Mengekspor detail konfigurasi perkakas tekuk ke berkas CSV

Save bend FX along with NC - Jika opsi ini diaktifkan, saat penekukan dilakukan di dalam TruSmartCAM, output komponen akan disimpan ke direktori bersama berkas NC dan laporan untuk setiap penyiapan.

Bend output destination - Ini adalah tujuan tempat berkas NC, laporan, dan FX disimpan.

Process settings

Apply flat correction during bending - Saat opsi ini dipilih, TruSmartCAM memeriksa apakah dimensi datar diperbarui selama perkakas tekuk dan memperbarui kembali salinan induk yang digunakan untuk proses pemotongan.

Retain the legacy bend tooling when a FX file is imported - Aktifkan opsi ini untuk mempertahankan perkakas yang ada saat berkas FX lawas diimpor di TruSmartCAM.
