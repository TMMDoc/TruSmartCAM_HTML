Impor

Impor

Output settings

Save flat pattern - Aktifkan opsi ini agar pola datar dari komponen yang diimpor disimpan.

Format for flat pattern - Opsi ini digunakan untuk memilih format berkas DXF atau GEO.

Flat pattern destination - Ini adalah lokasi tempat pola datar akan disimpan.

Import settings

Units for DXF files - Ini adalah satuan ukuran yang digunakan untuk mengimpor berkas DXF; pengguna dapat memilih antara mm atau inci.

Material lookup keys - Beberapa entri pencarian dapat ditetapkan menggunakan pemisah koma di antaranya. Saat sebuah komponen diimpor, TruSmartCAM menggunakan kunci-kunci ini untuk mencari nilai material. Nilai yang dicari kemudian digunakan untuk menyelesaikan material mentah. Nilai asli disimpan dalam Properti Misc komponen.

Revision lookup keys - Saat sebuah komponen diimpor, nilai revisi dari berkas komponen mentah (berkas komponen yang sedang diimpor) dibandingkan dengan nilai revisi yang ada di repositori. Impor dibatalkan jika revisinya sama. Pemetaan bidang kustom kini juga didukung untuk berkas DXF. Untuk berkas DXF, data bidang kustom diekstraksi dari lapisan teks pada gambar atau lampiran PPI.

Use geometry comparison on same CAD revision - Membandingkan geometri saat mengimpor komponen dengan revisi CAD yang sama dan meminta pengguna untuk mengganti atau melewati impor jika perbedaan terdeteksi. Lihat Import configuration untuk detail lebih lanjut.

Part name keys - Opsi ini bekerja mirip dengan kunci material dan Revision lookup keys. Atur satu atau beberapa Part name keys untuk menggunakan Part name PPI alih-alih nama berkas sebagai nama komponen.

Thickness lookup keys - Beberapa entri pencarian dapat ditetapkan menggunakan pemisah koma di antaranya. Saat sebuah komponen diimpor, TruSmartCAM menggunakan kunci-kunci ini untuk mencari nilai ketebalan. Nilai yang dicari kemudian digunakan untuk menyelesaikan ketebalan. Nilai asli disimpan dalam Properti Misc komponen.

Thickness comparison fudge - Ini digunakan dalam pencarian material mentah saat sebuah komponen diimpor. TruSmartCAM mencoba menyelesaikan material mentah setelah nama material dan ketebalan diurai. Untuk informasi lebih lanjut, lihat topik Thickness fudge di bawah.

Identify shapes after a flat is imported - Saat sebuah komponen diimpor, bentuk-bentuk internal dalam komponen dapat dikenali dan diidentifikasi secara otomatis.

Shape identification fudge - Nilai fudge identifikasi bentuk dapat diatur pada:

  1. Global level - Nilai ini digunakan sebagai default untuk semua bentuk.

  2. Individual Shape Level - Nilai default dapat ditimpa dengan mengatur nilai fudge pada tingkat bentuk individual. Memilih bentuk dalam dialog Shape Library akan menampilkan nilai fudge. Secara default, ini diatur ke 0, dan nilai global default digunakan untuk bentuk-bentuk tersebut.

Rotate flat horizontally - Umumnya meja mesin pemotong berbentuk persegi panjang dan lebih lebar. Untuk meningkatkan kelayakan perkakas, putar komponen sepanjang lebar komponen setelah komponen diimpor.

Part rotation threshold - Atur ini sebagai jumlah minimum untuk mengizinkan rotasi. Komponen apa pun yang lebih kecil dari nilai yang diatur tidak akan diputar.

Misc settings

Enable pre-import external tools - Aktifkan opsi impor pre-import external tools untuk mengaktifkan Creo Reader. TruSmartCAM mengunggah instans keluarga yang telah diekstraksi sebelumnya dari komponen yang di-drop. Perlu diperhatikan bahwa ekstraksi instans dilakukan selama pengunggahan komponen (sebagai operasi pre-import), sehingga perangkat lunak Creo harus diinstal pada komputer tempat komponen diunggah.

Ignore drawing colors in Flat thumbnails for clarity - Aktifkan opsi ini untuk menghasilkan thumbnail grayscale yang lebih tajam. Warna lapisan dan entitas teks diabaikan demi kejelasan gambar.

Use only one Engine for all import tasks - Saat diaktifkan, hanya satu core engine yang digunakan untuk tugas impor.

Thickness fudge

Thickness comparison fudge memilih nilai ketebalan lembar terdekat saat ketebalan lembar yang diinginkan tidak tersedia dalam inventaris, dengan membandingkan nilai ketebalan lembar dalam inventaris.

Sebagai contoh, mari kita asumsikan hal berikut:

  1. Kita memiliki komponen dengan ketebalan lembar 1,6 mm dan material baja.

  2. Nilai Thickness comparison fudge adalah 0,1 mm.

  3. Inventaris memiliki lembar baja dengan ketebalan 1,5 mm, 1,55 mm, dan 1,7 mm.

TruSmartCAM memilih lembar dengan nilai ketebalan terdekat setelah membandingkan nilai Thickness comparison fudge (0,1 mm) dengan item yang diimpor (berukuran 1,6 mm). Dalam kasus ini, 1,55 mm akan menjadi pilihan.
