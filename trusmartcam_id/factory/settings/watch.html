Pantau

Watch Settings memungkinkan TruSmartCAM memantau folder yang ditentukan dan secara otomatis mengimpor berkas ke dalam sistem. Ini membantu mengotomatiskan impor Part, Job, Assembly, dan Order tanpa intervensi manual.

Watch settings

Enable 'Live Folder' - Mengaktifkan pemantauan otomatis folder yang ditentukan.

Watch this folder - Menentukan folder yang akan dipantau untuk berkas yang masuk.

Watch sub-folders also - Menyertakan semua subfolder dalam proses pemantauan.

After file import

After import - Setelah berkas diimpor, pengguna memiliki dua opsi. Berkas dapat dihapus dari lokasi atau dipindahkan ke lokasi yang berbeda.

  • Delete imported file - Menghapus berkas sumber setelah impor berhasil.

  • Move imported file - Memindahkan berkas sumber ke folder yang ditentukan dalam Move files to this folder setelah impor berhasil.

Move files to this folder - Menentukan folder tujuan tempat berkas yang berhasil diimpor akan dipindahkan saat After import diatur ke Move imported file.

Move spreadsheets with errors to this folder - Memindahkan impor yang gagal ke folder kesalahan yang ditentukan.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Secara otomatis mengimpor berkas spreadsheet yang terdeteksi di folder pantau.

Do not import spreadsheet with errors - Mencegah berkas yang mengandung kesalahan validasi agar tidak diimpor.

Spreadsheet import option - Memilih jenis data yang akan diimpor dari dropdown. Format spreadsheet yang didukung dapat mencakup CSV, XLSX, atau XML. Opsi yang tersedia adalah:

  • Import Jobs - Mengimpor data pekerjaan dari spreadsheet.

  • Import Orders - Mengimpor data pesanan dari spreadsheet.

  • Import Assemblies - Mengimpor data rakitan dari spreadsheet.

  • Import Parts - Mengimpor data komponen dari spreadsheet.

Informasi tambahan

  • Gunakan jalur UNC (\\ServerName\FolderPath) atau drive yang dipetakan (M:\FolderPath) saat mengonfigurasi folder pantau. Jangan gunakan jalur lokal seperti C:\FolderPath.

  • Komputer yang menjalankan layanan TruSmartCAM Engine harus memiliki akses baca dan tulis ke folder pantau yang dikonfigurasi. Tanpa izin yang memadai, berkas mungkin tidak terdeteksi, terimpor, terpindah, atau terhapus dengan sukses.

  • Pemetaan spreadsheet harus dikonfigurasi sebelum mengaktifkan Watch Settings. Jika tidak, TruSmartCAM tidak akan dapat memproses berkas spreadsheet yang terdeteksi di folder pantau.
