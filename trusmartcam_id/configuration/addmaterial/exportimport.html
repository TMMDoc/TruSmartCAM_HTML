Ekspor/Impor material

Ekspor/Impor material

Menggunakan format teks

Untuk mengekspor material inventaris, navigasikan ke Factory → Sheets, klik Export/Import , pilih Export sheets, pilih .txt, dan simpan ke folder target.

Buka file .csv yang diekspor, tambahkan Material Mentah dan Lembar baru dengan detail yang diperlukan, lalu simpan file.

Untuk mengimpor file yang diperbarui, navigasikan ke Factory → Sheets → Export/Import, pilih Import, pilih file TXT yang dimodifikasi, dan material serta lembar yang baru ditambahkan akan muncul di TruSmartCAM.

Menggunakan format CSV

  • Klik Factory → Sheets → Export/Import…​ → Export sheets. Pilih file CSV dan simpan ke folder target.

  • Tambahkan lembar dan parameter lembar, simpan file .csv.

  • Menggunakan Import sheets, pilih file .csv yang dimodifikasi.

  • Material dan lembar yang baru ditambahkan akan muncul di TruSmartCAM.

Impor Material harus berupa file berbasis teks yang disusun khusus dan mencakup format berikut.

Material-Name=[BendMaterial],[Density],[FName];
RawMaterial-Thickness,[Name]=[Film],[Treatment],[Surface];
Sheet-Width,Height,Grain,Desc,HeatNumber=Qty,[Factory],[Shelf],[Cost],[Comments]

Contoh: Aluminum0.5,Aluminum-051500,1500,None,=112,,,22,2500,1250,Horizontal,=105,,,7,2500,1500,None,=100

Untuk membuat file impor dengan mudah, ekspor material terlebih dahulu lalu lakukan modifikasi atau lihat strukturnya.
