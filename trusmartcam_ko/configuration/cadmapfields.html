CAD에서 필드 매핑(조회 키)

  • Factory → Settings → Import 에서 Import settings 섹션 아래. Pick Material lookup keys 를 클릭합니다. Select Fields 페이지가 나타납니다.

  • Browse 를 클릭하고 필요한 DXF 파일을 선택합니다.

  • Select Field 에 MAT, REV, THK 정보가 채워집니다.

  • MAT 를 선택하고 OK 를 클릭합니다.

  • Material lookup keys 필드가 MAT 필드로 업데이트됩니다. 마찬가지로 REV 및 THK 필드를 사용하여 Revision 및 Thickness lookup key 를 구성합니다.

  • File → Open → Import parts 로 이동하여 동일한 DXF 파일을 선택합니다.

  • 선택한 lookup key 에서 채워진 Material, Thickness 및 Revision 값과 함께 부품을 가져옵니다.

Part 00.04 를 두 번 클릭하면 Part detail 페이지에 Misc Properties 아래 CAD 파일에서 매핑된 필드 정보가 표시됩니다.
