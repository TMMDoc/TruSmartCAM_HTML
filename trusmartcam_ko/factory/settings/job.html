Output settings

Save layout NC and reports - 레이아웃 NC 와 리포트를 저장하려면 이 옵션을 활성화합니다.

Save layout file - 레이아웃 파일을 저장하려면 이 옵션을 활성화합니다.

Output simulation preview in reports - 다른 출력과 함께 툴링 시뮬레이션 미리 보기를 생성하려면 이 옵션을 활성화합니다. 이는 레이저/펀치 툴링에 대한 짧은 GIF 애니메이션입니다.

Do not delete program outputs on layout/job completion - 이 옵션을 활성화하면 작업/레이아웃이 완료로 표시될 때 프로그램 출력에 대한 삭제 작업을 건너뜁니다.

Nest settings

Mix parts from multiple Jobs - 혼합 모드 네스팅을 지원합니다. 더 나은 패킹 효율성을 위해 여러 작업의 부품을 함께 네스팅해야 합니다.

Do not auto-release layouts - 모든 레이아웃이 릴리스된 상태가 될 때까지 레이아웃이 생산에 사용될 수 없도록 합니다.

Re-nesting packing cut-off - 이 값은 네스트된 레이아웃이 승인 대기열에 유지되어 새 부품이 계획될 때 다시 네스트되는지, 아니면 생산용으로 릴리스되어 관련 출력이 출력 폴더로 내보내지는지를 결정하는 데 사용됩니다.

Interactive sheet-name prefix - 이 섹션은 사용자가 네스트되는 부품과 네스트 결과를 더 잘 제어할 수 있는 interactive nesting 을 지원하는 데 사용됩니다. 대화형으로 네스트된 레이아웃에는 auto-nesting 과 다른 명명 체계를 사용합니다.

Update sheet inventory on nest (un)release - 이 옵션을 활성화하면 네스트를 머신으로 보낼 때 시트 인벤토리가 업데이트됩니다. 또한 머신에서 네스트를 리콜하면 시트가 인벤토리로 반환됩니다.

Automate remnant inventory management - 이 스위치를 선택하면 소프트웨어가 잔재 인벤토리 관리를 자동화합니다. 선택하지 않으면 잔재 관리가 대화형이 됩니다.

Auto-refresh Out-of-date layouts - 선택하면 소프트웨어가 부품의 절단 솔루션이 계산된 후 해당 부품에 연결된 모든 Out-of-date Layouts 를 새로 고칩니다.

Automate twin-line nesting - twin-line 자동화를 활성화하려면 이 옵션을 선택합니다.

Pull workflow settings

Use 'Pull workflow' - 이 옵션은 고도로 자율적인 계획 및 네스팅 시스템이 필요한 사용자에게 유용합니다. 활성화하면 TruSmartCAM 이(가) 필요에 따라 네스팅을 계획합니다.

Nests per station - 이 값은 스테이션당 생성할 레이아웃 수를 설정합니다.

Maximum sheets per nest - 이 값은 고유 네스트에 대한 최대 시트 수를 제어하는 데 사용됩니다. 예를 들어, 대량(예: 500개)이 필요한 큰 부품(전체 시트를 채우는)이 있는 오더가 있는 경우 - TruSmartCAM 은(는) pull 모드에서 더 이상 500개 복사본이 있는 단일 네스트를 생성하지 않습니다. 대신 네스트당 10개 복사본(10이 최대)을 생성합니다.

Bend programs per station - 이 값은 스테이션당 생성할 밴딩 프로그램 수를 설정합니다.

Mark the task completed, when the program outputs are removed - 대상 출력 위치에서 출력이 제거될 때 레이아웃이 Done 으로 표시되도록 이 옵션을 활성화합니다.

Spreadsheet import settings

CAD lookup directories - TruSmartCAM 은(는) 가져온 CSV 에 언급된 부품 항목을 부품 라이브러리에서 로드하려고 시도합니다. 그러나 부품이 부품 라이브러리에서 사용할 수 없는 경우 이 대화 상자에 설정된 디렉터리 순서에 따라 조회 디렉터리에서 부품을 가져오려고 시도합니다.

Use recursive CAD search - 후속 결과에 대해 검색을 반복하려면 이 옵션을 활성화합니다.

Create a blank part for the missing CAD files - TruSmartCAM 라이브러리나 조회 디렉터리에 부품이 존재하지 않는 경우 TruSmartCAM 이(가) 사용할 수 없는 해당 부품에 대해 빈 부품을 생성합니다.

Do not show New Job dialog if the spreadsheet has no error - CSV 항목이 깨끗한 경우(즉, DB 와 데이터 불일치가 없거나 모든 필드가 올바르게 나열된 경우) TruSmartCAM 은(는) 작업 개요 창을 표시하지 않고 CSV 를 가져오거나 드롭하는 즉시 작업을 처리합니다.

Prefer Raw-Material column over Material + Thickness - 지원되는 스프레드시트 유형:

  1. Pattern 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Pattern 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Pattern 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

이 옵션을 선택하지 않으면 Pattern 1 이 기본 스프레드시트 유형으로 간주됩니다. CSV 형식이 Pattern 3 유형인 경우 Pattern 3 도 지원합니다.

이 옵션을 선택하고 CSV 가 Pattern 2 유형인 경우 TruSmartCAM 이(가) CSV 의 Material 및 Thickness 필드에서 Raw Material 을 확인합니다.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Layout 또는 Job 이 완료될 때 CSV 내보내기를 활성화하려면 이 옵션을 선택합니다. 완료된 리포트는 Factory → Settings → Reports 설정에서 지정한 Reports 대상에 저장됩니다.
