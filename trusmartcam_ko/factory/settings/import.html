가져오기

Output settings

Save flat pattern - 가져온 부품의 flat pattern 을 저장하려면 이 옵션을 활성화합니다.

Format for flat pattern - 이 옵션은 DXF 또는 GEO 파일 형식 중 하나를 선택하는 데 사용됩니다.

Flat pattern destination - flat pattern 이 저장될 위치입니다.

Import settings

Units for DXF files - DXF 파일을 가져올 측정 단위이며, 사용자는 mm 또는 inch 중에서 선택할 수 있습니다.

Material lookup keys - 여러 조회 항목을 쉼표 구분자로 구분하여 할당할 수 있습니다. 부품을 가져올 때 TruSmartCAM 은(는) 이러한 키를 사용하여 재료 값을 검색합니다. 검색된 값은 원자재를 확인하는 데 사용됩니다. 원래 값은 부품 Misc Properties 에 저장됩니다.

Revision lookup keys - 부품을 가져올 때 원본 부품 파일(가져오는 부품 파일)의 개정 값이 리포지토리의 기존 개정 값과 비교됩니다. 개정이 동일하면 가져오기가 중단됩니다. 이제 DXF 파일에 대해서도 사용자 지정 필드 매핑이 지원됩니다. DXF 파일의 경우 사용자 지정 필드 데이터가 도면의 텍스트 레이어 또는 PPI 첨부에서 추출됩니다.

Use geometry comparison on same CAD revision - 동일한 CAD 개정으로 부품을 가져올 때 지오메트리를 비교하고 차이가 감지되면 사용자에게 가져오기를 교체하거나 건너뛰도록 요청합니다. 자세한 내용은 가져오기 구성 를 참조하십시오.

Part name keys - 이 옵션은 재료 및 Revision lookup keys 와 유사하게 작동합니다. 파일 이름 대신 PPI Part name 을 부품 이름으로 사용하려면 하나 이상의 Part name keys 를 설정합니다.

Thickness lookup keys - 여러 조회 항목을 쉼표 구분자로 구분하여 할당할 수 있습니다. 부품을 가져올 때 TruSmartCAM 은(는) 이러한 키를 사용하여 두께 값을 검색합니다. 검색된 값은 두께를 확인하는 데 사용됩니다. 원래 값은 부품 Misc Properties 에 저장됩니다.

Thickness comparison fudge - 부품을 가져올 때 원자재를 조회하는 데 사용됩니다. TruSmartCAM 은(는) 재료 이름과 두께가 구문 분석된 후 원자재를 확인하려고 시도합니다. 자세한 내용은 아래의 [Thickness fudge] 항목을 참조하십시오.

Identify shapes after a flat is imported - 부품을 가져올 때 부품 내의 내부 형상을 자동으로 인식하고 식별할 수 있습니다.

Shape identification fudge - shape identification fudge 값은 다음에서 설정할 수 있습니다:

  1. Global level - 이 값은 모든 형상에 대한 기본값으로 사용됩니다.

  2. Individual Shape Level - 개별 형상 수준에서 fudge 값을 설정하여 기본값을 재정의할 수 있습니다. Shape Library 대화 상자에서 형상을 선택하면 fudge 값이 표시됩니다. 기본적으로 이 값은 0 으로 설정되며, 이러한 형상에는 기본 전역 값이 사용됩니다.

Rotate flat horizontally - 일반적으로 절단 머신 테이블은 직사각형이고 더 넓습니다. 툴링 실현 가능성을 높이려면 부품을 가져온 후 부품 너비를 따라 부품을 회전합니다.

Part rotation threshold - 회전을 허용할 최소 숫자로 설정합니다. 설정된 값보다 작은 부품은 회전되지 않습니다.

Misc settings

Enable pre-import external tools - Creo Reader 를 활성화하려면 pre-import external tools 가져오기 옵션을 활성화합니다. TruSmartCAM 은(는) 드롭된 부품의 사전 추출된 패밀리 인스턴스를 업로드합니다. 인스턴스 추출은 부품 업로드 중(사전 가져오기 작업으로)에 수행되므로 부품을 업로드하는 컴퓨터에 Creo 소프트웨어가 설치되어 있어야 합니다.

Ignore drawing colors in Flat thumbnails for clarity - 그레이스케일의 더 선명한 썸네일을 생성하려면 이 옵션을 활성화합니다. 이미지 선명도를 위해 레이어 색상과 텍스트 엔터티가 무시됩니다.

Use only one Engine for all import tasks - 활성화하면 가져오기 작업에 하나의 엔진 코어만 사용됩니다.

두께 보정

Thickness comparison fudge 는 원하는 시트 두께가 인벤토리에서 사용할 수 없을 때 인벤토리에 있는 시트의 두께 값을 비교하여 가장 가까운 시트 두께 값을 선택합니다.

예를 들어, 다음과 같이 가정해 보겠습니다:

  1. 시트 두께가 1.6 mm 이고 재료가 steel 인 부품이 있습니다.

  2. Thickness comparison fudge 값은 0.1 mm 입니다.

  3. 인벤토리에는 두께 1.5 mm, 1.55 mm 및 1.7 mm 의 steel 시트가 있습니다.

TruSmartCAM 은(는) Thickness comparison fudge 값(0.1 mm)을 가져온 항목(1.6 mm 측정)과 비교한 후 가장 가까운 두께 값의 시트를 선택합니다. 이 경우 1.55 mm 가 선택됩니다.
