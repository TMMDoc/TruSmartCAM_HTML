Output settings

Save cut outputs - 툴링 결과는 툴링이 OK 이고 이러한 내보내기 설정이 활성화되어 구성된 경우에만 저장됩니다. Cut NC 를 저장하려면 이 옵션을 활성화합니다.

Output tooling simulation preview - 다른 출력과 함께 툴링 시뮬레이션 미리 보기를 생성하려면 이 옵션을 활성화합니다. 이는 레이저/펀치 툴링에 대한 짧은 GIF 애니메이션입니다.

Cut output destination - NC 와 리포트가 저장될 대상입니다.

MetaCAM settings

Lookup MetaCAM materials by raw-material names (DMM 과 유사한 통합의 경우 활성화) - 이 스타일이 활성화되면 TruSmartCAM 이(가) 원자재 이름으로 페이지를 생성하고 auto-tooling 시 부품에 할당합니다.

MetaCAM sync folders - 이 Cut 설정은 config-push Monitor 명령을 사용할 때 config.dat 와 함께 동기화되어야 하는 추가 MetaCAM 폴더를 추가하는 데 사용됩니다. config-push 는 로컬 파일을 TruSmartCAM 리포지토리에 저장하며, 이는 MetaCAM 이(가) (재)시작될 때 다른 컴퓨터에 다운로드됩니다. Engine 컴퓨터는 MetaCAM 머신에 대한 auto tooling 이 완료되면 이를 자동으로 동기화해야 하며, Tools 외에 다른 설치별 후보로는 Etc, Reports 및 Machines 폴더가 있습니다.

DMM config sync location - Dynamic Machine Management config sync 를 설정할 위치입니다.

TecZone Settings

Enable multi-pass nesting - 이렇게 하면 레이저가 동일한 윤곽에서 여러 번 절단할 수 있습니다(더 두꺼운 재료에 선호됨).
