서버 설치

SQL 과 함께 TruSmartCAM Server 를 설치하려면 지침을 따르십시오.

Administrator Rights

이 설치를 실행하려면 사용자에게 관리자 권한이 있어야 합니다.

  • Setup.TruSmartCAM.<version>.exe 를 실행하여 설치를 시작합니다.

버전은 숫자입니다.

  • 라이선스 계약을 읽고 I accept the agreement 를 선택한 다음 Next 를 클릭합니다.

1단계 : 설치 위치

  • 설치 디렉터리를 지정하거나 기본 설치 경로 C:\Program Files\TRUMPF\TMM\Praxis 를 그대로 두고 Next 를 클릭합니다.

    • C:\Program Files\TRUMPF\TMM\Praxis - 설치 폴더에는 다음 폴더가 포함됩니다: Bin, MetaCAM, Samples, Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - 데이터 폴더에는 다음 폴더가 포함됩니다: TruSmartCAM, TecZone, MetaCAM.

2단계 : 구성 요소 선택

Installation Type Components

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Picks all Stations Terminal like TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Picks by user choice.

  • Full Installation 을 선택합니다. TruSmartCAM Tools 에서 Code Senders 와 Bend Code Senders 를 선택합니다. 이제 설치 유형이 Custom 으로 변경됩니다. Next 를 클릭합니다.

3단계 : SQL Server 설치 선택

SQL Express 2022 설치는 TruSmartCAM Server 에만 필요합니다. 이 옵션은 Client 및 Sync 설치에서는 사용할 수 없습니다. 또한 이는 처음에 Checked ON 상태로 설치되며 이후에는 무시할 수 있습니다. TruSmartCAM 서버에 SQL 이 이미 설치되어 있으면 사용자는 Step 3 을 무시할 수 있습니다.

  • Select Additional Tasks 에서: Install SQL Express 를 클릭하고 Next 를 클릭합니다.

  • Ready to Install 에서: 모든 설치 기능을 요약하고 Install 을 클릭합니다.

4단계 : SQL Server 설치

TruSmartCAM 구성 요소가 설치되면 설치 관리자가 SQL 서버 설치를 진행합니다. License Agreement 를 수락하여 진행하고 기본 옵션으로 SQL express 를 설치합니다.

설치가 완료되면 Close 를 클릭하고 설치를 완료합니다.

Windows 버전에 따라 SQL 설치를 닫으면 다시 시작 메시지가 표시될 수 있습니다.

5단계 : Windows 바탕 화면 바로 가기

  • SQL 설치 후 시스템이 다시 시작되지 않으면 Launch TruSmartCAM 확인란을 선택하고 Finish 를 클릭합니다.

  • 시스템이 다시 시작되면 Desktop 에서 TruSmartCAM 바로 가기 아이콘을 실행하거나 Windows Start Program 에서 TruSmartCAM 를 입력하고 Run as administrator 를 선택합니다.

Server installation : TruSmartCAM 및 TruSmartCAM License 바로 가기 아이콘이 Desktop 에서 사용할 수 있습니다.
Client/SYNC Installation : TruSmartCAM 바로 가기 아이콘만 Desktop 에서 사용할 수 있습니다.

6단계 : 라이선스 등록

  • Serial Number 필드에 Trumpf Metamation Service Team 에서 제공한 TruSmartCAM Serial key 를 입력합니다. "Registered to" 필드에 <Company Name> 및 E-Mail 을 입력합니다. OK 를 클릭합니다.

네트워크 방화벽이 라이선스 등록을 차단하거나 TruSmartCAM Server PC 에 인터넷이 없는 경우 TruSmartCAM 라이선스는 Offline 활성화로 수행됩니다. C:\ProgramData\TRUMPF\TMM\Praxis 폴더의 Prax.request 를 Trumpf Metamation Service Team 에 이메일로 보냅니다. Trumpf Metamation Team 에서 이 폴더에 넣어야 하는 Prax.lock 을 제공합니다.

7단계 : 초기 일회성 구성

  • Database Name 을 입력하고 Data Storage Location 을 설정합니다. Use SQL Server 확인란을 선택하고 데이터베이스에 연결할 SQL 서버 이름을 선택합니다. OK 를 클릭합니다.

  • TruSmartCAM Desktop Client 가 열리고 하단에 Database Connection Succeeded 가 표시됩니다.

  • TruSmartCAM, TecZone 및 MetaCAM 구성 파일이 기본 구성 머신 또는 TruSmartCAM 라이선스 머신에 대해 생성되었습니다. 동일한 구성이 모든 TruSmartCAM Client 에서 공유됩니다.

Welcome 화면에 Windows User LoginName 이 TruSmartCAM Login 및 Name 으로 표시됩니다. 첫 번째 TruSmartCAM User 는 Site Admin 으로 간주됩니다. Email 과 Password 를 입력합니다. OK 를 클릭합니다.

다음에 로그인 자격 증명을 저장하려면 Remember me 확인란을 선택합니다. Remember me 확인란을 지우면 TruSmartCAM 애플리케이션이 시작될 때마다 로그인 및 암호 대화 상자가 표시됩니다.

8단계 : TruSmartCAM 로그인

  • TruSmartCAM 를 닫았다가 다시 엽니다. 시스템에서 TruSmartCAM 로그인 자격 증명을 입력하라는 메시지를 표시합니다.

  • 로그인한 사용자 이름이 TruSmartCAM 애플리케이션 헤더의 사용자 아이콘 옆에 표시됩니다.

  • 사용자 아이콘 위로 마우스를 가져가면 시스템에 다음이 표시됩니다:

    • 사용자 역할(예: Programmer, Admin).

    • 로그아웃 바로 가기: Ctrl+L.

  • 사용자 아이콘을 클릭하면 다음을 수행할 수 있는 메뉴가 열립니다:

    • Edit information…​ - 프로필 세부 정보를 업데이트합니다.

    • Change password…​ - 계정 암호를 변경합니다.

    • Sign out - 애플리케이션에서 로그아웃합니다.

    • Cancel - 변경하지 않고 메뉴를 닫습니다.

9단계 : 팩토리 머신 구성

  • TruSmartCAM License [All machines enables license bit] : 기본 TruSmartCAM Machine 및 Material 이 Factory Configuration 으로 간주됩니다.

  • TruSmartCAM License [No demo and few machine bit enabled] : 해당 소수의 머신과 기본 Material 이 Factory Configuration 으로 간주됩니다.

  • (Open → Import) C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts 에서 새 Part 를 가져오고 Part 가 성공적으로 가져와졌는지 확인합니다.

Note 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor with Engine Installation (Site admin rights):

    • Site Admin TruSmartCAM Rights 와 함께 Engine 이 있는 TruSmartCAM Monitor 에는 다음 옵션이 있습니다:

      1. 모든 TruSmartCAM Client 에 TruSmartCAM 구성, TecZone, MetaCAM 구성을 푸시합니다. 또한 New TruSmartCAM User Login 을 생성할 권한이 있습니다.

      2. Show Agents 는 TruSmartCAM License 에 대해 자동화 작업을 수행하는 데 사용할 수 있는 총 엔진을 표시합니다.

  • TruSmartCAM Monitor without Engine Installation (Site admin rights):

  • TruSmartCAM Monitor without Engine Installation (Non Site Admin rights):

TruSmartCAM 애플리케이션을 실행하는 PC 에는 Engine TruSmartCAM 구성 요소가 설치되어 있어야 합니다[Server PC 또는 모든 Client 설치]. 모든 자동화 작업을 수행하려면 Engine TruSmartCAM 구성 요소가 설치된 PC 가 24x7 로 실행되고 있어야 합니다.
Note 2 : OpenGL

  • TruSmartCAM 애플리케이션이 열리는 동안 즉시 닫히고 pmonitor 도 작업 표시줄에 표시되지 않습니다.

  • 이는 OpenGl 문제를 나타냅니다.

  • 이를 확인하는 또 다른 방법: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts 를 열면 OpenGL 문제에 대한 오류 대화 상자가 표시됩니다.

  • TruSmartCAM 애플리케이션이 성공적으로 열리도록 C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini 의 options 섹션을 GLVersion=1 로 업데이트합니다.

[Options]
GLVersion=1.0
