포트 요구 사항

TruSmartCAM 서버 : 7371

서버는 이 TCP 포트에서 클라이언트 요청을 대기합니다. 서버 컴퓨터에서 이 포트로의 수신 연결이 허용되어야 합니다.

플로팅 라이선스 서버 : 5776

Floating License Server 는 이 포트에서 라이선스 요청을 대기합니다. floating license 서버 컴퓨터(TruSmartCAM Server)에서 이 포트로의 수신 연결이 허용되어야 합니다.

클라우드 라이선스 연결 : 7567

이 포트는 TecZone(Bending Software)와 Floating License Server 가 Metamation Cloud 로 라이선스 요청을 보내는 데 사용됩니다. 따라서 라이선스 활성화 및 갱신을 위해 이 포트에서 발신 연결이 허용되어야 합니다.

설치 및 지원 요구 사항

  • TruSmartCAM 애플리케이션을 설치하려면 관리자 권한이 필요합니다.

  • Contractor VPN 또는 보안 연결을 통한 원격 진단 도구.
