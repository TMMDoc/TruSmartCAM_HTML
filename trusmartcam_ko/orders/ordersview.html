오더 보기

Orders 페이지 오른쪽의 옵션은 처리 단계에 따른 오더의 다양한 보기를 나타냅니다. 보기를 선택하면 표시된 오더가 업데이트되어 워크플로의 특정 단계에 집중할 수 있습니다.

Ready

Ready 보기를 선택하면 준비되었지만 아직 작업으로 변환되지 않은 오더가 표시됩니다.

  • 작업 생성 준비가 된 오더를 표시합니다.

  • 처리 대기 중인 오더를 식별하는 데 유용합니다.

Active

Active 보기를 선택하면 작업으로 변환되어 현재 처리 중인 오더가 표시됩니다.

  • 이미 Job 단계로 이동된 오더를 나타냅니다.

  • 실행 중인 오더를 추적하는 데 도움이 됩니다.

  • 진행 중인 생산을 모니터링하는 데 유용합니다.

Done

Done 보기를 선택하면 처리가 완료된 오더가 표시됩니다.

  • 관련 작업이 완료된 오더를 표시합니다.

  • 워크플로가 완료되었음을 나타냅니다.

  • 검토 및 기록 보관에 유용합니다.

All

All 보기를 선택하면 단계에 관계없이 모든 오더가 표시됩니다.

  • 모든 오더의 전체 개요를 제공합니다.

  • 모든 단계에 걸쳐 검색하고 관리하는 데 유용합니다.

오더 상태 표시줄

각 오더 타일 아래에 표시되는 상태 표시줄은 오더가 작업에 연결되어 있는지 여부를 나타냅니다. 두 가지 유형이 있습니다:

  • 막대 없음 - 오더가 어떤 작업에도 할당되지 않았습니다.

  • 막대 있음 - 오더가 작업의 일부이며, 막대는 아래 나열된 해당 작업 상태를 표시합니다.
