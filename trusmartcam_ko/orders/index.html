오더

오더

오더는 어떤 부품을 얼마나 많은 수량으로 언제까지 제조해야 하는지 정의합니다. 오더는 TruSmartCAM 에서 생산 계획 및 실행을 주도합니다. 오더는 다양한 방법으로 생성하거나 가져올 수 있으며, 생산 계획을 위해 작업으로 변환할 수 있습니다.

오더 패널

Open in read-only mode for viewing
선택한 오더를 읽기 전용 모드로 엽니다.

Check-out the document for editing
선택한 오더의 편집을 활성화합니다.

Delete
선택한 오더를 삭제합니다.

New…​

오더를 작업, 어셈블리 또는 다른 오더로 변환합니다.

Assign Customer…​

오더에 고객을 할당합니다.

Set Due Date…​

오더의 납기일을 설정합니다.

Priority

오더의 우선순위 수준을 지정합니다. 사용 가능한 옵션은 Normal, Low, High 및 Urgent 입니다.

Part Order

오더 내 부품에 할당된 참조 ID 를 지정합니다.

Quantity

오더의 부품 또는 인스턴스 수를 지정합니다.

Prev / Next / Part

오더 내 이전 또는 다음 부품으로 이동합니다.

Sort and filter

이러한 필터를 사용하여 Same Material, Same Customer, Same Due Date 또는 Same Priority 를 공유하는 다른 오더를 봅니다.

오더 편집

하나 이상의 오더를 선택하고 마우스 오른쪽 버튼으로 클릭하여 수량, 납기일, 우선순위 및 고객 정보와 같은 공통 오더 세부 정보를 수정합니다.

선택한 여러 오더에 서로 다른 값이 필요한 경우 Check-out for Editing 옵션을 사용하여 요구 사항에 따라 각 오더를 개별적으로 편집합니다.

오더에 대한 모든 업데이트는 즉시 데이터베이스에 적용됩니다. Delete 명령을 사용하여 order library 에서 오더를 제거합니다.

Delete 명령은 오더만 제거합니다. 해당 오더에 연결된 부품은 Part library 에서 삭제되지 않습니다.

오더 계획

하나 이상의 오더를 선택하고 마우스 오른쪽 버튼으로 클릭한 다음 New…​ → Job 을 클릭하여 선택한 오더를 작업으로 변환합니다. Sort and Filter 옵션을 사용하여 작업 생성 전에 관련 오더를 함께 그룹화합니다.

오더가 작업으로 변환되면:

  • 작업이 Jobs 페이지로 이동됩니다

  • 오더가 Orders 목록에서 제거됩니다

  • 그런 다음 표준 작업 계획 워크플로를 생산 계획 및 네스팅에 사용할 수 있습니다

작업 계획 워크플로에 대한 자세한 내용은 자동 계획 를 참조하십시오.

추가 정보

  • 오더가 포함된 작업이 삭제되면 작업 또는 부품이 Completed 로 표시되지 않는 한 관련 오더가 자동으로 Orders Ready 페이지로 다시 이동됩니다.

  • 생산 요구 사항에 따라 Edit Job 창을 통해 기존 작업에서 오더를 추가하거나 제거할 수 있습니다.
