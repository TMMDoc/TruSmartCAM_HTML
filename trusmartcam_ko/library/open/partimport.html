부품 가져오기

부품을 가져오기 전에 파일 형식이 TruSmartCAM 과(와) 호환되는지 확인하십시오. 자세한 내용은 지원되는 파일 형식 를 참조하십시오.

가져오기 후 재료와 두께가 부품에 매핑되지 않은 경우 part panel 을 사용하여 재료를 할당하십시오.

가져오기 방법

Part Library 로 부품을 가져오는 방법에는 세 가지가 있습니다:

  1. Import via file

  2. Drag and drop

  3. Watch folder

파일을 통한 가져오기

Import parts…​ 옵션을 사용하여 2D 또는 3D 부품 파일을 Part Library 로 가져올 수 있습니다.

  • 명령 표시줄에서 open 아이콘을 클릭하고 Import parts…​ 옵션을 선택합니다.

  • Open 대화 상자가 나타납니다 — CAD 파일(2D 또는 3D)을 선택합니다.

  • 선택한 CAD 파일의 미리 보기가 표시됩니다.

  • 필요한 부품을 선택하고 Open 을 클릭합니다.

  • 시스템은 업데이트된 툴링 상태와 함께 사용 가능한 모든 머신에 대해 부품을 자동 툴링합니다.

드래그 앱 드롭

  • 부품 파일을 TruSmartCAM Part Library 로 직접 끌어다 놓습니다.

감시 폴더

Watch 설정을 사용하면 새 파일에 대해 폴더를 감시하고 자동으로 Part Library 로 가져올 수 있습니다.

구성하려면 감시 설정 페이지를 참조하십시오.

  • UNC(Universal Naming Convention) 경로 \\192.168.1.11\<Folder path> 또는 매핑된 드라이브 M:\<Folder Path> 를 사용하십시오.

  • Engine 을 실행하는 PC 에는 이 폴더에 대한 읽기/쓰기 액세스 권한이 있어야 합니다.

  • Watch 서비스는 로컬 PC 가 아닌 Engine PC 에서 파일을 찾으므로 C:\<Folder Path> 와 같은 로컬 경로를 사용하지 마십시오.

가져오기 구성

Use geometry comparison on same CAD revision

동일한 CAD 리비전으로 부품을 가져올 때 TruSmartCAM 은(는) CAD 파일의 형상을 기존 부품과 비교할 수 있습니다.

  • 이를 활성화하려면 factory → settings → Import 에서 Revision lookup keys(예: REV)를 구성합니다. 그런 다음 Use geometry comparison on same CAD revision 옵션을 활성화합니다.

동일한 CAD 리비전에서의 형상 비교는 Revision lookup keys 가 구성된 경우에만 작동합니다.

  • 이제 특정 리비전(예: Revision 1)으로 part library 에 부품을 가져옵니다.

  • 동일한 리비전 값으로 동일한 부품을 다시 가져옵니다.

  • TruSmartCAM 은(는) 새로 가져온 CAD 파일의 형상을 기존 부품과 비교합니다.

  • 형상 차이가 감지되면 TruSmartCAM 은(는) 다음 여부를 묻는 메시지를 표시합니다:

    • 동일한 리비전 값을 유지하면서 기존 부품을 새 형상으로 Replace 합니다.

    • 가져오기를 Skip 하여 기존 부품과 그 형상을 유지합니다.

이를 통해 사용자는 기존 부품의 교체 여부를 계속 제어하면서 리비전 값을 변경하지 않고 부품 형상을 업데이트할 수 있습니다.

가져온 부품은 추가 사용을 위해 자동으로 라이브러리에 추가됩니다. 자세한 내용은 라이브러리 를 참조하십시오.
