오더 가져오기

오더는 다음 방법을 사용하여 생성하거나 가져올 수 있습니다:

  1. 스프레드시트 파일에서 오더 가져오기.

  2. watch 설정을 통해 자동으로 오더 가져오기.

  3. part library 의 기존 부품에서 오더 생성.

  4. assembly static nest 에서 오더 생성.

스프레드시트에서 오더 가져오기

  • Open → Import Orders…​ 로 이동합니다.

  • 지원되는 스프레드시트 형식에는 CSV, XLSX 및 XML 이 포함됩니다.

  • 필요한 스프레드시트 파일을 선택하고 Open 을 클릭합니다.

  • 가져오기 프로세스는 Job/Assembly 가져오기 워크플로와 유사합니다.

스프레드시트를 Orders 페이지로 직접 끌어다 놓아 오더를 가져올 수도 있습니다.

감시 설정을 사용하여 오더 가져오기

  • Watch settings 에서 Import spreadsheet from 'Live Folder' 옵션을 활성화합니다.

  • Spreadsheet import option 에서 Import Orders 를 선택합니다.

  • 오더를 가져올 폴더 위치를 구성합니다.

  • 시스템은 구성된 폴더를 지속적으로 모니터링합니다.

  • 새로 추가된 스프레드시트 파일이 자동으로 Orders 로 가져와집니다.

자세한 구성 단계는 감시 설정 설명서를 참조하십시오.

부품 라이브러리에서 오더 생성

  • Part Library 에서 필요한 부품을 선택합니다.

  • 마우스 오른쪽 버튼을 클릭하고 New…​ → Order 를 선택하여 New Orders 대화 상자를 엽니다.

  • 수량, 납기일 및 우선순위와 같은 필요한 세부 정보를 입력합니다.

  • OK 를 클릭하여 오더를 생성합니다.

  • 시스템이 자동으로 Orders 페이지로 전환됩니다.

  • 생성된 오더는 작업 생성을 위해 Orders Ready 페이지에 표시됩니다.

어셈블리에서 오더 생성

  • 필요한 Assembly 를 마우스 오른쪽 버튼으로 클릭합니다.

  • New…​ → Order 를 선택하여 New Orders 대화 상자를 엽니다.

  • 필요한 Assembly count 를 입력합니다.

  • OK 를 클릭하여 오더를 생성합니다.
