작업 가져오기

CSV 또는 XLSX에서 가져오기

일반적인 텍스트 형식으로 작업을 가져올 수도 있습니다.

  • File → Open → Import Jobs 를 클릭하면 Open Folder 대화 상자가 나타납니다. C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv 를 선택합니다.

  • 모든 부품이 csv 위치 또는 lookup 폴더 디렉터리에 있으면 csv 필드와 일치하는 모든 부품을 나열하여 new job 창이 나타납니다.

  • 누락된 부품은 무시되며 new job 창에 나타나지 않습니다.

  • 처음에 Part 상태는 Nascent 입니다.

  • OK 를 클릭하면 이제 부품이 Part Library 로 가져와집니다.

Create a blank part for the missing CAD files

스프레드시트(.csv 또는 .xlsx)를 사용하여 작업을 가져올 때 시스템에서 사용할 수 없는 CAD 파일을 참조하는 행이 있을 수 있습니다.

  • 이를 처리하려면 Factory → Settings → Job 로 이동하여 Spreadsheet import settings 아래에서 Create a blank part for the missing CAD files 를 활성화합니다.

이 옵션을 선택하면:

  • 작업 가져오기 중 특정 행에 CAD 파일이 누락된 경우 시스템은 누락된 CAD 파일 대신 자동으로 blank 부품을 생성합니다.

  • new job 창에서 이러한 누락된 부품은 관련 CAD 파일이 누락되었음을 나타내기 위해 노란색으로 시각적으로 강조 표시됩니다.

  • 누락된 부품은 CSV 의 매핑된 필드(부품 이름, 재료, 두께, 수량 등)를 계속 갖습니다. 그러나 part 상태는 Nascent 로 표시되며, 이는 아직 실제 형상이 없는 빈 자리 표시자일 뿐임을 의미합니다.

이렇게 하면 누락된 CAD 파일로 인한 오류 없이 작업 가져오기를 계속 진행할 수 있습니다 — 나중에 올바른 CAD 파일이 제공되면 blank 부품을 업데이트하거나 교체할 수 있습니다.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings → Do not show the New Job dialog if the spreadsheet has no error

  • 이 확인란을 선택하면 스프레드시트에 오류(누락된 부품, 누락된 날짜 또는 잘못된 데이터)가 없는 경우 시스템이 New Job 대화 상자를 표시하지 않고 자동으로 새 작업을 생성합니다.

  • 이 확인란을 지우면 스프레드시트에 오류가 없더라도 사용자 검토 및 확인을 위해 New Job 대화 상자가 항상 나타납니다.

Prefer raw-material column over material + thickness

factory → Settings → Job → Prefer Raw-Material column over Material + Thickness

  • 이 확인란을 선택하면 시스템은 스프레드시트가 Raw-Material 열(예: Steel-20)을 사용할 것으로 예상합니다. 즉, 재료 유형과 두께가 한 열의 단일 값으로 결합되어야 합니다.

  • 이 확인란을 지우면 시스템은 스프레드시트에 Material 및 Thickness 에 대한 별도의 열(예: Steel 및 2.00)이 있을 것으로 예상합니다. 시스템은 가져오는 동안 내부적으로 이들을 결합합니다.

CSV/XLSX를 사용하는 감시 폴더

  • factory → Settings → Watch settings 에서 Enable 'Live Folder' 및 Watch sub-folders also 를 선택합니다.

  • watch 폴더 경로(UNC 또는 매핑된 드라이브)를 설정합니다.

  • Spreadsheet import settings 에서 Import spreadsheet from 'Live Folder' 를 선택합니다.

  • Spreadsheet Import 옵션에서 Import Jobs 를 선택합니다.

* C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv 를 복사하여 Watch Folder 에 붙여넣습니다.

  • 시스템은 CSV 를 확인하고 자동으로 작업을 생성하려고 시도합니다.

  • CAD 파일이 누락된 경우 필요한 CAD 데이터를 찾을 수 없으므로 작업이 생성되지 않습니다.

CAD 조회 디렉터리 및 재귀 CAD 검색 - 구성되지 않음

  • factory → Settings → Job → Spreadsheet import settings 에서 CAD lookup directories 가 설정되지 않고 Use recursive CAD search 가 사용되지 않으면 시스템은 CAD 파일을 자동으로 검색하지 않습니다.

  • Create a blank part for the missing CAD files 확인란을 선택하면 CAD 파일이 누락된 경우에도 작업이 생성됩니다.

  • 이 경우 작업의 모든 부품이 nascent(blank) 부품으로 생성됩니다 — 즉, CAD 파일을 찾을 수 없어 형상이 없음을 의미합니다.

CAD 조회 디렉터리 및 재귀 CAD 검색 - 구성됨

factory → Settings → Job → Spreadsheet import settings 아래에서 CAD lookup directories 가 (C:\Program Files\TRUMPF\TMM\Praxis\Samples) 로 설정되고 Use recursive CAD search 가 활성화되면:

  • 시스템은 지정된 폴더와 모든 하위 폴더에서 스프레드시트에 언급된 필요한 CAD 파일을 자동으로 검색합니다.

  • Create a blank part for the missing CAD files 도 활성화되어 있으므로 CAD 파일을 여전히 찾을 수 없으면 시스템은 자리 표시자로 blank 부품을 생성합니다.
