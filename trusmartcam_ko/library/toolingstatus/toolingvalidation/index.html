툴링 검증

이 섹션에서는 TruSmartCAM 에서 부품의 툴링 정보에 액세스하고 수정하는 방법을 설명합니다.

  • 부품 타일을 마우스 오른쪽 버튼으로 클릭하여 part panel 을 열고 툴링 옵션에 액세스합니다.

  • Toolings 를 클릭하여 사용 가능한 첫 번째 툴링된 인스턴스로 전환합니다.

  • 또는 툴링된 인스턴스를 직접 클릭하여 머신 세부 정보와 툴링 옵션을 봅니다.

  • 를 사용하여 Open in read-only mode for viewing 를 수행합니다.

  • 를 사용하여 Check-out the document for editing 를 수행합니다.

  • 선택한 툴링된 인스턴스가 TecZone 또는 MetaCAM 에서 열립니다.

  • 수동 툴링 검사를 수행하고 필요한 변경을 수행합니다.

  • 저장을 시도하면 Unsaved Changes 대화 상자에서 편집을 확인하라는 메시지가 표시됩니다.

  • Yes 를 클릭하여 저장을 진행합니다.

  • 시스템은 저장 후 Tooling Validation 을 다시 수행합니다.

  • 오류가 없으면 TruSmartCAM 에 변경 사항을 저장하는 옵션이 나타납니다.

  • 툴링 오류가 발견되면 오류 메시지가 표시됩니다:

  • 저장 후 부품 툴링 상태가 part library 에서 업데이트됩니다.

  • 툴링된 인스턴스의 녹색은 체크인되었음을 나타냅니다.

  • Tooled Instance Author 는 마지막으로 편집한 사람으로 업데이트됩니다.

  • User-edited 필드는 툴링된 인스턴스가 수동으로 수정되었는지 여부를 나타냅니다. 사용자가 인스턴스를 체크아웃하고 변경을 수행하면 저장 시 이 필드가 자동으로 Yes 로 설정됩니다.

  • 부품이 현재 편집 중인 경우 해당 타일에 사용자 아이콘이 나타납니다.

  • 타일 위에 마우스를 올리면 누가 체크아웃했는지와 체크아웃한 시간이 표시됩니다.

  • 부품이 체크아웃된 동안 동일한 툴링된 인스턴스에 대해 Check-out the document for editing 옵션이 비활성화되고 Cancel Check-out 옵션이 활성화됩니다.
