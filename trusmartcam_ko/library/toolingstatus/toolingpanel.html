툴링 패널

이 섹션에서는 툴링 인스턴스를 관리하는 데 사용되는 Export outputs, Check Tooling, Suppress Tooling, Set as Base-Flat…​, Copy Tooling 및 기타 옵션과 같은 툴링 관련 작업을 설명합니다.

Open in read-only mode for viewing
선택한 툴링을 읽기 전용 모드로 엽니다.

Check-out the document for editing
선택한 툴링의 편집을 활성화합니다.

Export Outputs

선택한 툴링 출력을 구성된 대상으로 내보냅니다.

Check Tooling

변경 없이 기존 툴링을 검증하고 검증에 실패하면 상태를 업데이트합니다.

Copy Tooling…​

선택한 참조 툴링에서 punch, 시퀀스 및 back gauge 설정을 복사하여 가능한 경우 다른 솔루션에 적용합니다.

Set as Base-Flat…​

선택한 bend 또는 fold 툴링을 절단 솔루션 생성을 위한 참조 flat 크기로 표시합니다.

Re-tool…​

다른 툴링에 영향을 주지 않고 부품에 대한 선택한 툴링을 다시 처리합니다.

Suppress Tooling

선택한 툴링을 억제하여 추가 처리 및 출력 생성에서 제외합니다.

Prev / Next / Part

이전 또는 다음 툴링으로 이동하거나 상위 부품으로 돌아갑니다.

Sort and filter

빠른 참조를 위해 선택한 툴링과 유사한 특성을 공유하는 다른 툴링을 표시합니다.

Export Outputs

이 옵션은 부품 출력을 Factory Settings 에 구성된 대상으로 내보냅니다. (밴딩 설정 및 절단 설정 참조)

전체 부품이 아니라 선택한 툴링 작업과 관련된 툴링만 내보내집니다.

내보낸 파일은 작업 유형에 따라 다릅니다. Bend 및 Fold 작업의 경우 NC 파일과 리포트가 생성됩니다. Cut 및 Punch 작업의 경우 부품 파일만 내보내집니다.

Check Tooling

  • CAM Settings 에 변경이 있거나 bend 공구가 손실된 경우 부품을 다시 툴링할 필요가 없습니다.

  • 대신 Check Tooling 을 사용하여 변경 없이 기존 툴링을 검증합니다.

  • 검증에 실패하면 해당 인스턴스의 툴링 상태가 업데이트되고 관련 출력 파일이 제거됩니다.

  • Check Tooling 은 이전에 Ignore Errors 를 사용하여 수동으로 재정의된 오류가 있는 부품도 감지하고 필요한 경우 상태를 오류로 업데이트합니다.

Copy tooling

copy tooling 을 사용하면 한 솔루션에서 다른 솔루션으로 bend 툴링을 빠르게 적용하여 시간과 노력을 절약할 수 있습니다.

이는 선택한 참조 툴링(솔루션)에서 punch, 시퀀스 및 back gauge 설정을 복사하고 동일한 설정을 다른 모든 솔루션에 적용하려고 시도합니다.

  • 복사된 설정이 대상 머신에 적합하면 저장되어 사용됩니다.

  • 설정이 적합하지 않으면 해당 머신의 원래 툴링은 변경되지 않습니다.

예를 들어, 서로 다른 머신에 대해 서로 다른 툴링이 있을 수 있습니다:

  • 여기서 Machine 5230X 4A 는 Gooseneck punch 를 사용하고, Machine 5230SX 6A 는 Pointed punch 를 사용합니다.

Machine 5230X 4A 에서 Copy Tooling…​ 를 사용하면 Gooseneck 설정을 다른 모든 머신에 복사하려고 시도합니다.

동일한 punch, 시퀀스 및 back gauge 설정이 가능한 곳마다 적용됩니다. 복사된 설정을 사용할 수 없는 경우 원래 툴링은 변경되지 않습니다.

copy tooling 을 적용한 후 Gooseneck 설정이 적합한 다른 모든 머신에 성공적으로 적용되었습니다.

Set as Base-Flat…​

Set as Base-Flat…​ 기능은 절단 솔루션 생성을 위한 참조 flat 크기로 사용되는 bend 또는 fold 툴링을 정의합니다. 툴링이 Base-Flat 으로 표시되면 TruSmartCAM 은(는) 해당 머신을 기반으로 부품의 flat 크기를 업데이트하고 그에 따라 절단 솔루션을 재생성합니다. Base-Flat 툴링은 UI 에서 파란색 테두리로 표시됩니다.

서로 다른 bend 머신은 동일한 부품에 대해 flat 크기에 약간의 차이를 생성할 수 있습니다. 툴링을 Base-Flat 으로 설정하면 TruSmartCAM 은(는) 해당 머신의 flat 크기를 마스터 참조로 사용하고 절단 솔루션을 자동으로 재계산합니다.

여기서 여러 머신에 걸쳐 동일한 부품에 대한 서로 다른 flat 크기를 볼 수 있습니다:

이 예에서는 5230X 4A 툴링이 Base-Flat 으로 설정되고 업데이트된 flat 크기가 부품 속성에 적용됩니다:

자동 베이스 플랫 선택

팩토리 설정 Apply flat correction during bending 이 활성화된 경우:

  • TruSmartCAM 은(는) 부품 가져오기 중에 (최대 bend 길이 표를 포함하는) bend 툴링을 Base-Flat 으로 자동으로 설정합니다.

  • 선택한 bend 툴링에 오류가 발생하거나 적합하지 않은 경우 TruSmartCAM 은(는) 지능적으로 전환하여 다른 유효한 bend 툴링을 Base-Flat 으로 설정합니다. 이렇게 하면 flat 크기 참조와 절단 솔루션이 수동 개입 없이 항상 일관되고 유효하게 유지됩니다.

향상된 베이스 플랫 관리

TruSmartCAM 은(는) bend 또는 fold 툴링 편집을 저장할 때 Save to Praxis 대화 상자에서 Base-Flat 옵션을 제공합니다. 이러한 옵션은 OK 상태의 툴링에만 나타나며 flat 크기와 절단 솔루션이 정확하게 유지되도록 합니다.

Set as Base-Flat and calculate cutting solution

이 옵션은 툴링을 처음으로 Base-Flat 으로 표시하고 해당 절단 솔루션을 자동으로 생성하는 데 사용됩니다.

다음과 같은 경우에 나타납니다:

  • 툴링이 현재 Base-Flat 으로 표시되지 않은 경우.

  • 사용자가 편집을 위해 툴링을 체크아웃하고 변경 사항을 저장하는 경우.

이 옵션을 사용하려면 bend 또는 fold 툴링을 체크아웃하고 bend 매개변수 또는 flat 크기 변경과 같은 필요한 수정을 수행합니다. Ctrl+S 를 눌러 변경 사항을 저장합니다. Save to Praxis 대화 상자에서 Set as Base-Flat and calculate cutting solution 를 선택하고 OK 를 클릭합니다. TruSmartCAM 은(는) 툴링을 Base-Flat 으로 설정하고 업데이트된 flat 크기를 사용하여 절단 솔루션을 생성합니다.

Update the base-flat and re-calculate cutting solution

이 옵션은 툴링이 이미 Base-Flat 으로 표시되어 있고 편집되어 flat 크기와 절단 솔루션을 재생성해야 하는 경우에 사용됩니다.

다음과 같은 경우에 나타납니다:

  • 툴링이 이미 Base-Flat 으로 표시된 경우.

  • 사용자가 체크아웃하고 편집한 후 변경 사항을 저장하는 경우.

기존 Base-Flat 툴링을 편집할 때 필요에 따라 bend 매개변수 또는 flat 크기 형상을 업데이트합니다. Save to Praxis 대화 상자에서 Update the base-flat and re-calculate cutting solution 를 선택합니다. 그러면 TruSmartCAM 이(가) Base-Flat 툴링을 업데이트하고 관련된 모든 절단 솔루션을 재생성하여 최신 변경 사항을 반영합니다.

한 번에 하나의 bend 툴링만 Base-Flat 으로 설정할 수 있습니다.

Base-Flat 이 변경되면 기존 절단 솔루션이 자동으로 다시 처리됩니다.

이 기능은 TruSmartCAM 내에서 bend 및 fold 툴링 모두에 사용할 수 있습니다.

Re-tool

이 옵션은 부품에 대한 선택한 툴링을 다시 처리합니다.

Tooling panel 에서 필요한 툴링을 마우스 오른쪽 버튼으로 클릭하고 Re-tool…​ 를 클릭합니다.

진행하기 전에 확인 대화 상자가 표시됩니다.

Yes 를 클릭하여 다시 툴링을 계속하거나 No 를 클릭하여 작업을 취소합니다.

선택한 툴링만 다시 툴링됩니다. 부품과 관련된 다른 툴링은 영향을 받지 않습니다. 선택한 툴링과 관련된 기존 출력은 다시 툴링하는 과정에서 제거되고 재생성됩니다.

툴링 데이터가 오래되었거나 잘못되었거나 머신 또는 툴링 구성이 변경된 경우 이 옵션을 사용합니다.

Ignore errors

  • 툴링된 인스턴스에 경고가 표시되지만 계속 진행하려는 경우 Ignore errors 를 클릭하여 경고를 재정의할 수 있습니다.

  • 이렇게 하면 툴링 문제가 있더라도 시스템이 해당 인스턴스에 대한 출력 파일을 내보낼 수 있습니다.

경고를 안전하게 무시할 수 있다고 확신하는 경우에만 Ignore Errors 를 사용하십시오. 실제 오류를 재정의하면 머신 손상이나 안전 위험이 발생할 수 있습니다.

툴링 억제/억제 해제

  • 머신이 비활성 상태이거나 특정 부품이 특정 머신에서 처리되는 것을 원하지 않는 경우 Suppress Tooling 을 사용하여 해당 머신에서 네스팅에서 해당 부품을 제외합니다.

  • 억제한 후 툴링된 인스턴스 위에 마우스를 올리면 다음과 같은 메시지가 표시됩니다: "Tooling suppressed by <User name> on <Date Time>".

  • Suppress tooling 은 해당 머신 및 부품에 대한 출력 파일을 제거합니다.

  • Unsuppress tooling 을 사용하여 해당 머신에서 부품에 대한 툴링 상태를 복원합니다.

  • 억제 해제되면 해당 출력 파일이 다시 생성됩니다.
