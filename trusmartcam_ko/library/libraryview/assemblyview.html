어셈블리에서 정적 네스트 생성

Interactive nesting 마법사를 사용하여 어셈블리에 대한 static nest 를 생성할 수 있습니다. 이러한 네스트는 선택한 어셈블리에만 연결된 고정 레이아웃입니다.

  • assys 보기로 전환합니다.

  • 필요한 어셈블리를 마우스 오른쪽 버튼으로 클릭하고 Create Nests…​ 를 선택합니다.

  • Interactive Nesting 마법사가 열립니다.

  • 기본적으로 interactive nesting 마법사는 Select Machine & Material 페이지로 전환됩니다.

  • 머신은 사용 가능한 생산 부하를 나타내는 색상 막대와 함께 표시됩니다:

    • 녹색 막대: 예약된 시간

    • 회색 막대: 사용 가능한 시간(8시간 교대 중)

  • 각 머신 아래에서 선택한 Part 는 Raw-Material(Parts/Total Quantity)과 함께 그룹화됩니다.

  • 부품에 머신에 대한 유효한 툴링 솔루션이 없으면 해당 부품과 재료는 지정된 머신에 대한 처리에서 무시됩니다.

  • 한 머신에 대해 원자재를 선택하면 다른 머신에서는 사용할 수 없습니다.

  • 머신 네스트 계획이 설정되면 선호하는 시트를 선택하고 Priority, Quantity, Margins 등과 같은 시트 매개변수를 재정의합니다.

  • All Sheets, Standard Sheets 또는 Remnant Sheets 를 표시하도록 시트를 필터링할 수 있습니다. next 를 클릭합니다.

이 단계에서는 수량을 늘릴 수 없습니다. 시트 재고 수량과 동일하게 유지하거나 줄여서 네스팅 결과를 확인할 수 있습니다.

  • Interactive nesting plan 창에 Update Qty 가 나타납니다.

  • 기본적으로 Pick All (F5) 는 네스팅을 위해 모든 부품을 포함하거나, 우선순위 부품을 수동으로 선택하고 부품 수량을 조정할 수 있습니다. next 를 클릭합니다.

  • 네스팅이 시작되고 시트에 네스트된 부품이 파란색 상태로 업데이트됩니다.

  • 머신의 생산 부하가 네스트 결과에 따라 업데이트됩니다.

  • 일부 부품이 네스트되지 않은 상태로 남아 있으면 Some parts remain unnested 메시지가 나타납니다 - 이러한 부품은 원래 작업에 남아 있습니다.

    • 적합한 시트가 없는 경우 부품이 네스트되지 않은 상태로 남을 수 있습니다.

  • Static Nest 를 편집하여 네스트되지 않은 부품을 포함할 수 있습니다:

    • 네스트되지 않은 부품을 삽입할 레이아웃을 선택하고 편집을 위해 체크아웃합니다.

  • TecZone 이(가) 열립니다. Pick 또는 Pick All 을 클릭하여 상위 어셈블리에서 네스트되지 않은 부품을 선택합니다.

  • 필요에 따라 레이아웃에서 부품을 배치합니다.

  • 생성된 네스트는 쉽게 식별할 수 있도록 상위 어셈블리의 이름을 따서 자동으로 명명됩니다.

Static nest 는 다른 어셈블리의 부품을 포함할 수 없습니다. 혼합 어셈블리 네스트를 허용하면 다른 어셈블리를 릴리스하지 않고 하나의 어셈블리를 릴리스할 수 없으므로 설계상 혼합이 허용되지 않습니다.

비판금 구성 요소

  • 어셈블리를 가져오면 판금 부품이 추출되어 Part Library 의 어셈블리에 추가됩니다.

  • 판금이 아닌 구성 요소는 분리되어 Components 에 추가됩니다.

  • 어셈블리는 Assembly Library 에 추가되고 해당 BOM(Bill of Materials)에는 부품과 구성 요소가 모두 포함됩니다.

  • 부품이 이미 판금 부품으로 가져와진 경우 시스템은 기존 항목을 업데이트하고 Part Library 에서 중복 항목을 제거합니다.

  • 어셈블리를 선택하면 부품과 구성 요소가 모두 표시되며, 구성 요소 수량은 구성 요소 이미지 아래에 표시됩니다(선택한 어셈블리 구성 요소 수 및 전체 구성 요소 수).

  • 구성 요소 툴팁에는 이름, 재료 및 크기가 표시됩니다. 구성 요소는 생산 중에 제외됩니다 - 네스트되지 않으며 구성 요소에 대한 시트가 생성되지 않습니다.

  • 샘플 어셈블리 및 구성 요소는 다음에서 사용할 수 있습니다: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Assys\Components, 이는 구성 요소 가져오기 및 어셈블리 워크플로를 테스트하는 데 사용할 수 있습니다.

어셈블리에서 작업 생성

  • 어셈블리를 마우스 오른쪽 버튼으로 클릭하고 New…​ 를 클릭한 다음 Job 을 클릭합니다.

  • New Job 대화 상자에서 어셈블리 수를 설정하고 OK 를 클릭한 다음 필요에 따라 작업 세부 정보(예: 납기일 및 우선순위)를 업데이트합니다.

  • 시스템은 어셈블리에서 작업을 생성하고 static nest 를 job nest 로 복사하여 시트 수를 업데이트합니다. 복사된 네스트에는 작업 ID 가 접두사로 붙습니다.

  • Job nest 는 원래 static nest 에 영향을 주지 않고 편집하거나 삭제할 수 있습니다.

  • Job nest 는 Adapt/Compact…​ 또는 Add parts…​ 를 사용하여 다시 패킹할 수 있습니다.

  • 자세한 단계는 조정/압축 및 부품 추가 를 참조하십시오.

부품이 네스트에 나타나지 않으면 nest edit 대화 상자를 확인하십시오 - 네스트되지 않은 부품을 수동으로 삽입할 수 있습니다.

저장된 검색 및 필터를 사용하여 여러 어셈블리에서 부품을 빠르게 찾을 수 있습니다.

네스트를 작업으로 복사할 때 혼동을 피하기 위해 명확하고 설명적인 어셈블리 및 네스트 이름을 사용하십시오.
