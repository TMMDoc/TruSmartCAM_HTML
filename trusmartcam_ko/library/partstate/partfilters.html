부품 필터

Part Library Filter 를 사용하면 특정 조건을 적용하여 라이브러리에서 부품을 빠르게 검색하고 찾을 수 있습니다. 기준에 맞는 부품으로만 결과를 좁혀 이러한 필터를 통해 관련 부품을 효율적으로 관리하고 액세스할 수 있습니다.

State

  • State 필터를 사용하여 현재 상태를 기준으로 부품을 검색합니다.

  • 드롭다운에는 사용 가능한 라이브러리 부품에 따라 적용 가능한 모든 상태가 표시됩니다.

  • 상태 목록은 선택한 부품과 해당 상태에 따라 동적으로 변경됩니다.

  • 예를 들어, Material Missing 을 선택하여 해결되지 않은 재료 상태의 부품을 봅니다.

Status

  • Status 필터를 사용하여 툴링 상태를 기준으로 부품을 검색합니다.

  • 드롭다운에는 툴링 상태가 색상 상자로 표시되고 사용 가능한 모든 머신과 적용 가능한 오류가 표시됩니다.

  • 색상 상자는 다음 상태를 나타냅니다:

    • 흰색: 툴링 정상

    • 주황색: 툴링에 오류 있음

    • 노란색: 툴링에 경고 있음

    • 회색: 툴링 억제됨

  • 부품에 좁은 플랜지 또는 툴링 미할당 오류가 있는 경우 이를 선택하면 해당 부품이 표시됩니다.

  • 선택한 머신에서 억제된 툴링이 있는 부품은 회색 상자를 클릭하면 표시됩니다.

Bend mounts

  • Bend mounts 필터를 사용하여 사용된 밴드 공구를 기준으로 부품을 검색합니다.

  • 드롭다운에는 사용 가능한 모든 밴드 공구가 표시되며 공구 이름, 유형(punch, gooseneck, radius 등) 또는 설명으로 필터링할 수 있습니다.

  • 여러 공구를 선택하고 Match all 을 클릭하여 선택한 두 공구를 모두 사용하는 공구를 정렬합니다.
