대화형 네스팅

Interactive nesting 은 단일 부품, 작업의 일부 부품, 단일 작업 또는 여러 작업에 대한 네스트 계획을 생성하는 데 사용할 수 있습니다. 머신과 재료를 선택하고 시트 매개변수를 설정하며 네스팅 결과를 대화형으로 검토할 수 있습니다.

부품 또는 작업을 마우스 오른쪽 버튼으로 클릭하고 Plan Part…​/Plan Job…​ → Run Interactive Nesting…​ 옵션을 선택합니다.

  • Interactive Nesting 창이 열립니다.

  • 기본적으로 interactive nesting 창은 Select Machine & Material 페이지로 전환됩니다.

  • 머신은 사용 가능한 생산 부하를 나타내는 색상 막대와 함께 표시됩니다:

    • 녹색 막대: 예약된 시간

    • 회색 막대: 사용 가능한 시간(8시간 교대 중)

  • 각 머신 아래에서 선택한 Part 는 Raw-Material(Parts/Total Quantity)과 함께 그룹화됩니다.

  • 부품에 머신에 대한 유효한 툴링 솔루션이 없으면 해당 부품과 재료는 지정된 머신에 대한 처리에서 무시됩니다.

  • 한 머신에 대해 원자재를 선택하면 다른 머신에서는 사용할 수 없습니다.

  • 머신 네스트 계획이 설정되면 선호하는 시트를 선택하고 Priority, Quantity, Margins 등과 같은 시트 매개변수를 재정의합니다.

  • All Sheets, Standard Sheets 또는 Remnant Sheets 를 표시하도록 시트를 필터링할 수 있습니다. Next 를 클릭합니다.

이 단계에서는 수량을 늘릴 수 없습니다. 시트 재고 수량과 동일하게 유지하거나 줄여서 네스팅 결과를 확인할 수 있습니다.

  • Interactive nesting plan 창에 Update Qty 가 나타납니다.

  • 기본적으로 Pick All (F5) 는 네스팅을 위해 모든 부품을 포함하거나, 우선순위 부품을 수동으로 선택하고 부품 수량을 조정할 수 있습니다. Next 를 클릭합니다.

  • 네스팅이 시작되고 시트에 네스트된 부품이 파란색 상태로 업데이트됩니다.

  • 머신의 생산 부하가 네스트 결과에 따라 업데이트됩니다.

  • 네스트된 레이아웃은 축척에 맞게 그려지며 Nest Results 탭에 표시됩니다.

  • 일부 부품이 네스트되지 않은 상태로 남아 있으면 Some parts remain unnested 메시지가 나타납니다 - 이러한 부품은 원래 작업에 남아 있습니다.

    • 네스트되지 않는 이유는 네스트할 시트를 사용할 수 없기 때문일 수 있습니다

  • Interactive Nest 결과는 다음과 같이 접두사가 붙습니다: factory → settings → Job → Nest settings, Interactive sheet-name prefix.

  • interactive nest 레이아웃에는 문자 L 이 접두사로 붙습니다.
