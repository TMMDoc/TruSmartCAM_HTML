Importowanie zespołów

Zespoły to grupy powiązanych części połączonych w jedną jednostkę, co umożliwia zarządzanie wieloma częściami razem jako jedną całością.

Zespoły możesz importować przy użyciu następujących metod:

  1. Import z pliku

  2. Przeciągnij i upuść

  3. Import z arkusza kalkulacyjnego

Import z pliku

Zespół można zaimportować do biblioteki części za pomocą opcji Import Assemblies…​.

  • Kliknij ikonę Open na pasku poleceń i wybierz Import Assemblies…​, albo użyj File → Open → Import Assemblies…​.

  • Pojawi się okno dialogowe Open. Wybierz żądany plik lub pliki zespołu.

  • Wyświetlany jest podgląd wybranego zespołu.

  • Kliknij Open, aby zaimportować zespół.

  • Zaimportowane zespoły są wymienione w widoku Assemblies w bibliotece części.

Przeciągnij i upuść

  • Przeciągnij i upuść zespół bezpośrednio do biblioteki części TruSmartCAM.

Import z arkusza kalkulacyjnego

  • Użyj File → Open → Import Assemblies…​ i wybierz plik CSV, XLSX lub XML albo przeciągnij i upuść plik.

  • Przed importem przejrzyj i zaktualizuj szczegóły oraz ilości zespołów. Użyj Add…​ lub Remove…​, aby wprowadzić zmiany.

  • Po imporcie zespoły można przygotować i przypisać im statyczne nesty (Static Nests).
