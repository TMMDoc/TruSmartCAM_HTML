Importowanie zadań job

Import z pliku csv lub xlsx

Zadania job możesz również importować w popularnych formatach tekstowych

  • Kliknij File → Open → Import Jobs, pojawi się okno dialogowe Open Folder. Wybierz C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Jeśli wszystkie części istnieją w lokalizacji pliku csv lub w katalogach folderu wyszukiwania, pojawi się okno new job, w którym wymienione są wszystkie części pasujące do pól csv.

  • Brakujące części są ignorowane i nie pojawiają się w oknie new job.

  • Początkowo status części to Nascent.

  • Kliknij OK — teraz części są importowane do biblioteki części.

Create a blank part for the missing CAD files

Podczas importowania zadań job za pomocą arkusza kalkulacyjnego (.csv lub .xlsx) mogą czasami wystąpić wiersze odwołujące się do plików CAD, które nie są dostępne w systemie.

  • Aby sobie z tym poradzić, przejdź do Factory → Settings → Job, w sekcji Spreadsheet import settings włącz Create a blank part for the missing CAD files

Gdy ta opcja jest wybrana:

  • Jeśli dla dowolnego wiersza brakuje pliku CAD podczas importu zadania job, system automatycznie utworzy pustą część w miejsce brakującego pliku CAD.

  • W oknie new job te brakujące części są wizualnie wyróżnione na żółto, aby wskazać, że powiązany plik CAD jest niedostępny.

  • Brakująca część nadal będzie miała zmapowane pola (takie jak nazwa części, materiał, grubość, ilość itd.) z pliku CSV. Jej status części będzie jednak wyświetlany jako Nascent, co oznacza, że jest to tylko pusty symbol zastępczy bez rzeczywistej geometrii.

Gwarantuje to, że import zadania job może być kontynuowany bez błędów z powodu brakujących plików CAD — możesz później zaktualizować lub zastąpić pustą część prawidłowym plikiem CAD, gdy stanie się dostępny.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Gdy to pole wyboru jest zaznaczone, system automatycznie tworzy nowe zadanie job bez wyświetlania okna dialogowego New Job, jeśli arkusz kalkulacyjny nie zawiera błędów (brakujących części, brakujących dat ani nieprawidłowych danych).

  • Gdy to pole wyboru jest wyczyszczone, okno dialogowe New Job jest zawsze wyświetlane w celu przeglądu i potwierdzenia przez użytkownika, nawet jeśli arkusz kalkulacyjny nie zawiera błędów.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Gdy to pole wyboru jest zaznaczone, system oczekuje, że arkusz kalkulacyjny będzie używał kolumny Raw-Material (na przykład Steel-20). Oznacza to, że typ materiału i grubość powinny być połączone w jednej wartości w jednej kolumnie.

  • Gdy to pole wyboru jest wyczyszczone, system oczekuje, że arkusz kalkulacyjny będzie miał osobne kolumny dla Material i Thickness (na przykład Steel i 2.00). System łączy je wewnętrznie podczas importu.

Folder monitorowany przy użyciu CSV/XLSX

  • W factory → Settings→ Watch settings zaznacz Enable 'Live Folder' oraz Watch sub-folders also.

  • Ustaw ścieżkę folderu monitorowanego (UNC lub dysk zmapowany).

  • W Spreadsheet import settings zaznacz Import spreadsheet from 'Live Folder'.

  • Wybierz Import Jobs z opcji importu arkusza kalkulacyjnego.

  • Skopiuj C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv i wklej do folderu monitorowanego.

  • System sprawdza plik CSV i próbuje automatycznie utworzyć zadanie job.

  • Jeśli brakuje pliku CAD, zadanie job nie jest tworzone, ponieważ nie znaleziono wymaganych danych CAD.

Katalog wyszukiwania CAD i rekurencyjne wyszukiwanie CAD — nieskonfigurowane

  • W factory → Settings → Job → Spreadsheet import settings, jeśli nie ustawiono żadnego CAD lookup directories i nie użyto Use recursive CAD search, system nie wyszukuje plików CAD automatycznie.

  • Jeśli pole wyboru Create a blank part for the missing CAD files jest zaznaczone, zadanie job zostanie utworzone nawet wtedy, gdy brakuje plików CAD.

  • W takim przypadku wszystkie części w zadaniu job zostaną utworzone jako części nascent (puste) — oznacza to, że nie mają geometrii, ponieważ nie można było znaleźć plików CAD.

Katalog wyszukiwania CAD i rekurencyjne wyszukiwanie CAD — skonfigurowane

Gdy CAD lookup directories jest ustawiony na (C:\Program Files\TRUMPF\TMM\Praxis\Samples) a Use recursive CAD search jest włączone w factory → Settings → Job → Spreadsheet import settings:

  • System automatycznie przeszukuje określony folder i wszystkie jego podfoldery w poszukiwaniu wymaganych plików CAD wymienionych w arkuszu kalkulacyjnym.

  • Create a blank part for the missing CAD files jest również włączone, więc jeśli jakiś plik CAD nadal nie zostanie znaleziony, system utworzy pustą część jako symbol zastępczy.
