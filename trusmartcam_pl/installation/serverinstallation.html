Instalacja serwera

Postępuj zgodnie z instrukcjami, aby zainstalować serwer TruSmartCAM wraz z SQL.

Uprawnienia administratora

Aby wykonać tę instalację, użytkownik musi posiadać uprawnienia administracyjne.

  • Uruchom Setup.TruSmartCAM.<version>.exe, aby rozpocząć instalację.

Wersja jest liczbą.

  • Przeczytaj umowę licencyjną, wybierz I accept the agreement, a następnie kliknij Next.

Krok 1 : Lokalizacja instalacji

  • Podaj katalog instalacji lub zaakceptuj domyślną lokalizację C:\Program Files\TRUMPF\TMM\Praxis i kliknij Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Folder instalacji będzie zawierał następujące foldery: Bin, MetaCAM, Samples i Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Folder danych będzie zawierał następujące foldery: TruSmartCAM, TecZone i MetaCAM.

Krok 2 : Wybór komponentów

Typ instalacji Komponenty

Full

Serwer + klient desktopowy + Engine

Client

Klient desktopowy

Server

Serwer + klient desktopowy

Station

Wybiera wszystkie terminale stacji, takie jak TecZone, MetaCAM, RightAngle (kontroler gięcia), Vulcan (kontroler maszyny laserowej)

Custom

Wybór według uznania użytkownika.

  • Wybierz Full Installation. Wybierz Code Senders oraz Bend Code Senders z narzędzi TruSmartCAM. Teraz typ instalacji zmienia się na Custom. Kliknij Next.

Krok 3 : Wybór instalacji SQL Server

Instalacja SQL Express 2022 jest potrzebna tylko dla serwera TruSmartCAM. Ta opcja nie jest dostępna dla instalacji Client i Sync. Ponadto jest ona zaznaczona i instalowana za pierwszym razem, a następnie można ją pominąć. Jeśli SQL jest już zainstalowany na serwerze TruSmartCAM, użytkownik może pominąć krok 3.

  • W Select Additional Tasks: kliknij Install SQL Express i kliknij Next.

  • W Ready to Install: podsumuj wszystkie funkcje instalacji i kliknij Install.

Krok 4 : Instalacja SQL Server

Po zainstalowaniu komponentów TruSmartCAM instalator kontynuuje instalację serwera SQL. Zaakceptuj umowę licencyjną, aby kontynuować, i zainstaluj SQL Express z domyślnymi opcjami.

Po zakończeniu instalacji kliknij Close i zakończ instalację.

W zależności od wersji systemu Windows zamknięcie instalacji SQL może wymusić ponowne uruchomienie komputera.

Krok 5 : Skróty na pulpicie Windows

  • Po instalacji SQL, jeśli system nie uruchomi się ponownie, zaznacz pole wyboru Launch TruSmartCAM i kliknij Finish.

  • Jeśli system uruchomi się ponownie, uruchom skrót TruSmartCAM na pulpicie lub wpisz TruSmartCAM w menu Start systemu Windows i wybierz Run as administrator.

Instalacja serwera: ikony skrótów TruSmartCAM oraz TruSmartCAM License są dostępne na pulpicie.
Instalacja Client/SYNC: na pulpicie dostępna jest tylko ikona skrótu TruSmartCAM.

Krok 6 : Rejestracja licencji

  • W polu Serial Number wpisz klucz seryjny TruSmartCAM dostarczony przez zespół serwisowy Trumpf Metamation. Wpisz <Nazwa firmy> w polu "Registered to" oraz adres e-mail. Kliknij OK.

W przypadku gdy zapora sieciowa blokuje rejestrację licencji lub gdy na komputerze serwera TruSmartCAM nie ma dostępu do internetu, licencja TruSmartCAM jest realizowana poprzez aktywację offline. Wyślij e-mailem plik Prax.request z folderu C:\ProgramData\TRUMPF\TMM\Praxis do zespołu serwisowego Trumpf Metamation. Zespół Trumpf Metamation dostarczy plik Prax.lock, który należy umieścić w tym folderze.

Krok 7 : Wstępna jednorazowa konfiguracja

  • Wpisz nazwę bazy danych i ustaw lokalizację przechowywania danych. Zaznacz pole wyboru Use SQL Server i wybierz nazwę serwera SQL, z którym ma zostać nawiązane połączenie z bazą danych. Kliknij OK.

  • Klient desktopowy TruSmartCAM otwiera się, wyświetlając Database Connection Succeeded w dolnej części ekranu.

  • Pliki konfiguracyjne TruSmartCAM, TecZone i MetaCAM zostały utworzone z domyślnymi maszynami konfiguracyjnymi lub na podstawie maszyn licencjonowanych TruSmartCAM. Ta sama konfiguracja będzie współdzielona przez wszystkich klientów TruSmartCAM.

Ekran powitalny wyświetla nazwę logowania użytkownika Windows jako login i nazwę TruSmartCAM. Pierwszy użytkownik TruSmartCAM jest traktowany jako Site Admin. Podaj adres e-mail i hasło. Kliknij OK .

Zaznacz pole wyboru Remember me, aby zapisać dane logowania na przyszłość. Wyczyszczenie pola wyboru Remember me spowoduje wyświetlanie okna dialogowego logowania i hasła przy każdym uruchomieniu aplikacji TruSmartCAM.

Krok 8 : Logowanie do TruSmartCAM

  • Zamknij TruSmartCAM i otwórz go ponownie. System poprosi o podanie danych logowania TruSmartCAM.

  • Nazwa zalogowanego użytkownika jest wyświetlana obok ikony użytkownika w nagłówku aplikacji TruSmartCAM.

  • Po najechaniu kursorem na ikonę użytkownika system wyświetla:

    • Rolę użytkownika (na przykład: Programmer, Admin).

    • Skrót do wylogowania: Ctrl+L.

  • Kliknięcie ikony użytkownika otwiera menu, które umożliwia:

    • Edit information…​ - Aktualizacja szczegółów profilu.

    • Change password…​ - Zmiana hasła do konta.

    • Sign out - Wylogowanie z aplikacji.

    • Cancel - Zamknięcie menu bez wprowadzania zmian.

Krok 9 : Konfiguracja maszyny fabrycznej

  • Licencja TruSmartCAM [bit licencji włączający wszystkie maszyny]: domyślna maszyna i materiał TruSmartCAM są traktowane jako konfiguracja fabryczna.

  • Licencja TruSmartCAM [brak wersji demo i włączony bit kilku maszyn]: te nieliczne maszyny oraz domyślny materiał są traktowane jako konfiguracja fabryczna.

  • (Open → Import) nową część z C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts i sprawdź, czy część została zaimportowana pomyślnie.

Uwaga 1 : Monitor TruSmartCAM

  • Monitor TruSmartCAM z instalacją Engine (uprawnienia Site Admin):

    • Monitor TruSmartCAM z Engine oraz uprawnieniami Site Admin TruSmartCAM będzie miał następujące opcje:

      1. Przekazywanie konfiguracji TruSmartCAM, TecZone, MetaCAM do wszystkich klientów TruSmartCAM. Ponadto uprawnienia do tworzenia nowego loginu użytkownika TruSmartCAM.

      2. Show Agents wyświetli łączną liczbę dostępnych silników (engine) do wykonywania zadań automatyzacji zgodnie z licencją TruSmartCAM.

  • Monitor TruSmartCAM bez instalacji Engine (uprawnienia Site Admin):

  • Monitor TruSmartCAM bez instalacji Engine (uprawnienia inne niż Site Admin):

Komputer, na którym działa aplikacja TruSmartCAM, musi mieć zainstalowany komponent Engine TruSmartCAM [komputer serwera lub dowolna instalacja klienta]. Komputer z zainstalowanym komponentem Engine TruSmartCAM powinien działać 24 godziny na dobę, 7 dni w tygodniu, aby wykonywać wszystkie zadania automatyzacji.
Uwaga 2 : OpenGL

  • Aplikacja TruSmartCAM podczas otwierania zamyka się natychmiast, a pmonitor nie jest wyświetlany na pasku zadań.

  • Oznacza to problem z OpenGL.

  • Inny sposób potwierdzenia tego: otwórz C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts , który wyświetla okno dialogowe błędu dotyczące problemu z OpenGL.

  • Zaktualizuj C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , sekcję options z wartością GLVersion=1, aby aplikacja TruSmartCAM otwierała się pomyślnie.

[Options]
GLVersion=1.0
