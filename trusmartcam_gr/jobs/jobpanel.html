Πίνακας εργασιών

Αυτή η ενότητα εξηγεί ενέργειες σχετικές με την εργασία όπως Export outputs, Reset job…​, Mark complete…​, Export job…​, και άλλες επιλογές που χρησιμοποιούνται για τη διαχείριση στιγμιοτύπων εργασίας.

Open in read-only mode for viewing
Ανοίγει την επιλεγμένη εργασία σε λειτουργία μόνο για ανάγνωση.

Check-out the document for editing
Ενεργοποιεί την επεξεργασία της επιλεγμένης εργασίας.

Delete
Διαγράφει την επιλεγμένη εργασία.

View Report
Ανοίγει την αναφορά παραγωγής για την επιλεγμένη εργασία.

Export Outputs

Εξάγει τα έτοιμα για τη μηχανή αρχεία εξόδου (αρχεία NC και αναφορές) που δημιουργήθηκαν για την επιλεγμένη εργασία.

Plan Job…​

Δημιουργεί κατανεμημένες διατάξεις για τα εξαρτήματα της επιλεγμένης εργασίας.

Reset Job…​

Αφαιρεί όλες τις διατάξεις που δημιουργήθηκαν για την εργασία και επαναφέρει τα εξαρτήματά της στην κατάσταση που μπορούν να σχεδιαστούν.

Mark Complete…​

Σημαδεύει την εργασία και όλες τις κατανομές της ως ολοκληρωμένες μετά την παραγωγή.

Export Job…​

Εξάγει την πλήρη εργασία ως πακέτο που μπορεί να επαναχρησιμοποιηθεί ή να εισαχθεί σε άλλο σύστημα.

Prev / Next / Layout

Μεταβαίνει στην προηγούμενη ή την επόμενη διάταξη εντός της επιλεγμένης εργασίας.

Ταξινόμηση και φιλτράρισμα

Χρησιμοποιήστε αυτά τα φίλτρα για να δείτε άλλες εργασίες που μοιράζονται τον ίδιο Same Customer, Same Part.

Export outputs

  • Επιλέξτε την απαιτούμενη εργασία.

  • Κάντε κλικ στο Export outputs.

  • Αυτό εξάγει τα έτοιμα για τη μηχανή αρχεία εξόδου που δημιουργήθηκαν για την επιλεγμένη εργασία.

  • Τα Export Outputs μπορούν να αποθηκευτούν είτε στην προεπιλεγμένη τοποθεσία που έχει ρυθμιστεί στις Factory Settings είτε σε μια προσαρμοσμένη τοποθεσία χρησιμοποιώντας το Browse…​.

  • Εξάγει μόνο αρχεία εξόδου μηχανής (όπως NC και αναφορές) για την εργασία.

  • Αυτά τα αρχεία χρησιμοποιούνται απευθείας για την παραγωγή και μπορούν να αποσταλούν στη μηχανή.

Reset job…​

Επαναφέρει την επιλεγμένη εργασία αφαιρώντας όλες τις διατάξεις που δημιουργήθηκαν και καθιστώντας τα εξαρτήματα ξανά διαθέσιμα για σχεδιασμό.

Για να επαναφέρετε μια εργασία:

  • Κάντε δεξί κλικ στην εργασία και επιλέξτε Reset job…​.

  • Αυτό διαγράφει όλες τις υπάρχουσες κατανεμημένες διατάξεις για την επιλεγμένη εργασία και επαναφέρει όλα τα εξαρτήματά της στην κατάσταση που μπορούν να σχεδιαστούν.

  • Εάν οι διατάξεις περιέχουν εξαρτήματα από άλλες εργασίες, αυτά τα εξαρτήματα επαναφέρονται επίσης.

Export job…​

  • Επιλέξτε την απαιτούμενη εργασία.

  • Κάντε κλικ στο Export job…​.

  • Αυτή η επιλογή εξάγει την πλήρη εργασία ως πακέτο που μπορεί να επαναχρησιμοποιηθεί ή να εισαχθεί σε άλλο σύστημα.

  • Τα εξαγόμενα δεδομένα περιλαμβάνουν όλες τις πληροφορίες που απαιτούνται για την αναδημιουργία της εργασίας:

    • Λεπτομέρειες και ποσότητες εξαρτημάτων (αρχεία CSV).

    • Δεδομένα διάταξης και κατανομής (αρχεία CSV / FXYLT).

  • Τα εξαγόμενα αρχεία αποθηκεύονται ως φάκελος εργασίας στη ρυθμισμένη τοποθεσία εξαγωγής.

  • Αυτή η επιλογή χρησιμοποιείται για τη μεταφορά, την κοινή χρήση ή τη δημιουργία αντιγράφου ασφαλείας ολόκληρης της εργασίας.

Mark complete…​

  • Αφού η εργασία επεξεργαστεί στη μηχανή, ανοίξτε τον Πίνακα εργασιών και επιλέξτε Mark complete…​.

  • Όταν μια εργασία σημαδεύεται ως ολοκληρωμένη:

    • Όλες οι κατανομές υπό την εργασία σημαδεύονται ως ολοκληρωμένες.

    • Η εργασία αποχρωματίζεται, μετακινείται στο τέλος της λίστας και εμφανίζεται με πράσινο σημάδι επιλογής.

    • Όλες οι διατάξεις υπό την εργασία αφαιρούνται από τη λίστα ενεργών διατάξεων.

    • Οι καταστάσεις εξαρτήματος και εργασίας ενημερώνονται και οι επεξεργασμένες ποσότητες μεταβαίνουν στην ολοκληρωμένη κατάσταση.

    • Τα αρχεία εξόδου για όλες τις διατάξεις στην εργασία αφαιρούνται από την τοποθεσία εξόδου μηχανής για να αποφευχθεί η διπλή χρήση.
