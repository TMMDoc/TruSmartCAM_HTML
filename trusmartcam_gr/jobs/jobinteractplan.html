Διαδραστική κατανομή

Η διαδραστική κατανομή μπορεί να χρησιμοποιηθεί για τη δημιουργία σχεδίου κατανομής για ένα μεμονωμένο εξάρτημα, ορισμένα εξαρτήματα από μια εργασία, μια μεμονωμένη εργασία ή πολλαπλές εργασίες. Σας επιτρέπει να επιλέξετε μηχανές και υλικά, να ορίσετε παραμέτρους μεταλλικών πλακών και να εξετάσετε τα αποτελέσματα της κατανομής διαδραστικά.

Κάντε δεξί κλικ σε ένα εξάρτημα ή μια εργασία και επιλέξτε την επιλογή Plan Part…​/Plan Job…​ → Run Interactive Nesting…​.

  • Ανοίγει το παράθυρο Interactive Nesting.

  • Από προεπιλογή, το παράθυρο διαδραστικής κατανομής μεταβαίνει στη σελίδα Select Machine & Material.

  • Οι μηχανές εμφανίζονται με χρωματιστές ράβδους που υποδεικνύουν το διαθέσιμο φορτίο παραγωγής:

    • Πράσινη ράβδος: Προγραμματισμένες ώρες

    • Γκρι ράβδος: Διαθέσιμες ώρες (από βάρδια 8 ωρών)

  • Κάτω από κάθε μηχανή, τα επιλεγμένα εξαρτήματα ομαδοποιούνται με την πρώτη ύλη τους (Εξαρτήματα/Συνολική ποσότητα).

  • Εάν ένα εξάρτημα δεν έχει έγκυρη λύση εξοπλισμού για μια μηχανή, το συγκεκριμένο εξάρτημα και υλικό αγνοούνται κατά την επεξεργασία για τη συγκεκριμένη μηχανή.

  • Εάν μια πρώτη ύλη επιλεχθεί για μια μηχανή, δεν θα είναι διαθέσιμη για άλλες μηχανές.

  • Αφού οριστεί το σχέδιο κατανομής της μηχανής, επιλέξτε την προτιμώμενη μεταλλική πλάκα και παρακάμψτε παραμέτρους μεταλλικής πλάκας όπως Priority, Quantity, Margins κ.λπ.

  • Μπορείτε να φιλτράρετε τις μεταλλικές πλάκες για να εμφανίζονται All Sheets, Standard Sheets ή Remnant Sheets. Κάντε κλικ στο Next.

Δεν είναι δυνατή η αύξηση των ποσοτήτων σε αυτό το στάδιο. Μπορείτε είτε να τις διατηρήσετε ίδιες με την ποσότητα αποθέματος μεταλλικών πλακών είτε να τις μειώσετε και να ελέγξετε τα αποτελέσματα κατανομής.

  • Το Update Qty εμφανίζεται στο παράθυρο σχεδίου διαδραστικής κατανομής.

  • Από προεπιλογή, το Pick All (F5) περιλαμβάνει όλα τα εξαρτήματα για κατανομή ή μπορείτε να επιλέξετε χειροκίνητα τα εξαρτήματα προτεραιότητας και να προσαρμόσετε τις ποσότητες εξαρτημάτων. Κάντε κλικ στο Next.

  • Η κατανομή ξεκινά και τα κατανεμημένα στη μεταλλική πλάκα εξαρτήματα ενημερώνονται με μπλε κατάσταση χρώματος.

  • Το φορτίο παραγωγής της μηχανής ενημερώνεται βάσει του αποτελέσματος κατανομής.

  • Οι κατανεμημένες διατάξεις σχεδιάζονται υπό κλίμακα και εμφανίζονται στην καρτέλα Αποτελέσματα κατανομής.

  • Εάν ορισμένα εξαρτήματα παραμείνουν μη κατανεμημένα, εμφανίζεται το μήνυμα Some parts remain unnested — αυτά τα εξαρτήματα παραμένουν στην αρχική εργασία.

    • Ο λόγος μη κατανομής μπορεί να είναι μη διαθέσιμη μεταλλική πλάκα για κατανομή

  • Το αποτέλεσμα διαδραστικής κατανομής λαμβάνει πρόθεμα ως εξής: factory → settings → Job→ Nest settings, Interactive sheet-name prefix.

  • Οι διατάξεις διαδραστικής κατανομής λαμβάνουν πρόθεμα με το γράμμα L.
