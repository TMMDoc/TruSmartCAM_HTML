Εγκατάσταση διακομιστή

Ακολουθήστε τις οδηγίες για να εγκαταστήσετε τον διακομιστή TruSmartCAM μαζί με SQL.

Δικαιώματα διαχειριστή

Για την εκτέλεση αυτής της εγκατάστασης, ο χρήστης πρέπει να διαθέτει δικαιώματα διαχειριστή.

  • Εκτελέστε το Setup.TruSmartCAM.<version>.exe για να ξεκινήσετε την εγκατάσταση.

Η έκδοση είναι ένας αριθμός.

  • Διαβάστε τη σύμβαση άδειας χρήσης και επιλέξτε I accept the agreement και στη συνέχεια κάντε κλικ στο Next.

Βήμα 1 : Θέση εγκατάστασης

  • Ορίστε τον κατάλογο εγκατάστασης ή αποδεχτείτε την προεπιλεγμένη θέση εγκατάστασης C:\Program Files\TRUMPF\TMM\Praxis και κάντε κλικ στο Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Ο φάκελος εγκατάστασης θα περιέχει τους εξής φακέλους : Bin, MetaCAM, Samples και Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Ο φάκελος δεδομένων θα περιέχει τους εξής φακέλους : TruSmartCAM, TecZone και MetaCAM.

Βήμα 2 : Επιλογή στοιχείων

Τύπος εγκατάστασης Στοιχεία

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Επιλέγει όλα τα τερματικά σταθμών όπως TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Επιλέγει με βάση την επιλογή του χρήστη.

  • Επιλέξτε Full Installation. Επιλέξτε Code Senders και Bend Code Senders από τα Εργαλεία TruSmartCAM. Τώρα ο τύπος εγκατάστασης αλλάζει σε Custom. Κάντε κλικ στο Next.

Βήμα 3 : Επιλογή εγκατάστασης SQL Server

Η εγκατάσταση SQL Express 2022 χρειάζεται μόνο για τον διακομιστή TruSmartCAM. Αυτή η επιλογή δεν είναι διαθέσιμη για τις εγκαταστάσεις Πελάτη και Sync. Επίσης, είναι ενεργοποιημένη και εγκαθίσταται την πρώτη φορά και μπορεί να αγνοηθεί έκτοτε. Εάν το SQL είναι ήδη εγκατεστημένο στον διακομιστή TruSmartCAM, ο χρήστης μπορεί να αγνοήσει το Βήμα 3.

  • Στο Select Additional Tasks : Κάντε κλικ στο Install SQL Express και κάντε κλικ Next.

  • Στο Ready to Install : Συνοψίστε όλα τα χαρακτηριστικά εγκατάστασης και κάντε κλικ στο Install.

Βήμα 4 : Εγκατάσταση SQL Server

Μόλις εγκατασταθούν τα στοιχεία TruSmartCAM, το πρόγραμμα εγκατάστασης συνεχίζει με την εγκατάσταση του SQL server. Αποδεχτείτε τη σύμβαση άδειας χρήσης για να συνεχίσετε και εγκαταστήστε το SQL express με τις προεπιλεγμένες επιλογές.

Μόλις ολοκληρωθεί η εγκατάσταση, κάντε κλικ στο Close και ολοκληρώστε την εγκατάσταση.

Ανάλογα με την έκδοση των Windows, το κλείσιμο της εγκατάστασης SQL μπορεί να ζητήσει επανεκκίνηση.

Βήμα 5 : Συντομεύσεις επιφάνειας εργασίας Windows

  • Μετά την εγκατάσταση SQL, εάν το σύστημα δεν επανεκκινηθεί, τότε επιλέξτε το πλαίσιο ελέγχου Launch TruSmartCAM και κάντε κλικ στο Finish.

  • Εάν το σύστημα επανεκκινηθεί, τότε εκκινήστε το εικονίδιο συντόμευσης TruSmartCAM στην επιφάνεια εργασίας ή πληκτρολογήστε TruSmartCAM στο μενού Έναρξη των Windows και επιλέξτε Run as administrator.

Εγκατάσταση διακομιστή : Τα εικονίδια συντόμευσης TruSmartCAM και TruSmartCAM License είναι διαθέσιμα στην επιφάνεια εργασίας.
Εγκατάσταση Πελάτη/SYNC : Μόνο το εικονίδιο συντόμευσης TruSmartCAM είναι διαθέσιμο στην επιφάνεια εργασίας.

Βήμα 6 : Καταχώρηση άδειας χρήσης

  • Στο πεδίο Serial Number, πληκτρολογήστε το TruSmartCAM Serial key που παρέχεται από την ομάδα υπηρεσιών Trumpf Metamation. Πληκτρολογήστε <Company Name> στο πεδίο "Registered to" και το E-Mail. Κάντε κλικ στο OK.

Σε περίπτωση που το τείχος προστασίας του δικτύου μπλοκάρει την καταχώρηση της άδειας χρήσης ή δεν υπάρχει διαδίκτυο στο PC του διακομιστή TruSmartCAM, τότε η άδεια χρήσης TruSmartCAM ενεργοποιείται με εκτός σύνδεσης ενεργοποίηση. Στείλτε με email το Prax.request από τον φάκελο C:\ProgramData\TRUMPF\TMM\Praxis στην ομάδα υπηρεσιών Trumpf Metamation. Η ομάδα Trumpf Metamation θα παρέχει το Prax.lock το οποίο πρέπει να τοποθετηθεί σε αυτόν τον φάκελο.

Βήμα 7 : Αρχική εφάπαξ διαμόρφωση

  • Πληκτρολογήστε το όνομα της βάσης δεδομένων και ορίστε τη θέση αποθήκευσης δεδομένων. Επιλέξτε το πλαίσιο ελέγχου Use SQL Server και επιλέξτε το όνομα του SQL server για να συνδεθείτε στη βάση δεδομένων. Κάντε κλικ στο OK.

  • Ο πελάτης TruSmartCAM Desktop ανοίγει εμφανίζοντας Database Connection Succeeded στο κάτω μέρος.

  • Τα αρχεία διαμόρφωσης TruSmartCAM, TecZone και MetaCAM δημιουργήθηκαν με προεπιλεγμένες μηχανές διαμόρφωσης ή σύμφωνα με τις μηχανές της άδειας χρήσης TruSmartCAM. Η ίδια διαμόρφωση θα κοινοποιηθεί σε όλους τους πελάτες TruSmartCAM.

Η οθόνη καλωσορίσματος εμφανίζεται με το LoginName του χρήστη Windows ως όνομα σύνδεσης και όνομα TruSmartCAM. Ο πρώτος χρήστης TruSmartCAM θεωρείται Site Admin. Δώστε Email και κωδικό πρόσβασης. Κάντε κλικ στο OK .

Επιλέξτε το πλαίσιο ελέγχου Remember me για να αποθηκεύσετε τα διαπιστευτήρια σύνδεσης για την επόμενη φορά. Η απενεργοποίηση του πλαισίου ελέγχου Remember me θα ζητάει το παράθυρο διαλόγου σύνδεσης και κωδικού πρόσβασης κάθε φορά που εκκινείται η εφαρμογή TruSmartCAM.

Βήμα 8 : Σύνδεση στο TruSmartCAM

  • Κλείστε το TruSmartCAM και ανοίξτε το ξανά. Το σύστημα σας ζητάει να εισαγάγετε τα διαπιστευτήρια σύνδεσης στο TruSmartCAM.

  • Το όνομα χρήστη που έχει συνδεθεί εμφανίζεται δίπλα στο εικονίδιο χρήστη στην κεφαλίδα της εφαρμογής TruSmartCAM.

  • Όταν τοποθετήσετε τον δείκτη πάνω από το εικονίδιο χρήστη, το σύστημα εμφανίζει:

    • Τον ρόλο του χρήστη (για παράδειγμα: Programmer, Admin).

    • Μια συντόμευση για αποσύνδεση: Ctrl+L.

  • Κάνοντας κλικ στο εικονίδιο χρήστη ανοίγει ένα μενού που σας επιτρέπει να:

    • Edit information…​ - Να ενημερώσετε τα στοιχεία του προφίλ σας.

    • Change password…​ - Να αλλάξετε τον κωδικό πρόσβασης του λογαριασμού σας.

    • Sign out - Να αποσυνδεθείτε από την εφαρμογή.

    • Cancel - Να κλείσετε το μενού χωρίς να κάνετε καμία αλλαγή.

Βήμα 9 : Διαμόρφωση μηχανών Εργοστασίου

  • TruSmartCAM License [All machines enables license bit] : Οι προεπιλεγμένες μηχανές και υλικά TruSmartCAM θεωρούνται ως Διαμόρφωση Εργοστασίου.

  • TruSmartCAM License [No demo and few machine bit enabled] : Αυτές οι λίγες μηχανές και το προεπιλεγμένο υλικό θεωρούνται ως Διαμόρφωση Εργοστασίου.

  • (Open → Import) ένα νέο εξάρτημα από το C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts και επαληθεύστε εάν το εξάρτημα εισάχθηκε επιτυχώς.

Σημείωση 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor με εγκατάσταση Engine (δικαιώματα site admin):

    • Το TruSmartCAM Monitor με Engine μαζί με δικαιώματα Site Admin TruSmartCAM θα έχει τις ακόλουθες επιλογές:

      1. Διανομή της διαμόρφωσης TruSmartCAM, TecZone, MetaCAM σε όλους τους πελάτες TruSmartCAM. Έχει επίσης δικαιώματα για τη δημιουργία νέας σύνδεσης χρήστη TruSmartCAM.

      2. Το Show Agents θα εμφανίσει τον συνολικό διαθέσιμο engine για την εκτέλεση εργασιών αυτοματισμού σύμφωνα με την άδεια χρήσης TruSmartCAM.

  • TruSmartCAM Monitor χωρίς εγκατάσταση Engine (δικαιώματα site admin):

  • TruSmartCAM Monitor χωρίς εγκατάσταση Engine (χωρίς δικαιώματα site admin):

Το PC που εκτελεί την εφαρμογή TruSmartCAM πρέπει να έχει εγκατεστημένο το στοιχείο Engine TruSmartCAM [Server PC ή σε οποιαδήποτε εγκατάσταση Πελάτη]. Το PC με εγκατεστημένο το στοιχείο Engine TruSmartCAM πρέπει να λειτουργεί 24x7 για να εκτελεί όλες τις εργασίες αυτοματισμού.
Σημείωση 2 : OpenGL

  • Η εφαρμογή TruSmartCAM κατά το άνοιγμα κλείνει αμέσως και επίσης το pmonitor δεν εμφανίζεται στη γραμμή εργασιών.

  • Αυτό αντιπροσωπεύει ζήτημα OpenGl.

  • Ένας άλλος τρόπος για να το επιβεβαιώσετε: Ανοίξτε το C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts το οποίο εμφανίζει παράθυρο διαλόγου σφάλματος σχετικά με το ζήτημα OpenGL.

  • Ενημερώστε το C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , την ενότητα options με GLVersion=1 ώστε η εφαρμογή TruSmartCAM να ανοίγει επιτυχώς.

[Options]
GLVersion=1.0
