Εργασία

Output settings

Save layout NC and reports - Ενεργοποιήστε αυτήν την επιλογή για να αποθηκευτούν το NC διάταξης και οι αναφορές.

Save layout file - Ενεργοποιήστε αυτήν την επιλογή για να αποθηκευτεί το αρχείο διάταξης.

Output simulation preview in reports - Ενεργοποιήστε αυτήν την επιλογή για να δημιουργηθεί η προεπισκόπηση προσομοίωσης εξοπλισμού μαζί με τα άλλα αποτελέσματα. Πρόκειται για μια σύντομη κινούμενη εικόνα GIF για τον εξοπλισμό λέιζερ/διάτρησης.

Do not delete program outputs on layout/job completion - Η ενεργοποίηση αυτής της επιλογής θα παραλείψει τη λειτουργία διαγραφής για τα αποτελέσματα του προγράμματος όταν μια εργασία/διάταξη επισημανθεί ως ολοκληρωμένη.

Nest settings

Mix parts from multiple Jobs - Υποστηρίζει τη μικτή κατανομή. Τα εξαρτήματα από πολλαπλές εργασίες θα πρέπει να κατανέμονται μαζί για καλύτερη αποδοτικότητα συσκευασίας.

Do not auto-release layouts - Αυτό θα αποτρέψει τη διαθεσιμότητα των διατάξεων για παραγωγή μέχρι όλες οι διατάξεις να βρίσκονται σε κατάσταση αποδέσμευσης.

Re-nesting packing cut-off - Αυτή η τιμή χρησιμοποιείται για να αποφασιστεί αν μια κατανεμημένη διάταξη διατηρείται στην ουρά έγκρισης και κατανέμεται εκ νέου όταν σχεδιάζονται νέα εξαρτήματα ή αποδεσμεύονται για παραγωγή και τα σχετικά αποτελέσματα εξάγονται στον φάκελο αποτελεσμάτων.

Interactive sheet-name prefix - Αυτή η ενότητα χρησιμοποιείται για την υποστήριξη διαδραστικής κατανομής όπου ο χρήστης έχει περισσότερο έλεγχο στα εξαρτήματα που κατανέμονται και στο αποτέλεσμα της κατανομής. Χρησιμοποιήστε ένα σχήμα ονοματοδοσίας, διαφορετικό από την αυτόματη κατανομή, για τις διαδραστικά κατανεμημένες διατάξεις.

Update sheet inventory on nest (un)release - Εάν αυτή η επιλογή είναι ενεργοποιημένη, το απόθεμα μεταλλικών πλακών θα ενημερώνεται όταν αποστέλλεται μια κατανομή σε μια μηχανή. Επίσης, η ανάκληση της κατανομής από τη μηχανή θα επιστρέψει την πλάκα στο απόθεμα.

Automate remnant inventory management - Οταν επιλεγεί αυτός ο διακόπτης, το λογισμικό αυτοματοποιεί τη διαχείριση αποθέματος υπολειμμάτων. Εάν δεν επιλεγεί, η διαχείριση υπολειμμάτων γίνεται διαδραστική.

Auto-refresh Out-of-date layouts - Οταν είναι επιλεγμένο, το λογισμικό ανανεώνει όλες τις ui:EGTag.SelectOutOfDate[Out-of-date Layouts] που συνδέονται με ένα εξάρτημα μετά τον υπολογισμό των λύσεων κοπής του.

Automate twin-line nesting - Επιλέξτε αυτήν την επιλογή για να ενεργοποιήσετε την αυτοματοποίηση διπλής γραμμής.

Pull workflow settings

Use 'Pull workflow' - Αυτή η επιλογή είναι χρήσιμη για χρήστες που χρειάζονται ένα ιδιαίτερα αυτόνομο σύστημα σχεδιασμού και κατανομής. Οταν είναι ενεργοποιημένη, το TruSmartCAM σχεδιάζει την κατανομή κατά απαίτηση.

Nests per station - Αυτή η τιμή ορίζει πόσες διατάξεις ανά σταθμό θα δημιουργούνται.

Maximum sheets per nest - Αυτή η τιμή χρησιμοποιείται για τον έλεγχο του μέγιστου αριθμού πλακών για μια μοναδική κατανομή. Έτσι, για παράδειγμα, αν υπάρχει μια παραγγελία με ένα μεγάλο εξάρτημα (που γεμίζει ολόκληρη την πλάκα), που χρειάζεται σε μεγάλες ποσότητες (έστω 500) - το TruSmartCAM δεν δημιουργεί πλέον μια μοναδική κατανομή με 500 αντίγραφα σε λειτουργία pull. Αντ' αυτού, δημιουργεί 10 αντίγραφα ανά κατανομή, όπου 10 είναι το μέγιστο.

Bend programs per station - Αυτή η τιμή ορίζει πόσα προγράμματα κάμψης ανά σταθμό θα δημιουργούνται.

Mark the task completed, when the program outputs are removed - Ενεργοποιήστε αυτήν την επιλογή για μια διάταξη να επισημαίνεται ως Ολοκληρωμένη όταν τα αποτελέσματα αφαιρούνται από τον προορισμό αποτελεσμάτων.

Spreadsheet import settings

CAD lookup directories - Το TruSmartCAM θα προσπαθήσει να φορτώσει την καταχώρηση εξαρτήματος που αναφέρεται στο εισαγόμενο CSV από τη βιβλιοθήκη εξαρτημάτων. Ωστόσο, εάν το εξάρτημα δεν είναι διαθέσιμο στη βιβλιοθήκη εξαρτημάτων, τότε θα προσπαθήσει να ανακτήσει τα εξαρτήματα από τους καταλόγους αναζήτησης με βάση τη σειρά των καταλόγων που ορίζονται σε αυτό το παράθυρο.

Use recursive CAD search - Ενεργοποιήστε αυτήν την επιλογή για να επαναλαμβάνεται η αναζήτηση για διαδοχικά αποτελέσματα.

Create a blank part for the missing CAD files - Εάν τα εξαρτήματα δεν υπάρχουν στη βιβλιοθήκη TruSmartCAM ή στους καταλόγους αναζήτησης, το TruSmartCAM θα δημιουργήσει ένα κενό εξάρτημα για αυτά τα μη διαθέσιμα εξαρτήματα.

Do not show New Job dialog if the spreadsheet has no error - Εάν οι καταχωρήσεις CSV είναι καθαρές, δηλαδή δεν υπάρχει ασυμφωνία δεδομένων από τη ΒΔ ή όλα τα πεδία αναφέρονται σωστά, το TruSmartCAM δεν θα εμφανίσει το παράθυρο επισκόπησης εργασίας και θα επεξεργαστεί την εργασία μόλις εισαχθεί ή εναποτεθεί το CSV.

Prefer Raw-Material column over Material + Thickness - Υποστηριζόμενοι τύποι λογιστικών φύλλων:

  1. Μοτίβο 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Μοτίβο 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Μοτίβο 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Εάν αυτή η επιλογή δεν είναι επιλεγμένη, το Μοτίβο 1 θα θεωρηθεί ο προεπιλεγμένος τύπος λογιστικού φύλλου. Υποστηρίζουμε επίσης το Μοτίβο 3 σε περίπτωση που η μορφή CSV είναι τύπου Μοτίβο 3.

Εάν αυτή η επιλογή είναι επιλεγμένη και το CSV είναι τύπου Μοτίβο 2, τότε το TruSmartCAM θα επιλύσει την πρώτη ύλη από τα πεδία Material και Thickness του CSV.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Επιλέξτε αυτήν την επιλογή για να ενεργοποιήσετε την εξαγωγή CSV όταν μια διάταξη ή εργασία ολοκληρωθεί. Οι ολοκληρωμένες αναφορές αποθηκεύονται στον προορισμό Αναφορών που καθορίζεται στις ρυθμίσεις Factory → Settings → Reports.
