Εισαγωγή

Output settings

Save flat pattern - Ενεργοποιήστε αυτήν την επιλογή για να αποθηκευτεί το αναπτυγμένο σχέδιο ενός εισαγόμενου εξαρτήματος.

Format for flat pattern - Αυτή η επιλογή χρησιμοποιείται για την επιλογή μορφής αρχείου DXF ή GEO.

Flat pattern destination - Αυτή είναι η τοποθεσία όπου θα αποθηκευτεί το αναπτυγμένο σχέδιο.

Import settings

Units for DXF files - Αυτή είναι η μονάδα μέτρησης με την οποία θα εισαχθεί ένα αρχείο DXF· ο χρήστης μπορεί να επιλέξει μεταξύ mm ή inch.

Material lookup keys - Μπορούν να εκχωρηθούν πολλαπλές καταχωρήσεις αναζήτησης χρησιμοποιώντας κόμμα ως διαχωριστικό μεταξύ τους. Οταν εισάγεται ένα εξάρτημα, το TruSmartCAM χρησιμοποιεί αυτά τα κλειδιά για να αναζητήσει τιμές υλικού. Οι αναζητούμενες τιμές χρησιμοποιούνται στη συνέχεια για την επίλυση της πρώτης ύλης. Οι αρχικές τιμές αποθηκεύονται στις ιδιότητες Misc Properties του εξαρτήματος.

Revision lookup keys - Οταν εισάγεται ένα εξάρτημα, η τιμή αναθεώρησης από το αρχικό αρχείο εξαρτήματος (το αρχείο εξαρτήματος που εισάγεται) συγκρίνεται με την υπάρχουσα τιμή αναθεώρησης στο αποθετήριο. Η εισαγωγή εγκαταλείπεται εάν η αναθεώρηση είναι η ίδια. Η χαρτογράφηση προσαρμοσμένων πεδίων υποστηρίζεται πλέον και για τα αρχεία DXF. Για τα αρχεία DXF, τα δεδομένα του προσαρμοσμένου πεδίου εξάγονται από το επίπεδο κειμένου στο σχέδιο ή από συνημμένο PPI.

Use geometry comparison on same CAD revision - Συγκρίνει τη γεωμετρία κατά την εισαγωγή ενός εξαρτήματος με την ίδια αναθεώρηση CAD και ζητάει από τον χρήστη να αντικαταστήσει ή να παραλείψει την εισαγωγή εάν εντοπιστούν διαφορές, δείτε Import configuration για περισσότερες λεπτομέρειες.

Part name keys - Αυτή η επιλογή λειτουργεί παρόμοια με τα κλειδιά υλικού και τα Revision lookup keys. Ορίστε ένα ή περισσότερα Part name keys για να χρησιμοποιήσετε το PPI Part name αντί για το όνομα αρχείου ως όνομα εξαρτήματος.

Thickness lookup keys - Μπορούν να εκχωρηθούν πολλαπλές καταχωρήσεις αναζήτησης χρησιμοποιώντας κόμμα ως διαχωριστικό μεταξύ τους. Οταν εισάγεται ένα εξάρτημα, το TruSmartCAM χρησιμοποιεί αυτά τα κλειδιά για να αναζητήσει τιμές πάχους. Οι αναζητούμενες τιμές χρησιμοποιούνται στη συνέχεια για την επίλυση του πάχους. Οι αρχικές τιμές αποθηκεύονται στις ιδιότητες Misc Properties του εξαρτήματος.

Thickness comparison fudge - Αυτό χρησιμοποιείται κατά την αναζήτηση της πρώτης ύλης όταν εισάγεται ένα εξάρτημα. Το TruSmartCAM προσπαθεί να επιλύσει την πρώτη ύλη αφού αναλυθούν το όνομα υλικού και το πάχος. Για περισσότερες πληροφορίες, ανατρέξτε στο θέμα Thickness fudge παρακάτω.

Identify shapes after a flat is imported - Οταν εισάγεται ένα εξάρτημα, τα εσωτερικά σχήματα εντός του εξαρτήματος μπορούν να αναγνωριστούν και να ταυτοποιηθούν αυτόματα.

Shape identification fudge - Η τιμή fudge ταυτοποίησης σχήματος μπορεί να οριστεί στο:

  1. Καθολικό επίπεδο - Αυτή η τιμή χρησιμοποιείται ως προεπιλογή για όλα τα σχήματα.

  2. Επίπεδο μεμονωμένου σχήματος - Η προεπιλεγμένη τιμή μπορεί να παρακαμφθεί ορίζοντας την τιμή fudge στο επίπεδο του μεμονωμένου σχήματος. Η επιλογή του σχήματος στο παράθυρο Shape Library εμφανίζει την τιμή fudge. Από προεπιλογή, αυτή είναι 0 και χρησιμοποιείται η προεπιλεγμένη καθολική τιμή για τέτοια σχήματα.

Rotate flat horizontally - Γενικά οι τράπεζες των μηχανών κοπής είναι ορθογώνιες και πλατύτερες. Για τη βελτίωση της εφικτότητας του εξοπλισμού, περιστρέψτε το εξάρτημα κατά μήκος του πλάτους μετά την εισαγωγή του.

Part rotation threshold - Ορίστε αυτό ως τον ελάχιστο αριθμό για να επιτρέπεται η περιστροφή. Κάθε εξάρτημα μικρότερο από την ορισμένη τιμή δεν θα περιστρέφεται.

Misc settings

Enable pre-import external tools - Ενεργοποιήστε την επιλογή εισαγωγής εξωτερικών εργαλείων πριν την εισαγωγή για να ενεργοποιήσετε το Creo Reader. Το TruSmartCAM μεταφορτώνει τα προ-εξαγμένα στιγμιότυπα οικογένειας του εξαρτήματος που εναποτίθεται. Λάβετε υπόψη ότι η εξαγωγή στιγμιοτύπων πραγματοποιείται κατά τη μεταφόρτωση του εξαρτήματος (ως λειτουργία πριν την εισαγωγή), οπότε το λογισμικό Creo πρέπει να είναι εγκατεστημένο στον υπολογιστή από τον οποίο μεταφορτώνεται το εξάρτημα.

Ignore drawing colors in Flat thumbnails for clarity - Ενεργοποιήστε αυτήν την επιλογή για να δημιουργηθούν πιο ευκρινείς μινιατούρες σε αποχρώσεις του γκρι. Τα χρώματα των επιπέδων και οι οντότητες κειμένου αγνοούνται για λόγους ευκρίνειας της εικόνας.

Use only one Engine for all import tasks - Οταν είναι ενεργοποιημένο, χρησιμοποιείται μόνο ένας πυρήνας μηχανής για όλες τις εργασίες εισαγωγής.

Thickness fudge

Το Thickness comparison fudge επιλέγει την πλησιέστερη τιμή πάχους μεταλλικής πλάκας όταν η επιθυμητή τιμή πάχους δεν είναι διαθέσιμη στο απόθεμα, συγκρίνοντας την τιμή πάχους των πλακών στο απόθεμα.

Για παράδειγμα, ας υποθέσουμε τα εξής:

  1. Έχουμε ένα εξάρτημα με πάχος μεταλλικής πλάκας 1.6 mm και υλικό χάλυβα.

  2. Η τιμή Thickness comparison fudge είναι 0.1 mm.

  3. Το απόθεμα έχει χαλύβδινες πλάκες με πάχος 1.5 mm, 1.55 mm και 1.7 mm.

Το TruSmartCAM επιλέγει μια πλάκα με την πλησιέστερη τιμή πάχους αφού συγκρίνει την τιμή Thickness comparison fudge (0.1 mm) με το εισαγόμενο στοιχείο (1.6 mm). Σε αυτήν την περίπτωση, η επιλογή θα είναι 1.55 mm.
