Παραγγελίες

Μια παραγγελία ορίζει ποια εξαρτήματα πρέπει να κατασκευαστούν, σε ποια ποσότητα και έως πότε. Καθοδηγεί τον σχεδιασμό και την εκτέλεση της παραγωγής στο TruSmartCAM. Οι παραγγελίες μπορούν να δημιουργηθούν ή να εισαχθούν με διάφορες μεθόδους και μπορούν να μετατραπούν σε εργασίες για τον σχεδιασμό της παραγωγής.

Πίνακας παραγγελιών

Open in read-only mode for viewing
Ανοίγει την επιλεγμένη παραγγελία σε λειτουργία μόνο για ανάγνωση.

Check-out the document for editing
Ενεργοποιεί την επεξεργασία της επιλεγμένης παραγγελίας.

Delete
Διαγράφει την επιλεγμένη παραγγελία.

New…​

Μετατρέπει την παραγγελία σε εργασία, συγκρότημα ή άλλη παραγγελία.

Assign Customer…​

Αντιστοιχίζει έναν πελάτη στην παραγγελία.

Set Due Date…​

Ορίζει την Ημερομηνία παράδοσης για την παραγγελία.

Priority

Καθορίζει το επίπεδο προτεραιότητας της παραγγελίας. Οι διαθέσιμες επιλογές είναι Normal, Low, High και Urgent.

Part Order

Καθορίζει το αναγνωριστικό αναφοράς που έχει αντιστοιχιστεί σε ένα εξάρτημα εντός της παραγγελίας.

Quantity

Καθορίζει τον αριθμό των εξαρτημάτων ή των παρουσιών στην παραγγελία.

Prev / Next / Part

Μεταβαίνει στο προηγούμενο ή στο επόμενο εξάρτημα εντός της παραγγελίας.

Ταξινόμηση και φιλτράρισμα

Χρησιμοποιήστε αυτά τα φίλτρα για να προβάλετε άλλες παραγγελίες που έχουν κοινό Same Material, Same Customer, Same Due Date ή Same Priority.

Επεξεργασία παραγγελιών

Επιλέξτε μία ή περισσότερες παραγγελίες και κάντε δεξί κλικ για να τροποποιήσετε κοινές λεπτομέρειες της παραγγελίας, όπως ποσότητα, Ημερομηνία παράδοσης, προτεραιότητα και στοιχεία πελάτη.

Εάν πολλές επιλεγμένες παραγγελίες απαιτούν διαφορετικές τιμές, χρησιμοποιήστε την επιλογή Check-out for Editing για να επεξεργαστείτε κάθε παραγγελία ξεχωριστά ανάλογα με την απαίτηση.

Τυχόν ενημερώσεις που γίνονται στις παραγγελίες εφαρμόζονται αμέσως στη βάση δεδομένων. Χρησιμοποιήστε την εντολή Delete για να αφαιρέσετε παραγγελίες από τη βιβλιοθήκη παραγγελιών.

Η εντολή Delete αφαιρεί μόνο τις παραγγελίες. Τα εξαρτήματα που συνδέονται με τις αντίστοιχες παραγγελίες δεν διαγράφονται από τη βιβλιοθήκη εξαρτημάτων.

Σχεδιασμός παραγγελιών

Επιλέξτε μία ή περισσότερες παραγγελίες, κάντε δεξί κλικ και κάντε κλικ στο New…​ → Job για να μετατρέψετε τις επιλεγμένες παραγγελίες σε εργασίες. Χρησιμοποιήστε τις επιλογές Ταξινόμησης και Φιλτραρίσματος για να ομαδοποιήσετε σχετικές παραγγελίες πριν από τη δημιουργία της εργασίας.

Μόλις οι παραγγελίες μετατραπούν σε εργασία:

  • Η εργασία μετακινείται στη σελίδα Εργασίες

  • Οι παραγγελίες αφαιρούνται από τη λίστα Παραγγελίες

  • Στη συνέχεια, μπορεί να χρησιμοποιηθεί η τυπική ροή εργασιών σχεδιασμού εργασιών για τον σχεδιασμό της παραγωγής και την κατανομή

Για περισσότερες πληροφορίες σχετικά με τη ροή εργασιών σχεδιασμού εργασιών, ανατρέξτε στο Auto Plan

Πρόσθετες πληροφορίες

  • Εάν διαγραφεί μια εργασία που περιέχει παραγγελίες, οι σχετικές παραγγελίες μετακινούνται αυτόματα πίσω στη σελίδα Παραγγελίες σε ετοιμότητα, εκτός εάν η εργασία ή το εξάρτημα έχει επισημανθεί ως Ολοκληρωμένο.

  • Οι παραγγελίες μπορούν να προστεθούν ή να αφαιρεθούν από μια υπάρχουσα εργασία μέσω του παραθύρου Edit Job ανάλογα με τις απαιτήσεις παραγωγής.
