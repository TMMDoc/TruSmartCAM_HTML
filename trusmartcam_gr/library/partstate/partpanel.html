Πίνακας εξαρτήματος

Αυτή η ενότητα εξηγεί ενέργειες που σχετίζονται με εξαρτήματα, όπως Re-import, Re-tool, Rename, Export outputs, κ.λπ., που χρησιμοποιούνται για τη διαχείριση των περιπτώσεων εξαρτημάτων.

Open in read-only mode for viewing
Ανοίγει το επιλεγμένο εξάρτημα σε λειτουργία μόνο για ανάγνωση.

Check-out the document for editing
Ενεργοποιεί την επεξεργασία του επιλεγμένου εξαρτήματος.

Delete
Διαγράφει το επιλεγμένο εξάρτημα.

New…​

Το επιλεγμένο εξάρτημα μπορεί να μετατραπεί σε νέα παραγγελία, εργασία ή συγκρότημα.

Export Outputs

Εξάγει το αποτέλεσμα του εξαρτήματος στον διαμορφωμένο προορισμό.

Re-import…​

Επιτρέπει την εκ νέου εισαγωγή του επιλεγμένου εξαρτήματος.

Re-tool…​

Επιτρέπει την επανεπεξεργασία του επιλεγμένου εξαρτήματος.

Rename…​

Για την αλλαγή του ονόματος του επιλεγμένου εξαρτήματος.

Assign Material…​

Καθορίζει το υλικό που σχετίζεται με το επιλεγμένο εξάρτημα.

Assign Customer…​

Καθορίζει τον πελάτη που σχετίζεται με το επιλεγμένο εξάρτημα.

Rolling direction

Καθορίζει τον προσανατολισμό κατά μήκος του οποίου ελαύνεται το υλικό. Οι διαθέσιμες επιλογές είναι None, Horizontal και Vertical.

Prev / Next / Toolings

Μεταβαίνει στο προηγούμενο ή επόμενο εξάρτημα ή εξοπλισμό.

Sort and filter

Χρησιμοποιήστε αυτά τα φίλτρα για να δείτε άλλα εξαρτήματα που μοιράζονται το ίδιο χαρακτηριστικό με το επιλεγμένο εξάρτημα: Same Material, Same Customer, Same Bend count, ή Same State.

Re-import

  • Κάντε δεξί κλικ σε οποιοδήποτε εξάρτημα και κάντε κλικ στο Re-import…​.

  • Όλες οι περιπτώσεις εξοπλισμού του επιλεγμένου εξαρτήματος σε όλες τις μηχανές διαγράφονται, συμπεριλαμβανομένων των αυτόματα και χειροκίνητα εξοπλισμένων περιπτώσεων.

  • Τα υπάρχοντα αρχεία εξόδου (CAD, Bend και Cut) αφαιρούνται.

  • Τα εξαρτήματα εισάγονται εκ νέου και εφαρμόζονται νέα επικύρωση CAD και εξοπλισμός για όλες τις μηχανές.

  • Νέα αρχεία εξόδου δημιουργούνται με βάση το ενημερωμένο αποτέλεσμα εξοπλισμού.

Re-tool

  • Κάντε δεξί κλικ σε οποιοδήποτε εξάρτημα και κάντε κλικ στο Re-tool…​.

  • Όλες οι μηχανές είναι επιλεγμένες από προεπιλογή και ομαδοποιούνται ως Laser, Punch, Panel και Press brake.

  • Κάντε κλικ στο OK για να συνεχίσετε. Αυτό αφαιρεί τόσο τις αυτόματα όσο και τις χειροκίνητα εξοπλισμένες περιπτώσεις για τις επιλεγμένες μηχανές και διαγράφει τα σχετικά αρχεία εξόδου.

  • Όταν είναι επιλεγμένο το πλαίσιο ελέγχου Retain existing outputs, μόνο τα εξαρτήματα των οποίων τα αποτελέσματα αφαιρέθηκαν νωρίτερα θα εξοπλιστούν εκ νέου, τα άλλα αποτελέσματα παραμένουν αμετάβλητα. Αν δεν είναι επιλεγμένο, όλα τα αρχεία εξόδου για τις επιλεγμένες μηχανές αφαιρούνται και αναδημιουργούνται κατά τον επανεξοπλισμό.

  • Αν οι ρυθμίσεις CAM άλλαξαν για οποιαδήποτε μηχανή, επιλέξτε αυτή τη μηχανή και εξοπλίστε εκ νέου τα εξαρτήματα.

  • Αν ένα εργαλείο (LTT, punch ή bend) αλλάξει ή λείπει, ενημερώστε τη μηχανή και εξοπλίστε εκ νέου μόνο τα επηρεαζόμενα εξαρτήματα.

Rename

Αυτή η ενότητα εξηγεί πώς να μετονομάσετε ένα ή πολλαπλά εξαρτήματα στο TruSmartCAM.

  • Κάντε δεξί κλικ στο εξάρτημα και κάντε κλικ στο Rename…​.

  • Εμφανίζεται ένα παράθυρο διαλόγου επιβεβαίωσης μετονομασίας που εμφανίζει το τρέχον όνομα εξαρτήματος.

  • Εισαγάγετε το νέο όνομα και κάντε κλικ στο εικονίδιο ελέγχου ✓ για επιβεβαίωση, ή κάντε κλικ στο εικονίδιο σταυρού ✗ για ακύρωση της λειτουργίας μετονομασίας.

  • Για να μετονομάσετε πολλαπλά εξαρτήματα, επιλέξτε όλα τα απαιτούμενα εξαρτήματα, στη συνέχεια κάντε δεξί κλικ σε οποιοδήποτε από αυτά και κάντε κλικ στο Rename…​.

  • Εμφανίζεται ένα παράθυρο διαλόγου επιβεβαίωσης με τον συνολικό αριθμό των επιλεγμένων εξαρτημάτων.

  • Για κάθε εξάρτημα, εισαγάγετε το νέο όνομα και κάντε κλικ στο εικονίδιο ελέγχου ✓ για επιβεβαίωση ένα προς ένα.

  • Αν κάποιο εξάρτημα επιλέχθηκε κατά λάθος, κάντε κλικ στο εικονίδιο σταυρού ✗ για ακύρωση. Εναλλακτικά, μπορείτε να κάνετε δεξί κλικ στο εξάρτημα και να κάνετε κλικ στο Cancel Rename για να παραλείψετε τη μετονομασία.

Export outputs

Αυτή η επιλογή εξάγει το αποτέλεσμα του εξαρτήματος στον προορισμό που έχει διαμορφωθεί στο Factory Settings. (Βλέπε Bend Settings και Cut Settings)

Η θέση εξόδου ορίζεται ξεχωριστά για Bend, Fold και Cut στις αντίστοιχες ρυθμίσεις εξόδου. Όλος ο εξοπλισμός που σχετίζεται με λειτουργίες bend, fold και cut εξάγεται για ολόκληρο το εξάρτημα.

Τα εξαγόμενα αρχεία εξαρτώνται από τον τύπο λειτουργίας. Για λειτουργίες Bend και Fold, δημιουργούνται αρχεία NC και αναφορές. Για λειτουργίες Cut και Punch, εξάγονται μόνο τα αρχεία εξαρτήματος.

Ανάθεση υλικού σε εξάρτημα

Τα εξαρτήματα με την κατάσταση Material not assigned πρέπει να ενημερωθούν πριν από περαιτέρω επεξεργασία. Τα παρακάτω βήματα εξηγούν πώς να αναθέσετε υλικό.

  • Κάντε δεξί κλικ στο εξάρτημα που εμφανίζει την κατάσταση Material not assigned και επιλέξτε Assign Material…​.

  • Ανοίγει το παράθυρο Assign Material.

  • Το παράθυρο διαλόγου έχει τέσσερις ενότητες:

    • Suggestions - Προτείνει αυτόματα πρώτες ύλες με βάση το πάχος του εισαγόμενου εξαρτήματος.

    • All Materials - Εμφανίζει όλους τους τύπους υλικού που ορίζονται στο TruSmartCAM.

    • All Raw-Materials - Εμφανίζει όλες τις πρώτες ύλες που είναι διαθέσιμες στο σύστημα.

    • Used Raw-Materials - Εμφανίζει τις πιο πρόσφατα χρησιμοποιημένες πρώτες ύλες για γρήγορη πρόσβαση.

  • Μπορείτε να χρησιμοποιήσετε το πεδίο Search στο επάνω μέρος για να βρείτε γρήγορα υλικά. Για παράδειγμα, πληκτρολογήστε "steel" για να εμφανίσετε όλα τα αντίστοιχα υλικά σε όλες τις τρεις ενότητες.

  • Από τη φιλτραρισμένη λίστα, επιλέξτε το απαιτούμενο υλικό (π.χ. Steel-25) από τη λίστα Πρώτης Ύλης.

  • Το επιλεγμένο υλικό θα ανατεθεί στο εξάρτημα.

Rolling direction

Η Rolling direction αναφέρεται στον προσανατολισμό της κόκκωσης σε ένα εξάρτημα, ο οποίος μπορεί να επηρεάσει τον τρόπο κοπής και επεξεργασίας του εξαρτήματος. Αυτή η επιλογή σας επιτρέπει να καθορίσετε την Rolling direction για ένα εξάρτημα στη Βιβλιοθήκη Εξαρτημάτων. Με βάση την επιλεγμένη κατεύθυνση, το εξάρτημα θα τοποθετηθεί στον σωστό προσανατολισμό για κοπή στις διαθέσιμες μηχανές.

  • Κάντε δεξί κλικ σε οποιοδήποτε πλακίδιο εξαρτήματος στη Βιβλιοθήκη Εξαρτημάτων ή στο παράθυρο Εργασίας.

  • Επιλέξτε την προτιμώμενη κατεύθυνση κύλισης:

    • None

    • Horizontal

    • Vertical

  • Το εξάρτημα εξοπλίζεται εκ νέου αυτόματα για όλες τις διαθέσιμες μηχανές κοπής με βάση την επιλεγμένη κατεύθυνση κύλισης.

  • Το πλακίδιο εξαρτήματος θα εμφανίσει την επιλεγμένη κατεύθυνση κύλισης όπως φαίνεται παρακάτω:
