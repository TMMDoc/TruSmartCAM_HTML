Πίνακας εξοπλισμού

Αυτή η ενότητα εξηγεί ενέργειες που σχετίζονται με τον εξοπλισμό, όπως Export outputs, Check Tooling, Suppress Tooling, Set as Base-Flat…​, Copy Tooling, και άλλες επιλογές που χρησιμοποιούνται για τη διαχείριση περιπτώσεων εξοπλισμού.

Open in read-only mode for viewing
Ανοίγει τον επιλεγμένο εξοπλισμό σε λειτουργία μόνο για ανάγνωση.

Check-out the document for editing
Ενεργοποιεί την επεξεργασία του επιλεγμένου εξοπλισμού.

Export Outputs

Εξάγει το αποτέλεσμα του επιλεγμένου εξοπλισμού στον διαμορφωμένο προορισμό.

Check Tooling

Επικυρώνει τον υπάρχοντα εξοπλισμό χωρίς να κάνει αλλαγές και ενημερώνει την κατάστασή του αν η επικύρωση αποτύχει.

Copy Tooling…​

Αντιγράφει τη διάταξη εμβόλου, ακολουθίας και οπίσθιου οδηγού από τον επιλεγμένο εξοπλισμό αναφοράς και την εφαρμόζει σε άλλες λύσεις όπου είναι εφικτό.

Set as Base-Flat…​

Σημειώνει τον επιλεγμένο εξοπλισμό κάμψης ή δίπλωσης ως το μέγεθος επίπεδης αναφοράς για τη δημιουργία λύσεων κοπής.

Re-tool…​

Επανεπεξεργάζεται τον επιλεγμένο εξοπλισμό για το εξάρτημα χωρίς να επηρεάζει άλλους εξοπλισμούς.

Suppress Tooling

Καταστέλλει τον επιλεγμένο εξοπλισμό ώστε να εξαιρείται από περαιτέρω επεξεργασία και δημιουργία εξόδου.

Prev / Next / Part

Μεταβαίνει στον προηγούμενο ή επόμενο εξοπλισμό, ή πίσω στο γονικό εξάρτημα.

Sort and filter

Εμφανίζει άλλους εξοπλισμούς που μοιράζονται παρόμοια χαρακτηριστικά με τον επιλεγμένο εξοπλισμό για γρήγορη αναφορά.

Export Outputs

Αυτή η επιλογή εξάγει το αποτέλεσμα του εξαρτήματος στον προορισμό που έχει διαμορφωθεί στο Factory Settings. (Βλέπε Bend Settings και Cut Settings)

Εξάγεται μόνο ο εξοπλισμός που σχετίζεται με την επιλεγμένη λειτουργία εξοπλισμού, όχι ολόκληρο το εξάρτημα.

Τα εξαγόμενα αρχεία εξαρτώνται από τον τύπο λειτουργίας. Για λειτουργίες Bend και Fold, δημιουργούνται αρχεία NC και αναφορές. Για λειτουργίες Cut και Punch, εξάγονται μόνο τα αρχεία εξαρτήματος.

Check Tooling

  • Αν υπάρχει αλλαγή στις ρυθμίσεις CAM ή χαθεί ένα εργαλείο κάμψης, δεν χρειάζεται να εξοπλίσετε εκ νέου το εξάρτημα.

  • Αντ' αυτού, χρησιμοποιήστε το Check Tooling για να επικυρώσετε τον υπάρχοντα εξοπλισμό χωρίς να κάνετε οποιεσδήποτε αλλαγές.

  • Αν η επικύρωση αποτύχει, η κατάσταση εξοπλισμού αυτής της περίπτωσης ενημερώνεται και τα σχετικά αρχεία εξόδου αφαιρούνται.

  • Το Check Tooling εντοπίζει επίσης εξαρτήματα όπου τα σφάλματα είχαν προηγουμένως παρακαμφθεί χειροκίνητα χρησιμοποιώντας το Ignore Errors και ενημερώνει την κατάστασή τους σε σφάλμα αν χρειάζεται.

Copy tooling

Το copy tooling σας επιτρέπει να εφαρμόζετε γρήγορα εξοπλισμό κάμψης από μία λύση σε άλλες, εξοικονομώντας χρόνο και προσπάθεια.

Αυτό αντιγράφει τη διάταξη εμβόλου, ακολουθίας και οπίσθιου οδηγού από έναν επιλεγμένο εξοπλισμό αναφοράς (λύση) και προσπαθεί να εφαρμόσει τις ίδιες ρυθμίσεις σε όλες τις άλλες λύσεις.

  • Αν η αντιγραμμένη διάταξη είναι εφικτή για μια μηχανή-στόχο, αποθηκεύεται και χρησιμοποιείται.

  • Αν η διάταξη δεν είναι εφικτή, ο αρχικός εξοπλισμός για αυτή τη μηχανή παραμένει αμετάβλητος.

Για παράδειγμα, μπορεί να έχετε διαφορετικό εξοπλισμό για διαφορετικές μηχανές:

  • Εδώ, η Μηχανή 5230X 4A χρησιμοποιεί έμβολο Gooseneck, η Μηχανή 5230SX 6A χρησιμοποιεί έμβολο Pointed.

Όταν χρησιμοποιείτε το Copy Tooling…​ στη Μηχανή 5230X 4A, προσπαθεί να αντιγράψει τη διάταξη Gooseneck σε όλες τις άλλες μηχανές.

Οι ίδιες ρυθμίσεις εμβόλου, ακολουθίας και οπίσθιου οδηγού εφαρμόζονται όπου είναι δυνατόν. Αν η αντιγραμμένη διάταξη δεν μπορεί να χρησιμοποιηθεί, ο αρχικός εξοπλισμός παραμένει αμετάβλητος.

Μετά την εφαρμογή του copy tooling, η διάταξη Gooseneck έχει εφαρμοστεί επιτυχώς σε όλες τις άλλες μηχανές όπου είναι εφικτό.

Set as Base-Flat…​

Η λειτουργία Set as Base-Flat…​ καθορίζει ποιος εξοπλισμός κάμψης ή δίπλωσης χρησιμοποιείται ως το μέγεθος επίπεδης αναφοράς για τη δημιουργία λύσεων κοπής. Όταν ένας εξοπλισμός σημειώνεται ως Base-Flat, το TruSmartCAM ενημερώνει το επίπεδο μέγεθος του εξαρτήματος με βάση αυτή τη μηχανή και αναδημιουργεί τις λύσεις κοπής ανάλογα. Οι εξοπλισμοί Base-Flat εμφανίζονται με μπλε περίγραμμα στο περιβάλλον χρήστη.

Διαφορετικές μηχανές κάμψης μπορεί να παράγουν ελαφρές διακυμάνσεις στο επίπεδο μέγεθος για το ίδιο εξάρτημα. Όταν ορίζετε έναν εξοπλισμό ως Base-Flat, το TruSmartCAM χρησιμοποιεί το επίπεδο μέγεθος αυτής της μηχανής ως την κύρια αναφορά και υπολογίζει αυτόματα εκ νέου τις λύσεις κοπής.

Εδώ, μπορούμε να δούμε διαφορετικά επίπεδα μεγέθη για το ίδιο εξάρτημα σε διάφορες μηχανές:

Σε αυτό το παράδειγμα, ο εξοπλισμός 5230X 4A ορίζεται ως Base-Flat και το ενημερωμένο επίπεδο μέγεθος εφαρμόζεται στις ιδιότητες του εξαρτήματος:

Αυτόματη επιλογή base flat

Όταν είναι ενεργοποιημένη η εργοστασιακή ρύθμιση Apply flat correction during bending:

  • Το TruSmartCAM ορίζει αυτόματα τον εξοπλισμό κάμψης (που περιέχει τον πίνακα μέγιστου μήκους κάμψης) ως Base-Flat κατά την εισαγωγή του εξαρτήματος.

  • Αν ο επιλεγμένος εξοπλισμός κάμψης παρουσιάσει σφάλμα ή δεν είναι εφικτός, το TruSmartCAM μεταβαίνει έξυπνα και ορίζει έναν άλλο έγκυρο εξοπλισμό κάμψης ως Base-Flat. Αυτό διασφαλίζει ότι η αναφορά επίπεδου μεγέθους και οι λύσεις κοπής παραμένουν πάντα συνεπείς και έγκυρες χωρίς χειροκίνητη παρέμβαση.

Βελτιωμένη διαχείριση base flat

Το TruSmartCAM παρέχει επιλογές Base-Flat στο παράθυρο διαλόγου Save to Praxis κατά την αποθήκευση επεξεργασιών εξοπλισμού κάμψης ή δίπλωσης. Αυτές οι επιλογές εμφανίζονται μόνο για εξοπλισμούς σε κατάσταση OK και διασφαλίζουν ότι το επίπεδο μέγεθος και οι λύσεις κοπής παραμένουν ακριβή.

Set as Base-Flat and calculate cutting solution

Αυτή η επιλογή χρησιμοποιείται για να σημειώσετε έναν εξοπλισμό ως Base-Flat για πρώτη φορά και να δημιουργήσετε αυτόματα την αντίστοιχη λύση κοπής.

Εμφανίζεται όταν:

  • Ο εξοπλισμός δεν έχει επί του παρόντος σημειωθεί ως Base-Flat.

  • Ο χρήστης έχει κάνει checkout τον εξοπλισμό για επεξεργασία και αποθηκεύει τις αλλαγές.

Για να χρησιμοποιήσετε αυτή την επιλογή, κάντε checkout τον εξοπλισμό κάμψης ή δίπλωσης και κάντε τις απαιτούμενες τροποποιήσεις, όπως αλλαγές στις παραμέτρους κάμψης ή στο επίπεδο μέγεθος. Πατήστε Ctrl+S για να αποθηκεύσετε τις αλλαγές. Στο παράθυρο διαλόγου Save to Praxis, επιλέξτε Set as Base-Flat and calculate cutting solution και κάντε κλικ στο OK. Το TruSmartCAM θα ορίσει τον εξοπλισμό ως Base-Flat και θα δημιουργήσει τη λύση κοπής χρησιμοποιώντας το ενημερωμένο επίπεδο μέγεθος.

Update the base-flat and re-calculate cutting solution

Αυτή η επιλογή χρησιμοποιείται όταν ο εξοπλισμός έχει ήδη σημειωθεί ως Base-Flat και έχει επεξεργαστεί, απαιτώντας την αναδημιουργία του επίπεδου μεγέθους και των λύσεων κοπής.

Εμφανίζεται όταν:

  • Ο εξοπλισμός έχει ήδη σημειωθεί ως Base-Flat.

  • Ο χρήστης τον έχει κάνει checkout, επεξεργαστεί και αποθηκεύει τις αλλαγές.

Κατά την επεξεργασία του υπάρχοντος εξοπλισμού Base-Flat, ενημερώστε τις παραμέτρους κάμψης ή τη γεωμετρία επίπεδου μεγέθους όπως χρειάζεται. Στο παράθυρο διαλόγου Save to Praxis, επιλέξτε Update the base-flat and re-calculate cutting solution. Το TruSmartCAM θα ενημερώσει τότε τον εξοπλισμό Base-Flat και θα αναδημιουργήσει όλες τις σχετικές λύσεις κοπής ώστε να αντικατοπτρίζουν τις πιο πρόσφατες αλλαγές.

Μόνο ένας εξοπλισμός κάμψης μπορεί να οριστεί ως Base-Flat κάθε φορά.

Όταν αλλάζει το Base-Flat, οι υπάρχουσες λύσεις κοπής επανεπεξεργάζονται αυτόματα.

Αυτή η λειτουργία είναι διαθέσιμη τόσο για εξοπλισμούς κάμψης όσο και δίπλωσης εντός του TruSmartCAM.

Re-tool

Αυτή η επιλογή επανεπεξεργάζεται τον επιλεγμένο εξοπλισμό για το εξάρτημα.

Κάντε δεξί κλικ στον απαιτούμενο εξοπλισμό στον Πίνακα εξοπλισμού και κάντε κλικ στο Re-tool…​

Εμφανίζεται ένα παράθυρο διαλόγου επιβεβαίωσης πριν προχωρήσετε.

Κάντε κλικ στο Yes για να συνεχίσετε με τον επανεξοπλισμό, ή στο No για ακύρωση της λειτουργίας.

Μόνο ο επιλεγμένος εξοπλισμός εξοπλίζεται εκ νέου. Άλλοι εξοπλισμοί που σχετίζονται με το εξάρτημα δεν επηρεάζονται. Τα υπάρχοντα αποτελέσματα που σχετίζονται με τον επιλεγμένο εξοπλισμό αφαιρούνται και αναδημιουργούνται κατά τη διαδικασία επανεξοπλισμού.

Χρησιμοποιήστε αυτή την επιλογή όταν τα δεδομένα εξοπλισμού είναι παρωχημένα, εσφαλμένα ή όταν γίνονται αλλαγές στις διαμορφώσεις μηχανής ή εξοπλισμού.

Ignore errors

  • Αν μια εξοπλισμένη περίπτωση εμφανίζει προειδοποίηση και θέλετε παρόλα αυτά να προχωρήσετε με αυτήν, μπορείτε να παρακάμψετε την προειδοποίηση κάνοντας κλικ στο Ignore errors.

  • Αυτό θα επιτρέψει στο σύστημα να εξάγει αρχεία εξόδου για αυτή την περίπτωση, ακόμα και αν υπήρχαν ζητήματα εξοπλισμού.

Χρησιμοποιήστε το Ignore Errors μόνο όταν είστε βέβαιοι ότι η προειδοποίηση μπορεί να αγνοηθεί με ασφάλεια. Η παράκαμψη πραγματικών σφαλμάτων μπορεί να οδηγήσει σε ζημιά μηχανής ή κινδύνους ασφαλείας.

Καταστολή/Άρση καταστολής εξοπλισμού

  • Όταν μια μηχανή είναι ανενεργή ή δεν θέλετε ένα συγκεκριμένο εξάρτημα να επεξεργαστεί από μια συγκεκριμένη μηχανή, χρησιμοποιήστε το Suppress Tooling για να εξαιρέσετε αυτό το εξάρτημα από την κατανομή σε αυτή τη μηχανή.

  • Μετά την καταστολή, τοποθετώντας το ποντίκι πάνω από την εξοπλισμένη περίπτωση εμφανίζεται ένα μήνυμα όπως: "Tooling suppressed by <User name> on <Date Time>".

  • Η καταστολή εξοπλισμού αφαιρεί το αρχείο εξόδου για αυτή τη μηχανή και το εξάρτημα.

  • Χρησιμοποιήστε το Unsuppress tooling για να επαναφέρετε την κατάσταση εξοπλισμού για το εξάρτημα σε αυτή τη μηχανή.

  • Όταν αρθεί η καταστολή, το αντίστοιχο αρχείο εξόδου δημιουργείται ξανά.
