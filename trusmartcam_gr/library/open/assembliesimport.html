Εισαγωγή συγκροτημάτων

Τα συγκροτήματα είναι ομάδες συναφών εξαρτημάτων συνδυασμένων σε μία ενιαία μονάδα, επιτρέποντάς σας να διαχειρίζεστε πολλαπλά εξαρτήματα μαζί ως μία οντότητα.

Μπορείτε να εισάγετε συγκροτήματα με τις ακόλουθες μεθόδους:

  1. Εισαγωγή μέσω αρχείου

  2. Μεταφορά και απόθεση

  3. Εισαγωγή από υπολογιστικό φύλλο

Εισαγωγή μέσω αρχείου

Ένα συγκρότημα μπορεί να εισαχθεί στη Βιβλιοθήκη Εξαρτημάτων χρησιμοποιώντας την επιλογή Import Assemblies…​.

  • Κάντε κλικ στο εικονίδιο Open στη γραμμή εντολών και επιλέξτε Import Assemblies…​, ή χρησιμοποιήστε File → Open → Import Assemblies…​.

  • Εμφανίζεται το παράθυρο διαλόγου Open. Επιλέξτε το(α) απαιτούμενο(α) αρχείο(α) συγκροτήματος.

  • Εμφανίζεται μια προεπισκόπηση του επιλεγμένου συγκροτήματος.

  • Κάντε κλικ στο Open για να εισαγάγετε το συγκρότημα.

  • Τα εισαγόμενα συγκροτήματα εμφανίζονται στην προβολή Συγκροτημάτων στη Βιβλιοθήκη Εξαρτημάτων.

Μεταφορά και απόθεση

  • Μεταφέρετε και αποθέστε ένα συγκρότημα απευθείας στη Βιβλιοθήκη Εξαρτημάτων του TruSmartCAM.

Εισαγωγή από υπολογιστικό φύλλο

  • Χρησιμοποιήστε File → Open → Import Assemblies…​ και επιλέξτε ένα αρχείο CSV, XLSX ή XML, ή μεταφέρετε και αποθέστε το αρχείο.

  • Ελέγξτε και ενημερώστε τα στοιχεία και τις ποσότητες του συγκροτήματος πριν από την εισαγωγή. Χρησιμοποιήστε Add…​ ή Remove…​ για τροποποίηση.

  • Μετά την εισαγωγή, τα συγκροτήματα μπορούν να προετοιμαστούν και να τους ανατεθούν Στατικές Κατανομές.
