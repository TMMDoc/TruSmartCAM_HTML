Bewaken

Met de bewakingsinstellingen kan TruSmartCAM een aangewezen map bewaken en automatisch bestanden in het systeem importeren. Dit helpt het importeren van onderdelen, jobs, samenstellingen en orders te automatiseren zonder handmatige tussenkomst.

Watch settings

Enable 'Live Folder' - Schakelt automatische bewaking van de opgegeven map in.

Watch this folder - Geeft de map op die moet worden bewaakt op binnenkomende bestanden.

Watch sub-folders also - Neemt alle submappen op in het bewakingsproces.

After file import

After import - Nadat het bestand is geïmporteerd, heeft de gebruiker twee opties. Het bestand kan worden verwijderd van de locatie of worden verplaatst naar een andere locatie.

  • Delete imported file - Verwijdert het bronbestand na een succesvolle import.

  • Move imported file - Verplaatst het bronbestand naar de map die is opgegeven in Move files to this folder na een succesvolle import.

Move files to this folder - Geeft de doelmap op waar succesvol geïmporteerde bestanden naartoe moeten worden verplaatst wanneer After import is ingesteld op Move imported file.

Move spreadsheets with errors to this folder - Verplaatst mislukte imports naar de opgegeven foutmap.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Importeert automatisch spreadsheetbestanden die in de bewakingsmap worden gedetecteerd.

Do not import spreadsheet with errors - Voorkomt dat bestanden met validatiefouten worden geïmporteerd.

Spreadsheet import option - Selecteert het type te importeren gegevens uit het vervolgkeuzemenu. Ondersteunde spreadsheetindelingen kunnen CSV, XLSX of XML zijn. De beschikbare opties zijn:

  • Import Jobs - Importeert jobgegevens uit de spreadsheet.

  • Import Orders - Importeert ordergegevens uit de spreadsheet.

  • Import Assemblies - Importeert samenstellingsgegevens uit de spreadsheet.

  • Import Parts - Importeert onderdeelgegevens uit de spreadsheet.

Aanvullende informatie

  • Gebruik een UNC-pad (\\ServerName\FolderPath) of een toegewezen station (M:\FolderPath) bij het configureren van de bewakingsmap. Gebruik geen lokale paden zoals C:\FolderPath.

  • De computer waarop de TruSmartCAM Engine-service draait, moet lees- en schrijftoegang hebben tot de geconfigureerde bewakingsmap. Zonder voldoende rechten worden bestanden mogelijk niet gedetecteerd, geïmporteerd, verplaatst of succesvol verwijderd.

  • De spreadsheettoewijzing moet worden geconfigureerd voordat de bewakingsinstellingen worden ingeschakeld. Anders kan TruSmartCAM de spreadsheetbestanden die in de bewakingsmap worden gedetecteerd, niet verwerken.
