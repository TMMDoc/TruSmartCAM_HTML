Rapporter

Rapporter

Report settings

Report destination - Använd detta alternativ för att ange platsen där rapporterna ska sparas.

Report Output Format - Anger formatet för rapporten vid export (PDF eller HTML).

Job report settings

Include layout images in the report - Aktivera denna inställning för att inkludera bilder av layouterna i en rapport.

Include part images in the report - Aktivera denna inställning för att inkludera bilder av detaljerna i en rapport.

Include layout reports in the job report - Aktivera denna inställning för att länka till layoutrapporterna i en jobrapport.

Label report settings

Enable label reports - Aktivera denna inställning för att tillåta generering av etiketter antingen från jobbet eller en layout, där högerklick och val av Export Layouts respektive Send to Machine visar ett alternativ för att visa etikettrapporten.

Label size (W x H) - Anger etikettens bredd och höjd i millimeter. Dessa värden definierar de fysiska måtten för den genererade etiketten.

QR code field - Definierar det datafält som ska kodas in i QR-koden på etiketten. Rullgardinslistan inkluderar Part Name, Part Order och None. Det valda fältvärdet visas som en QR-kod.

Barcode field - Definierar det datafält som ska kodas in i streckkoden på etiketten. Rullgardinslistan inkluderar Part Name, Part Order och None. Det valda fältvärdet visas som en streckkod.

Show part image - När detta är aktiverat inkluderas detaljbilden i den genererade etikettrapporten.
