Bevaka

Inställningar för bevakning gör det möjligt för TruSmartCAM att övervaka en angiven mapp och automatiskt importera filer till systemet. Detta hjälper till att automatisera importen av detaljer, job, sammanställningar och order utan manuellt ingripande.

Watch settings

Enable 'Live Folder' - Aktiverar automatisk övervakning av den angivna mappen.

Watch this folder - Anger vilken mapp som ska övervakas för inkommande filer.

Watch sub-folders also - Inkluderar alla undermappar i övervakningsprocessen.

After file import

After import - Efter att filen har importerats har användaren två alternativ. Filen kan raderas från platsen eller flyttas till en annan plats.

  • Delete imported file - Tar bort källfilen efter en lyckad import.

  • Move imported file - Flyttar källfilen till den mapp som anges i Move files to this folder efter en lyckad import.

Move files to this folder - Anger destinationsmappen där filer som importerats framgångsrikt ska flyttas när After import är inställt på Move imported file.

Move spreadsheets with errors to this folder - Flyttar misslyckade importer till den angivna felmappen.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Importerar automatiskt kalkylbladsfiler som upptäcks i den bevakade mappen.

Do not import spreadsheet with errors - Förhindrar att filer som innehåller valideringsfel importeras.

Spreadsheet import option - Väljer vilken typ av data som ska importeras från rullgardinsmenyn. Stödda kalkylbladsformat kan inkludera CSV, XLSX eller XML. De tillgängliga alternativen är:

  • Import Jobs - Importerar jobdata från kalkylbladet.

  • Import Orders - Importerar orderdata från kalkylbladet.

  • Import Assemblies - Importerar sammanställningsdata från kalkylbladet.

  • Import Parts - Importerar detaljdata från kalkylbladet.

Ytterligare information

  • Använd en UNC-sökväg (\\ServerName\FolderPath) eller en mappad enhet (M:\FolderPath) när du konfigurerar den bevakade mappen. Använd inte lokala sökvägar som C:\FolderPath.

  • Datorn som kör TruSmartCAM Engine-tjänsten måste ha läs- och skrivbehörighet till den konfigurerade bevakade mappen. Utan tillräckliga behörigheter kanske filer inte upptäcks, importeras, flyttas eller raderas korrekt.

  • Kalkylbladsmappning måste konfigureras innan inställningarna för bevakning aktiveras. Annars kommer TruSmartCAM inte att kunna behandla kalkylbladsfiler som upptäcks i den bevakade mappen.
