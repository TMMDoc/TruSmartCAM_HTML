Aviseringar

Aviseringar informerar användare om CAD- och tooling-fel som uppstår i systemet. De säkerställer att problem kommuniceras omgående så att lämpliga åtgärder kan vidtas.

E-postavisering

Funktionen för e-postavisering låter användare konfigurera och ta emot automatiserade e-postvarningar för CAD- och tooling-fel. När den är konfigurerad skickar systemet automatiskt e-post till de angivna mottagarna närhelst en relevant händelse inträffar, vilket säkerställer att problem åtgärdas omgående.

För att konfigurera e-postaviseringar, navigera till: factory > settings > Notifications

Sidan Notifications består av följande avsnitt:

Aviseringsinställningar

Avsnittet Notification settings styr hur e-postvarningar genereras och levereras till mottagare.

  • Enable email notifications - Ger systemet möjlighet att skicka aviseringar baserat på de konfigurerade villkoren.

  • Notification recipients - Anger mottagarnas e-postadress(er). Flera mottagare kan läggas till genom att separera dem med ett kommatecken (,) eller ett mellanslag.

  • Send messages in batch - Kombinerar flera aviseringar i ett enda e-postmeddelande. Meddelanden som genereras inom ett definierat tidsintervall grupperas tillsammans, vilket hjälper till att minska e-postvolymen och förhindra en rörig inkorg.

  • Attach tooling simulation preview where applicable - Bifogar en förhandsvisning av tooling-simuleringen till aviserings-e-posten när den är tillgänglig. Detta är användbart för att granska tooling-relaterade problem direkt från e-posten.

Att inkludera förhandsvisningen av simuleringen kan öka e-postens storlek avsevärt.

Mail settings

Avsnittet Mail settings definierar konfigurationen för den utgående e-postservern som systemet använder för att leverera e-postaviseringar. Dessa inställningar måste konfigureras korrekt för att aviseringar ska kunna skickas.

  • SMTP server - Anger SMTP-serveradressen som används för att skicka utgående e-post (till exempel smtp.gmail.com). Denna information finns vanligtvis i kontot eller inställningsavsnittet i användarens e-postklient.

  • SMTP port - Definierar portnumret som e-postservern använder för att skicka e-post över internet. Vanliga värden inkluderar 465 (SSL) och 587 (TLS).

  • Transport protocol - Anger protokollet som används för att skicka e-post säkert från applikationen till e-postservern (till exempel SSL eller TLS).

  • Server needs authentication - Aktiverar autentisering för SMTP-servern. När det är aktiverat valideras användarnamnet och lösenordet av servern innan e-post skickas.

  • User-name - Anger e-postkontot som används för att autentisera mot SMTP-servern och skicka aviseringar.

  • Password - Anger lösenordet som är kopplat till det e-postkonto som används för autentisering.

  • Sender address - Anger avsändarens e-postadress som visas för mottagarna när aviseringar tas emot.

  • Test…​ - Skickar ett test-e-postmeddelande för att verifiera konfigurationen av e-postservern.

Klicka på Test…​ för att validera inställningen. Ett bekräftelsemeddelande visas om testet lyckas; annars visas ett felmeddelande som anger orsaken till felet.

  • E-postaviseringar utlöses inte i interaktivt läge (till exempel när du redigerar eller manuellt sparar en detalj).

  • E-postleverans hanteras i bakgrunden och kan försenas.

  • Aviseringar kanske inte levereras om systemet eller Engine stoppas innan behandlingen är slutförd.
