Import

Import

Output settings

Save flat pattern - Aktivera detta alternativ för att spara den utbredda geometrin för en importerad detalj.

Format for flat pattern - Detta alternativ används för att välja antingen DXF- eller GEO-filformat.

Flat pattern destination - Detta är platsen där den utbredda geometrin sparas.

Import settings

Units for DXF files - Detta är måttenheten som en DXF-fil importeras med. Användaren kan välja mellan mm eller tum.

Material lookup keys - Flera uppslagningsposter kan tilldelas genom att använda ett kommatecken som avgränsare mellan dem. När en detalj importeras använder TruSmartCAM dessa nycklar för att söka efter materialvärden. De uppslagna värdena används sedan för att fastställa råmaterialet. Originalvärdena lagras i detaljens övriga egenskaper (Misc Properties).

Revision lookup keys - När en detalj importeras jämförs revisionsvärdet från den ursprungliga detaljfilen (den detaljfil som importeras) med det befintliga revisionsvärdet i förvaret. Importen avbryts om revisionen är densamma. Anpassad fältmappning stöds nu också för DXF-filer. För DXF-filer extraheras data för anpassade fält från textlagret i ritningen eller från en PPI-bilaga.

Use geometry comparison on same CAD revision - Jämför geometrin vid import av en detalj med samma CAD-revision och uppmanar användaren att ersätta eller hoppa över importen om skillnader upptäcks. Se Import configuration för mer information.

Part name keys - Detta alternativ fungerar på liknande sätt som Revision lookup keys för material. Ange en eller flera Part name keys för att använda PPI Part name istället för filnamnet som detaljnamn.

Thickness lookup keys - Flera uppslagningsposter kan tilldelas genom att använda ett kommatecken som avgränsare mellan dem. När en detalj importeras använder TruSmartCAM dessa nycklar för att söka efter tjockleksvärden. De uppslagna värdena används sedan för att fastställa tjockleken. Originalvärdena lagras i detaljens övriga egenskaper (Misc Properties).

Thickness comparison fudge - Detta används vid uppslagning av råmaterialet när en detalj importeras. TruSmartCAM försöker fastställa råmaterialet efter att materialnamnet och tjockleken har tolkats. För mer information, se avsnittet Thickness fudge nedan.

Identify shapes after a flat is imported - När en detalj importeras kan inre former i detaljen automatiskt kännas igen och identifieras.

Shape identification fudge - Toleransvärdet för formidentifiering kan ställas in på:

  1. Global level - Detta värde används som standard för alla former.

  2. Individual Shape Level - Standardvärdet kan åsidosättas genom att ange toleransvärdet på den enskilda formnivån. När formen väljs i dialogrutan Shape Library visas toleransvärdet. Som standard är detta inställt på 0, och standardvärdet för hela systemet används för sådana former.

Rotate flat horizontally - I allmänhet är skärmaskinens bord rektangulära och bredare. För att förbättra tooling-genomförbarheten roteras detaljen längs detaljens bredd efter att detaljen har importerats.

Part rotation threshold - Ange detta som det lägsta antal som tillåter rotation. Detaljer som är mindre än det inställda värdet roteras inte.

Misc settings

Enable pre-import external tools - Aktivera importalternativet för externa verktyg före import för att aktivera Creo Reader. TruSmartCAM laddar upp de förextraherade familjeinstanserna av den släppta detaljen. Observera att instansextraheringen utförs under uppladdningen av detaljen (som en åtgärd före import), så Creo-programvaran måste vara installerad på den dator varifrån detaljen laddas upp.

Ignore drawing colors in Flat thumbnails for clarity - Aktivera detta alternativ för att generera skarpare miniatyrbilder i gråskala. Lagerfärgerna och textentiteterna ignoreras för bildens tydlighets skull.

Use only one Engine for all import tasks - När detta är aktiverat används endast en Engine-kärna för importuppgifter.

Thickness fudge

Inställningen Thickness comparison fudge väljer det närmaste plåttjockleksvärdet när en önskad plåttjocklek inte finns tillgänglig i lagret, genom att jämföra tjockleksvärdet för plåtar i lagret.

Låt oss till exempel anta följande:

  1. Vi har en detalj med plåttjocklek 1,6 mm och material stål.

  2. Värdet för Thickness comparison fudge är 0,1 mm.

  3. Lagret har stålplåtar med tjocklekarna 1,5 mm, 1,55 mm och 1,7 mm.

TruSmartCAM väljer en plåt med det närmaste tjockleksvärdet efter att ha jämfört värdet för Thickness comparison fudge (0,1 mm) med den importerade posten (som mäter 1,6 mm). I detta fall blir 1,55 mm valet.
