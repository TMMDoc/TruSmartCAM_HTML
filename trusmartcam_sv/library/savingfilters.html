Spara filter

Sparade filter gör att du kan återanvända kriterier som ofta tillämpas i Parts, Jobs och Layouts, vilket effektiviserar ditt arbetsflöde. Varje modul levereras med standardfilter, men ytterligare filterlistor kan skapas av Site Admins eller Programmers vid behov. Att återanvända sparade filter sparar tid och bidrar till att behålla konsekvens mellan sökningar.

  • Klicka på ikonen för att visa standardfiltren.

Steg för att spara filter

  • Klicka på ikonen , välj valfritt filterobjekt.

  • Från rullgardinsmenyn för det valda filterobjektet väljer du ett alternativ. En bockmarkering visas bredvid det valda villkoret.

  • För att tillämpa villkoret klickar du på ikonen och väljer sedan Add Condition Ctrl++. Du kan upprepa detta steg för att lägga till flera villkor.

  • För att spara dessa valda filter med villkor klickar du på Save Filter…​ Ctrl+S.

  • Ange namnet och klicka sedan på Save.

  • I dialogrutan Save Filter kan du även ta bort tidigare sparade filter.

  • Dessa filter sparas i standardfilterlistan. Här sparas Material till standardlistan.

Filter som skapats av SiteAdmin och Admin delas mellan alla användare. Filter som skapats av Programmer och Operator delas endast mellan användarrollerna Programmer och Operator.

Filterkommandon

Kommando Ikon Genvägar Beskrivning

Clear Selection

Ctrl+X

Avmarkerar alla valda alternativ och uppdaterar vyn med filterobjekt.

Select Highlighted

Ctrl+A

Väljer alla markerade alternativ. Detta kommando förblir inaktiverat om markering av objekt inte är tillämpligt för det valda fältet.

Match All

&

Visar endast objekt som uppfyller alla valda villkor.

Pin In/Out Menu

Ctrl+Down/Up

När den är fäst förblir rullgardinsmenyn öppen även när fokus flyttas till ett annat fönster.

Close Menu

Esc

Stänger rullgardinsmenyn.
