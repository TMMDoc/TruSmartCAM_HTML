Detaljpanel

Detta avsnitt beskriver detaljrelaterade åtgärder såsom Re-import, Re-tool, Rename, Export outputs, etc., som används för att hantera detaljinstanser.

Open in read-only mode for viewing
Öppnar den valda detaljen i skrivskyddat läge.

Check-out the document for editing
Aktiverar redigering av den valda detaljen.

Delete
Raderar den valda detaljen.

New…​

Den valda detaljen kan konverteras till en ny order, job eller sammanställning.

Export Outputs

Exporterar detaljutdatan till den konfigurerade destinationen.

Re-import…​

Gör det möjligt att importera den valda detaljen igen.

Re-tool…​

Gör det möjligt att bearbeta den valda detaljen på nytt.

Rename…​

För att ändra namnet på den valda detaljen.

Assign Material…​

Anger materialet som är associerat med den valda detaljen.

Assign Customer…​

Anger kunden som är associerad med den valda detaljen.

Rolling direction

Definierar orienteringen längs vilken materialet valsas. De tillgängliga alternativen är None, Horizontal och Vertical.

Prev / Next / Toolings

Navigerar till föregående eller nästa detalj eller tooling.

Sort and filter

Använd dessa filter för att visa andra detaljer som delar samma attribut som den valda detaljen: Same Material, Same Customer, Same Bend count eller Same State.

Re-import

  • Högerklicka på valfri detalj och klicka på Re-import…​.

  • Alla valda detaljens tooling-instanser på alla maskiner rensas, inklusive automatiskt toolade och manuellt toolade instanser.

  • Befintliga utdatafiler (CAD, Bend och Cut) tas bort.

  • Detaljerna importeras på nytt, och ny CAD-validering och tooling tillämpas för alla maskiner.

  • Nya utdatafiler skapas baserat på det uppdaterade tooling-resultatet.

Re-tool

  • Högerklicka på valfri detalj och klicka på Re-tool…​.

  • Alla maskiner är markerade som standard och grupperade som Laser, Punch, Panel och Press brake.

  • Klicka på OK för att fortsätta. Detta tar bort både automatiskt toolade och manuellt toolade instanser för de valda maskinerna, och raderar relaterade utdatafiler.

  • När kryssrutan Retain existing outputs är markerad toolas endast de detaljer om vars utdata tidigare togs bort, andra utdata förblir orörda. Om den är omarkerad tas alla utdatafiler för de valda maskinerna bort och regenereras under omtoolningen.

  • Om CAM-inställningarna ändrades för någon maskin, välj den maskinen och toola om detaljerna.

  • Om ett verktyg (LTT, stans eller bockning) ändras eller saknas, uppdatera maskinen och toola endast om de påverkade detaljerna.

Rename

Detta avsnitt beskriver hur du byter namn på en eller flera detaljer i TruSmartCAM.

  • Högerklicka på detaljen och klicka på Rename…​.

  • En bekräftelsedialog för namnbyte visas med det aktuella detaljnamnet.

  • Ange det nya namnet och klicka på bock-ikonen ✓ för att bekräfta, eller klicka på kryss-ikonen ✗ för att avbryta namnbytet.

  • För att byta namn på flera detaljer, välj alla önskade detaljer, högerklicka sedan på någon av dem och klicka på Rename…​.

  • En bekräftelsedialog visas med det totala antalet valda detaljer.

  • För varje detalj, ange det nya namnet och klicka på bock-ikonen ✓ för att bekräfta en i taget.

  • Om någon detalj valdes av misstag, klicka på kryss-ikonen ✗ för att avbryta. Alternativt kan du högerklicka på detaljen och klicka på Cancel Rename för att hoppa över namnbytet.

Export outputs

Detta alternativ exporterar detaljutdatan till den destination som konfigurerats i Factory Settings. (Se Bend Settings och Cut Settings)

Utdataplatsen definieras separat för Bend, Fold och Cut i deras respektive utdatainställningar. Alla toolingar som är associerade med bocknings-, viknings- och skäroperationer exporteras för hela detaljen.

De exporterade filerna beror på operationstypen. För bocknings- och vikningsoperationer genereras NC-filer och rapporter. För skär- och stansoperationer exporteras endast detaljfilerna.

Tilldela material till detalj

Detaljer med statusen Material not assigned måste uppdateras innan vidare bearbetning. Stegen nedan förklarar hur du tilldelar material.

  • Högerklicka på detaljen som visar statusen Material not assigned och välj Assign Material…​.

  • Fönstret Assign Material öppnas.

  • Dialogrutan har fyra sektioner:

    • Suggestions - Föreslår automatiskt råmaterial baserat på den importerade detaljens tjocklek.

    • All Materials - Listar alla materialtyper som definierats i TruSmartCAM.

    • All Raw-Materials - Visar alla råmaterial som finns tillgängliga i systemet.

    • Used Raw-Materials - Visar de senast använda råmaterialen för snabb åtkomst.

  • Du kan använda fältet Search högst upp för att snabbt hitta material. Skriv till exempel "steel" för att visa alla matchande material i de tre sektionerna.

  • Från den filtrerade listan, välj det önskade materialet (t.ex. Steel-25) från råmateriallistan.

  • Det valda materialet tilldelas detaljen.

Rolling direction

Rolling direction avser orienteringen av valsriktningen i en detalj, vilket kan påverka hur detaljen skärs och bearbetas. Detta alternativ låter dig ange Rolling direction för en detalj i detaljbiblioteket. Baserat på den valda riktningen placeras detaljen i rätt orientering för skärning på de tillgängliga maskinerna.

  • Högerklicka på valfri detaljbricka i detaljbiblioteket eller job-fönstret.

  • Välj den önskade valsriktningen:

    • None

    • Horizontal

    • Vertical

  • Detaljen toolas om automatiskt för alla tillgängliga skärmaskiner baserat på den valda valsriktningen.
