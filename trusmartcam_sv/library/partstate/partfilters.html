Detaljfilter

Filtren i detaljbiblioteket låter dig snabbt söka efter och hitta detaljer i biblioteket genom att tillämpa specifika villkor. Genom att begränsa resultaten till endast de detaljer som uppfyller dina kriterier gör dessa filter det enklare att hantera och komma åt relevanta detaljer effektivt.

State

  • Använd filtret State för att söka detaljer baserat på deras aktuella tillstånd.

  • Rullgardinsmenyn visar alla tillämpliga tillstånd beroende på vilka biblioteksdetaljer som finns tillgängliga.

  • Listan över tillstånd ändras dynamiskt utifrån de valda detaljerna och deras status.

  • Välj till exempel Material Missing för att visa detaljer med olöst materialtillstånd.

Status

  • Använd filtret Status för att söka detaljer baserat på tooling-status.

  • Rullgardinsmenyn visar tooling-tillstånd som färgade rutor samt alla tillgängliga maskiner och deras tillämpliga fel.

  • De färgade rutorna representerar följande tillstånd:

    • Vit: Tooling OK

    • Orange: Tooling har fel

    • Gul: Tooling har varning

    • Grå: Tooling undertryckt

  • Om en detalj har fel av typen smal fläns eller tooling ej tilldelad, visar valet av dessa respektive detaljer.

  • Detaljer med undertryckt tooling på den valda maskinen visas genom att klicka på den grå rutan.

Bend mounts

  • Använd filtret Bend mounts för att söka detaljer baserat på använt bockningsverktyg.

  • Rullgardinsmenyn visar alla tillgängliga bockningsverktyg och kan filtreras efter verktygsnamn, typ (stans, gooseneck, radie, etc.) eller beskrivning.

  • Välj flera verktyg och klicka på Match all för att sortera de verktyg som använder båda de valda verktygen.
