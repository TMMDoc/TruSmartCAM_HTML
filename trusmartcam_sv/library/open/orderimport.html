Importera order

Order kan skapas eller importeras med följande metoder:

  1. Importera order från kalkylbladsfiler.

  2. Importera order automatiskt via bevakningsinställningar.

  3. Skapa order från befintliga detaljer i detaljbiblioteket.

  4. Skapa order från statiska nests för sammanställningar.

Importera order från kalkylblad

  • Navigera till Open → Import Orders…​.

  • Stödda kalkylbladsformat inkluderar CSV, XLSX och XML.

  • Välj önskad kalkylbladsfil och klicka på Open.

  • Importprocessen liknar arbetsflödet för import av job/sammanställning.

Du kan också dra och släppa kalkylbladet direkt på ordersidan för att importera order.

Importera order med bevakningsinställningar

  • Aktivera alternativet Import spreadsheet from 'Live Folder' i Watch settings.

  • Välj Import Orders i Spreadsheet import option.

  • Konfigurera mappläget som order ska importeras från.

  • Systemet övervakar kontinuerligt den konfigurerade mappen.

  • Nyligen tillagda kalkylbladsfiler importeras automatiskt till Orders.

För detaljerade konfigurationssteg, se dokumentationen Bevakningsinställningar.

Skapa order från detaljbiblioteket

  • Välj önskade detaljer från detaljbiblioteket.

  • Högerklicka och välj New…​ → Order för att öppna dialogrutan New Orders.

  • Ange nödvändiga uppgifter såsom antal, förfallodatum och prioritet.

  • Klicka på OK för att skapa ordern.

  • Systemet växlar automatiskt till ordersidan.

  • Skapade order visas på sidan Orders Ready för jobbskapande.

Skapa order från sammanställning

  • Högerklicka på önskad sammanställning.

  • Välj New…​ → Order för att öppna dialogrutan New Orders.

  • Ange önskat Assembly count.

  • Klicka på OK för att skapa ordern.
