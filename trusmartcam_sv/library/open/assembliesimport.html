Importera sammanställningar

Sammanställningar är grupper av relaterade detaljer som kombineras till en enda enhet, vilket gör att du kan hantera flera detaljer tillsammans som en enhet.

Du kan importera sammanställningar med följande metoder:

  1. Import via fil

  2. Dra och släpp

  3. Import från kalkylblad

Import via fil

En sammanställning kan importeras till detaljbiblioteket med alternativet Import Assemblies…​.

  • Klicka på Open-ikonen i kommandofältet och välj Import Assemblies…​, eller använd File → Open → Import Assemblies…​.

  • Dialogrutan Open visas. Välj önskad(e) sammanställningsfil(er).

  • En förhandsgranskning av den valda sammanställningen visas.

  • Klicka på Open för att importera sammanställningen.

  • Importerade sammanställningar listas under vyn Assemblies i detaljbiblioteket.

Dra och släpp

  • Dra och släpp en sammanställning direkt in i TruSmartCAM detaljbibliotek.

Import från kalkylblad

  • Använd File → Open → Import Assemblies…​ och välj en CSV-, XLSX- eller XML-fil, eller dra och släpp filen.

  • Granska och uppdatera sammanställningens detaljer och antal före import. Använd Add…​ eller Remove…​ för att göra ändringar.

  • Efter import kan sammanställningar förberedas och tilldelas statiska nests.
