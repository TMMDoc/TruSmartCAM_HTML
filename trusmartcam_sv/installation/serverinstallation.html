Serverinstallation

Följ instruktionerna för att installera TruSmartCAM Server tillsammans med SQL.

Administratörsrättigheter

För att köra denna installation måste användaren ha administratörsbehörighet.

  • Kör Setup.TruSmartCAM.<version>.exe för att börja installationen.

Versionen är ett nummer.

  • Läs licensavtalet och välj I accept the agreement och klicka sedan på Next.

Steg 1 : Installationsplats

  • Ange installationskatalogen eller acceptera installationens standard C:\Program Files\TRUMPF\TMM\Praxis och klicka på Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Installationsmappen kommer att innehålla följande mappar: Bin, MetaCAM, Samples och Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Datamappen kommer att innehålla följande mappar: TruSmartCAM, TecZone och MetaCAM.

Steg 2 : Val av komponenter

Installationstyp Komponenter

Full

Server + Desktop-klient + Engine

Client

Desktop-klient

Server

Server + Desktop-klient

Station

Väljer alla stationsterminaler som TecZone, MetaCAM, RightAngle (bockningsstyrenhet), Vulcan (styrenhet för lasermaskin)

Custom

Väljs enligt användarens val.

  • Välj Full-installation. Välj Code Senders och Bend Code Senders från TruSmartCAM-verktygen. Nu ändras installationstypen till Custom. Klicka på Next.

Steg 3 : Välj installation av SQL Server

Installation av SQL Express 2022 behövs endast för TruSmartCAM Server. Detta alternativ är inte tillgängligt för klient- och synkroniseringsinstallationer. Även detta är markerat och installeras första gången och kan ignoreras därefter. Om SQL redan är installerat i TruSmartCAM-servern kan användaren ignorera Steg 3.

  • I Select Additional Tasks : Klicka på Install SQL Express och klicka på Next.

  • I Ready to Install : Sammanfatta alla installationsfunktioner och klicka på Install.

Steg 4 : Installation av SQL Server

När TruSmartCAM-komponenterna är installerade fortsätter installationsprogrammet med installationen av SQL-servern. Acceptera licensavtalet för att fortsätta och installera SQL Express med standardalternativen.

När installationen är klar, klicka på Close och slutför installationen.

Beroende på Windows-versionen kan stängning av SQL-installationen begära en omstart.

Steg 5 : Genvägar på Windows-skrivbordet

  • Efter SQL-installationen, om systemet inte startar om, markera kryssrutan Launch TruSmartCAM och klicka på Finish.

  • Om systemet startar om, starta genvägsikonen TruSmartCAM på skrivbordet eller skriv TruSmartCAM i Windows startmeny och välj Run as administrator.

Serverinstallation : Genvägsikonerna TruSmartCAM och TruSmartCAM License finns tillgängliga på skrivbordet.
Klient-/SYNC-installation : Endast genvägsikonen TruSmartCAM är tillgänglig på skrivbordet.

Steg 6 : Licensregistrering

  • I fältet Serial Number skriver du TruSmartCAM-serienyckeln som tillhandahålls av Trumpf Metamation Service Team. Skriv <Company Name> i fältet "Registered to" och e-post. Klicka på OK.

Om nätverkets brandvägg blockerar licensregistreringen eller om det inte finns något internet i TruSmartCAM Server-PC:n görs TruSmartCAM-licensen genom offlineaktivering. Skicka Prax.request från mappen C:\ProgramData\TRUMPF\TMM\Praxis via e-post till Trumpf Metamation Service Team. Trumpf Metamation Team tillhandahåller Prax.lock som ska läggas i denna mapp.

Steg 7 : Inledande engångskonfiguration

  • Skriv databasnamnet och ange plats för datalagring. Markera kryssrutan Use SQL Server och välj SQL-serverns namn för att ansluta till databasen. Klicka på OK.

  • TruSmartCAM Desktop-klienten öppnas och visar Database Connection Succeeded nere till vänster.

  • Konfigurationsfilerna för TruSmartCAM, TecZone och MetaCAM skapades med standardkonfigurationens maskiner eller mot TruSmartCAM-licensmaskinerna. Samma konfiguration delas över alla TruSmartCAM-klienter.

Välkomstskärmen visas med Windows-användarens inloggningsnamn som TruSmartCAM-inloggning och namn. Den första TruSmartCAM-användaren betraktas som Site Admin. Ange e-post och lösenord. Klicka på OK .

Markera kryssrutan Remember me för att spara inloggningsuppgifterna till nästa gång. Om du avmarkerar Remember me visas dialogrutan för inloggning och lösenord varje gång TruSmartCAM-applikationen startas.

Steg 8 : TruSmartCAM-inloggning

  • Stäng TruSmartCAM och öppna det igen. Systemet uppmanar dig att ange TruSmartCAM- inloggningsuppgifterna.

  • Det inloggade användarnamnet visas bredvid användarikonen i TruSmartCAM- applikationens rubrik.

  • När du håller muspekaren över användarikonen visar systemet:

    • Användarrollen (till exempel: Programmer, Admin).

    • En genväg för att logga ut: Ctrl+L.

  • Genom att klicka på användarikonen öppnas en meny där du kan:

    • Edit information…​ - Uppdatera dina profiluppgifter.

    • Change password…​ - Ändra ditt kontos lösenord.

    • Sign out - Logga ut från applikationen.

    • Cancel - Stäng menyn utan att göra några ändringar.

Steg 9 : Konfiguration av fabriksmaskin

  • TruSmartCAM-licens [licensbit som aktiverar alla maskiner] : Standardmaskinen TruSmartCAM och material betraktas som fabrikskonfiguration.

  • TruSmartCAM-licens [ingen demo och några få maskinbitar aktiverade] : Dessa få maskiner och standardmaterial betraktas som fabrikskonfiguration.

  • (Open → Import) en ny detalj från C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts och verifiera om detaljen har importerats korrekt.

Anmärkning 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor med Engine-installation (Site admin-rättigheter):

    • TruSmartCAM Monitor med Engine tillsammans med Site Admin TruSmartCAM-rättigheter kommer att ha följande alternativ:

      1. Skicka TruSmartCAM-konfiguration, TecZone-, MetaCAM-konfiguration över alla TruSmartCAM- klienter. Har också rättigheter att skapa en ny TruSmartCAM-användarinloggning.

      2. Show Agents visar det totala antalet tillgängliga engines för att utföra automationsuppgifter som är mot TruSmartCAM-licensen.

  • TruSmartCAM Monitor utan Engine-installation (Site admin-rättigheter):

  • TruSmartCAM Monitor utan Engine-installation (utan Site Admin-rättigheter):

PC:n som kör TruSmartCAM-applikationen måste ha TruSmartCAM-komponenten Engine installerad [Server-PC eller i någon klientinstallation]. PC:n med TruSmartCAM-komponenten Engine installerad bör köras dygnet runt för att utföra alla automationsuppgifter.
Anmärkning 2 : OpenGL

  • TruSmartCAM-applikationen stängs omedelbart när den öppnas och även pmonitor visas inte i aktivitetsfältet.

  • Detta representerar ett OpenGL-problem.

  • Ett annat sätt att bekräfta detta: Öppna C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts som visar en feldialogruta om OpenGL-problemet.

  • Uppdatera C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , avsnittet options med GLVersion=1 gör att TruSmartCAM-applikationen öppnas korrekt.

[Options]
GLVersion=1.0
