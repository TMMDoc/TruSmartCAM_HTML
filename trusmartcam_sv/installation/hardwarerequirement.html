Kräver ett standardanvändarkonto
Ett standardanvändarkonto krävs för att TruSmartCAM Server ska köras som tjänst i Aktivitetshanteraren och för att Monitor ska köras. Det bör ställas in i läget för automatisk inloggning.

Portkrav

TruSmartCAM Server : 7371

Servern väntar på klientförfrågningar på denna TCP-port. Inkommande anslutningar bör tillåtas till denna port på serverdatorn.

Floating License Server : 5776

Floating License Server väntar på licensförfrågningar på denna port. Inkommande anslutningar bör tillåtas till denna port på datorn för floating license server (TruSmartCAM Server).

Licensanslutning till molnet : 7567

Denna port används av TecZone (bockningsprogramvara) och Floating License Server för att skicka licensförfrågningar till Metamation Cloud. Utgående anslutning bör därför tillåtas på denna port för licensaktiveringar och -förnyelser.

Krav för installation och support

  • Administratörsbehörighet krävs för att installera TruSmartCAM-applikationen.

  • Fjärrdiagnostikverktyg via entreprenörens VPN eller en säker anslutning.
