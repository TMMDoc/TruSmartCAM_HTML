Order

Order

En order definierar vilka detaljer som behöver tillverkas, i vilket antal och när. Den styr produktionsplanering och genomförande i TruSmartCAM. Order kan skapas eller importeras med olika metoder, och de kan konverteras till job för produktionsplanering.

Orderpanel

Open in read-only mode for viewing
Öppnar den valda ordern i skrivskyddat läge.

Check-out the document for editing
Aktiverar redigering av den valda ordern.

Delete
Tar bort den valda ordern.

New…​

Konverterar ordern till ett job, en sammanställning eller en annan order.

Assign Customer…​

Tilldelar en kund till ordern.

Set Due Date…​

Anger förfallodatum för ordern.

Priority

Anger orderns prioritetsnivå. Tillgängliga alternativ är Normal, Low, High och Urgent.

Part Order

Anger det referens-ID som tilldelats en detalj inom ordern.

Quantity

Anger antalet detaljer eller instanser i ordern.

Prev / Next / Part

Navigerar till föregående eller nästa detalj inom ordern.

Sortera och filtrera

Använd dessa filter för att visa andra order som delar Same Material, Same Customer, Same Due Date eller Same Priority.

Redigera order

Markera en eller flera order och högerklicka för att ändra gemensamma orderuppgifter såsom antal, förfallodatum, prioritet och kundinformation.

Om flera markerade order kräver olika värden använder du alternativet Check-out for Editing för att redigera varje order individuellt utifrån behovet.

Alla uppdateringar som görs på orderna tillämpas omedelbart på databasen. Använd kommandot Delete för att ta bort order från orderbiblioteket.

Kommandot Delete tar bort endast orderna. Detaljer som är kopplade till respektive order tas inte bort från detaljbiblioteket.

Planera order

Markera en eller flera order, högerklicka och klicka på New…​ → Job för att konvertera de markerade orderna till job. Använd alternativen Sortera och Filtrera för att gruppera relevanta order tillsammans innan job skapas.

När orderna har konverterats till ett job:

  • Jobbet flyttas till sidan Jobs

  • Orderna tas bort från orderlistan

  • Det vanliga arbetsflödet för jobbplanering kan sedan användas för produktionsplanering och nesting

För mer information om arbetsflödet för jobbplanering, se Auto Plan

Ytterligare information

  • Om ett job som innehåller order tas bort, flyttas de tillhörande orderna automatiskt tillbaka till sidan Orders Ready, såvida inte jobbet eller detaljen är markerad som Completed.

  • Order kan läggas till i eller tas bort från ett befintligt job via fönstret Edit Job utifrån produktionskraven.
