Job-panel

Detta avsnitt förklarar job-relaterade åtgärder som Export outputs, Reset job…​, Mark complete…​, Export job…​ och andra alternativ som används för att hantera job-instanser.

Open in read-only mode for viewing
Öppnar det valda jobbet i skrivskyddat läge.

Check-out the document for editing
Aktiverar redigering av det valda jobbet.

Delete
Tar bort det valda jobbet.

View Report
Öppnar produktionsrapporten för det valda jobbet.

Export Outputs

Exporterar de maskinfärdiga utdatafilerna (NC-filer och rapporter) som genererats för det valda jobbet.

Plan Job…​

Genererar nestade layouter för detaljerna i det valda jobbet.

Reset Job…​

Tar bort alla genererade layouter för jobbet och återställer dess detaljer till planerbart tillstånd.

Mark Complete…​

Markerar jobbet och alla dess nests som slutförda efter produktion.

Export Job…​

Exporterar hela jobbet som ett paket som kan återanvändas eller importeras till ett annat system.

Prev / Next / Layout

Navigerar till föregående eller nästa layout inom det valda jobbet.

Sortera och filtrera

Använd dessa filter för att visa andra job som delar Same Customer, Same Part.

Export outputs

  • Välj önskat job.

  • Klicka på Export outputs.

  • Detta exporterar de maskinfärdiga utdatafilerna som genererats för det valda jobbet.

  • Export Outputs kan sparas antingen på den standardplats som konfigurerats i Factory Settings eller på en anpassad plats med hjälp av Browse…​.

  • Det exporterar endast maskinutdatafiler (till exempel NC och rapporter) för jobbet.

  • Dessa filer används direkt för produktion och kan skickas till maskinen.

Reset job…​

Återställer det valda jobbet genom att ta bort alla genererade layouter och göra detaljerna tillgängliga för planering igen.

För att återställa ett job:

  • Högerklicka på jobbet och välj Reset job…​.

  • Detta tar bort alla befintliga nestade layouter för det valda jobbet och återställer alla dess detaljer till plangerbart tillstånd.

  • Om layouterna innehåller detaljer från andra job återställs även dessa detaljer.

Export job…​

  • Välj önskat job.

  • Klicka på Export job…​.

  • Detta alternativ exporterar hela jobbet som ett paket som kan återanvändas eller importeras till ett annat system.

  • Den exporterade datan innehåller all information som krävs för att återskapa jobbet:

    • Detaljinformation och antal (CSV-filer).

    • Layout- och nesting-data (CSV-/FXYLT-filer).

  • De exporterade filerna sparas som en job-mapp på den konfigurerade export- platsen.

  • Detta alternativ används för att överföra, dela eller säkerhetskopiera hela jobbet.

Mark complete…​

  • När jobbet har bearbetats i maskinen, öppna Job-panelen och välj Mark complete…​.

  • När ett job markeras som slutfört:

    • Alla nests under jobbet markeras som slutförda.

    • Jobbet gråtonas, flyttas till slutet av listan och visas med en grön bock.

    • Alla layouter under jobbet tas bort från listan över aktiva layouter.

    • Detalj- och job-statusar uppdateras och bearbetade antal flyttas till slutfört tillstånd.

    • Utdatafiler för alla layouter i jobbet tas bort från maskinens utdataplats för att undvika dubbel användning.
