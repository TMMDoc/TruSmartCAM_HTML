Layout-panel

Detta avsnitt förklarar layoutrelaterade åtgärder såsom Send to machine, Recall from machine, Export outputs, Mark complete, Add parts…​, Adapt/Compact…​, Split layout och andra alternativ som används för att hantera layoutinstanser.

Open in read-only mode for viewing
Öppnar den valda layouten i skrivskyddat läge.

Check-out the document for editing
Möjliggör redigering av den valda layouten.

Delete
Tar bort den valda layouten.

View Report
Öppnar standardlayoutrapporten och den etikettspecifika rapporten för den valda layouten.

Send to Machine…​

Skickar den valda layouten till maskinen och exporterar utdatafilerna (fxlyt, NC, report, csv) till jobbets utdataplats.

Add Parts…​

Lägger till fler detaljer i en dåligt packad layout med guiden för ompackning av layout.

Adapt/Compact…​

Omnestar den valda layouten för att komprimera detaljerna och frigöra användbar yta.

Change LTT…​

Ändrar plåten som tilldelats den valda layouten.

Split Layouts…​

Delar upp den valda layouten i två eller flera separata layouter.

Rename…​

Byter namn på den valda layouten.

Job / Prev / Next / Parts

Navigerar upp till det överordnade jobbet, till föregående eller nästa layout inom det valda jobbet, eller ned till detaljerna som ingår i layouten.

Sort and filter

Använd dessa filter för att visa andra layouter som delar samma attribut som den valda layouten: Same Machine, Same Material, Same LTT, Same Priority, Same State, Same Sheet, Same Part, Same Remnant State, eller Same Rolling Direction.

Send to machine

  • När en nest är klar (fylld eller brådskande) kan du skicka den till maskinen.

  • Högerklicka på nesten och välj Send to machine…​.

  • En mapp skapas automatiskt med nestens namn.

  • Utdatafiler (fxlyt, NC, report, csv) exporteras till jobbets utdataplats.

  • Nests som skickats till maskinen visas med en blå bock.

När de har frisätts försöker systemet inte packa om dem igen.

Recall from machine

  • Om utdata behöver valideras eller uppdateras (till exempel för att lägga till fler detaljer):

    • Högerklicka på den exporterade layouten.

    • Välj Recall from machine…​.

  • Utdatafilerna och mappen (fxlyt, NC, report, csv) tas bort.

  • Nesten blir redigerbar igen.

  • Du kan göra ändringar och skicka den till maskinen igen.

Export outputs

  • Högerklicka på valfri layout (nest) som har skickats till maskinen och klicka på Export outputs.

  • Alternativet Export Outputs exporterar NC-, Report- och Layout-filerna till respektive utdatamapp för maskinen.

  • Detta alternativ regenererar NC-filen med de aktuella enhetsinställningarna för layouten.

Export Outputs är inte tillgängligt för layouter som är slutförda och layouter som väntar i kö för ompackning.

Markera som slutförd

  • När nesten har bearbetats i maskinen, högerklicka på nesten och välj Mark complete…​.

  • Du kan välja flera nests och markera dem som slutförda samtidigt.

  • När en nest markeras som slutförd:

    • Den nedtonas, flyttas till slutet av listan och visas med en grön bock.

    • Layouten tas bort från listan med aktiva layouter.

    • Detalj- och jobbstatusar uppdateras och bearbetade antal flyttas till det slutförda tillståndet.

    • Utdatafiler för den layouten tas bort från maskinens utdataplats för att undvika dubbelanvändning.

Add parts…​

  • Använd detta alternativ för att lägga till fler detaljer i en relativt dåligt packad layout. Precis som interaktiv nesting är detta ett guidestyrt alternativ som kan användas på en enskild eller flera layouter samtidigt.

  • TruSmartCAM visar guiden för ompackning av layout i huvudarbetsområdet när detta alternativ används. Håll ned tangenten Ctrl och välj en eller flera detaljer som ska packas på layouten/layouterna och tryck på Next.

  • De valda detaljerna visas i nästa steg med en redigerbar antalskolumn. Uppdatera detaljantalen vid behov i fältet Update Qty. Klicka på Next för att gå vidare till nestingen. Observera att antalet endast kan ökas, inte minskas.

  • Alla layouter nestas separat och de nestade resultaten visas med de nyligen packade detaljerna placerade på dem. När du väljer layouten visas alla befintliga layoutdetaljer. Resultatet förkastas automatiskt om ingen ny detalj placeras under ompackningen. En layout med flera kopior kan resultera i olika mönster efter ompackningen.

Adapt/Compact…​

  • Detta guidebaserade kommando kan användas för att anpassa en layout från en maskin till en annan när den ursprungliga maskinen är ur drift eller när maskinbelastningen behöver balanseras.

  • Det kan användas när den planerade plåten är slut i lager och layouten behöver planeras om på en annan tillgänglig plåt.

  • Du kan slå samman layouter som packats på mindre plåtar till större plåtar för att använda material mer effektivt.

  • Du kan dela upp layouter som packats på större plåtar till mindre plåtar om stora plåtlager inte finns tillgängliga.

  • Du kan förbättra packningseffektiviteten för flera layouter (även från olika maskiner) genom att slå samman dem.

  • Använd det genom att välja en eller flera layouter och klicka på Adapt/Compact…​ för att öppna guiden i arbetsområdet.

  • Den vänstra rutan visar alla valda layouter och rutan Parts visar layoutdetaljerna.

  • Välj målmaskin och plåtmaterial och klicka sedan på next för att utföra omnestingen.

  • De nya nestresultaten visas i resultatrutan.

  • Klicka på next för att spara den anpassade eller komprimerade layouten.

Dela upp en layout

Alternativet Split layouts…​ gör att du kan dela upp en befintlig layout i flera layouter genom att ändra antal, utan att behöva göra om tooling eller nesting.

Denna funktion är särskilt användbar i följande scenarier:

  1. När du behöver producera en del av det totala antalet omedelbart samtidigt som du schemalägger återstående antal för senare produktion.

  2. När produktionskraven behöver fördelas över flera skift eller dagar för att optimera arbetsflödet och resursanvändningen.

  3. När en specifik maskin tillfälligt är otillgänglig eller upptagen och du behöver justera layouten för att anpassa den till de aktuella produktionsbegränsningarna.

Utför följande steg för att dela upp en layout:

  • Välj den önskade layouten i layoutvyn.

  • Klicka på Split layouts…​.

  • Ange det önskade värdet i New Copies.

  • Klicka på OK.

Den valda layouten är nu uppdelad i två layouter med justerade antal.
