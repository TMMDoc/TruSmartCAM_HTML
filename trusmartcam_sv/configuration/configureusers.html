Konfigurera användare

  • TruSmartCAM-klienter med olika roller används för att styra fabriks- konfigurationen.

    • Lägga till nya maskiner, material och plåtar.

    • Redigera maskinkonfigurationer.

    • Redigera detaljer, jobs och sammanställningar.

    • Redigera/uppdatera nest-plåtar, planera job.

    • Lägga till/redigera användare.

  • Datorn där Pserver installeras betraktas som den första TruSmartCAM-användaren.

  • TruSmartCAM använder Windows-inloggningsuppgifterna som TruSmartCAM-användarnamn, vilket är Site Admin.

  • Nästa installation, dvs. användarnamnet på datorn där TruSmartCAM Client installeras, betraktas som Programmer.

Endast Site Admin kan redigera andra användares information och ändra lösenordet.
