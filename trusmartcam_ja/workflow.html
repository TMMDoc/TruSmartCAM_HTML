ワークフロー

ワークフロー

TruSmartCAM は、板金製造プロセスを管理・最適化する Manufacturing Execution System です。TruSmartCAM のワークフローは、特定のタスクまたはプロセスを完了するために従う一連のステップで構成されます。ワークフローは、さまざまな製造プロセスに合わせてカスタマイズし、特定のニーズに適応させることができます。TruSmartCAM のワークフローには通常、次のステップが含まれます:

1. システムを構成する

TruSmartCAM を製造環境に合わせて構成します。この基礎的なステップには、マシンの機能とパラメーターの定義、利用可能な材料と板厚範囲の追加、パンチとダイを含むツーリングライブラリの構成、さまざまなマシン構成のためのセットアップシートの作成、および適切な権限を持つユーザーアカウントの管理が含まれます。適切に構成されたシステムは、正確な処理を保証し、後の段階でのエラーを防止します。このセットアップは通常、初期導入時に一度実行し、ファクトリーの進化に合わせて定期的に更新します。

詳細については、Add/Remove machine、Material、 Sheets、Setup tooling、および Configure users を参照してください。

2. 部品をライブラリに追加する

DXF、DWG、STEP ファイルなどのサポートされている形式を使用して、2D または 3D CAD 部品を部品ライブラリにインポートします。インポート中、TruSmartCAM は部品ジオメトリを自動的に分析し、製造可能性を検証し、必要な板金技術（レーザー、パンチ、またはそれらの組み合わせ）を割り当て、プレビューサムネイルを生成します。インポートされた部品はライブラリビューにタイルとして表示され、色分けされたアイコンが部品のステータス、技術タイプ、材料要件、および検出された問題を示します。この視覚的なシステムにより、部品の準備状況を一目で素早く評価できます。

詳細については、Library を参照してください。

3. 部品とツーリングを検証する

インポートした各部品について、潜在的な生産上の問題を確認します。部品ジオメトリが有効で製造可能であること、ツーリングの割り当てが正確で利用可能であること、材料と板厚の選択が在庫と一致していること、および成形部品の曲げシーケンスが適切に定義されていることを検証します。問題が検出された場合は、TecZone で部品を開き、ジオメトリの変更、ツーリングの再割り当てや最適化、処理パラメーターの調整、または材料仕様の修正を行います。この段階で問題を解決することで、生産の遅延を防ぎ、製造時のスクラップを削減できます。

詳細については、Part state および Tooling status を参照してください。

4. 部品をジョブに整理する

検証済みの部品を、生産要件に基づいてジョブにグループ化します。ジョブは論理的な生産単位を表し、単一の顧客オーダーの部品、共通の材料と板厚を共有する部品、納期が近い部品、または生産戦略に基づく組み合わせを含めることができます。ジョブは計画のためのコンテナーを提供し、関連する部品のバッチ処理を可能にし、ネスティングによる効率的な材料利用を実現し、追跡とレポート作成を簡素化します。ジョブは、部品を選択して手動で作成することも、事前定義されたルールとフィルターに基づいて自動的に作成することもできます。

詳細については、Jobs を参照してください。

5. ジョブを生産マシンに計画する

ジョブが作成されたら、適切な生産マシンに割り当てます。サポートされている技術（レーザー、パンチ、タレット）、材料と板厚の対応能力、利用可能なツーリング、および現在の作業負荷など、マシンの機能を考慮します。適切なマシンが複数存在する場合は、生産の優先度、マシンの空き状況、セットアップ要件、またはコスト最適化に基づいて選択します。割り当ては、柔軟性のために手動で行うことも、事前に構成されたルールとマシンスケジューリングアルゴリズムに基づいて自動的に行うこともできます。

詳細については、Plan job を参照してください。

6. ジョブの NC をリリースする

この段階で、切断レイアウトが生成されます。TecZone を使用して、レイアウトを編集したり、切断技術をレイアウトに追加したりすることができます。その後、NC 出力をエクスポートし、マシンコントローラーまたは指定されたネットワーク上の場所に転送します。次にジョブはロックされてそれ以上の変更が防止され、生産追跡のためにステータスが "Released" に更新されます。

詳細については、Send/Recall NC を参照してください。

7. 生産を完了してジョブを確定する

リリースされたジョブを、割り当てられたマシンで実行します。生産中、マシンオペレーターは NC プログラムに従い、切断中に部品の品質を検証し、材料のロードとアンロードを管理し、マシンのアラームや問題に対処します。生産が終了したら、TruSmartCAM で個々の部品またはジョブ全体を完了としてマークします。この最終ステップでは、在庫記録を更新し、実際の生産時間と材料使用量を記録し、レポート作成と分析のためにジョブデータをアーカイブし、ワークフローサイクルを完了します。

詳細については、Mark complete を参照してください。
