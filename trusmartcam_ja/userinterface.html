ユーザーインターフェイス

ユーザーインターフェイス

TruSmartCAM のユーザーインターフェイスは、コマンドバーとメニューバーを通じてすべての主要機能へのアクセスを提供し、効率的なナビゲーションと操作を可能にします。

コマンドバー

Open - 部品、ジョブ、オーダー、アセンブリをライブラリにインポートします。詳細については、Open を参照してください。

Language - ユーザーインターフェイスの言語を変更します。詳細については、Language を参照してください。

Library - 部品とアセンブリが別々に表示されるライブラリのホームページを開きます。詳細については、Library を参照してください。

Jobs - インポートまたは作成されたジョブを表示します。詳細については、Jobs を参照してください。

Factory - 生産セットアップのためのルート、材料、ユーザー、顧客データを構成・管理する中央の場所を開きます。詳細については、Factory を参照してください。

Info - ソフトウェアに関する情報を表示します。

メニューバー

File - 部品、ジョブ、オーダー、アセンブリを開くオプション、およびアプリケーションを終了するオプションを提供します。

View - 画面の切り替えや、異なるビューへのアクセスを可能にします。

Help - ヘルプマニュアルおよびソフトウェア更新オプションへのアクセスを提供します。

Admin - 管理設定および構成オプションが含まれます。

サブコマンド

Parts - 部品ライブラリの項目を表示します。

Assys - ライブラリビューでアセンブリ項目に切り替えます。

Export - 現在の部品またはツーリングレポートを CSV としてエクスポートします。
