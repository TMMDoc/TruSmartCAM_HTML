ジョブビュー

このセクションでは、Jobs、Parts、Nests、Edit、Simulate、Export など、Job ビューで利用可能なさまざまなビューについて説明します。

Jobs

jobs オプションを選択すると、現在ソフトウェアにセットアップされているすべてのジョブのリストが表示されます。ジョブをダブルクリックしてその詳細を表示したり、右クリックして追加のオプションにアクセスしたりできます。

  • ジョブはタイルビューで表示され、各ジョブは Job ID、Job Ref、顧客名、Total parts、Due Date、ジョブステータスバーなどの基本プロパティとともに表示されます。

  • 各ジョブタイルには、部品画像もスタックされたカード形式で表示されます。マウスホイールを使用して、ジョブ内のすべての部品をスクロールできます。

ジョブの詳細

  • タイルをダブルクリックするか、タイルを選択した後に Enter キーを押すと、ビューが詳細モードに切り替わります。

  • 詳細ページには、ネストされたシート（レイアウト）がある場合はそれとともに、部品リストが表示されます。

  • 上/下矢印キーを使用して、詳細ページでジョブを切り替えます。

  • 部品スタック上でマウスホイールをスクロールすると、部品リストとレイアウトの両方で部品が強調表示されます。

  • レイアウトを選択すると、そのレイアウトと、そこにネストされたすべての部品が部品リストで強調表示されます。強調表示は 1 分後に自動的にオフになります。

  • Nest summary:

    • Parts: ジョブ内のオーダーアイテムの総数と合計数量を表示します。

    • Sheets: ネストされたシートの総数と合計シート数量を表示します。

  • Work Steps:

    • Bending: 割り当てられたマシンと処理されるそのオーダー数量を表示します。

    • Cutting: 割り当てられたマシンと処理されるそのオーダー数量を表示します。

優先度

  • まず、画面左側の Jobs アイコンをクリックし、編集するジョブを選択してから、画面右側の edit をクリックします（Jobs オプションが選択されていることを確認してください）。

  • または、選択したジョブを右クリックして Check-out the document for editing アイコンをクリックします。

  • edit をクリックすると、edit job ウィンドウが表示されます。このウィンドウで、ジョブの優先度を設定または変更できます。

  • ジョブ部品の優先度に基づいて、ジョブタイルのジョブ Reference がそれに応じて色分けされます。

  • ジョブ部品は、まず優先度で、次に納期で並べ替えられます。また、優先度に応じて色分けされます。

  • ネスティング時には、Urgent 部品が最初に考慮され、次に High、次に Normal、最後に Low 優先度の部品がネストシートの残りのスペースに配置されます。

  • ネストシートも優先度に応じて並べ替えられ、色分けされます。

ステータス

  • ジョブステータスバーは、処理済みまたは残りの数量に基づいて、ジョブの進行状況または状態を示すためにカラーコードを使用します。

  • ジョブ内の部品とネストシートも、JOB 全体における個々のステータスを反映するために一致する色で強調表示されます。

  • カラーコーディングは追跡を改善し、オペレーターが一目で生産ステータスを簡単に確認できるようにします。

Parts

Active Parts ビューには、アクティブなジョブ内で現在進行中のすべての部品が表示されます。

各部品は、部品名、寸法、材料、板厚、数量、納期などの主要な詳細を示すタイルとして表されます。部品の視覚的なプレビューも表示されます。

このビューは、ユーザーが個々の部品の処理ステータスを監視し、進行中のジョブ全体でその進捗を追跡するのに役立ちます。

Nests

Active Nests ビューには、アクティブなジョブ内で現在進行中のすべてのネストが表示されます。

各ネストは、部品数や処理ステータスなどの関連する詳細とともに表されます。ネストされた部品の視覚的なレイアウトも表示されます。

このビューは、ユーザーがネスティングの進捗を監視し、部品がシート上でどのように配置され処理されるかを追跡するのに役立ちます。

Edit

Edit オプションを使用すると、選択したアイテムを変更できます。

現在のビューに基づいて、選択したインスタンスが編集用に開かれます:

  • Jobs ビューでは、選択したジョブが編集用に開かれます。

  • Active Parts ビューでは、選択した部品が編集用に開かれます。

  • Active Nests ビューでは、選択したネストが編集用に開かれます。

Export csv

Export オプションを使用すると、ジョブ情報を選択して CSV ファイルにエクスポートできます。

  • jobs アイコンをクリックします。

  • 画面右側の export オプションをクリックします。

  • 利用可能なフィールドを示すダイアログボックスが表示されます:

  • エクスポートするフィールドのチェックボックスを選択します。

  • 選択したフィールドでデータをグループ化する場合は、Group By オプションを使用します。

  • Export をクリックして CSV ファイルを生成します。

追加情報

画面右側には、Simulate、Goto、Back の 3 つの追加アイコンもあります。

  • Simulate は、選択したアイテムをより詳細に表示するために開きます。

  • Goto は、選択した部品またはネストにフォーカスと表示を切り替えます。

  • Back は、現在の場所から 1 レベル戻ります。たとえば、シミュレーション中に Back をクリックするとメインジョブに戻り、ジョブからはメインの jobs 表示に戻ります。
