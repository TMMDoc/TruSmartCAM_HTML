Report sender

Report sender

  • デフォルトでは、ネストがマシンに送信されると、すべての出力ファイル（NC、Report、CSV）がネストにちなんで名付けられたフォルダーに保存されます。

  • すべての出力をネストフォルダーに送信する代わりに、Report Sender を使用して NC、Report、CSV ファイルを特定のフォルダーにエクスポートできます。

  • これを構成するには、Factory → routes → Code sender に移動し、ReportSender を選択します。

  • NC ファイル、Report ファイル、CSV ファイルの宛先フォルダーを設定します。

  • ネストに対して Send to Machine…​ が実行されると、NC、Report、CSV ファイルは、デフォルトのネストフォルダーではなく、構成されたフォルダーにエクスポートされます。

  • ネストに対して Recall from Machine…​ が実行されると、対応する NC、Report、CSV ファイルは、構成された Report Sender 宛先フォルダーから削除されます。

  • これにより、出力フォルダーには有効なファイルのみが残り、エクスポートされたファイルの管理が容易になります。
