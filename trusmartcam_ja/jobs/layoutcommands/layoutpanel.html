Layout panel

このセクションでは、レイアウトインスタンスを管理するために使用する Send to machine、Recall from machine、Export outputs、Mark complete、Add parts…​、Adapt/Compact…​、Split layout などのレイアウト関連のアクションについて説明します。

Open in read-only mode for viewing
選択したレイアウトを読み取り専用モードで開きます。

Check-out the document for editing
選択したレイアウトの編集を有効にします。

Delete
選択したレイアウトを削除します。

View Report
選択したレイアウトの標準レイアウトレポートとラベル固有のレポートを開きます。

Send to Machine…​

選択したレイアウトをマシンに送信し、出力ファイル（fxlyt、NC、report、csv）をジョブ出力の場所にエクスポートします。

Add Parts…​

レイアウト repack ウィザードを使用して、パッキングの不十分なレイアウトに部品を追加します。

Adapt/Compact…​

選択したレイアウトを再ネスティングして部品を圧縮し、使用可能な領域を解放します。

Change LTT…​

選択したレイアウトに割り当てられたシートを変更します。

Split Layouts…​

選択したレイアウトを 2 つ以上の別々のレイアウトに分割します。

Rename…​

選択したレイアウトの名前を変更します。

Job / Prev / Next / Parts

親ジョブに移動したり、選択したジョブ内の前または次のレイアウトに移動したり、レイアウトに含まれる部品に移動したりします。

並べ替えとフィルター

これらのフィルターを使用して、選択したレイアウトと同じ属性を共有する他のレイアウトを表示します: Same Machine、Same Material、Same LTT、Same Priority、Same State、Same Sheet、Same Part、Same Remnant State、または Same Rolling Direction。

Send to machine

  • ネストの準備ができたら（充填済みまたは緊急に必要な場合）、マシンに送信できます。

  • ネストを右クリックして Send to machine…​ を選択します。

  • ネストにちなんで名付けられたフォルダーが自動的に作成されます。

  • 出力ファイル（fxlyt、NC、report、csv）が JOB 出力の場所にエクスポートされます。

  • マシンに送信されたネストは、青いチェックマークとともに表示されます。

リリースされると、それらのネストは repacking のために再試行されなくなります。

Recall from machine

  • 出力に検証または更新が必要な場合（たとえば、部品を追加する場合）:

    • エクスポートされたレイアウトを右クリックします。

    • Recall from machine…​ を選択します。

  • 出力ファイルとフォルダー（fxlyt、NC、report、csv）が削除されます。

  • ネストは再び編集可能になります。

  • 変更を加えて、再度マシンに送信できます。

Export outputs

  • マシンに送信された任意のレイアウト（ネスト）を右クリックし、Export outputs をクリックします。

  • Export Outputs オプションは、NC、Report、Layout ファイルをそれぞれのマシン出力フォルダーにエクスポートします。

  • このオプションは、レイアウトの現在の単位設定で NC ファイルを再生成します。

Export Outputs は、Completed のレイアウトや、repacking のためにキューで待機しているレイアウトでは利用できません。

Mark complete

  • ネストがマシンで処理されたら、ネストを右クリックして Mark complete…​ を選択します。

  • 複数のネストを選択して、同時に完了としてマークできます。

  • ネストが完了としてマークされると:

    • グレー表示になり、リストの末尾に移動され、緑のチェックマークとともに表示されます。

    • レイアウトはアクティブなレイアウトリストから削除されます。

    • 部品とジョブのステータスが更新され、処理された数量が完了状態に移動します。

    • そのレイアウトの出力ファイルは、重複使用を避けるためにマシン出力の場所から削除されます。

Add parts…​

  • このオプションを使用して、比較的パッキングの不十分なレイアウトに部品を追加します。Interactive Nesting と同様に、これはウィザード駆動のオプションであり、単一または複数のレイアウトで同時に使用できます。

  • このオプションを使用すると、TruSmartCAM はメイン作業領域に Layout repack ウィザードをマウントします。Ctrl キーを押しながら、レイアウトにパッキングする 1 つ以上の部品を選択し、Next を押します。

  • 選択した部品は、編集可能な数量列とともに次のステップに表示されます。必要に応じて、Update Qty フィールドで部品数量を更新します。Next をクリックしてネスティングに進みます。数量は増やすことのみができ、減らすことはできないことに注意してください。

  • すべてのレイアウトは個別にネスティングされ、ネストされた結果に新しくパッキングされた部品が配置されて表示されます。レイアウトを選択すると、既存のすべてのレイアウト部品が表示されます。repacking 中に新しい部品が配置されない場合、結果は自動的に破棄されます。複数のコピーを持つレイアウトは、repacking 後に異なるパターンになる場合があります。

Adapt/Compact…​

  • このウィザードベースのコマンドは、元のマシンがダウンしている場合やマシンの作業負荷のバランスを取る必要がある場合に、レイアウトをあるマシンから別のマシンに適合させるために使用できます。

  • 計画されたシートが在庫切れで、レイアウトを別の利用可能なシートで再計画する必要がある場合に使用できます。

  • より小さなシートにパッキングされたレイアウトをより大きなシートにマージして、材料をより効率的に使用できます。

  • 大きなシートの在庫が利用できない場合は、より大きなシートにパッキングされたレイアウトをより小さなシートに分割できます。

  • 複数のレイアウト（異なるマシンからのものでも）をマージすることで、パッキング効率を高めることができます。

  • これを使用するには、1 つ以上のレイアウトを選択し、Adapt/Compact…​ をクリックして作業領域でウィザードを開きます。

  • 左ペインにはすべての選択したレイアウトが表示され、Parts ペインにはレイアウト部品が表示されます。

  • ターゲットマシンとシート材料を選択し、next をクリックして再ネスティングを実行します。

  • 新しいネスト結果が結果ペインに表示されます。

  • next をクリックして、適合または圧縮されたレイアウトを保存します。

レイアウトの分割

Split layouts…​ オプションを使用すると、ツーリングやネスティングをやり直すことなく、数量を変更することで既存のレイアウトを複数のレイアウトに分割できます。

この機能は、特に次のシナリオで役立ちます:

  1. 残りの数量を後の生産のためにスケジュールしながら、合計数量の一部をすぐに生産する必要がある場合。

  2. ワークフローとリソース利用を最適化するために、生産要件を複数のシフトまたは日にわたって分配する必要がある場合。

  3. 特定のマシンが一時的に利用できないか占有されており、現在の生産制約に対応するためにレイアウトを調整する必要がある場合。

レイアウトを分割するには、次の手順を実行します:

  • Layouts ビューで、必要なレイアウトを選択します。

  • Split layouts…​ をクリックします。

  • New Copies に必要な値を入力します。

  • OK をクリックします。

選択したレイアウトが、調整された数量で 2 つのレイアウトに分割されます。
