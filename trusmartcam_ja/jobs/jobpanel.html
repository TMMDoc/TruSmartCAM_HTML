ジョブパネル

このセクションでは、ジョブインスタンスを管理するために使用する Export outputs、Reset job…​、Mark complete…​、Export job…​ などのジョブ関連のアクションについて説明します。

Open in read-only mode for viewing
選択したジョブを読み取り専用モードで開きます。

Check-out the document for editing
選択したジョブの編集を有効にします。

Delete
選択したジョブを削除します。

View Report
選択したジョブの生産レポートを開きます。

Export Outputs

選択したジョブ用に生成されたマシン対応の出力ファイル（NC ファイルとレポート）をエクスポートします。

Plan Job…​

選択したジョブ内の部品のネストされたレイアウトを生成します。

Reset Job…​

ジョブ用に生成されたすべてのレイアウトを削除し、その部品を計画可能な状態にリセットします。

Mark Complete…​

生産後にジョブとそのすべてのネストを完了としてマークします。

Export Job…​

完全なジョブを、再利用または別のシステムにインポートできるパッケージとしてエクスポートします。

Prev / Next / Layout

選択したジョブ内の前または次のレイアウトに移動します。

並べ替えとフィルター

これらのフィルターを使用して、Same Customer、Same Part を共有する他のジョブを表示します。

Export outputs

  • 必要なジョブを選択します。

  • Export outputs をクリックします。

  • これにより、選択したジョブ用に生成されたマシン対応の出力ファイルがエクスポートされます。

  • Export Outputs は、Factory Settings で構成されたデフォルトの場所に保存するか、Browse…​ を使用してカスタムの場所に保存できます。

  • ジョブのマシン出力ファイル（NC やレポートなど）のみをエクスポートします。

  • これらのファイルは生産に直接使用され、マシンに送信できます。

Reset job…​

生成されたすべてのレイアウトを削除し、部品を再度計画できるようにして、選択したジョブをリセットします。

ジョブをリセットするには:

  • ジョブを右クリックして Reset job…​ を選択します。

  • これにより、選択したジョブの既存のネストされたレイアウトがすべて削除され、そのすべての部品が計画可能な状態にリセットされます。

  • レイアウトに他のジョブの部品が含まれている場合、それらの部品もリセットされます。

Export job…​

  • 必要なジョブを選択します。

  • Export job…​ をクリックします。

  • このオプションは、完全なジョブを、再利用または別のシステムにインポートできるパッケージとしてエクスポートします。

  • エクスポートされたデータには、ジョブを再作成するために必要なすべての情報が含まれます:

    • 部品の詳細と数量（CSV ファイル）。

    • レイアウトとネスティングデータ（CSV / FXYLT ファイル）。

  • エクスポートされたファイルは、構成されたエクスポートの場所にジョブフォルダーとして保存されます。

  • このオプションは、ジョブ全体の転送、共有、またはバックアップに使用されます。

Mark complete…​

  • ジョブがマシンで処理されたら、Job パネルを開いて Mark complete…​ を選択します。

  • ジョブが完了としてマークされると:

    • ジョブ下のすべてのネストが完了としてマークされます。

    • ジョブはグレー表示になり、リストの末尾に移動され、緑のチェックマークとともに表示されます。

    • ジョブ下のすべてのレイアウトがアクティブなレイアウトリストから削除されます。

    • 部品とジョブのステータスが更新され、処理された数量が完了状態に移動します。

    • ジョブ内のすべてのレイアウトの出力ファイルが、重複使用を避けるためにマシン出力の場所から削除されます。
