Interactive nesting

Interactive nesting は、単一の部品、ジョブ内のいくつかの部品、単一のジョブ、または複数のジョブのネスト計画を作成するために使用できます。マシンと材料を選択し、シートパラメーターを設定し、ネスティング結果をインタラクティブに確認できます。

部品またはジョブを右クリックして、Plan Part…​/Plan Job…​ → Run Interactive Nesting…​ オプションを選択します。

  • Interactive Nesting ウィンドウが開きます。

  • デフォルトでは、interactive nesting ウィンドウは Select Machine & Material ページに切り替わります。

  • マシンは、利用可能な生産負荷を示すカラーバーとともに表示されます:

    • 緑のバー: 予定時間

    • グレーのバー: 利用可能な時間（8 時間シフトのうち）

  • 各マシンの下で、選択した部品がその素材（部品/合計数量）とともにグループ化されます。

  • 部品にマシン用の有効なツーリングソリューションがない場合、その部品と材料は、指定されたマシンの処理では無視されます。

  • ある素材が 1 つのマシン用に選択されている場合、それは他のマシンでは利用できません。

  • マシンのネスト計画が設定されたら、優先するシートを選択し、Priority、Quantity、Margins などのシートパラメーターを上書きします。

  • シートをフィルターして、All Sheets、Standard Sheets、または Remnant Sheets を表示できます。Next をクリックします。

この段階では数量を増やすことはできません。シート在庫数量と同じままにするか、減らしてネスティング結果を確認するかのいずれかです。

  • Update Qty が interactive nesting plan ウィンドウに表示されます。

  • デフォルトでは、Pick All (F5) はすべての部品をネスティングに含めます。または、手動で優先部品を選択して部品数量を調整できます。Next をクリックします。

  • ネスティングが開始され、シートにネストされた部品が青色のステータスで更新されます。

  • マシンの生産負荷は、ネスト結果に基づいて更新されます。

  • ネストされたレイアウトは縮尺どおりに描画され、Nest Results タブに表示されます。

  • 一部の部品がネストされないままの場合、Some parts remain unnested というメッセージが表示されます。これらの部品は元のジョブに残ります。

    • ネストされない理由は、ネスティングに使用できるシートがないことが考えられます

  • Interactive Nest 結果には次のプレフィックスが付きます: factory → settings → Job → Nest settings、Interactive sheet-name prefix。

  • interactive nest レイアウトには、文字 L のプレフィックスが付きます。
