新しい材料とシートの追加

新しい材料とシートの追加

シート管理には、Factory アイコンをクリックして sheets を選択することでアクセスできます。これにより、セットアップされた材料の概要が表示されます。左側に一覧表示されている任意の材料を選択すると、利用可能なシート、板厚、サイズ、数量が表示されます。

新しい材料を追加するには、factory の sheets ページから Add new → New Material…​ をクリックします。

Material、Raw Material、Thickness と材料パラメーターを入力します。OK をクリックします。

材料の表示

factory → Sheets の View…​ オプションには次のオプションがあります。

  • Expand All: すべての材料カテゴリを展開します。

  • Collapse All: すべての材料カテゴリを折りたたみます。

  • Show All Materials: シート在庫に関係なく、すべての素材を一覧表示します。

  • Show Inventory Materials: シート在庫がある素材のみを一覧表示します。

太字で表示されている素材の板厚は、シートが利用可能であることを表します。

シートの追加

新しいシートを追加するには、factory の Sheets ページから Add new → New Sheet をクリックします。シートパラメーターを変更します。

  • Search Sheets (Ctrl + F)…​: サイズ、圧延方向、コメント、ヒート番号、残材、蒸発に関してシートをフィルターします。

  • スライダー (+ / –): シートプレビューのズームレベルを調整します。

  • Filter by: 選択したオプション（Width、Height、Area、Quantity、Grain、または Type）に基づいてシートプレビューを制御します。

材料またはシートの編集または削除は、部品がその材料に割り当てられる前、またはレイアウトがそのシートにネストされる前にのみ行うことができます。

この段階では材料名の変更はできません。そのため、新しい材料を作成する必要があります。
