サーバーのインストール

以下の手順に従って、SQL とともに TruSmartCAM サーバーをインストールします。

管理者権限

このインストールを実行するには、ユーザーが管理者権限を持っている必要があります。

  • Setup.TruSmartCAM.<version>.exe を実行してインストールを開始します。

Version は数値です。

  • ライセンス契約を読み、I accept the agreement を選択して、Next をクリックします。

ステップ 1: インストール場所

  • インストールディレクトリを指定するか、インストールのデフォルト C:\Program Files\TRUMPF\TMM\Praxis を受け入れて、Next をクリックします。

    • C:\Program Files\TRUMPF\TMM\Praxis - インストールフォルダーには、次のフォルダーが含まれます: Bin、MetaCAM、Samples、Tracker。

    • C:\ProgramData\TRUMPF\TMM\Praxis - データフォルダーには、次のフォルダーが含まれます: TruSmartCAM、TecZone、MetaCAM。

ステップ 2: コンポーネントの選択

インストールタイプ コンポーネント

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

TecZone、MetaCAM、RightAngle（Bend Controller）、Vulcan（Laser Machine Controller）などのすべてのステーション端末を選択します

Custom

ユーザーの選択によって選択します。

  • Full Installation を選択します。TruSmartCAM Tools から Code Senders と Bend Code Senders を選択します。すると、インストールタイプが Custom に変わります。Next をクリックします。

ステップ 3: Install SQL Server の選択

SQL Express 2022 のインストールは、TruSmartCAM サーバーにのみ必要です。このオプションは、Client および Sync のインストールでは利用できません。また、これは初回のみチェックがオンになってインストールされ、それ以降は無視できます。TruSmartCAM サーバーに SQL がすでにインストールされている場合、ユーザーはステップ 3 を無視できます。

  • Select Additional Tasks で: Install SQL Express をクリックし、Next をクリックします。

  • Ready to Install で: すべてのインストール機能をまとめて、Install をクリックします。

ステップ 4: SQL Server のインストール

TruSmartCAM コンポーネントがインストールされると、インストーラーは SQL サーバーのインストールを続行します。ライセンス契約を受け入れて続行し、デフォルトのオプションで SQL Express をインストールします。

インストールが完了したら、Close をクリックしてインストールを完了します。

Windows のバージョンによっては、SQL インストールを閉じると再起動を求められる場合があります。

ステップ 5: Windows デスクトップショートカット

  • SQL のインストール後、システムが再起動しない場合は、Launch TruSmartCAM チェックボックスを選択して Finish をクリックします。

  • システムが再起動する場合は、デスクトップの Launch TruSmartCAM ショートカットアイコンを起動するか、Windows のスタートプログラムで TruSmartCAM と入力して Run as administrator を実行します。

Server installation : TruSmartCAM と TruSmartCAM License のショートカットアイコンがデスクトップに表示されます。
Client/SYNC Installation : TruSmartCAM ショートカットアイコンのみがデスクトップに表示されます。

ステップ 6: ライセンス登録

  • Serial Number フィールドに、Trumpf Metamation サービスチームから提供された TruSmartCAM Serial key を入力します。"Registered to" フィールドに <Company Name> と E-Mail を入力します。OK をクリックします。

ネットワークファイアウォールがライセンス登録をブロックする場合、または TruSmartCAM サーバー PC にインターネットがない場合、TruSmartCAM ライセンスはオフラインアクティベーションで行われます。C:\ProgramData\TRUMPF\TMM\Praxis フォルダーの Prax.request を Trumpf Metamation サービスチームにメールで送信します。Trumpf Metamation チームが Prax.lock を提供するので、これをこのフォルダーにドロップする必要があります。

ステップ 7: 初回の一度限りの構成

  • Database Name を入力し、Data Storage Location を設定します。Use SQL Server チェックボックスを選択し、データベースに接続する SQL サーバー名を選択します。OK をクリックします。

  • TruSmartCAM デスクトップクライアントが開き、下部に Database Connection Succeeded と表示されます。

  • TruSmartCAM、TecZone、MetaCAM の構成ファイルは、デフォルトの構成マシンで、または TruSmartCAM ライセンスマシンに対して作成されました。同じ構成がすべての TruSmartCAM クライアント間で共有されます。

Welcome 画面には、Windows ユーザーの LoginName が TruSmartCAM の Login および Name として表示されます。最初の TruSmartCAM ユーザーは Site Admin と見なされます。Email と Password を入力します。OK をクリックします。

次回のためにログイン認証情報を保存するには、Remember me チェックボックスを選択します。Remember me チェックボックスをオフにすると、TruSmartCAM アプリケーションを起動するたびにログインとパスワードのダイアログが表示されます。

ステップ 8: TruSmartCAM サインイン

  • TruSmartCAM を閉じて、再度開きます。システムは TruSmartCAM のログイン認証情報を入力するように求めます。

  • ログインしているユーザー名は、TruSmartCAM アプリケーションのヘッダーにあるユーザーアイコンの横に表示されます。

  • ユーザーアイコンにカーソルを合わせると、システムは次を表示します:

    • ユーザーロール（例: Programmer、Admin）。

    • ログアウトのショートカット: Ctrl+L。

  • ユーザーアイコンをクリックすると、次のことができるメニューが開きます:

    • Edit information…​ - プロファイルの詳細を更新します。

    • Change password…​ - アカウントのパスワードを変更します。

    • Sign out - アプリケーションからサインアウトします。

    • Cancel - 変更を加えずにメニューを閉じます。

ステップ 9: ファクトリーマシンの構成

  • TruSmartCAM License [すべてのマシンがライセンスビットを有効化] : デフォルトの TruSmartCAM マシンと材料がファクトリー構成と見なされます。

  • TruSmartCAM License [デモなし、一部のマシンビットが有効] : それらの一部のマシンとデフォルトの材料がファクトリー構成と見なされます。

  • 次の場所から新しい部品を (Open → Import) し、 C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts 部品が正常にインポートされたかどうかを確認します。

注記 1: TruSmartCAM Monitor

  • Engine インストールありの TruSmartCAM Monitor（Site admin 権限）:

    • Engine ありの TruSmartCAM Monitor と Site Admin の TruSmartCAM 権限には、次のオプションがあります:

      1. TruSmartCAM の構成、TecZone、MetaCAM の構成をすべての TruSmartCAM クライアントにプッシュします。また、新しい TruSmartCAM ユーザーログインを作成する権限もあります。

      2. Show Agents は、TruSmartCAM ライセンスに対して自動化タスクを実行するために利用可能なエンジンの総数を表示します。

  • Engine インストールなしの TruSmartCAM Monitor（Site admin 権限）:

  • Engine インストールなしの TruSmartCAM Monitor（Site Admin 以外の権限）:

TruSmartCAM アプリケーションを実行する PC には、Engine TruSmartCAM コンポーネントがインストールされている必要があります [サーバー PC または任意のクライアントインストール]。Engine TruSmartCAM コンポーネントがインストールされた PC は、すべての自動化タスクを実行するために 24 時間 365 日稼働している必要があります。
注記 2: OpenGL

  • TruSmartCAM アプリケーションを開くとすぐに閉じてしまい、pmonitor もタスクバーに表示されません。

  • これは OpenGL の問題を表しています。

  • これを確認する別の方法: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts を開くと、OpenGL の問題に関するエラーダイアログが表示されます。

* C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini の options セクションを GLVersion=1 で更新すると、TruSmartCAM アプリケーションが正常に開きます。

[Options]
GLVersion=1.0
