ポート要件

TruSmartCAM Server : 7371

サーバーは、この TCP ポートでクライアントの要求を待機します。サーバーコンピューターでは、このポートへの受信接続を許可する必要があります。

Floating License Server : 5776

Floating License Server は、このポートでライセンス要求を待機します。フローティングライセンスサーバーコンピューター（TruSmartCAM サーバー）では、このポートへの受信接続を許可する必要があります。

クラウドへのライセンス接続 : 7567

このポートは、TecZone（曲げソフトウェア）と Floating License Server が Metamation Cloud にライセンス要求を送信するために使用します。そのため、ライセンスのアクティベーションと更新のために、このポートで送信接続を許可する必要があります。

インストールとサポートの要件

  • TruSmartCAM アプリケーションのインストールには管理者権限が必要です。

  • Contractor VPN またはセキュアな接続を介したリモート診断ツール。
