ツーリングパネル

このセクションでは、ツーリングインスタンスを管理するために使用する Export outputs、Check Tooling、Suppress Tooling、Set as Base-Flat…​、Copy Tooling などのツーリング関連のアクションについて説明します。

Open in read-only mode for viewing
選択したツーリングを読み取り専用モードで開きます。

Check-out the document for editing
選択したツーリングの編集を有効にします。

Export Outputs

選択したツーリングの出力を構成された宛先にエクスポートします。

Check Tooling

変更を加えずに既存のツーリングを検証し、検証が失敗した場合はステータスを更新します。

Copy Tooling…​

選択した参照ツーリングから punch、シーケンス、back gauge のセットアップをコピーし、可能な限り他のソリューションに適用します。

Set as Base-Flat…​

選択した曲げまたは折り曲げツーリングを、切断ソリューションを生成するための参照フラットサイズとしてマークします。

Re-tool…​

他のツーリングに影響を与えずに、部品の選択したツーリングを再処理します。

Suppress Tooling

選択したツーリングを抑制して、さらなる処理と出力生成から除外します。

Prev / Next / Part

前または次のツーリングに移動するか、親部品に戻ります。

並べ替えとフィルター

すばやく参照できるように、選択したツーリングと類似の特性を共有する他のツーリングを表示します。

Export Outputs

このオプションは、Factory Settings で構成された宛先に部品の出力をエクスポートします。（Bend Settings および Cut Settings を参照）

部品全体ではなく、選択したツーリング操作に関連付けられたツーリングのみがエクスポートされます。

エクスポートされるファイルは操作のタイプに依存します。曲げと折り曲げの操作では、NC ファイルとレポートが生成されます。切断とパンチの操作では、部品ファイルのみがエクスポートされます。

Check Tooling

  • CAM 設定に変更があった場合や曲げ工具が失われた場合でも、部品を Re-tool する必要はありません。

  • 代わりに、Check Tooling を使用して、変更を加えずに既存のツーリングを検証します。

  • 検証が失敗した場合、そのインスタンスのツーリングステータスが更新され、関連する出力ファイルが削除されます。

  • Check Tooling は、以前に Ignore Errors を使用して手動で上書きされたエラーがある部品も検出し、必要に応じてそのステータスをエラーに更新します。

Copy tooling

Copy tooling を使用すると、あるソリューションの曲げツーリングを他のソリューションにすばやく適用でき、時間と手間を節約できます。

これは、選択した参照ツーリング（ソリューション）から punch、シーケンス、back gauge のセットアップをコピーし、同じ設定を他のすべてのソリューションに適用しようとします。

  • コピーしたセットアップがターゲットマシンで実行可能な場合、保存されて使用されます。

  • セットアップが実行不可能な場合、そのマシンの元のツーリングは変更されません。

たとえば、マシンごとに異なるツーリングがある場合があります:

  • ここでは、Machine 5230X 4A は Gooseneck punch を使用し、Machine 5230SX 6A は Pointed punch を使用しています。

Machine 5230X 4A で Copy Tooling…​ を使用すると、Gooseneck のセットアップを他のすべてのマシンにコピーしようとします。

同じ punch、シーケンス、back gauge の設定が可能な限り適用されます。コピーしたセットアップが使用できない場合、元のツーリングは変更されません。

Copy tooling を適用すると、Gooseneck のセットアップが、実行可能な他のすべてのマシンに正常に適用されました。

Set as Base-Flat…​

Set as Base-Flat…​ 機能は、切断ソリューションを生成するための参照フラットサイズとして、どの曲げまたは折り曲げツーリングを使用するかを定義します。ツーリングが Base-Flat としてマークされると、TruSmartCAM はそのマシンに基づいて部品のフラットサイズを更新し、それに応じて切断ソリューションを再生成します。Base-Flat ツーリングは、UI で青い枠線で表示されます。

異なる曲げマシンは、同じ部品に対してフラットサイズにわずかな違いを生じる場合があります。ツーリングを Base-Flat として設定すると、TruSmartCAM はそのマシンのフラットサイズをマスター参照として使用し、切断ソリューションを自動的に再計算します。

自動 Base-Flat 選択

ファクトリー設定 Apply flat correction during bending が有効になっている場合:

  • TruSmartCAM は、部品のインポート時に、（最大曲げ長テーブルを含む）曲げツーリングを Base-Flat として自動的に設定します。

  • 選択した曲げツーリングでエラーが発生した場合や実行不可能な場合、TruSmartCAM はインテリジェントに切り替えて、別の有効な曲げツーリングを Base-Flat として設定します。これにより、フラットサイズの参照と切断ソリューションが、手動の介入なしに常に一貫性を保ち有効なままになります。

拡張された Base-Flat 管理

TruSmartCAM は、曲げまたは折り曲げツーリングの編集を保存するときに、Save to Praxis ダイアログで Base-Flat オプションを提供します。これらのオプションは、OK 状態のツーリングにのみ表示され、フラットサイズと切断ソリューションが正確なままになるようにします。

Set as Base-Flat and calculate cutting solution

このオプションは、ツーリングを初めて Base-Flat としてマークし、対応する切断ソリューションを自動的に生成するために使用されます。

次の場合に表示されます:

  • ツーリングが現在 Base-Flat としてマークされていない。

  • ユーザーが編集のためにツーリングをチェックアウトし、変更を保存している。

このオプションを使用するには、曲げまたは折り曲げツーリングをチェックアウトし、曲げパラメーターやフラットサイズの変更など、必要な変更を加えます。Ctrl+S を押して変更を保存します。Save to Praxis ダイアログで Set as Base-Flat and calculate cutting solution を選択し、OK をクリックします。TruSmartCAM はツーリングを Base-Flat として設定し、更新されたフラットサイズを使用して切断ソリューションを生成します。

Update the base-flat and re-calculate cutting solution

このオプションは、ツーリングがすでに Base-Flat としてマークされていて編集されており、フラットサイズと切断ソリューションを再生成する必要がある場合に使用されます。

次の場合に表示されます:

  • ツーリングがすでに Base-Flat としてマークされている。

  • ユーザーがチェックアウトし、編集し、変更を保存している。

既存の Base-Flat ツーリングを編集するときは、必要に応じて曲げパラメーターまたはフラットサイズのジオメトリを更新します。Save to Praxis ダイアログで Update the base-flat and re-calculate cutting solution を選択します。その後、TruSmartCAM は Base-Flat ツーリングを更新し、最新の変更を反映するために関連するすべての切断ソリューションを再生成します。

一度に Base-Flat として設定できる曲げツーリングは 1 つだけです。

Base-Flat が変更されると、既存の切断ソリューションが自動的に再処理されます。

この機能は、TruSmartCAM 内の曲げツーリングと折り曲げツーリングの両方で利用できます。

Re-tool

このオプションは、部品の選択したツーリングを再処理します。

ツーリングパネルで必要なツーリングを右クリックし、Re-tool…​ をクリックします。

続行する前に確認ダイアログが表示されます。

Yes をクリックして再ツーリングを続行するか、No をクリックして操作をキャンセルします。

選択したツーリングのみが再ツーリングされます。部品に関連付けられた他のツーリングは影響を受けません。選択したツーリングに関連する既存の出力は、再ツーリングプロセス中に削除されて再生成されます。

ツーリングデータが古い、または不正確な場合、あるいはマシンやツーリングの構成に変更が加えられた場合に、このオプションを使用します。

Ignore errors

  • ツーリングされたインスタンスに警告が表示されても、それを続行したい場合は、Ignore errors をクリックして警告を上書きできます。

  • これにより、ツーリングに問題があった場合でも、システムはそのインスタンスの出力ファイルをエクスポートできます。

Ignore Errors は、警告を安全に無視できることが確実な場合にのみ使用してください。実際のエラーを上書きすると、マシンの損傷や安全上のリスクにつながる可能性があります。

ツーリングの抑制/抑制解除

  • マシンが非アクティブな場合や、特定の部品を特定のマシンで処理したくない場合は、Suppress Tooling を使用して、そのマシンでのネスティングからその部品を除外します。

  • 抑制後、ツーリングされたインスタンスにマウスを合わせると、「Tooling suppressed by <User name> on <Date Time>」のようなメッセージが表示されます。

  • Suppress tooling は、そのマシンと部品の出力ファイルを削除します。

  • Unsuppress tooling を使用して、そのマシンでの部品のツーリングステータスを復元します。

  • 抑制が解除されると、それぞれの出力ファイルが再度生成されます。
