フィルターの保存

フィルターの保存

保存されたフィルターを使用すると、部品、ジョブ、レイアウトで頻繁に適用する条件を再利用でき、ワークフローを効率化できます。各モジュールにはデフォルトのフィルターが用意されていますが、必要に応じて Site Admin または Programmer が追加のフィルターリストを作成できます。保存されたフィルターを再利用することで時間を節約し、検索全体で一貫性を保つのに役立ちます。

  • アイコンをクリックして、デフォルトのフィルターを表示します。

フィルターを保存する手順

  • アイコンをクリックし、任意のフィルター項目を選択します。

  • 選択したフィルター項目のドロップダウンメニューから、オプションを選択します。選択した条件の横にチェックマークが表示されます。

  • 条件を適用するには、 アイコンをクリックしてから Add Condition Ctrl++ を選択します。この手順を繰り返して複数の条件を追加できます。

  • 条件付きで選択したフィルターを保存するには、Save Filter…​ Ctrl+S をクリックします。

  • 名前を入力してから Save をクリックします。

  • Save Filter ダイアログから、以前に保存したフィルターを削除することもできます。

  • これらのフィルターはデフォルトのフィルターリストに保存されます。ここでは Material がデフォルトリストに保存されます。

SiteAdmin と Admin が作成したフィルターは、すべてのユーザー間で共有されます。Programmer と Operator が作成したフィルターは、Programmer と Operator のユーザーロールにのみ共有されます。

フィルターコマンド

コマンド アイコン ショートカット 説明

Clear Selection

Ctrl+X

選択したすべての選択肢を解除し、フィルター項目ビューを更新します。

Select Highlighted

Ctrl+A

強調表示されたすべての選択肢を選択します。選択したフィールドで項目の強調表示が適用できない場合、このコマンドは無効のままになります。

Match All

&

選択したすべての条件を満たす項目のみを表示します。

Pin In/Out Menu

Ctrl+Down/Up

ピン留めすると、現在のフォーカスが別のウィンドウに移動しても、ドロップダウンメニューは開いたままになります。

Close Menu

Esc

ドロップダウンメニューを閉じます。
