部品パネル

このセクションでは、部品インスタンスを管理するために使用する Re-import、Re-tool、Rename、Export outputs などの部品関連のアクションについて説明します。

Open in read-only mode for viewing
選択した部品を読み取り専用モードで開きます。

Check-out the document for editing
選択した部品の編集を有効にします。

Delete
選択した部品を削除します。

New…​

選択した部品を新しいオーダー、ジョブ、またはアセンブリに変換できます。

Export Outputs

部品の出力を構成された宛先にエクスポートします。

Re-import…​

選択した部品を再度インポートできます。

Re-tool…​

選択した部品を再処理できます。

Rename…​

選択した部品の名前を変更します。

Assign Material…​

選択した部品に関連付けられた材料を指定します。

Assign Customer…​

選択した部品に関連付けられた顧客を指定します。

Rolling direction

材料が圧延される方向を定義します。利用可能なオプションは None、Horizontal、Vertical です。

Prev / Next / Toolings

前または次の部品またはツーリングに移動します。

並べ替えとフィルター

これらのフィルターを使用して、選択した部品と同じ属性を共有する他の部品を表示します: Same Material、Same Customer、Same Bend count、または Same State。

Re-import

  • 任意の部品を右クリックして Re-import…​ をクリックします。

  • 自動ツーリングされたインスタンスと手動ツーリングされたインスタンスを含む、すべてのマシンの選択した部品ツーリングインスタンスがクリアされます。

  • 既存の出力ファイル（CAD、Bend、Cut）が削除されます。

  • 部品が再インポートされ、すべてのマシンに対して新しい CAD 検証とツーリングが適用されます。

  • 更新されたツーリング結果に基づいて、新しい出力ファイルが作成されます。

Re-tool

  • 任意の部品を右クリックして Re-tool…​ をクリックします。

  • すべてのマシンがデフォルトでオンになり、Laser、Punch、Panel、Press brake としてグループ化されます。

  • OK をクリックして続行します。これにより、選択したマシンの自動ツーリングされたインスタンスと手動ツーリングされたインスタンスの両方が削除され、関連する出力ファイルが削除されます。

  • Retain existing outputs チェックボックスを選択すると、以前に出力が削除された部品のみが再ツーリングされ、他の出力はそのまま保持されます。オフにすると、選択したマシンのすべての出力ファイルが削除され、再ツーリング中に再生成されます。

  • いずれかのマシンの CAM 設定が変更された場合は、そのマシンを選択して部品を Re-tool します。

  • 工具（LTT、punch、または bend）が変更されたか見つからない場合は、マシンを更新し、影響を受けた部品のみを Re-tool します。

Rename

このセクションでは、TruSmartCAM で 1 つまたは複数の部品の名前を変更する方法を説明します。

  • 部品を右クリックして Rename…​ をクリックします。

  • 現在の部品名を表示する名前変更確認ダイアログが表示されます。

  • 新しい名前を入力し、チェック ✓ アイコンをクリックして確定するか、クロス ✗ アイコンをクリックして名前変更操作をキャンセルします。

  • 複数の部品の名前を変更するには、必要な部品をすべて選択し、そのいずれかを右クリックして Rename…​ をクリックします。

  • 選択した部品の総数を表示する確認ダイアログが表示されます。

  • 各部品について、新しい名前を入力し、チェック ✓ アイコンをクリックして 1 つずつ確定します。

  • 誤って部品を選択した場合は、クロス ✗ アイコンをクリックしてキャンセルします。あるいは、部品を右クリックして Cancel Rename をクリックして名前変更をスキップできます。

Export outputs

このオプションは、Factory Settings で構成された宛先に部品の出力をエクスポートします。（Bend Settings および Cut Settings を参照）

出力場所は、Bend、Fold、Cut のそれぞれの出力設定で個別に定義されます。曲げ、折り曲げ、切断の操作に関連するすべてのツーリングが、部品全体についてエクスポートされます。

エクスポートされるファイルは操作のタイプに依存します。曲げと折り曲げの操作では、NC ファイルとレポートが生成されます。切断とパンチの操作では、部品ファイルのみがエクスポートされます。

部品の材料割り当て

Material not assigned ステータスの部品は、さらなる処理の前に更新する必要があります。以下の手順で材料を割り当てる方法を説明します。

  • Material not assigned ステータスを表示する部品を右クリックして Assign Material…​ を選択します。

  • Assign Material ウィンドウが開きます。

  • ダイアログには 4 つのセクションがあります。

    • Suggestions - インポートされた部品の板厚に基づいて素材を自動的に提案します。

    • All Materials - TruSmartCAM で定義されたすべての材料タイプを一覧表示します。

    • All Raw-Materials - システムで利用可能なすべての素材を表示します。

    • Used Raw-Materials - すばやくアクセスできるように、最近使用した素材を表示します。

  • 上部の Search フィールドを使用して、材料をすばやく見つけられます。たとえば、"steel" と入力すると、3 つのセクション全体で一致するすべての材料が表示されます。

  • フィルターされたリストから、Raw-Material リストの必要な材料（例: Steel-25）を選択します。

  • 選択した材料が部品に割り当てられます。

Rolling direction

Rolling direction は、部品内の圧延方向の向きを指し、部品の切断と処理方法に影響を与える可能性があります。このオプションを使用すると、部品ライブラリ内の部品の Rolling direction を指定できます。選択した方向に基づいて、部品は利用可能なマシンで切断するための正しい向きに配置されます。

  • 部品ライブラリまたはジョブウィンドウ内の任意の部品タイルを右クリックします。

  • 優先する圧延方向を選択します:

    • None

    • Horizontal

    • Vertical

  • 選択した圧延方向に基づいて、部品は利用可能なすべての切断マシンに対して自動的に再ツーリングされます。
