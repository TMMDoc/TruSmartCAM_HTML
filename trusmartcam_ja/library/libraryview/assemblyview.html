アセンブリから静的ネストを作成する

Interactive nesting ウィザードを使用して、アセンブリの静的ネストを生成できます。これらのネストは、選択したアセンブリにのみ関連付けられた固定レイアウトです。

  • assys ビューに切り替えます。

  • 必要なアセンブリを右クリックして Create Nests…​ を選択します。

  • Interactive Nesting ウィザードが開きます。

  • デフォルトでは、Interactive nesting ウィザードは Select Machine & Material ページに切り替わります。

  • マシンは、利用可能な生産負荷を示すカラーバーとともに表示されます。

    • 緑のバー: スケジュールされた時間

    • グレーのバー: 利用可能な時間（8 時間シフトのうち）

  • 各マシンの下で、選択した部品がその素材（部品数/総数量）とともにグループ化されます。

  • 部品にマシンの有効なツーリングソリューションがない場合、その部品と材料は特定のマシンの処理対象から無視されます。

  • あるマシンに対して素材が選択されている場合、その素材は他のマシンでは使用できません。

  • マシンネスト計画が設定されたら、優先するシートを選択し、Priority、Quantity、Margins などのシートパラメーターを上書きします。

  • シートをフィルターして All Sheets、Standard Sheets、または Remnant Sheets を表示できます。next をクリックします。

この段階で数量を増やすことはできません。シート在庫数量と同じにするか、減らしてネスティング結果を確認できます。

  • Update Qty が Interactive nesting plan ウィンドウに表示されます。

  • デフォルトでは、Pick All (F5) はネスティングのためにすべての部品を含めますが、優先部品を手動で選択して部品数量を調整することもできます。next をクリックします。

  • ネスティングが開始され、シートにネストされた部品は青色のステータスで更新されます。

  • マシンの生産負荷はネスト結果に基づいて更新されます。

  • 一部の部品がネストされないまま残っている場合、Some parts remain unnested というメッセージが表示されます。これらの部品は元のジョブに残ります。

    • 適切なシートが利用できない場合、部品はネストされないまま残ることがあります。

  • 静的ネストを編集して、ネストされていない部品を含めることができます。

    • ネストされていない部品を挿入するレイアウトを選択し、編集のためにチェックアウトします。

  • TecZone が開きます。Pick または Pick All をクリックして、親アセンブリからネストされていない部品を選択します。

  • 必要に応じて、部品をレイアウトに配置します。

  • 生成されたネストは、識別を容易にするために親アセンブリにちなんで自動的に名前が付けられます。

静的ネストには他のアセンブリの部品を含めることはできません。混在したアセンブリネストを許可すると、他のアセンブリをリリースせずに 1 つのアセンブリをリリースできなくなるため、混在は設計上禁止されています。

板金以外のコンポーネント

  • アセンブリがインポートされると、板金部品が抽出され、部品ライブラリのアセンブリに追加されます。

  • 板金以外のコンポーネントは分離され、Components に追加されます。

  • アセンブリは Assembly Library に追加され、その BOM（部品表）には部品とコンポーネントの両方が含まれます。

  • 部品がすでに板金部品としてインポートされている場合、システムは既存のエントリを更新し、部品ライブラリから重複を削除します。

  • アセンブリを選択すると、部品とコンポーネントの両方が表示され、コンポーネントの数量がコンポーネント画像の下に表示されます（選択したアセンブリのコンポーネント数と総コンポーネント数）。

  • コンポーネントのツールチップには、名前、材料、サイズが表示されます。コンポーネントは生産中に除外されます。ネストされず、コンポーネント用のシートは生成されません。

  • サンプルのアセンブリとコンポーネントは次の場所で利用できます: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Assys\Components, これらを使用して、コンポーネントのインポートとアセンブリのワークフローをテストできます。

アセンブリからのジョブの作成

  • アセンブリを右クリックし、New…​ をクリックして、Job をクリックします。

  • New Job ダイアログで、アセンブリ数を設定し、OK をクリックしてから、必要に応じてジョブの詳細（納期や優先度など）を更新します。

  • システムはアセンブリからジョブを作成し、静的ネストをジョブネストとしてコピーして、シート数を更新します。コピーされたネストにはジョブ ID がプレフィックスとして付けられます。

  • ジョブネストは、元の静的ネストに影響を与えることなく編集または削除できます。

  • ジョブネストは、Adapt/Compact…​ または Add parts…​ を使用して再パックできます。

  • 詳細な手順については、Adapt/Compact および Add parts を参照してください。

部品がネストに表示されない場合は、ネスト編集ダイアログを確認してください。ネストされていない部品を手動で挿入できます。

保存された検索とフィルターを使用して、複数のアセンブリにまたがる部品をすばやく見つけます。

ネストをジョブにコピーするときの混乱を避けるために、明確で分かりやすいアセンブリ名とネスト名を使用してください。
