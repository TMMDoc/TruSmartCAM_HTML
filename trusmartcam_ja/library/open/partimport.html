部品のインポート

部品のインポート

部品をインポートする前に、ファイル形式が TruSmartCAM と互換性があることを確認してください。詳細については、supported file formats を参照してください。

インポート後に材料と板厚が部品にマッピングされていない場合は、部品パネルを使用して材料を割り当てます。

インポート方法

部品を部品ライブラリにインポートするには 3 つの方法があります。

  1. ファイル経由でのインポート

  2. ドラッグアンドドロップ

  3. 監視フォルダー

ファイル経由でのインポート

Import parts…​ オプションを使用して、2D または 3D の部品ファイルを部品ライブラリにインポートできます。

  • コマンドバーから open アイコンをクリックし、Import parts…​ オプションを選択します。

  • Open ダイアログが表示されます — 任意の CAD ファイル（2D または 3D）を選択します。

  • 選択した CAD ファイルのプレビューが表示されます。

  • 必要な部品を選択して Open をクリックします。

  • システムは、更新されたツーリングステータスで、利用可能なすべてのマシンに対して部品を自動でツーリングします。

ドラッグアンドドロップ

  • 部品ファイルを TruSmartCAM の部品ライブラリに直接ドラッグアンドドロップします。

監視フォルダー

監視設定を使用すると、フォルダーを監視して新しいファイルを部品ライブラリに自動的にインポートできます。

構成するには、Watch settings ページを参照してください。

  • UNC（Universal Naming Convention）パス \\192.168.1.11\<Folder path> またはマップされたドライブ M:\<Folder Path> を使用します。

  • Engine を実行している PC は、このフォルダーへの読み取り/書き込みアクセス権を持っている必要があります。

  • Watch サービスは、ローカル PC ではなく Engine PC 上でファイルを検索するため、C:\<Folder Path> のようなローカルパスは使用しないでください。

インポート構成

Use geometry comparison on same CAD revision

同じ CAD リビジョンの部品をインポートするとき、TruSmartCAM は CAD ファイルのジオメトリを既存の部品と比較できます。

  • これを有効にするには、factory → settings → Import で Revision lookup keys（例: REV）を構成します。次に、Use geometry comparison on same CAD revision オプションを有効にします。

同じ CAD リビジョンでのジオメトリ比較は、Revision lookup keys が構成されている場合にのみ機能します。

  • ここで、特定のリビジョン（例: Revision 1）で部品を部品ライブラリにインポートします。

  • 同じ部品を同じリビジョン値で再度インポートします。

  • TruSmartCAM は、新しくインポートされた CAD ファイルのジオメトリを既存の部品と比較します。

  • ジオメトリの差異が検出されると、TruSmartCAM は次のいずれかを尋ねるプロンプトを表示します。

    • 新しいジオメトリで既存の部品を Replace し、同じリビジョン値を保持します。

    • インポートを Skip し、既存の部品とそのジオメトリを保持します。

これにより、ユーザーはリビジョン値を変更せずに部品ジオメトリを更新しながら、既存の部品を置換するかどうかを制御できます。

インポートされた部品は、さらなる使用のために自動的にライブラリに追加されます。詳細については、Library を参照してください。
