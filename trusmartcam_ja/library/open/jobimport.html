ジョブのインポート

csv または xlsx からのインポート

一般的なテキスト形式でジョブをインポートすることもできます。

  • File → Open → Import Jobs をクリックすると、Open Folder ダイアログが表示されます。次を選択します: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • すべての部品が csv の場所またはルックアップフォルダーディレクトリに存在する場合、csv のフィールドに一致するすべての部品を一覧表示して new job ウィンドウが表示されます。

  • 存在しない部品は無視され、new job ウィンドウには表示されません。

  • 最初は部品ステータスは Nascent です。

  • OK をクリックすると、部品が部品ライブラリにインポートされます。

Create a blank part for the missing CAD files

スプレッドシート（.csv または .xlsx）を使用してジョブをインポートする場合、システムで利用できない CAD ファイルを参照する行が含まれていることがあります。

  • これに対処するには、Factory → Settings → Job に移動し、Spreadsheet import settings の下で Create a blank part for the missing CAD files を有効にします。

このオプションを選択すると:

  • ジョブのインポート中にいずれかの行の CAD ファイルが見つからない場合、システムは見つからない CAD ファイルの代わりに空白の部品を自動的に作成します。

  • new job ウィンドウでは、関連する CAD ファイルが見つからないことを示すために、これらの見つからない部品が黄色で視覚的に強調表示されます。

  • 見つからない部品には、CSV からのマップされたフィールド（部品名、材料、板厚、数量など）が引き続き含まれます。ただし、その部品状態は Nascent と表示され、これはまだ実際のジオメトリがない空のプレースホルダーであることを意味します。

これにより、CAD ファイルが見つからないことによるエラーなしでジョブのインポートを続行できます。空白の部品は、正しい CAD ファイルが利用可能になったときに、後で更新または置換できます。

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings → Do not show the New Job dialog if the spreadsheet has no error

  • このチェックボックスを選択すると、スプレッドシートにエラー（部品の欠落、日付の欠落、無効なデータ）がない場合、システムは New Job ダイアログを表示せずに新しいジョブを自動的に作成します。

  • このチェックボックスをオフにすると、スプレッドシートにエラーがない場合でも、ユーザーの確認のために常に New Job ダイアログが表示されます。

Prefer raw-material column over material + thickness

factory → Settings → Job → Prefer Raw-Material column over Material + Thickness

  • このチェックボックスを選択すると、システムはスプレッドシートが Raw-Material 列（例: Steel-20）を使用することを想定します。つまり、材料の種類と板厚を 1 つの列の単一の値に結合する必要があります。

  • このチェックボックスをオフにすると、システムはスプレッドシートに Material と Thickness の別々の列（例: Steel と 2.00）があることを想定します。システムはインポート中にそれらを内部的に結合します。

CSV/XLSX を使用した監視フォルダー

  • factory → Settings → Watch settings で Enable 'Live Folder' と Watch sub-folders also をオンにします。

  • 監視フォルダーのパス（UNC またはマップされたドライブ）を設定します。

  • Spreadsheet import settings で Import spreadsheet from 'Live Folder' をオンにします。

  • Spreadsheet Import オプションから Import Jobs を選択します。

  • 次をコピーします: C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv それを監視フォルダーに貼り付けます。

  • システムは CSV をチェックし、ジョブを自動的に作成しようとします。

  • CAD ファイルが見つからない場合、必要な CAD データが見つからないため、ジョブは作成されません。

CAD ルックアップディレクトリと再帰的 CAD 検索 - 未構成

  • factory → Settings → Job → Spreadsheet import settings で、CAD lookup directories が設定されておらず、Use recursive CAD search が使用されていない場合、システムは CAD ファイルを自動的に検索しません。

  • Create a blank part for the missing CAD files チェックボックスを選択すると、CAD ファイルが見つからない場合でもジョブが作成されます。

  • この場合、ジョブ内のすべての部品は nascent（空白）の部品として作成されます。これは、CAD ファイルが見つからなかったためジオメトリがないことを意味します。

CAD ルックアップディレクトリと再帰的 CAD 検索 - 構成済み

CAD lookup directories が (C:\Program Files\TRUMPF\TMM\Praxis\Samples) に設定され、factory → Settings → Job → Spreadsheet import settings で Use recursive CAD search が有効になっている場合:

  • システムは、指定されたフォルダーとそのすべてのサブフォルダーを自動的に検索して、スプレッドシートに記載されている必要な CAD ファイルを見つけます。

  • Create a blank part for the missing CAD files も有効になっているため、いずれかの CAD ファイルがまだ見つからない場合、システムはプレースホルダーとして空白の部品を作成します。
