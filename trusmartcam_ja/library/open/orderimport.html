オーダーのインポート

オーダーのインポート

オーダーは、次の方法で作成またはインポートできます。

  1. スプレッドシートファイルからオーダーをインポートする。

  2. 監視設定を介してオーダーを自動的にインポートする。

  3. 部品ライブラリ内の既存の部品からオーダーを作成する。

  4. アセンブリの静的ネストからオーダーを作成する。

スプレッドシートからオーダーをインポートする

  • Open → Import Orders…​ に移動します。

  • サポートされるスプレッドシート形式には、CSV、XLSX、XML があります。

  • 必要なスプレッドシートファイルを選択して Open をクリックします。

  • インポートプロセスは Job/Assembly のインポートワークフローと同様です。

スプレッドシートを Orders ページに直接ドラッグアンドドロップしてオーダーをインポートすることもできます。

監視設定を使用してオーダーをインポートする

  • Watch settings で Import spreadsheet from 'Live Folder' オプションを有効にします。

  • Spreadsheet import option で Import Orders を選択します。

  • オーダーをインポートするフォルダーの場所を構成します。

  • システムは、構成されたフォルダーを継続的に監視します。

  • 新しく追加されたスプレッドシートファイルは、自動的に Orders にインポートされます。

詳細な構成手順については、Watch settings のドキュメントを参照してください。

部品ライブラリからオーダーを作成する

  • 部品ライブラリから必要な部品を選択します。

  • 右クリックして New…​ → Order を選択し、New Orders ダイアログを開きます。

  • 数量、納期、優先度などの必要な詳細を入力します。

  • OK をクリックしてオーダーを作成します。

  • システムは自動的に Orders ページに切り替わります。

  • 作成されたオーダーは、ジョブ作成のために Orders Ready ページに表示されます。

アセンブリからオーダーを作成する

  • 必要なアセンブリを右クリックします。

  • New…​ → Order を選択し、New Orders ダイアログを開きます。

  • 必要な Assembly count を入力します。

  • OK をクリックしてオーダーを作成します。
