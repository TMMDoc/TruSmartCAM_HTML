Import

Output settings

Save flat pattern - このオプションを有効にすると、インポートされた部品のフラットパターンが保存されます。

Format for flat pattern - このオプションは、DXF または GEO のいずれかのファイル形式を選択するために使用されます。

Flat pattern destination - これは、フラットパターンが保存される場所です。

Import settings

Units for DXF files - これは、DXF ファイルがインポートされる測定単位です。ユーザーは mm または inch を選択できます。

Material lookup keys - 複数のルックアップエントリを、それらの間にカンマ区切りを使用して割り当てることができます。部品がインポートされると、TruSmartCAM はこれらのキーを使用して材料値を検索します。検索された値は、素材を解決するために使用されます。元の値は、部品の Misc Properties に保存されます。

Revision lookup keys - 部品がインポートされると、raw 部品ファイル（インポートされる部品ファイル）のリビジョン値が、リポジトリ内の既存のリビジョン値と比較されます。リビジョンが同じ場合、インポートは中止されます。カスタムフィールドマッピングは、DXF ファイルでもサポートされるようになりました。DXF ファイルの場合、カスタムフィールドデータは図面のテキストレイヤーまたは PPI 添付ファイルから抽出されます。

Use geometry comparison on same CAD revision - 同じ CAD リビジョンで部品をインポートするときにジオメトリを比較し、違いが検出された場合はインポートを置き換えるかスキップするようにユーザーに促します。詳細については、Import configuration を参照してください。

Part name keys - このオプションは、材料および Revision lookup keys と同様に機能します。1 つ以上の Part name keys を設定して、部品名としてファイル名の代わりに PPI Part name を使用します。

Thickness lookup keys - 複数のルックアップエントリを、それらの間にカンマ区切りを使用して割り当てることができます。部品がインポートされると、TruSmartCAM はこれらのキーを使用して板厚値を検索します。検索された値は、板厚を解決するために使用されます。元の値は、部品の Misc Properties に保存されます。

Thickness comparison fudge - これは、部品がインポートされるときに素材を検索する際に使用されます。TruSmartCAM は、材料名と板厚が解析された後に素材を解決しようとします。詳細については、以下の Thickness fudge トピックを参照してください。

Identify shapes after a flat is imported - 部品がインポートされると、部品内の内側の形状を自動的に認識して識別できます。

Shape identification fudge - shape identification fudge 値は、次のレベルで設定できます:

  1. グローバルレベル - この値は、すべての形状のデフォルトとして使用されます。

  2. 個別形状レベル - デフォルト値は、個別形状レベルで fudge 値を設定することで上書きできます。Shape Library ダイアログで形状を選択すると、fudge 値が表示されます。デフォルトでは、これは 0 に設定されており、そのような形状にはデフォルトのグローバル値が使用されます。

Rotate flat horizontally - 一般的に、切断マシンのテーブルは長方形で幅が広くなっています。ツーリングの実現可能性を高めるために、部品がインポートされた後、部品幅に沿って部品を回転させます。

Part rotation threshold - これを回転を許可する最小数として設定します。設定した値より小さい部品は回転されません。

Misc settings

Enable pre-import external tools - Creo Reader を有効にするために、pre-import external tools インポートオプションを有効にします。TruSmartCAM は、ドロップされた部品の事前抽出されたファミリインスタンスをアップロードします。インスタンス抽出は部品アップロード中（pre-import 操作として）に実行されるため、部品がアップロードされるコンピューターに Creo ソフトウェアがインストールされている必要があることに注意してください。

Ignore drawing colors in Flat thumbnails for clarity - このオプションを有効にすると、グレースケールのよりシャープなサムネイルが生成されます。画像の鮮明さのために、レイヤーの色とテキストエンティティは無視されます。

Use only one Engine for all import tasks - 有効にすると、重要なタスクに 1 つのエンジンコアのみが使用されます。

Thickness fudge

Thickness comparison fudge は、目的のシート板厚が在庫にない場合に、在庫内のシートの板厚値を比較することで、最も近いシート板厚値を選択します。

たとえば、次のように仮定します:

  1. シート板厚が 1.6 mm、材料が steel の部品があります。

  2. Thickness comparison fudge 値は 0.1 mm です。

  3. 在庫には、板厚 1.5 mm、1.55 mm、1.7 mm の steel シートがあります。

TruSmartCAM は、Thickness comparison fudge 値（0.1 mm）をインポートされたアイテム（1.6 mm）と比較した後、最も近い板厚値のシートを選択します。この場合、1.55 mm が選択されます。
