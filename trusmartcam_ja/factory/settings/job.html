Output settings

Save layout NC and reports - このオプションを有効にすると、layout NC とレポートが保存されます。

Save layout file - このオプションを有効にすると、layout ファイルが保存されます。

Output simulation preview in reports - このオプションを有効にすると、他の出力とともにツーリングシミュレーションプレビューが生成されます。これは laser/punch ツーリング用の短い GIF アニメーションです。

Do not delete program outputs on layout/job completion - このオプションを有効にすると、job/layout が完了としてマークされたときに、プログラム出力の削除操作がスキップされます。

Nest settings

Mix parts from multiple Jobs - 混合モードのネスティングをサポートします。パッキング効率を高めるために、複数のジョブの部品を一緒にネストする必要があります。

Do not auto-release layouts - これにより、すべてのレイアウトがリリース済み状態になるまで、レイアウトが生産で利用可能になるのを停止します。

Re-nesting packing cut-off - この値は、ネストされたレイアウトを承認キューに保持し、新しい部品が計画されたときに再ネストするか、生産用にリリースして関連する出力を出力フォルダーにエクスポートするかを決定するために使用されます。

Interactive sheet-name prefix - このセクションは、ネストされる部品とネスト結果をユーザーがより制御できるインタラクティブネスティングをサポートするために使用されます。インタラクティブにネストされたレイアウトには、auto-nesting とは異なる命名規則を使用します。

Update sheet inventory on nest (un)release - このオプションを有効にすると、ネストをマシンに送信するときにシート在庫が更新されます。また、マシンからネストをリコールすると、シートが在庫に戻されます。

Automate remnant inventory management - このスイッチを選択すると、ソフトウェアは残材在庫管理を自動化します。選択しない場合、残材管理はインタラクティブになります。

Auto-refresh Out-of-date layouts - チェックすると、ソフトウェアは、部品の切断ソリューションが計算された後、その部品にリンクされたすべての Out-of-date Layouts を更新します。

Automate twin-line nesting - このオプションをチェックすると、twin-line 自動化が有効になります。

Pull workflow settings

Use 'Pull workflow' - このオプションは、高度に自律的な計画およびネスティングシステムを必要とするユーザーに役立ちます。有効にすると、TruSmartCAM はオンデマンドでネスティングを計画します。

Nests per station - この値は、ステーションごとに作成するレイアウト数を設定します。

Maximum sheets per nest - この値は、一意のネストに対する最大シート数を制御するために使用されます。たとえば、大きな部品（シート全体を埋める）を含むオーダーが大量（たとえば 500）に必要な場合、TruSmartCAM は pull モードで 500 コピーの単一ネストを作成しなくなります。代わりに、最大 10 として、ネストごとに 10 コピーを作成します。

Bend programs per station - この値は、ステーションごとに作成する bend プログラム数を設定します。

Mark the task completed, when the program outputs are removed - このオプションを有効にすると、出力がターゲット出力先から削除されたときに、レイアウトが Done としてマークされます。

Spreadsheet import settings

CAD lookup directories - TruSmartCAM は、インポートされた CSV に記載された部品エントリを part library から読み込もうとします。ただし、部品が part library で利用できない場合は、このダイアログで設定されたディレクトリの順序に基づいて、ルックアップディレクトリから部品を取得しようとします。

Use recursive CAD search - このオプションを有効にすると、連続した結果に対して検索が繰り返されます。

Create a blank part for the missing CAD files - 部品が TruSmartCAM ライブラリまたはルックアップディレクトリに存在しない場合、TruSmartCAM はそれらの利用できない部品に対して空白の部品を作成します。

Do not show New Job dialog if the spreadsheet has no error - CSV エントリがクリーンな場合（つまり、DB からのデータの不一致がない、またはすべてのフィールドが適切にリストされている）、TruSmartCAM は job overview ウィンドウを表示せず、CSV がインポートまたはドロップされるとすぐにジョブを処理します。

Prefer Raw-Material column over Material + Thickness - サポートされているスプレッドシートタイプ:

  1. Pattern 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. Pattern 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Pattern 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

このオプションがチェックされていない場合、Pattern 1 がデフォルトのスプレッドシートタイプと見なされます。CSV 形式が Pattern 3 タイプの場合は、Pattern 3 もサポートします。

このオプションがチェックされ、CSV が Pattern 2 タイプの場合、TruSmartCAM は CSV の Material および Thickness フィールドから Raw Material を解決します。

Spreadsheet output settings

Export Job/Layout completion report (.csv) - このオプションをチェックすると、Layout または Job が完了したときに CSV エクスポートが有効になります。完了したレポートは、Factory → Settings → Reports 設定で指定された Reports 宛先に保存されます。
