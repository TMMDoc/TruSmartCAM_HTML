Notifications

Notifications は、システム内で発生する CAD およびツーリングエラーについてユーザーに通知します。適切な対処ができるように、問題が迅速に伝達されることを保証します。

Email notification

Email notification 機能を使用すると、ユーザーは CAD およびツーリングエラーの自動メールアラートを構成して受信できます。構成すると、関連するイベントが発生するたびに、システムは指定された受信者に自動的にメールを送信し、問題が迅速に対処されることを保証します。

メール通知を構成するには、次に移動します: factory > settings > Notifications

Notifications ページは、次のセクションで構成されます:

Notification settings

Notification settings セクションは、メールアラートがどのように生成され、受信者に配信されるかを制御します。

  • Enable email notifications - 構成された条件に基づいてシステムが通知を送信できるようにします。

  • Notification recipients - 受信者のメールアドレスを指定します。カンマ（,）またはスペースで区切ることで、複数の受信者を追加できます。

  • Send messages in batch - 複数の通知を 1 つのメールにまとめます。定義された時間間隔内に生成されたメッセージがグループ化され、メール量の削減と煩雑さの防止に役立ちます。

  • Attach tooling simulation preview where applicable - 利用可能な場合、ツーリングシミュレーションプレビューを通知メールに添付します。これは、メールから直接ツーリング関連の問題を確認するのに役立ちます。

シミュレーションプレビューを含めると、メールサイズが大幅に増加する可能性があります。

Mail settings

Mail settings セクションは、システムがメール通知を配信するために使用する送信メールサーバー構成を定義します。通知を正常に送信するには、これらの設定を正しく構成する必要があります。

  • SMTP server - 送信メールの送信に使用される SMTP サーバーアドレスを指定します（例: smtp.gmail.com）。この情報は通常、ユーザーのメールクライアントのアカウントまたは設定セクションで利用できます。

  • SMTP port - メールサーバーがインターネット経由でメールを送信するために使用するポート番号を定義します。一般的な値には 465（SSL）と 587（TLS）があります。

  • Transport protocol - アプリケーションからメールサーバーに安全にメールを送信するために使用されるプロトコルを指定します（例: SSL または TLS）。

  • Server needs authentication - SMTP サーバーの認証を有効にします。有効にすると、メールが送信される前に、ユーザー名とパスワードがサーバーによって検証されます。

  • User-name - SMTP サーバーで認証して通知を送信するために使用されるメールアカウントを指定します。

  • Password - 認証に使用されるメールアカウントに関連付けられたパスワードを指定します。

  • Sender address - 通知が受信されたときに受信者に表示される送信者メールアドレスを指定します。

  • Test…​ - テストメールを送信して、メールサーバー構成を検証します。

Test…​ をクリックして、セットアップを検証します。テストが成功すると確認メッセージが表示され、それ以外の場合は失敗の原因を示すエラーメッセージが表示されます。

  • メール通知は、インタラクティブモード（たとえば、部品の編集や手動保存中）ではトリガーされません。

  • メール配信はバックグラウンドで処理され、遅延する場合があります。

  • 処理が完了する前にシステムまたはエンジンが停止された場合、通知が配信されないことがあります。
