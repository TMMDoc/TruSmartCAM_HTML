导入 job

从 csv 或 xlsx 导入

您也可以以常见的文本格式导入 job

  • 单击 File → Open → Import Jobs，出现 Open Folder 对话框。选择 C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • 如果所有零件都存在于 csv 位置或查找文件夹目录中，则会出现 new job 窗口，列出与 csv 字段匹配的所有零件。

  • 缺失的零件会被忽略，且不会出现在 new job 窗口中。

  • 最初零件状态为 Nascent。

  • 单击 OK ，现在零件已导入到零件库中。

Create a blank part for the missing CAD files

使用电子表格（.csv 或 .xlsx）导入 job 时，有时可能会有部分 行引用了系统中不可用的 CAD 文件。

  • 要处理这种情况，请转到 Factory → Settings → Job， 在 Spreadsheet import settings 下启用 Create a blank part for the missing CAD files

选择此选项时：

  • 如果在 job 导入期间某一行缺失 CAD 文件，系统将自动 创建一个空白零件以代替缺失的 CAD 文件。

  • 在 new job 窗口中，这些缺失的零件会以黄色 高亮显示，以表明关联的 CAD 文件缺失。

  • 缺失的零件仍将保留其来自 CSV 的映射字段（如零件名称、材料、 厚度、数量等）。但是，其零件状态将显示为 Nascent，即它只是 一个尚无实际几何体的空占位符。

这确保 job 导入仍可继续进行，而不会因缺失 CAD 文件而出错 — 当正确的 CAD 文件可用时，您可以稍后更新或替换空白零件。

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • 选中此复选框时，如果电子表格没有错误（无缺失零件、 缺失日期或无效数据），系统会自动创建新 job 而不显示 New Job 对话框。

  • 清除此复选框时，即使电子表格没有错误，New Job 对话框也始终 会出现，以供用户审阅和确认。

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • 选中此复选框时，系统希望电子表格使用 Raw-Material 列（例如 Steel-20）。这意味着材料类型和厚度应组合为一列中的单个值。

  • 清除此复选框时，系统希望电子表格具有分开的 Material 和 Thickness 列（例如 Steel 和 2.00）。系统在导入期间在内部将它们组合。

使用 CSV/XLSX 的监视文件夹

  • 在 factory → Settings→ Watch settings 中选中 Enable 'Live Folder' 和 Watch sub-folders also。

  • 设置监视文件夹路径（UNC 或映射驱动器）。

  • 在 Spreadsheet import settings 中，选中 Import spreadsheet from 'Live Folder'。

  • 从电子表格导入选项中选择 Import Jobs。

  • 复制 C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv 并将其粘贴到监视文件夹中。

  • 系统检查 CSV 并尝试自动创建 job。

  • 如果 CAD 文件缺失，则不会创建 job，因为找不到所需的 CAD 数据。

CAD 查找目录和递归 CAD 搜索 - 未配置

  • 在 factory → Settings → Job → Spreadsheet import settings 中， 如果未设置 CAD lookup directories 且未使用 Use recursive CAD search，则系统 不会自动搜索 CAD 文件。

  • 如果选中 Create a blank part for the missing CAD files 复选框， 则即使 CAD 文件缺失，job 仍将被创建。

  • 在这种情况下，job 中的所有零件都将被创建为 nascent（空白）零件 — 即它们没有几何体，因为找不到 CAD 文件。

CAD 查找目录和递归 CAD 搜索 - 已配置

当 CAD lookup directories 设置为 (C:\Program Files\TRUMPF\TMM\Praxis\Samples) 且在 factory → Settings → Job → Spreadsheet import settings 下启用 Use recursive CAD search 时：

  • 系统自动在指定文件夹及其所有子文件夹中搜索电子表格中提到的 所需 CAD 文件。

  • 也启用了 Create a blank part for the missing CAD files， 因此如果仍找不到任何 CAD 文件，系统将创建一个空白零件作为占位符。
