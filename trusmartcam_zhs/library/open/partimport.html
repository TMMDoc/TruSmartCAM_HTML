导入零件

在导入零件之前，请确保文件格式与 TruSmartCAM 兼容。 有关更多详细信息，请参阅 支持的文件格式。

如果导入后未将材料和厚度映射到零件，请使用零件面板分配 材料。

导入方法

将零件导入到零件库有三种方法：

  1. 通过文件导入

  2. 拖放

  3. 监视文件夹

通过文件导入

可以使用 Import parts…​ 选项将 2D 或 3D 零件文件 导入到零件库中。

  • 从命令栏单击 open 图标，并选择 Import parts…​ 选项。

  • 出现 Open 对话框 — 选择任意 CAD 文件（2D 或 3D）。

  • 显示所选 CAD 文件的预览。

  • 选择所需的零件并单击 Open。

  • 系统为所有可用机床自动处理 tooling，并更新 tooling 状态。

拖放

  • 将零件文件直接拖放到 TruSmartCAM 零件库中。

监视文件夹

监视设置允许您监视文件夹中的新文件，并自动将其导入到 零件库中。

要进行配置，请参阅 监视设置页面。

  • 使用 UNC（通用命名约定）路径 \\192.168.1.11\<Folder path> 或 映射驱动器 M:\<Folder Path>。

  • 运行 Engine 的 PC 必须对此文件夹具有读/写访问权限。

  • 不要使用像 C:\<Folder Path> 这样的本地路径，因为监视服务 在 Engine PC 上查找文件 — 而不是本地 PC。

导入配置

Use geometry comparison on same CAD revision

当导入具有相同 CAD 修订版本的零件时，TruSmartCAM 可以将 CAD 文件的 几何体与现有零件进行比较。

  • 要启用此功能，请在 factory → settings →Import 中配置 Revision lookup keys（例如 REV）。然后启用 Use geometry comparison on same CAD revision 选项。

仅当配置了 Revision lookup keys 时，相同 CAD 修订版本上的几何体比较才能生效。

  • 现在，将具有特定修订版本（例如 Revision 1）的零件导入到零件库中。

  • 使用相同的修订版本值再次导入同一零件。

  • TruSmartCAM 将新导入的 CAD 文件的几何体与现有零件进行比较。

  • 如果检测到几何体差异，TruSmartCAM 将显示提示，询问是否：

    • Replace 使用新几何体替换现有零件，并保留相同的修订版本 值。

    • Skip 跳过导入，保留现有零件及其几何体。

这使用户能够在不更改修订版本值的情况下更新零件几何体，同时仍能 控制是否替换现有零件。

导入的零件会自动添加到库中以供进一步使用。有关更多信息， 请参阅 库。
