tooling 面板

本节介绍与 tooling 相关的操作，例如 Export outputs、 Check Tooling、Suppress Tooling、 Set as Base-Flat…​、Copy Tooling 以及用于管理 tooling 实例的其他选项。

Open in read-only mode for viewing
以只读模式打开所选 tooling。

Check-out the document for editing
启用对所选 tooling 的编辑。

Export Outputs

将所选 tooling 输出导出到配置的目标位置。

Check Tooling

在不进行任何更改的情况下验证现有 tooling，如果验证失败则更新其状态。

Copy Tooling…​

从所选参考 tooling 复制冲头、顺序和后挡料设置，并在可行的情况下将其应用于 其他解决方案。

Set as Base-Flat…​

将所选的折弯或折叠 tooling 标记为用于生成切割解决方案的参考展开尺寸。

Re-tool…​

在不影响其他 tooling 的情况下，为零件重新处理所选 tooling。

Suppress Tooling

抑制所选 tooling，使其排除在进一步处理和输出生成之外。

Prev / Next / Part

导航到上一个或下一个 tooling，或返回到父零件。

排序和筛选

显示与所选 tooling 具有相似特征的其他 tooling，以便快速参考。

Export Outputs

此选项将零件输出导出到 Factory Settings 中配置的目标 位置。（请参阅 折弯设置 和 切割设置）

仅导出与所选 tooling 操作关联的 tooling，而非整个零件。

导出的文件取决于操作类型。对于 Bend 和 Fold 操作，会生成 NC 文件和 报告。对于 Cut 和 Punch 操作，仅导出零件文件。

Check Tooling

  • 如果 CAM 设置发生更改或折弯刀具丢失，您无需重新 tooling 该零件。

  • 相反，请使用 Check Tooling 在不进行任何更改的情况下验证现有 tooling。

  • 如果验证失败，则该实例的 tooling 状态会更新，并且相关的输出文件会被移除。

  • Check Tooling 还会检测先前使用 Ignore Errors 手动覆盖错误的零件，并在需要时将其状态更新为错误。

Copy tooling

复制 tooling 功能允许您将折弯 tooling 从一个解决方案快速应用到其他解决方案， 从而节省时间和精力。

这会从所选参考 tooling（解决方案）复制冲头、顺序和后挡料设置，并尝试将相同的 设置应用于所有其他解决方案。

  • 如果复制的设置对目标机床可行，则会保存并使用。

  • 如果设置不可行，则该机床的原始 tooling 保持不变。

例如，您可能为不同的机床使用不同的 tooling：

  • 在此，机床 5230X 4A 使用鹅颈冲头，机床 5230SX 6A 使用尖头冲头。

当您在机床 5230X 4A 上使用 Copy Tooling…​ 时，它会 尝试将鹅颈设置复制到所有其他机床。

系统会在可能的情况下应用相同的冲头、顺序和后挡料设置。如果复制的设置无法 使用，则原始 tooling 保持不变。

应用复制 tooling 后，鹅颈设置已成功应用于所有可行的其他机床。

Set as Base-Flat…​

Set as Base-Flat…​ 功能定义使用哪个折弯或折叠 tooling 作为生成切割解决方案的参考展开尺寸。当某个 tooling 被标记为 Base-Flat 时， TruSmartCAM 会根据该机床更新零件的展开尺寸，并相应地重新生成切割解决方案。 Base-Flat tooling 在 UI 中以蓝色边框显示。

对于同一零件，不同的折弯机床可能会产生略微不同的展开尺寸。当您将某个 tooling 设置为 Base-Flat 时，TruSmartCAM 会使用该机床的展开尺寸作为主参考，并自动 重新计算切割解决方案。

自动 Base-Flat 选择

当启用工厂设置 Apply flat correction during bending 时：

  • 在零件导入期间，TruSmartCAM 会自动将折弯 tooling（包含最大折弯长度表的那个） 设置为 Base-Flat。

  • 如果所选的折弯 tooling 遇到错误或不可行，TruSmartCAM 会智能切换并将另一个 有效的折弯 tooling 设置为 Base-Flat。这可确保展开尺寸参考和切割解决方案始终 保持一致和有效，而无需手动干预。

增强的 Base-Flat 管理

保存折弯或折叠 tooling 编辑时，TruSmartCAM 会在 Save to Praxis 对话框中提供 Base-Flat 选项。这些选项 仅对处于 OK 状态的 tooling 显示，并确保展开尺寸和切割解决方案保持准确。

Set as Base-Flat and calculate cutting solution

此选项用于首次将某个 tooling 标记为 Base-Flat 并自动生成相应的切割解决方案。

出现于以下情况：

  • 该 tooling 当前未标记为 Base-Flat。

  • 用户已检出该 tooling 进行编辑并正在保存更改。

要使用此选项，请检出折弯或折叠 tooling 并进行所需的修改，例如更改折弯参数或 展开尺寸。按 Ctrl+S 保存更改。在 Save to Praxis 对话框中，选择 Set as Base-Flat and calculate cutting solution 并单击 OK。TruSmartCAM 会将该 tooling 设置为 Base-Flat，并使用更新后的 展开尺寸生成切割解决方案。

Update the base-flat and re-calculate cutting solution

当某个 tooling 已标记为 Base-Flat 并已被编辑，需要重新生成展开尺寸和切割 解决方案时，使用此选项。

出现于以下情况：

  • 该 tooling 已标记为 Base-Flat。

  • 用户已将其检出、编辑并正在保存更改。

编辑现有的 Base-Flat tooling 时，请根据需要更新折弯参数或展开尺寸几何形状。 在 Save to Praxis 对话框中，选择 Update the base-flat and re-calculate cutting solution。 然后，TruSmartCAM 会更新 Base-Flat tooling 并重新生成所有相关的切割解决方案， 以反映最新的更改。

一次只能将一个折弯 tooling 设置为 Base-Flat。

当 Base-Flat 更改时，现有的切割解决方案会自动重新处理。

此功能适用于 TruSmartCAM 中的折弯和折叠 tooling。

Re-tool

此选项会为零件重新处理所选 tooling。

在 tooling 面板中右键单击所需的 tooling，然后单击 Re-tool…​

在继续之前会显示一个确认对话框。

单击 Yes 继续重新 tooling，或单击 No 取消操作。

仅对所选 tooling 重新 tooling。与零件关联的其他 tooling 不受影响。与所选 tooling 相关的现有输出会在重新 tooling 过程中被移除并重新生成。

当 tooling 数据过时、不正确，或对机床或 tooling 配置进行更改时，请使用此选项。

Ignore errors

  • 如果 tooled 实例显示警告，而您仍想继续使用它，可以通过单击 Ignore errors 覆盖该警告。

  • 这将允许系统为该实例导出输出文件，即使存在 tooling 问题。

仅当您确定可以安全地忽略警告时才使用 Ignore Errors。覆盖实际 错误可能会导致机床损坏或安全风险。

抑制/取消抑制 tooling

  • 当机床处于非活动状态，或您不希望特定零件由特定机床处理时，请使用 Suppress Tooling 将该零件从该机床上的 nesting 中 排除。

  • 抑制后，将鼠标悬停在 tooled 实例上会显示类似以下的消息：“Tooling suppressed by <User name> on <Date Time>”。

  • 抑制 tooling 会移除该机床和零件的输出文件。

  • 使用 Unsuppress tooling 可恢复该机床上零件的 tooling 状态。

  • 取消抑制后，会再次生成相应的输出文件。
