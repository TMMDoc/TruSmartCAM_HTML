tooling 状态

在 TruSmartCAM 中，每个零件磁贴都直观地指示该零件在所有可用机床上的 tooling 状态。这有助于用户快速查看零件针对哪些机床进行了 tooling，以及 tooling 是否 就绪、需要审查或缺失。

  • tooling 状态使用图标和颜色指示器直接显示在零件磁贴上。

  • 每个图标代表一种机床技术（例如 Bend、Laser）。

  • 图标的颜色指示该机床当前的 tooling 状态。

下表说明了每个图标和颜色的含义，帮助用户准确解读 tooling 状态。

机床图标 描述

激光切割机

折弯机

面板折弯机

Tooling 正常

Tooling 存在警告

Tooling 不可用

tooling 错误

在 tooling 或制造准备阶段会发生 CAM（计算机辅助制造）错误。这些错误由刀具 碰撞、tooling 缺失或无效切割条件等问题引起。

以下图像显示了 tooling 期间可能显示在零件磁贴上的 tooling 错误状态示例。以下 各节介绍了每种 tooling 错误及其原因。

折弯 tooling 错误

  • Collisions detected 和 Gripper error ：折弯设置在模拟期间导致刀具或夹爪碰撞。

  • Tool Overload 和 Narrow flange or hole too close ： 折弯刀具过载，或孔位于离折弯线太近的位置，这可能会损坏零件或刀具。

  • Needs review 和 Short Punch/Die span ：tooling 设置需要手动检查，或 所选的模具/冲头跨距小于零件所需的跨距。

  • Tool Missing、Poor backguage 或 Part too big for this machine ：所需的折弯刀具 不可用、后挡料未正确配置，或零件对于所选机床来说太大。

切割 tooling 错误

  • Missing cutting condition ：未为原材料映射切割 条件，因此无法执行切割。

  • Untooled or partially tooled contours ：在 tooling 过程中，某些形状或边缘被遗漏或仅部分覆盖，使零件的切割不完整。
