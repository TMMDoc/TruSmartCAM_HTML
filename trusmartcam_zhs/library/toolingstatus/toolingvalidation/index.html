tooling 验证

本节介绍如何访问和修改 TruSmartCAM 中零件的 tooling 信息。

  • 右键单击任意零件磁贴即可打开零件面板并访问 tooling 选项。

  • 单击 Toolings 可切换到第一个可用的 tooled 实例。

  • 或者，直接单击某个 tooled 实例，即可查看机床详细信息和 tooling 选项。

  • 使用 可 Open in read-only mode for viewing。

  • 使用 可 Check-out the document for editing。

  • 所选的 tooled 实例会在 TecZone 或 MetaCAM 中打开。

  • 执行手动 tooling 检查并进行必要的更改。

  • 当您尝试保存时，会出现 Unsaved Changes 对话框，提示您确认所做的编辑。

  • 单击 Yes 继续保存。

  • 保存后，系统会再次执行 tooling 验证。

  • 如果没有错误，则会出现将更改保存到 TruSmartCAM 的选项。

  • 如果发现 tooling 错误，则会显示错误消息：

  • 保存后，零件的 tooling 状态会在零件库中更新。

  • tooled 实例上的绿色表示其已签入。

  • Tooled 实例作者会更新为最后一个编辑它的人。

  • User-edited 字段指示 tooled 实例是否已被手动 修改。当用户检出实例并进行任何更改时，保存时此字段会自动设置为“是”。

  • 如果某个零件正在被编辑，其磁贴上会出现一个用户图标。

  • 将鼠标悬停在磁贴上会显示检出它的人以及检出时间。

  • 当零件处于检出状态时，同一 tooled 实例的 Check-out the document for editing 选项会被禁用， 而 Cancel Check-out 选项会变为启用。
