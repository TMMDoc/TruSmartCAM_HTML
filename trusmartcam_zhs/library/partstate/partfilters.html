零件筛选器

零件库筛选器让您能够通过应用特定条件，在库中快速搜索和定位零件。通过将结果 缩小到仅符合您条件的零件，这些筛选器可让您更轻松地高效管理和访问相关零件。

State

  • 使用 State 筛选器可根据零件当前的状态搜索零件。

  • 下拉列表会根据可用的库零件显示所有适用的状态。

  • 状态列表会根据所选零件及其状态动态变化。

  • 例如，选择 Material Missing 可查看处于未解决材料状态的零件。

Status

  • 使用 Status 筛选器可根据 tooling 状态搜索零件。

  • 下拉列表会将 tooling 状态显示为彩色框，以及所有可用的机床及其适用的错误。

  • 彩色框表示以下状态：

    • 白色：Tooling 正常

    • 橙色：Tooling 存在错误

    • 黄色：Tooling 存在警告

    • 灰色：Tooling 已抑制

  • 如果某个零件存在窄翻边或未分配 tooling 错误，选择这些错误将显示相应的零件。

  • 单击灰色框，将显示在所选机床上 tooling 被抑制的零件。

Bend mounts

  • 使用 Bend mounts 筛选器可根据所用的折弯刀具搜索零件。

  • 下拉列表会显示所有可用的折弯刀具，并可按刀具名称、类型（冲头、鹅颈、半径 等）或描述进行筛选。

  • 选择多个刀具并单击 Match all，即可筛选出同时使用 这两个所选刀具的刀具。
