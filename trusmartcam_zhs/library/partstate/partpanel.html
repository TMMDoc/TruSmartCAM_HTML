零件面板

本节介绍与零件相关的操作，例如 Re-import、Re-tool、 Rename、Export outputs 等， 用于管理零件实例。

Open in read-only mode for viewing
以只读模式打开所选零件。

Check-out the document for editing
启用对所选零件的编辑。

Delete
删除所选零件。

New…​

所选零件可转换为新的订单、job 或装配体。

Export Outputs

将零件输出导出到配置的目标位置。

Re-import…​

允许再次导入所选零件。

Re-tool…​

允许重新处理所选零件。

Rename…​

更改所选零件的名称。

Assign Material…​

指定与所选零件关联的材料。

Assign Customer…​

指定与所选零件关联的客户。

Rolling direction

定义材料轧制的方向。可用选项为 None、Horizontal 和 Vertical。

Prev / Next / Toolings

导航到上一个或下一个零件或 tooling。

排序和筛选

使用这些筛选器可查看与所选零件具有相同属性的其他零件：Same Material、Same Customer、Same Bend count 或 Same State。

Re-import

  • 右键单击任意零件，然后单击 Re-import…​。

  • 所有机床上所选零件的所有 tooling 实例都会被清除，包括自动 tooled 和手动 tooled 的实例。

  • 现有的输出文件（CAD、Bend 和 Cut）会被移除。

  • 零件会被重新导入，并对所有机床应用全新的 CAD 验证和 tooling。

  • 系统会根据更新后的 tooling 结果创建新的输出文件。

Re-tool

  • 右键单击任意零件，然后单击 Re-tool…​。

  • 默认情况下，所有机床都处于选中状态，并分组为 Laser、Punch、Panel 和 Press brake。

  • 单击 OK 继续。这会移除所选机床的自动 tooled 和手动 tooled 实例，并删除相关的输出文件。

  • 当选中 Retain existing outputs 复选框时， 只有先前已移除输出的零件才会被重新 tooled，其他输出保持不变。如果未选中，则 所选机床的所有输出文件都会在重新 tooling 期间被移除并重新生成。

  • 如果任何机床的 CAM 设置发生更改，请选择该机床并重新 tooling 这些零件。

  • 如果某个刀具（LTT、冲头或折弯）发生更改或缺失，请更新机床并仅重新 tooling 受影响的零件。

Rename

本节介绍如何在 TruSmartCAM 中重命名一个或多个零件。

  • 右键单击零件，然后单击 Rename…​。

  • 会出现一个重命名确认对话框，显示当前零件名称。

  • 输入新名称并单击对勾 ✓ 图标进行确认，或单击叉号 ✗ 图标取消重命名 操作。

  • 要重命名多个零件，请选择所有所需零件，然后右键单击其中任意一个并单击 Rename…​。

  • 会出现一个确认对话框，显示所选零件的总数。

  • 对于每个零件，输入新名称并单击对勾 ✓ 图标逐个确认。

  • 如果误选了任何零件，请单击叉号 ✗ 图标取消。或者，您可以右键单击零件 并单击 Cancel Rename 以跳过重命名。

Export outputs

此选项将零件输出导出到 Factory Settings 中配置的目标 位置。（请参阅 折弯设置 和 切割设置）

输出位置在各自的输出设置中分别为 Bend、Fold 和 Cut 定义。与折弯、折叠和 切割操作关联的所有 tooling 都会针对整个零件导出。

导出的文件取决于操作类型。对于 Bend 和 Fold 操作，会生成 NC 文件和 报告。对于 Cut 和 Punch 操作，仅导出零件文件。

零件分配材料

状态为 Material not assigned 的零件需要先更新， 然后才能进一步处理。以下步骤介绍如何分配材料。

  • 右键单击显示状态 Material not assigned 的 零件，然后选择 Assign Material…​。

  • 会打开 Assign Material 窗口。

  • 该对话框有四个部分：

    • Suggestions - 根据导入零件的厚度自动 建议原材料。

    • All Materials - 列出 TruSmartCAM 中定义的所有材料 类型。

    • All Raw-Materials - 显示系统中所有可用的 原材料。

    • Used Raw-Materials - 显示最近使用的原材料， 以便快速访问。

  • 您可以使用顶部的 Search 字段快速查找材料。例如，键入 “steel”可在三个部分中显示所有匹配的材料。

  • 从筛选后的列表中，在原材料列表中选择所需的材料（例如 Steel-25）。

  • 所选材料将分配给该零件。

Rolling direction

Rolling direction 是指零件中纹理的方向，它会影响零件的 切割和处理方式。此选项允许您为零件库中的零件指定 Rolling direction。系统会根据所选方向，将零件放置在 正确的方向上，以便在可用机床上进行切割。

  • 右键单击零件库或 Job 窗口中的任意零件磁贴。

  • 选择首选的轧制方向：

    • None

    • Horizontal

    • Vertical

  • 系统会根据所选的轧制方向，为所有可用的切割机床自动重新 tooling 该零件。
