添加新材料和板材

添加新材料和板材

可通过单击Factory图标并选择sheets来访问板材管理。这将提供已设置材料的概览。选择左侧列出的任意材料会显示可用的板材、厚度、尺寸和数量。

要添加新材料，请从factory中的sheets页面单击Add new → New Material…​。

输入Material、Raw Material、Thickness和材料参数。单击OK。

查看材料

factory → Sheets中的View…​选项具有以下选项：

  • Expand All：展开所有材料类别。

  • Collapse All：折叠所有材料类别。

  • Show All Materials：列出所有原材料，无论板材库存如何。

  • Show Inventory Materials：仅列出有板材库存的原材料。

以粗体显示的原材料厚度表示板材可用性。

添加板材

要添加新板材，请从factory中的 Sheets 页面单击Add new → New Sheet。修改板材参数。

  • Search Sheets (Ctrl + F)…​：按尺寸、轧制方向、备注、炉号、余料和汽化筛选板材。

  • Slider (+ / –)：调整板材预览的缩放级别。

  • Filter by：根据所选选项控制板材预览（Width、Height、Area、Quantity、Grain或Type）。

只有在零件被分配给某材料或 layout 被 nest 到某板材之前，才能编辑或删除该材料或板材。

此阶段无法更改材料名称。因此，必须创建新材料。
