导入

Output settings

Save flat pattern - 启用此选项可保存导入零件的 展开图。

Format for flat pattern - 此选项用于选择 DXF 或 GEO 文件格式。

Flat pattern destination - 这是展开图将被 保存的位置。

Import settings

Units for DXF files - 这是导入 DXF 文件时使用的 计量单位，用户可以在 mm 或 inch 之间选择。

Material lookup keys - 可以使用逗号分隔符 分隔来指定多个查找条目。当导入零件时，TruSmartCAM 使用这些键来搜索材料值。搜索到的值随后被用于 解析原材料。原始值存储在零件的 Misc Properties 中。

Revision lookup keys - 当导入零件时，会将 原始零件文件（正在导入的零件文件）中的版本值与 存储库中现有的版本值进行比较。如果版本相同，则放弃导入。 现在 DXF 文件也支持自定义字段映射。对于 DXF 文件， 自定义字段数据从图纸中的文本图层或 PPI 附件中提取。

Use geometry comparison on same CAD revision - 在导入具有相同 CAD 版本的零件时比较几何图形，并在检测到差异时 提示用户替换或跳过导入，详情请参阅 导入配置。

Part name keys - 此选项的工作方式与材料和 Revision lookup keys 类似。设置一个或多个 Part name keys，以使用 PPI Part name 而不是文件名作为零件名称。

Thickness lookup keys - 可以使用逗号分隔符 分隔来指定多个查找条目。当导入零件时，TruSmartCAM 使用这些键来搜索厚度值。搜索到的值随后被用于 解析厚度。原始值存储在零件的 Misc Properties 中。

Thickness comparison fudge - 这用于在导入零件时 查找原材料。TruSmartCAM 在解析材料名称和厚度后尝试解析原 材料。有关更多信息，请参阅下面的 Thickness fudge 主题。

Identify shapes after a flat is imported - 当导入 零件时，可以自动识别和确定零件内部的形状。

Shape identification fudge - 形状 识别容差值可在以下位置设置：

  1. Global level - 此值用作所有形状的默认值。

  2. Individual Shape Level - 可通过在单个形状级别设置容差值来 覆盖默认值。在 Shape Library 对话框中选择形状会显示容差值。 默认情况下，此值设为 0，这样的形状将使用默认全局值。

Rotate flat horizontally - 通常切割机床的 工作台是矩形且较宽。为提高 tooling 的可行性，在导入零件后 沿零件宽度旋转零件。

Part rotation threshold - 将此值设为 允许旋转的最小数值。任何小于所设值的零件都不会 被旋转。

Misc settings

Enable pre-import external tools - 启用 导入前外部工具导入选项以启用 Creo Reader。TruSmartCAM 上传 所拖放零件的预提取族实例。请注意，实例提取是在零件上传期间 （作为导入前操作）执行的，因此 Creo 软件必须安装在上传零件的 计算机上。

Ignore drawing colors in Flat thumbnails for clarity - 启用此选项可生成灰度更清晰的缩略图。 为了图像清晰，将忽略图层颜色和文本实体。

Use only one Engine for all import tasks - 启用后，所有导入任务仅使用一个引擎内核。

Thickness fudge

Thickness comparison fudge 在库存中无法提供所需 板材厚度时，通过比较库存中板材的厚度值来选择最接近的 板材厚度值。

例如，假设如下：

  1. 我们有一个板材厚度为 1.6 mm、材料为钢的零件。

  2. Thickness comparison fudge 值为 0.1 mm。

  3. 库存中有厚度为 1.5 mm、1.55 mm 和 1.7 mm 的钢板。

TruSmartCAM 在将 Thickness comparison fudge 值（0.1 mm）与 导入项（测量为 1.6 mm）进行比较后，选择厚度值最接近的板材。 在这种情况下，将选择 1.55 mm。
