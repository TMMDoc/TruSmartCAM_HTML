Job

Output settings

Save layout NC and reports - 启用此选项可保存 layout NC 和报告。

Save layout file - 启用此选项可保存 layout 文件。

Output simulation preview in reports - 启用 此选项可在其他输出的同时生成 tooling 仿真预览。 这是针对激光/冲孔 tooling 的一段短小 GIF 动画。

Do not delete program outputs on layout/job completion - 启用此选项将在 job/layout 被标记为已完成时 跳过对程序输出的删除操作。

Nest settings

Mix parts from multiple Jobs - 支持混合 模式 nesting。来自多个 job 的零件应一起 nest，以获得更好的 排版效率。

Do not auto-release layouts - 这将阻止 layout 在所有 layout 处于已发布状态之前可用于生产。

Re-nesting packing cut-off - 此值用于 决定一个已 nest 的 layout 是否保留在审批队列中，并在规划新零件时 重新 nest，或者将其发布用于生产并将相关输出导出到输出文件夹。

Interactive sheet-name prefix - 本 部分用于支持交互式 nesting，用户可对所 nest 的零件及 nest 结果 拥有更多控制。为交互式 nest 的 layout 使用与自动 nesting 不同的 命名方案。

Update sheet inventory on nest (un)release - 启用 此选项后，将 nest 发送到机床时板材库存将更新。同样，从机床 召回 nest 将将板材退回库存。

Automate remnant inventory management - 选择此开关后， 软件会自动化余料库存管理。如未选择，则余料管理变为交互式。

Auto-refresh Out-of-date layouts - 勾选 时，软件会在零件的切割方案计算完成后刷新与该零件链接的所有 Out-of-date Layouts。

Automate twin-line nesting - 勾选此选项可启用 twin-line 自动化。

Pull workflow settings

Use 'Pull workflow' - 此选项对于需要高度 自主规划和 nesting 系统的用户很有用。启用后，TruSmartCAM 按需规划 nesting。

Nests per station - 此值用于设置每个 工站应创建多少个 layout。

Maximum sheets per nest - 此值用于 控制针对唯一 nest 的最大板材数量。例如，如果 有一个包含大零件（占满整块板材）的订单，需要 大数量（如 500 个）— TruSmartCAM 在 pull 模式下不再创建一个包含 500 个副本的单个 nest。相反，它每个 nest 创建 10 个副本，其中 10 是 最大值。

Bend programs per station - 此值用于 设置每个工站应创建多少个折弯程序。

Mark the task completed, when the program outputs are removed - 启用此选项后，当从目标输出位置移除输出时，layout 将 被标记为完成。

Spreadsheet import settings

CAD lookup directories - TruSmartCAM 将尝试 从零件库加载导入的 CSV 中提到的零件条目。 但是，如果零件库中没有该零件，则它将根据本对话框中设置的 目录顺序，尝试从查找目录中获取零件。

Use recursive CAD search - 启用此选项可对 后续结果重复进行搜索。

Create a blank part for the missing CAD files - 如果 TruSmartCAM 库或查找目录中不存在某些零件，TruSmartCAM 将 为这些不可用的零件创建一个空白零件。

Do not show New Job dialog if the spreadsheet has no error - 如果 CSV 条目无误，即数据与数据库无不匹配或所有字段均正确列出， TruSmartCAM 将不显示 job 概览窗口，并在导入或拖放 CSV 后立即 处理该 job。

Prefer Raw-Material column over Material + Thickness - 支持的电子表格类型：

  1. Pattern 1：PartName、Quantity、DueDate、Priority、RawMaterial

  2. Pattern 2：PartName、Quantity、DueDate、Priority、Material、Thickness

  3. Pattern 3：PartName、Quantity、DueDate、Priority、Material、Thickness、 RawMaterial

如果未勾选此选项，Pattern 1 将被视为默认的电子表格类型。 如果 CSV 格式为 Pattern 3 类型，我们也支持 Pattern 3。

如果勾选此选项且 CSV 为 Pattern 2 类型，则 TruSmartCAM 将 从 CSV 的 Material 和 Thickness 字段解析 Raw Material。

Spreadsheet output settings

Export Job/Layout completion report (.csv) - 勾选此选项可在 Layout 或 Job 完成时启用 CSV 导出。 已完成的报告保存在 Factory → Settings → Reports 设置中指定的 Reports 目标位置。
