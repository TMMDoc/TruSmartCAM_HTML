报告

Report settings

Report destination - 使用此选项指定 保存报告的位置。

Report Output Format - 指定导出时报告的格式 （PDF 或 HTML）。

Job report settings

Include layout images in the report - 启用此 设置可在报告中包含 layout 的图像。

Include part images in the report - 启用此设置 可在报告中包含零件的图像。

Include layout reports in the job report - 启用此 设置可在 job 报告内链接到 layout 报告。

Label report settings

Enable label reports - 启用此设置可允许 从 job 或 layout 生成标签，分别右键单击并选择 Export Layouts 或 Send to Machine 时，将提供显示标签报告的选项。

Label size (W x H) - 以毫米为单位指定标签的 宽度和高度。这些值定义了所生成标签的物理尺寸。

QR code field - 定义要编码到标签上 QR 码中的数据字段。下拉列表包括 Part Name、Part Order 和 None。所选字段值以 QR 码的形式显示。

Barcode field - 定义要编码到标签上条形 码中的数据字段。下拉列表包括 Part Name、Part Order 和 None。所选字段值以条形码的形式显示。

Show part image - 启用后，在所生成的标签 报告中包含零件图像。
