切割

Output settings

Save cut outputs - 仅当 tooling 正常且启用 并配置了这些导出设置时，tooling 结果才会被保存。 启用此选项可保存切割 NC。

Output tooling simulation preview - 启用此 选项可在其他输出的同时生成 tooling 仿真预览。 这是针对激光/冲孔 tooling 的一段短小 GIF 动画。

Cut output destination - 这是保存 NC 和 报告的目标位置。

MetaCAM settings

Lookup MetaCAM materials by raw-material names （对于类似 DMM 的集成请启用此项）- 启用此样式后， TruSmartCAM 按原材料名称生成页面，并在自动 tooling 时将其分配给零件。

MetaCAM sync folders - 此切割设置用于 添加额外的 MetaCAM 文件夹，当使用 config-push 监视命令时，这些 文件夹应与 config.dat 一起同步。config-push 将本地文件保存到 TruSmartCAM 存储库，当 MetaCAM（重新）启动时其他计算机会下载该库。 除 Tools 之外，当为 MetaCAM 机床完成自动 tooling 时，Engine 计算机 应自动同步它，其他一些特定于安装的候选项包括 Etc、 Reports 和 Machines 文件夹。

DMM config sync location - 这是设置 Dynamic Machine Management 配置同步的位置。

TecZone Settings

Enable multi-pass nesting - 这将启用激光 在同一轮廓上多次切割（适用于较厚的材料）。
