通知

通知向用户告知系统内发生的 CAD 和 tooling 错误。它们确保 及时传达问题，以便采取适当的措施。

电子邮件通知

电子邮件通知功能允许用户配置并接收针对 CAD 和 tooling 错误的 自动电子邮件警报。配置后，每当发生相关事件时，系统会 自动向指定收件人发送电子邮件，确保及时处理问题。

要配置电子邮件通知，请导航至： factory > settings > Notifications

Notifications 页面包含以下部分：

通知设置

Notification settings 部分控制如何生成 电子邮件警报并将其传送给收件人。

  • Enable email notifications - 使系统 能够根据所配置的条件发送通知。

  • Notification recipients - 指定收件人的 电子邮件地址。可以通过使用逗号（,）或空格分隔来 添加多个收件人。

  • Send messages in batch - 将多个 通知合并为一封电子邮件。在定义时间间隔内生成的消息会 被分组在一起，这有助于减少电子邮件数量并避免混乱。

  • Attach tooling simulation preview where applicable - 在可用时将 tooling 仿真预览附加到通知电子邮件中。 这有助于直接从电子邮件中查看与 tooling 相关的问题。

包含仿真预览可能会显著增加电子邮件的大小。

Mail settings

Mail settings 部分定义系统用于传送电子 邮件通知的发件邮件服务器配置。必须正确配置这些设置， 通知才能成功发送。

  • SMTP server - 指定用于发送发出电子邮件的 SMTP 服务器地址（例如 smtp.gmail.com）。此信息通常可在 用户邮件客户端的帐户或设置部分找到。

  • SMTP port - 定义邮件服务器用于通过互联网 发送电子邮件的端口号。常见值包括 465（SSL） 和 587（TLS）。

  • Transport protocol - 指定用于从应用程序 安全地向邮件服务器发送电子邮件的协议（例如 SSL 或 TLS）。

  • Server needs authentication - 为 SMTP 服务器启用身份验证。启用后，服务器会在发送电子邮件之前 验证用户名和密码。

  • User-name - 指定用于与 SMTP 服务器进行 身份验证并发送通知的电子邮件帐户。

  • Password - 指定与用于身份验证的电子邮件 帐户关联的密码。

  • Sender address - 指定接收通知时向收件人显示的发件人 电子邮件地址。

  • Test…​ - 发送测试电子邮件以验证邮件 服务器配置。

单击 Test…​ 验证设置。如果测试成功，将 显示确认消息；否则，将显示指示失败原因的错误消息。

  • 在交互模式下（例如编辑或手动保存零件时）不会触发电子邮件通知。

  • 电子邮件的传送在后台处理，可能会延迟。

  • 如果在处理完成之前系统或引擎停止，则可能无法传送通知。
