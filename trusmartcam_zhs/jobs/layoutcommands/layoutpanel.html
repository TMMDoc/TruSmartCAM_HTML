Layout 面板

本节介绍与 layout 相关的操作，例如 Send to machine、 Recall from machine、 Export outputs、 Mark complete、Add parts…​、 Adapt/Compact…​、 Split layout 以及用于管理 layout 实例的其他选项。

Open in read-only mode for viewing
以只读模式打开所选 layout。

Check-out the document for editing
启用对所选 layout 的编辑。

Delete
删除所选 layout。

View Report
打开所选 layout 的标准 layout 报告和标签专用报告。

Send to Machine…​

将所选 layout 发送到机床，并将输出文件 （fxlyt、NC、report、csv）导出到 job 输出位置。

Add Parts…​

使用 layout 重新排料向导向排料不佳的 layout 添加更多零件。

Adapt/Compact…​

重新 nesting 所选 layout，以压缩零件并释放可用区域。

Change LTT…​

更改分配给所选 layout 的板材。

Split Layouts…​

将所选 layout 拆分为两个或多个单独的 layout。

Rename…​

重命名所选 layout。

Job / Prev / Next / Parts

向上导航到父 job，导航到所选 job 内的上一个或下一个 layout， 或向下导航到 layout 中包含的零件。

Sort and filter

使用这些筛选器可查看与所选 layout 共享相同属性的其他 layout：Same Machine、Same Material、 Same LTT、Same Priority、 Same State、Same Sheet、Same Part、Same Remnant State 或 Same Rolling Direction。

Send to machine

  • 当 nest 准备就绪（已填满或急需）时，您可以将其发送到机床。

  • 右键单击 nest 并选择 Send to machine…​。

  • 系统会自动创建一个以 nest 命名的文件夹。

  • 输出文件（fxlyt、NC、report、csv）导出到 JOB 输出位置。

  • 发送到机床的 nest 会显示蓝色对勾标记。

一旦释放，这些 nest 将不再重试进行重新排料。

Recall from machine

  • 如果输出需要验证或更新（例如，添加更多零件）：

    • 右键单击导出的 layout。

    • 选择 Recall from machine…​。

  • 输出文件和文件夹（fxlyt、NC、report、csv）将被删除。

  • nest 再次变为可编辑。

  • 您可以进行更改并再次将其发送到机床。

Export outputs

  • 右键单击任何已发送到机床的 layout（nest），然后单击 Export outputs。

  • Export Outputs 选项将 NC、Report 和 Layout 文件导出到 相应的机床输出文件夹。

  • 此选项使用 layout 的当前单位设置重新生成 NC 文件。

Export Outputs 不适用于已完成的 Layout 以及在队列中 等待重新排料的 Layout。

标记完成

  • 在机床上处理完 nest 后，右键单击 nest 并 选择 Mark complete…​。

  • 您可以选择多个 nest 并同时将它们标记为完成。

  • 当 nest 标记为完成时：

    • 它会变灰、移动到列表末尾，并显示绿色对勾 标记。

    • 该 layout 会从活动 layout 列表中移除。

    • 零件和 job 状态会更新，已处理的数量会移动到 已完成状态。

    • 该 layout 的输出文件会从机床输出 位置移除，以避免重复使用。

Add parts…​

  • 使用此选项可向排料相对较差的 layout 添加更多零件。与 交互式 nesting 一样，这是一个向导驱动的选项，可以同时 用于单个或多个 layout。

  • 使用此选项时，TruSmartCAM 会在主工作区中装载 layout 重新排料向导。 按住 Ctrl 键并选择要在 layout 上排料的一个或多个 零件，然后按 Next。

  • 所选零件将在下一步显示，并带有可编辑的 数量列。如有需要，请在 Update Qty 字段中更新零件数量。单击 Next 继续进行 nesting。请注意， 数量只能增加，不能减少。

  • 所有 layout 会分别进行 nesting，nested 结果会显示 新排料的零件放置在其上。选择 layout 会显示所有 现有的 layout 零件。如果在重新排料期间未放置新零件，则结果会被自动丢弃。 具有多个副本的 layout 在重新排料后可能会产生不同的图案。

Adapt/Compact…​

  • 当原机床停机或需要平衡机床工作负载时， 可以使用此基于向导的命令将 layout 从一台 机床适配到另一台机床。

  • 当计划使用的板材缺货且需要在另一块可用板材上 重新规划 layout 时，可以使用它。

  • 您可以将排料在较小板材上的 layout 合并到较大的板材上， 以更有效地使用材料。

  • 如果没有大板材库存，您可以将排料在较大板材上的 layout 拆分到较小的板材上。

  • 您可以通过将多个 layout（甚至来自 不同机床的 layout）合并在一起来提高它们的排料效率。

  • 要使用它，请选择一个或多个 layout，然后单击 Adapt/Compact…​ 以在工作区中打开向导。

  • 左窗格显示所有选定的 layout，Parts 窗格显示 layout 零件。

  • 选择目标机床和板材材料，然后单击 next 以执行重新 nesting。

  • 新的 nest 结果显示在结果窗格中。

  • 单击 next 以保存适配或压缩后的 layout。

拆分 layout

Split layouts…​ 选项使您能够通过修改数量 将现有 layout 拆分为多个 layout， 而无需重做 tooling 或 nesting。

此功能在 以下场景中特别有用：

  1. 当您需要立即生产总数量的一部分，同时 安排剩余数量稍后生产时。

  2. 当生产需求需要分配到多个班次或 多天以优化工作流和资源利用时。

  3. 当特定机床暂时不可用或被占用，且您需要 调整 layout 以适应当前生产约束时。

要拆分 layout，请执行以下步骤：

  • 在 Layouts 视图中，选择所需的 layout。

  • 单击 Split layouts…​。

  • 在 New Copies 中输入所需的值。

  • 单击 OK。

所选 layout 现在已拆分为两个具有调整后数量的 layout。
