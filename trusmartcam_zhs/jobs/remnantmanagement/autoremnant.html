自动余料管理

启用余料

TruSmartCAM 支持在 nesting 期间从 layout 自动创建余料板材。此功能仅适用于 TecZone Laser 机床。

  • 单击 factory → Machines → Machine Defaults → Skeleton cuts。

  • 选择 Slice Sheet Skeleton 和 Create Remainder Sheet 选项以启用此功能。

启用后，nested 板材的剩余区域会根据分配的 X 和 Y 方向的最小余料板材值切分为余料板材。

配置自动余料

  • 单击 factory → Settings → Job。

  • 选择 Update sheet inventory on nest (un)release 和 Automate remnant inventory management。

自动余料

当您对零件进行 nesting 时，如果剩余的板材区域满足最小板材值 X 和 Y，TruSmartCAM 会自动从剩余空间创建余料板材。

  • 在 Job Nest 视图中，具有余料板材的 nest 会以绿色边框轮廓和灰色背景显示。

  • 双击 nest 以打开 Nest Detail 页面。余料板材信息会显示余料板材尺寸、数量和面积。

  • 右键单击 nest 并选择 Edit 以在 TecZone 中打开它。nest 显示零件之间的切分线和骨架切分线，以及雕刻的余料尺寸。（材料、厚度和余料尺寸）。

余料尺寸雕刻标记可帮助操作员无需测量即可拾取板材，从而便于在将来的 nest 中使用。

当您单击 Mark Complete 时，余料板材会显示绿色对勾标记，表示 nest 已完成。部分阴影的方形图标表示余料板材已创建并在板材库存中更新。

板材数据库会使用余料板材的尺寸和数量进行更新，这些板材通过板材尺寸末尾的星号（*）符号来标识。余料板材具有绿色边框。

job 的自动规划或交互式规划在 nest 规划中将余料板材视为高优先级，确保优先使用它们，以保持车间没有未使用的余料。
