Output settings

Save cut outputs - Les résultats d’outillage sont enregistrés uniquement si l’outillage est correct et si ces réglages d’exportation sont activés et configurés. Activez cette option pour que le NC de coupe soit enregistré.

Output tooling simulation preview - Activez cette option pour générer l’aperçu de simulation d’outillage en plus des autres sorties. Il s’agit d’une courte animation GIF pour l’outillage laser/poinçon.

Cut output destination - Il s’agit de la destination des fichiers NC et rapports à enregistrer.

MetaCAM settings

Lookup MetaCAM materials by raw-material names (Activez ceci pour les intégrations de type DMM) - Lorsque ce style est activé, TruSmartCAM génère des pages par noms de matière brute et les assigne aux pièces au moment de l’outillage automatique.

MetaCAM sync folders - Ce réglage de coupe est utilisé pour ajouter des dossiers MetaCAM supplémentaires qui doivent être synchronisés avec le config.dat lorsque la commande config-push du Moniteur est utilisée. Le config-push enregistre les fichiers locaux dans le référentiel TruSmartCAM, qui est téléchargé sur les autres ordinateurs lorsque MetaCAM (re)démarre. L’ordinateur Engine doit le synchroniser automatiquement lorsque l’outillage automatique est effectué pour une machine MetaCAM ; outre les dossiers Tools, d’autres candidats spécifiques à l’installation sont les dossiers Etc, Reports et Machines.

DMM config sync location - Il s’agit de l’emplacement pour la synchronisation de la configuration Dynamic Machine Management à définir.

TecZone Settings

Enable multi-pass nesting - Ceci permettra au laser de couper plusieurs fois sur le même contour (préférable pour les matières plus épaisses).
