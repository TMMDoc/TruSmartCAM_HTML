Importation

Output settings

Save flat pattern - Activez cette option pour que le développé d’une pièce importée soit enregistré.

Format for flat pattern - Cette option permet de choisir entre les formats de fichier DXF ou GEO.

Flat pattern destination - Il s’agit de l’emplacement où le développé sera enregistré.

Import settings

Units for DXF files - Il s’agit de l’unité de mesure avec laquelle un fichier DXF sera importé ; l’utilisateur peut choisir entre le mm ou le pouce.

Material lookup keys - Plusieurs entrées de recherche peuvent être attribuées en les séparant par une virgule. Lorsqu’une pièce est importée, TruSmartCAM utilise ces clés pour rechercher les valeurs de matière. Les valeurs recherchées sont ensuite utilisées pour résoudre la matière brute. Les valeurs d’origine sont stockées dans les propriétés diverses de la pièce.

Revision lookup keys - Lorsqu’une pièce est importée, la valeur de révision du fichier de pièce brute (le fichier de pièce en cours d’importation) est comparée à la valeur de révision existante dans le référentiel. L’importation est abandonnée si la révision est identique. Le mappage de champ personnalisé est désormais également pris en charge pour les fichiers DXF. Pour les fichiers DXF, les données de champ personnalisé sont extraites de la couche de texte du dessin ou d’une pièce jointe PPI.

Use geometry comparison on same CAD revision - Compare la géométrie lors de l’importation d’une pièce ayant la même révision CAO et invite l’utilisateur à remplacer ou ignorer l’importation si des différences sont détectées. Consultez Import configuration pour plus de détails.

Part name keys - Cette option fonctionne de la même manière que les Revision lookup keys et de matière. Définissez une ou plusieurs Part name keys pour utiliser le Part name PPI au lieu du nom de fichier comme nom de pièce.

Thickness lookup keys - Plusieurs entrées de recherche peuvent être attribuées en les séparant par une virgule. Lorsqu’une pièce est importée, TruSmartCAM utilise ces clés pour rechercher les valeurs d’épaisseur. Les valeurs recherchées sont ensuite utilisées pour résoudre l’épaisseur. Les valeurs d’origine sont stockées dans les propriétés diverses de la pièce.

Thickness comparison fudge - Ceci est utilisé pour rechercher la matière brute lorsqu’une pièce est importée. TruSmartCAM tente de résoudre la matière brute après l’analyse du nom de matière et de l’épaisseur. Pour plus d’informations, reportez-vous à la rubrique [Thickness fudge] ci-dessous.

Identify shapes after a flat is imported - Lorsqu’une pièce est importée, les formes intérieures de la pièce peuvent être automatiquement reconnues et identifiées.

Shape identification fudge - La valeur de tolérance d’identification de forme peut être définie à :

  1. Niveau global - Cette valeur est utilisée par défaut pour toutes les formes.

  2. Niveau de forme individuelle - La valeur par défaut peut être remplacée en définissant la valeur de tolérance au niveau de la forme individuelle. La sélection de la forme dans la boîte de dialogue Bibliothèque de formes affiche la valeur de tolérance. Par défaut, celle-ci est définie à 0, et la valeur globale par défaut est utilisée pour ces formes.

Rotate flat horizontally - En général, les tables des machines de coupe sont rectangulaires et plus larges. Pour améliorer la faisabilité de l’outillage, faites pivoter la pièce selon sa largeur après son importation.

Part rotation threshold - Définissez ceci comme le nombre minimal pour autoriser la rotation. Toute pièce plus petite que la valeur définie ne sera pas faite pivoter.

Misc settings

Enable pre-import external tools - Activez l’option d’importation d’outils externes pré-importation pour activer Creo Reader. TruSmartCAM charge les instances de famille pré-extraites de la pièce déposée. Veuillez noter que l’extraction d’instance est effectuée pendant le téléversement de la pièce (en tant qu’opération de pré-importation), de sorte que le logiciel Creo doit être installé sur l’ordinateur à partir duquel la pièce est téléversée.

Ignore drawing colors in Flat thumbnails for clarity - Activez cette option pour générer des vignettes plus nettes en niveaux de gris. Les couleurs de calque et les entités de texte sont ignorées pour plus de clarté de l’image.

Use only one Engine for all import tasks - Lorsqu’elle est activée, un seul cœur de moteur est utilisé pour les tâches d’importation.

Tolérance d’épaisseur

La Thickness comparison fudge choisit la valeur d’épaisseur de tôle la plus proche lorsqu’une épaisseur de tôle souhaitée n’est pas disponible dans l’inventaire, en comparant la valeur d’épaisseur des tôles de l’inventaire.

Par exemple, supposons ce qui suit :

  1. Nous avons une pièce avec une épaisseur de tôle de 1,6 mm et une matière en acier.

  2. La valeur Thickness comparison fudge est de 0,1 mm.

  3. L’inventaire dispose de tôles en acier d’épaisseur 1,5 mm, 1,55 mm et 1,7 mm.

TruSmartCAM choisit une tôle dont la valeur d’épaisseur est la plus proche après avoir comparé la valeur Thickness comparison fudge (0,1 mm) avec l’élément importé (mesurant 1,6 mm). Dans ce cas, 1,55 mm sera la sélection.
