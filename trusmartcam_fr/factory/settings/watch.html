Surveillance

Les réglages de surveillance permettent à TruSmartCAM de surveiller un dossier désigné et d’importer automatiquement des fichiers dans le système. Ceci permet d’automatiser l’importation de pièces, tâches, modules et ordres sans intervention manuelle.

Watch settings

Enable 'Live Folder' - Active la surveillance automatique du dossier spécifié.

Watch this folder - Spécifie le dossier à surveiller pour les fichiers entrants.

Watch sub-folders also - Inclut tous les sous-dossiers dans le processus de surveillance.

After file import

After import - Une fois le fichier importé, l’utilisateur dispose de deux options. Le fichier peut être supprimé de l’emplacement ou déplacé vers un autre emplacement.

  • Delete imported file - Supprime le fichier source après une importation réussie.

  • Move imported file - Déplace le fichier source vers le dossier spécifié dans Move files to this folder après une importation réussie.

Move files to this folder - Spécifie le dossier de destination où les fichiers importés avec succès doivent être déplacés lorsque After import est défini sur Move imported file.

Move spreadsheets with errors to this folder - Déplace les importations échouées vers le dossier d’erreurs spécifié.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Importe automatiquement les fichiers de feuille de calcul détectés dans le dossier de surveillance.

Do not import spreadsheet with errors - Empêche l’importation des fichiers contenant des erreurs de validation.

Spreadsheet import option - Sélectionne le type de données à importer dans la liste déroulante. Les formats de feuille de calcul pris en charge peuvent inclure CSV, XLSX ou XML. Les options disponibles sont :

  • Import Jobs - Importe les données de tâche depuis la feuille de calcul.

  • Import Orders - Importe les données d’ordre depuis la feuille de calcul.

  • Import Assemblies - Importe les données de module depuis la feuille de calcul.

  • Import Parts - Importe les données de pièce depuis la feuille de calcul.

Informations complémentaires

  • Utilisez un chemin UNC (\\ServerName\FolderPath) ou un lecteur mappé (M:\FolderPath) lors de la configuration du dossier de surveillance. N’utilisez pas de chemins locaux tels que C:\FolderPath.

  • L’ordinateur exécutant le service TruSmartCAM Engine doit disposer d’un accès en lecture et écriture au dossier de surveillance configuré. Sans autorisations suffisantes, les fichiers peuvent ne pas être détectés, importés, déplacés ou supprimés avec succès.

  • Le mappage de feuille de calcul doit être configuré avant d’activer les réglages de surveillance. Sinon, TruSmartCAM ne pourra pas traiter les fichiers de feuille de calcul détectés dans le dossier de surveillance.
