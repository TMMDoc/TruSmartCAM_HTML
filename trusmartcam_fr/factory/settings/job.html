Tâche

Output settings

Save layout NC and reports - Activez cette option pour que le NC de configuration et les rapports soient enregistrés.

Save layout file - Activez cette option pour que le fichier de configuration soit enregistré.

Output simulation preview in reports - Activez cette option pour générer l’aperçu de simulation d’outillage en plus des autres sorties. Il s’agit d’une courte animation GIF pour l’outillage laser/poinçon.

Do not delete program outputs on layout/job completion - L’activation de cette option ignorera l’opération de suppression des sorties de programme lorsqu’une tâche/configuration est marquée comme terminée.

Nest settings

Mix parts from multiple Jobs - Prend en charge l’imbrication en mode mixte. Les pièces de plusieurs tâches doivent être imbriquées ensemble pour une meilleure efficacité de placement.

Do not auto-release layouts - Ceci empêchera les configurations d’être disponibles pour la production jusqu’à ce que toutes les configurations soient dans un état libéré.

Re-nesting packing cut-off - Cette valeur est utilisée pour décider si une configuration imbriquée est maintenue dans la file d’attente d’approbation et est réimbriquée à nouveau lorsque de nouvelles pièces sont planifiées ou lorsqu’elles sont libérées pour la production et que les sorties associées sont exportées vers le dossier de sortie.

Interactive sheet-name prefix - Cette section est utilisée pour prendre en charge l’imbrication interactive où l’utilisateur a plus de contrôle sur les pièces imbriquées et le résultat de l’imbrication. Utilisez un schéma de nommage, différent de l’imbrication automatique, pour les configurations imbriquées de manière interactive.

Update sheet inventory on nest (un)release - Si cette option est activée, l’inventaire de tôles sera mis à jour lors de l’envoi d’une imbrication à une machine. De même, le rappel de l’imbrication depuis la machine renverra la tôle à l’inventaire.

Automate remnant inventory management - Lorsque ce commutateur est sélectionné, le logiciel automatise la gestion de l’inventaire des chutes. S’il n’est pas sélectionné, la gestion des chutes devient interactive.

Auto-refresh Out-of-date layouts - Lorsqu’elle est cochée, le logiciel actualise toutes les ui:EGTag.SelectOutOfDate[Out-of-date Layouts] liées à une pièce après le calcul de ses solutions de coupe.

Automate twin-line nesting - Cochez cette option pour activer l’automatisation twin-line.

Pull workflow settings

Use 'Pull workflow' - Cette option est utile pour les utilisateurs qui ont besoin d’un système de planification et d’imbrication hautement autonome. Lorsqu’elle est activée, TruSmartCAM planifie l’imbrication à la demande.

Nests per station - Cette valeur définit le nombre de configurations par station qui doivent être créées.

Maximum sheets per nest - Cette valeur est utilisée pour contrôler le nombre maximal de tôles par rapport à l’imbrication unique. Ainsi, par exemple, s’il y a un ordre avec une grande pièce (qui remplit toute la tôle), nécessaire en grandes quantités (disons 500), TruSmartCAM ne crée plus une seule imbrication avec 500 copies en mode pull. Au lieu de cela, il crée 10 copies par imbrication où 10 est le maximum.

Bend programs per station - Cette valeur définit le nombre de programmes de pliage par station qui doivent être créés.

Mark the task completed, when the program outputs are removed - Activez cette option pour qu’une configuration soit marquée comme terminée lorsque les sorties sont supprimées de la destination de sortie cible.

Spreadsheet import settings

CAD lookup directories - TruSmartCAM tentera de charger l’entrée de pièce mentionnée dans le CSV importé depuis la bibliothèque de pièces. Cependant, si la pièce n’est pas disponible dans la bibliothèque de pièces, il tentera alors de récupérer les pièces depuis les répertoires de recherche selon l’ordre des répertoires défini dans cette boîte de dialogue.

Use recursive CAD search - Activez cette option pour que la recherche soit répétée pour les résultats successifs.

Create a blank part for the missing CAD files - Si les pièces n’existent pas dans la bibliothèque TruSmartCAM ou les répertoires de recherche, TruSmartCAM créera une pièce vierge pour ces pièces indisponibles.

Do not show New Job dialog if the spreadsheet has no error - Si les entrées CSV sont correctes, c’est-à-dire aucune incohérence de données de la base de données ou tous les champs sont répertoriés correctement, TruSmartCAM n’affichera pas la fenêtre de vue d’ensemble de la tâche et traitera la tâche dès que le CSV est importé ou déposé.

Prefer Raw-Material column over Material + Thickness - Types de feuilles de calcul pris en charge :

  1. Modèle 1 : PartName, Quantity, DueDate, Priority, RawMaterial

  2. Modèle 2 : PartName, Quantity, DueDate, Priority, Material, Thickness

  3. Modèle 3 : PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

Si cette option n’est pas cochée, le Modèle 1 sera considéré comme le type de feuille de calcul par défaut. Nous prenons également en charge le Modèle 3 au cas où le format CSV serait de type Modèle 3.

Si cette option est cochée et que le CSV est de type Modèle 2, alors TruSmartCAM résoudra la matière brute à partir des champs Material et Thickness du CSV.

Spreadsheet output settings

Export Job/Layout completion report (.csv) - Cochez cette option pour activer l’exportation CSV lorsqu’une configuration ou une tâche est terminée. Les rapports terminés sont enregistrés à la destination des rapports spécifiée dans les réglages Factory → Settings → Reports.
