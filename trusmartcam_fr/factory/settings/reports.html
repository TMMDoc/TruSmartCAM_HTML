Rapports

Report settings

Report destination - Utilisez cette option pour spécifier l’emplacement où enregistrer les rapports.

Report Output Format - Spécifie le format du rapport lors de l’exportation (PDF ou HTML).

Job report settings

Include layout images in the report - Activez ce réglage pour inclure les images des configurations dans un rapport.

Include part images in the report - Activez ce réglage pour inclure les images des pièces dans un rapport.

Include layout reports in the job report - Activez ce réglage pour créer un lien vers les rapports de configuration à l’intérieur d’un rapport de tâche.

Label report settings

Enable label reports - Activez ce réglage pour permettre la génération d’étiquettes soit à partir de la tâche, soit à partir d’une configuration où un clic droit et la sélection de Export Layouts ou Send to Machine respectivement présenteront une option pour afficher le rapport d’étiquettes.

Label size (W x H) - Spécifie la largeur et la hauteur de l’étiquette en millimètres. Ces valeurs définissent les dimensions physiques de l’étiquette générée.

QR code field - Définit le champ de données à encoder dans le code QR sur l’étiquette. La liste déroulante inclut Part Name, Part Order et None. La valeur du champ sélectionné est affichée sous forme de code QR.

Barcode field - Définit le champ de données à encoder dans le code-barres sur l’étiquette. La liste déroulante inclut Part Name, Part Order et None. La valeur du champ sélectionné est affichée sous forme de code-barres.

Show part image - Lorsqu’elle est activée, inclut l’image de la pièce dans le rapport d’étiquettes généré.
