Installation du serveur

Suivez les instructions pour installer le serveur TruSmartCAM ainsi que SQL.

Administrator Rights

Pour exécuter cette installation, l’utilisateur doit disposer de privilèges administratifs.

  • Exécutez Setup.TruSmartCAM.<version>.exe pour démarrer l’installation.

La version est un numéro.

  • Lisez le contrat de licence, sélectionnez I accept the agreement, puis cliquez sur Next.

Étape 1 : Emplacement d’installation

  • Indiquez le répertoire d’installation ou acceptez la valeur par défaut C:\Program Files\TRUMPF\TMM\Praxis et cliquez sur Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Le dossier d’installation contiendra les dossiers suivants : Bin, MetaCAM, Samples et Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Le dossier de données contiendra les dossiers suivants : TruSmartCAM, TecZone et MetaCAM.

Étape 2 : Sélection des composants

Type d’installation Composants

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

Sélectionne tous les terminaux de station comme TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

Sélection selon le choix de l’utilisateur.

  • Choisissez l’installation complète (Full). Sélectionnez Code Senders et Bend Code Senders dans les outils TruSmartCAM. Le type d’installation devient alors Custom. Cliquez sur Next.

Étape 3 : Choisir l’installation de SQL Server

L’installation de SQL Express 2022 n’est nécessaire que pour le serveur TruSmartCAM. Cette option n’est pas disponible pour les installations Client et Sync. Elle est également cochée et installée la première fois et peut être ignorée par la suite. Si SQL est déjà installé sur le serveur TruSmartCAM, l’utilisateur peut ignorer l’étape 3.

  • Dans Select Additional Tasks : cliquez sur Install SQL Express et cliquez sur Next.

  • Dans Ready to Install : récapitulez toutes les fonctionnalités à installer et cliquez sur Install.

Étape 4 : Installation de SQL Server

Une fois les composants TruSmartCAM installés, le programme d’installation procède à l’installation du serveur SQL. Acceptez le contrat de licence pour continuer et installez SQL Express avec les options par défaut.

Une fois l’installation terminée, cliquez sur Close et terminez l’installation.

Selon la version de Windows, la fermeture de l’installation de SQL peut demander un redémarrage.

Étape 5 : Raccourcis du bureau Windows

  • Après l’installation de SQL, si le système ne redémarre pas, cochez la case Launch TruSmartCAM et cliquez sur Finish.

  • Si le système redémarre, lancez l’icône de raccourci TruSmartCAM sur le Bureau ou tapez TruSmartCAM dans le menu Démarrer de Windows et sélectionnez Run as administrator.

Installation du serveur : les icônes de raccourci TruSmartCAM et TruSmartCAM License sont disponibles sur le Bureau.
Installation Client/SYNC : seule l’icône de raccourci TruSmartCAM est disponible sur le Bureau.

Étape 6 : Enregistrement de la licence

  • Dans le champ Serial Number, tapez la clé de série TruSmartCAM fournie par l’équipe de service Trumpf Metamation. Tapez <Company Name> dans le champ "Registered to" et l’adresse e-mail. Cliquez sur OK.

Si le pare-feu réseau bloque l’enregistrement de la licence ou en l’absence de connexion Internet sur le PC serveur TruSmartCAM, la licence TruSmartCAM est activée hors ligne. Envoyez par e-mail le fichier Prax.request du dossier C:\ProgramData\TRUMPF\TMM\Praxis à l’équipe de service Trumpf Metamation. L’équipe Trumpf Metamation fournira le fichier Prax.lock qui devra être déposé dans ce dossier.

Étape 7 : Configuration initiale unique

  • Tapez le nom de la base de données et définissez l’emplacement de stockage des données. Cochez la case Use SQL Server et sélectionnez le nom du serveur SQL pour vous connecter à la base de données. Cliquez sur OK.

  • Le client de bureau TruSmartCAM s’ouvre en affichant Database Connection Succeeded en bas de l’écran.

  • Les fichiers de configuration TruSmartCAM, TecZone et MetaCAM ont été créés avec les machines de configuration par défaut ou selon les machines sous licence TruSmartCAM. La même configuration sera partagée entre tous les clients TruSmartCAM.

L’écran de bienvenue s’affiche avec le nom de connexion Windows comme identifiant et nom TruSmartCAM. Le premier utilisateur TruSmartCAM est considéré comme Site Admin. Indiquez l’adresse e-mail et le mot de passe. Cliquez sur OK .

Cochez la case Remember me pour enregistrer les identifiants de connexion pour la prochaine fois. Décocher la case Remember me affichera la boîte de dialogue de connexion et de mot de passe à chaque lancement de l’application TruSmartCAM.

Étape 8 : Connexion à TruSmartCAM

  • Fermez TruSmartCAM et rouvrez-le. Le système vous invite à saisir les identifiants de connexion TruSmartCAM.

  • Le nom d’utilisateur connecté s’affiche à côté de l’icône utilisateur dans l’en-tête de l’application TruSmartCAM.

  • Lorsque vous survolez l’icône utilisateur, le système affiche :

    • Le rôle de l’utilisateur (par exemple : Programmer, Admin).

    • Un raccourci pour se déconnecter : Ctrl+L.

  • Cliquer sur l’icône utilisateur ouvre un menu qui permet de :

    • Edit information…​ - Mettre à jour les détails de votre profil.

    • Change password…​ - Modifier le mot de passe de votre compte.

    • Sign out - Se déconnecter de l’application.

    • Cancel - Fermer le menu sans effectuer de modification.

Étape 9 : Configuration des machines d’usine

  • Licence TruSmartCAM [bit de licence activant toutes les machines] : la machine et la matière TruSmartCAM par défaut sont considérées comme la configuration d’usine.

  • Licence TruSmartCAM [aucune démo et quelques bits de machine activés] : ces quelques machines et la matière par défaut sont considérées comme la configuration d’usine.

  • (Open → Import) une nouvelle pièce depuis C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts et vérifiez si la pièce est importée correctement.

Note 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor avec installation du moteur (droits Site admin) :

    • Le TruSmartCAM Monitor avec moteur et droits TruSmartCAM Site Admin disposera des options suivantes :

      1. Diffuser la configuration TruSmartCAM, TecZone, MetaCAM vers tous les clients TruSmartCAM. Dispose également des droits pour créer une nouvelle connexion utilisateur TruSmartCAM.

      2. Show Agents affichera le nombre total de moteurs disponibles pour effectuer les tâches d’automatisation, conformément à la licence TruSmartCAM.

  • TruSmartCAM Monitor sans installation du moteur (droits Site admin) :

  • TruSmartCAM Monitor sans installation du moteur (droits non Site Admin) :

Le PC exécutant l’application TruSmartCAM doit avoir le composant Engine TruSmartCAM installé [PC serveur ou toute installation client]. Le PC sur lequel le composant Engine TruSmartCAM est installé doit fonctionner 24h/24 et 7j/7 pour effectuer toutes les tâches d’automatisation.
Note 2 : OpenGL

  • L’application TruSmartCAM, lors de son ouverture, se ferme immédiatement et le pmonitor n’est pas affiché dans la barre des tâches.

  • Cela correspond à un problème OpenGL.

  • Autre moyen de le confirmer : ouvrez C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts qui affiche une boîte de dialogue d’erreur concernant le problème OpenGL.

  • Mettez à jour C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , la section options avec GLVersion=1 permet d’ouvrir l’application TruSmartCAM correctement.

[Options]
GLVersion=1.0
