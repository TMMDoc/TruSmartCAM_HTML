Exigences relatives aux ports

TruSmartCAM Server : 7371

Le serveur attend les requêtes des clients sur ce port TCP. Les connexions entrantes doivent être autorisées sur ce port sur l’ordinateur serveur.

Floating License Server : 5776

Le serveur de licences flottantes attend les requêtes de licence sur ce port. Les connexions entrantes doivent être autorisées sur ce port sur l’ordinateur du serveur de licences flottantes (serveur TruSmartCAM).

License connection to Cloud : 7567

Ce port est utilisé par TecZone (logiciel de pliage) et le serveur de licences flottantes pour envoyer les requêtes de licence au cloud Metamation. Les connexions sortantes doivent donc être autorisées sur ce port pour les activations et les renouvellements de licence.

Exigences d’installation et de support

  • Privilèges administratifs requis pour installer l’application TruSmartCAM.
