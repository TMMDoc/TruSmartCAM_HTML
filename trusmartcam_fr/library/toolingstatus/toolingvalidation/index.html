Validation de l'outillage

Cette section décrit comment accéder aux informations d’outillage des pièces dans TruSmartCAM et les modifier.

  • Cliquez avec le bouton droit sur une vignette de pièce pour ouvrir le panneau de la pièce et accéder aux options d’outillage.

  • Cliquez sur Toolings pour basculer vers la première instance outillée disponible.

  • Vous pouvez également cliquer directement sur une instance outillée pour afficher les détails de la machine et les options d’outillage.

  • Utilisez pour Open in read-only mode for viewing.

  • Utilisez pour Check-out the document for editing.

  • L’instance outillée sélectionnée s’ouvre dans TecZone ou MetaCAM.

  • Effectuez des vérifications d’outillage manuelles et apportez les modifications nécessaires.

  • Lorsque vous tentez d’enregistrer, une boîte de dialogue Unsaved Changes vous invite à confirmer vos modifications.

  • Cliquez sur Yes pour poursuivre l’enregistrement.

  • Le système effectue à nouveau la validation de l’outillage après l’enregistrement.

  • S’il n’y a aucune erreur, l’option d’enregistrement des modifications dans TruSmartCAM apparaît.

  • Si des erreurs d’outillage sont détectées, un message d’erreur s’affiche :

  • Après l’enregistrement, le statut d’outillage de la pièce est mis à jour dans la bibliothèque de pièces.

  • Une couleur verte sur l’instance outillée indique qu’elle est archivée.

  • L’auteur de l’instance outillée est mis à jour avec la dernière personne l’ayant modifiée.

  • Le champ User-edited indique si l’instance outillée a été modifiée manuellement. Lorsqu’un utilisateur extrait l’instance et y apporte des modifications, ce champ est automatiquement défini sur Yes lors de l’enregistrement.

  • Si une pièce est en cours de modification, une icône d’utilisateur apparaît sur sa vignette.

  • Le survol de la vignette indique qui l’a extraite et l’heure de l’extraction.

  • Pendant que la pièce est extraite, l’option Check-out the document for editing est désactivée pour la même instance outillée, et l’option Cancel Check-out devient activée.
