Enregistrement des filtres

Les filtres enregistrés vous permettent de réutiliser des critères fréquemment appliqués dans les Pièces, les Tâches et les Configurations, en simplifiant votre flux de travail. Chaque module est fourni avec des filtres par défaut, mais des listes de filtres supplémentaires peuvent être créées par les administrateurs du site ou les programmeurs selon les besoins. La réutilisation des filtres enregistrés fait gagner du temps et aide à maintenir la cohérence entre les recherches.

  • Cliquez sur l’icône pour afficher les filtres par défaut.

Étapes pour enregistrer les filtres

  • Cliquez sur l’icône , sélectionnez un élément de filtre.

  • Dans le menu déroulant de l’élément de filtre sélectionné, choisissez une option. Une coche apparaîtra à côté de la condition sélectionnée.

  • Pour appliquer la condition, cliquez sur l’icône puis sélectionnez Add Condition Ctrl++. Vous pouvez répéter cette étape pour ajouter plusieurs conditions.

  • Pour enregistrer ces filtres sélectionnés avec des conditions, cliquez sur Save Filter…​ Ctrl+S.

  • Saisissez le nom puis cliquez sur Save.

  • Dans la boîte de dialogue Save Filter, vous pouvez également supprimer tout filtre précédemment enregistré.

  • Ces filtres seront enregistrés dans la liste de filtres par défaut. Ici, Material est enregistré dans la liste par défaut.

Les filtres créés par SiteAdmin et Admin sont partagés entre tous les utilisateurs. Les filtres créés par Programmer et Operator sont partagés uniquement avec les rôles d’utilisateur Programmers et Operators.

Commandes de filtre

Commande Icône Raccourcis Description

Clear Selection

Ctrl+X

Désélectionne tous les choix sélectionnés et actualise la vue des éléments de filtre.

Select Highlighted

Ctrl+A

Sélectionne tous les choix en surbrillance. Cette commande reste désactivée si la mise en surbrillance des éléments n’est pas applicable au champ sélectionné.

Match All

&

Affiche uniquement les éléments qui remplissent toutes les conditions sélectionnées.

Pin In/Out Menu

Ctrl+Down/Up

Une fois épinglé, le menu déroulant reste ouvert même lorsque le focus actuel passe à une autre fenêtre.

Close Menu

Esc

Ferme le menu déroulant.
