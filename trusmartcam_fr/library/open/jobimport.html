Importer des tâches

Importer depuis csv ou xlsx

Vous pouvez également importer des tâches dans des formats texte courants

  • Cliquez sur File → Open → Import Jobs, la boîte de dialogue Open Folder apparaît. Sélectionnez C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Si toutes les pièces existent à l’emplacement csv ou dans les répertoires du dossier de recherche, la fenêtre new job apparaît en répertoriant toutes les pièces correspondant aux champs csv.

  • Les pièces manquantes sont ignorées et n’apparaissent pas dans la fenêtre new job.

  • Au départ, le statut de la pièce est Nascent.

  • Cliquez sur OK, les pièces sont maintenant importées dans la bibliothèque de pièces.

Create a blank part for the missing CAD files

Lors de l’importation de tâches à l’aide d’une feuille de calcul (.csv ou .xlsx), vous pouvez parfois avoir des lignes référençant des fichiers CAD qui ne sont pas disponibles dans le système.

  • Pour gérer cela, accédez à Factory → Settings → Job, sous Spreadsheet import settings activez Create a blank part for the missing CAD files

Lorsque cette option est sélectionnée :

  • Si un fichier CAD est manquant pour une ligne lors de l’importation de la tâche, le système créera automatiquement une pièce vierge à la place du fichier CAD manquant.

  • Dans la fenêtre new job, ces pièces manquantes sont mises en évidence visuellement en jaune pour indiquer que le fichier CAD associé est manquant.

  • La pièce manquante conservera ses champs associés (comme le nom de la pièce, la matière, l’épaisseur, la quantité, etc.) à partir du CSV. Cependant, son état de pièce sera affiché comme Nascent, ce qui signifie qu’il ne s’agit que d’un espace réservé vide sans géométrie réelle pour le moment.

Cela garantit que l’importation de la tâche peut se poursuivre sans erreurs dues aux fichiers CAD manquants — vous pouvez ultérieurement mettre à jour ou remplacer la pièce vierge par le fichier CAD correct lorsqu’il devient disponible.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Lorsque cette case est cochée, le système crée automatiquement la nouvelle tâche sans afficher la boîte de dialogue New Job si la feuille de calcul ne contient aucune erreur (aucune pièce manquante, aucune date manquante ou aucune donnée invalide).

  • Lorsque cette case est décochée, la boîte de dialogue New Job apparaît toujours pour la vérification et la confirmation de l’utilisateur, même si la feuille de calcul ne contient aucune erreur.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Lorsque cette case est cochée, le système s’attend à ce que la feuille de calcul utilise la colonne Raw-Material (par exemple, Steel-20). Cela signifie que le type de matière et l’épaisseur doivent être combinés en une seule valeur dans une colonne.

  • Lorsque cette case est décochée, le système s’attend à ce que la feuille de calcul comporte des colonnes distinctes pour Material et Thickness (par exemple, Steel et 2.00). Le système les combine en interne lors de l’importation.

Dossier surveillé à l’aide de CSV/XLSX

  • Dans factory → Settings→ Watch settings cochez Enable 'Live Folder' et Watch sub-folders also.

  • Définissez le chemin du dossier surveillé (UNC ou lecteur mappé).

  • Dans Spreadsheet import settings, cochez Import spreadsheet from 'Live Folder'.

  • Sélectionnez Import Jobs dans les options d’importation de feuille de calcul.

  • Copiez C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv et collez-le dans le dossier surveillé.

  • Le système vérifie le CSV et tente de créer la tâche automatiquement.

  • Si le fichier CAD est manquant, aucune tâche n’est créée car les données CAD requises sont introuvables.

Répertoire de recherche CAD et recherche CAD récursive - non configuré

  • Dans factory → Settings → Job → Spreadsheet import settings, si aucun CAD lookup directories n’est défini et que Use recursive CAD search n’est pas utilisé, le système ne recherche pas automatiquement les fichiers CAD.

  • Si la case Create a blank part for the missing CAD files est cochée, la tâche sera quand même créée même lorsque les fichiers CAD sont manquants.

  • Dans ce cas, toutes les pièces de la tâche seront créées en tant que pièces nascentes (vierges) — ce qui signifie qu’elles n’ont aucune géométrie car les fichiers CAD sont introuvables.

Répertoire de recherche CAD et recherche CAD récursive - configuré

Lorsque CAD lookup directories est défini sur (C:\Program Files\TRUMPF\TMM\Praxis\Samples) et que Use recursive CAD search est activé sous factory → Settings → Job → Spreadsheet import settings :

  • Le système recherche automatiquement dans le dossier spécifié et tous ses sous-dossiers les fichiers CAD requis mentionnés dans la feuille de calcul.

  • Create a blank part for the missing CAD files est également activé, donc si un fichier CAD est toujours introuvable, le système créera une pièce vierge comme espace réservé.
