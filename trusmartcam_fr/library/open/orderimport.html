Importer des ordres

Les ordres peuvent être créés ou importés à l’aide des méthodes suivantes :

  1. Importation d’ordres à partir de fichiers de feuille de calcul.

  2. Importation automatique d’ordres via les réglages de surveillance.

  3. Création d’ordres à partir de pièces existantes dans la bibliothèque de pièces.

  4. Création d’ordres à partir d’imbrications statiques de modules.

Importer des ordres à partir d’une feuille de calcul

  • Accédez à Open → Import Orders…​.

  • Les formats de feuille de calcul pris en charge incluent CSV, XLSX et XML.

  • Sélectionnez le fichier de feuille de calcul requis et cliquez sur Open.

  • Le processus d’importation est similaire au flux d’importation des Tâches/Modules.

Vous pouvez également glisser-déposer directement la feuille de calcul dans la page Ordres pour importer des ordres.

Importer des ordres à l’aide des réglages de surveillance

  • Activez l’option Import spreadsheet from 'Live Folder' dans Watch settings.

  • Sélectionnez Import Orders dans Spreadsheet import option.

  • Configurez l’emplacement du dossier à partir duquel les ordres doivent être importés.

  • Le système surveille en continu le dossier configuré.

  • Les fichiers de feuille de calcul nouvellement ajoutés sont automatiquement importés dans les Ordres.

Pour les étapes de configuration détaillées, reportez-vous à la documentation Watch settings.

Créer des ordres à partir de la bibliothèque de pièces

  • Sélectionnez les pièces requises dans la bibliothèque de pièces.

  • Cliquez avec le bouton droit et choisissez New…​ → Order pour ouvrir la boîte de dialogue New Orders.

  • Saisissez les détails requis tels que la quantité, l’échéance et la priorité.

  • Cliquez sur OK pour créer les ordres.

  • Le système bascule automatiquement vers la page Ordres.

  • Les ordres créés sont affichés sur la page Ordres prêts pour la création de tâches.

Créer des ordres à partir d’un module

  • Cliquez avec le bouton droit sur le module requis.

  • Sélectionnez New…​ → Order pour ouvrir la boîte de dialogue New Orders.

  • Saisissez le Assembly count requis.

  • Cliquez sur OK pour créer les ordres.
