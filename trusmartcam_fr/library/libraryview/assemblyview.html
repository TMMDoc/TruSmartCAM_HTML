Créer des imbrications statiques à partir d’un module

Des imbrications statiques peuvent être générées pour un module à l’aide de l’assistant d’imbrication interactive. Ces imbrications sont des configurations fixes associées uniquement au module sélectionné.

  • Basculez vers la vue assys.

  • Cliquez avec le bouton droit sur le module requis et sélectionnez Create Nests…​.

  • L’assistant d’imbrication interactive s’ouvre.

  • Par défaut, l’assistant d’imbrication interactive bascule vers la page Select Machine & Material.

  • Les machines sont affichées avec des barres de couleur indiquant la charge de production disponible :

    • Barre verte : Heures planifiées

    • Barre grise : Heures disponibles (sur un poste de 8 heures)

  • Sous chaque machine, les pièces sélectionnées sont regroupées avec leur matière brute (Pièces/Quantité totale).

  • Si une pièce ne dispose pas d’une solution d’outillage valide pour une machine, cette pièce et cette matière sont ignorées lors du traitement pour une machine donnée.

  • Si une matière brute est sélectionnée pour une machine, elle ne sera pas disponible pour les autres machines.

  • Une fois le plan d’imbrication de la machine défini, sélectionnez la tôle préférée et remplacez les paramètres de la tôle comme Priority, Quantity, Margins, etc.

  • Vous pouvez filtrer les tôles pour afficher All Sheets, Standard Sheets ou Remnant Sheets. Cliquez sur next.

Il n’est pas possible d’augmenter les quantités à ce stade. Vous pouvez soit conserver la même quantité que l’inventaire des tôles, soit la réduire et vérifier les résultats de l’imbrication.

  • Update Qty apparaît dans la fenêtre du plan d’imbrication interactive.

  • Par défaut, Pick All (F5) inclut toutes les pièces pour l’imbrication, ou vous pouvez sélectionner manuellement les pièces prioritaires et ajuster les quantités de pièces. Cliquez sur next.

  • L’imbrication commence et les pièces imbriquées dans la tôle sont mises à jour avec un statut de couleur bleue.

  • La charge de production de la machine se met à jour en fonction du résultat de l’imbrication.

  • Si certaines pièces restent non imbriquées, le message Some parts remain unnested apparaît - ces pièces restent dans la tâche d’origine.

    • Une pièce peut rester non imbriquée si aucune tôle appropriée n’est disponible.

  • Les imbrications statiques peuvent être modifiées pour inclure les pièces non imbriquées :

    • Sélectionnez la configuration dans laquelle vous souhaitez insérer les pièces non imbriquées et extrayez-la pour modification.

  • TecZone s’ouvre. Cliquez sur Pick ou Pick All pour sélectionner les pièces non imbriquées du module parent.

  • Disposez la pièce dans la configuration selon les besoins.

  • Les imbrications générées sont automatiquement nommées d’après le module parent pour une identification facile.

Les imbrications statiques ne peuvent pas contenir de pièces provenant d’autres modules. Autoriser des imbrications de modules mixtes empêcherait la libération d’un module sans libérer les autres, le mélange est donc interdit par conception.

Composants hors tôle

  • Lorsqu’un module est importé, les pièces en tôle sont extraites et ajoutées aux modules dans la bibliothèque de pièces.

  • Les composants hors tôle sont séparés et ajoutés aux Components.

  • Le module est ajouté à la bibliothèque de modules et sa nomenclature (Bill of Materials) contient à la fois des pièces et des composants.

  • Si une pièce a déjà été importée en tant que pièce en tôle, le système met à jour l’entrée existante et supprime les doublons de la bibliothèque de pièces.

  • La sélection d’un module affiche à la fois les pièces et les composants, avec les quantités de composants affichées sous l’image du composant (nombre de composants du module sélectionné et nombre total de composants).

  • Les info-bulles des composants affichent le nom, la matière et la taille. Les composants sont exclus lors de la production - ils ne sont pas imbriqués, et aucune tôle n’est générée pour les composants.

  • Des exemples de modules et de composants sont disponibles à : C:\Program Files\TRUMPF\TMM\Praxis\Samples\Assys\Components, qui peuvent être utilisés pour tester les flux d’importation de composants et de modules.

Création d’une tâche à partir d’un module

  • Cliquez avec le bouton droit sur le module, cliquez sur New…​, puis Job.

  • Dans la boîte de dialogue New Job, définissez le nombre de modules, cliquez sur OK, puis mettez à jour les détails de la tâche (comme l’échéance et la priorité) selon les besoins.

  • Le système crée une tâche à partir du module et copie les imbrications statiques en tant qu’imbrications de tâche, en mettant à jour le nombre de tôles. Les imbrications copiées sont préfixées par l’identifiant de la tâche.

  • Les imbrications de tâche peuvent être modifiées ou supprimées sans affecter les imbrications statiques d’origine.

  • Les imbrications de tâche peuvent être recompactées à l’aide de Adapt/Compact…​ ou Add parts…​.

  • Pour des étapes détaillées, voir Adapt/Compact et Add parts.

Si une pièce n’apparaît pas dans une imbrication, vérifiez la boîte de dialogue de modification de l’imbrication - vous pouvez insérer manuellement les pièces non imbriquées.

Utilisez des recherches et des filtres enregistrés pour trouver rapidement des pièces dans plusieurs modules.

Utilisez des noms de modules et d’imbrications clairs et descriptifs pour éviter toute confusion lors de la copie des imbrications dans les tâches.
