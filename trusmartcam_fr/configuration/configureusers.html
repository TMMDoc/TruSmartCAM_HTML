Configurer les utilisateurs

  • Les clients TruSmartCAM avec différents rôles sont utilisés pour contrôler la configuration de l’usine.

    • Ajout de nouvelles machines, matières et tôles.

    • Modification des configurations de machines.

    • Modification des pièces, tâches et modules.

    • Modification / mise à jour des tôles d’imbrication, planification de tâche.

    • Ajout / modification des utilisateurs.

  • Le PC d’installation du Pserver est considéré comme le premier utilisateur TruSmartCAM.

  • TruSmartCAM utilise les identifiants Windows comme nom d’utilisateur TruSmartCAM, qui est Site Admin.

  • L’installation suivante, c’est-à-dire le nom d’utilisateur de l’ordinateur d’installation du client TruSmartCAM, est considérée comme Programmer.

Seul Site Admin peut modifier les informations des autres utilisateurs et changer le mot de passe.

Operator

Configuration / tâche terminée, ajout d’une nouvelle tôle, commandes de configuration

Tout le reste est refusé.
