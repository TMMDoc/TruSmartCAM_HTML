Imbrication interactive

L’imbrication interactive peut être utilisée pour créer un plan d’imbrication pour une seule pièce, quelques pièces d’une tâche, une seule tâche ou plusieurs tâches. Elle vous permet de sélectionner des machines et des matières, de définir des paramètres de tôle et d’examiner les résultats d’imbrication de manière interactive.

Effectuez un clic droit sur une pièce ou une tâche et sélectionnez l’option Plan Part…​/Plan Job…​ → Run Interactive Nesting…​.

  • La fenêtre Interactive Nesting s’ouvre.

  • Par défaut, la fenêtre d’imbrication interactive bascule vers la page Select Machine & Material.

  • Les machines sont affichées avec des barres de couleur indiquant la charge de production disponible :

    • Barre verte : heures planifiées

    • Barre grise : heures disponibles (sur une équipe de 8 heures)

  • Sous chaque machine, les pièces sélectionnées sont regroupées avec leur matière brute (pièces/quantité totale).

  • Si une pièce ne dispose pas d’une solution d’outillage valide pour une machine, cette pièce et cette matière sont ignorées pour le traitement sur la machine donnée.

  • Si une matière brute est sélectionnée pour une machine, elle ne sera pas disponible pour d’autres machines.

  • Une fois le plan d’imbrication de la machine défini, sélectionnez la tôle souhaitée et remplacez les paramètres de la tôle tels que Priority, Quantity, Margins, etc.

  • Vous pouvez filtrer les tôles pour afficher All Sheets, Standard Sheets ou Remnant Sheets. Cliquez sur Next.

Il n’est pas possible d’augmenter les quantités à ce stade. Vous pouvez soit conserver la même quantité que l’inventaire des tôles, soit la réduire et vérifier les résultats d’imbrication.

  • Update Qty apparaît dans la fenêtre du plan d’imbrication interactive.

  • Par défaut, Pick All (F5) inclut toutes les pièces pour l’imbrication, ou vous pouvez sélectionner manuellement les pièces prioritaires et ajuster les quantités de pièces. Cliquez sur Next.

  • L’imbrication démarre et les pièces imbriquées dans la tôle sont mises à jour avec un état de couleur bleue.

  • La charge de production de la machine est mise à jour en fonction du résultat de l’imbrication.

  • Les configurations imbriquées sont dessinées à l’échelle et affichées dans l’onglet Nest Results.

  • Si certaines pièces restent non imbriquées, le message Some parts remain unnested apparaît - ces pièces restent dans la tâche d’origine.

    • La raison de la non-imbrication peut être l’absence de tôle disponible pour l’imbrication.

  • Les résultats de l’imbrication interactive sont préfixés comme suit : factory → settings → Job→ Nest settings, Interactive sheet-name prefix.

  • Les configurations d’imbrication interactive sont préfixées par la lettre L.
