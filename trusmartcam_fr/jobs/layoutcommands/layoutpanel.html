Panneau de configuration

Cette section présente les actions liées aux configurations telles que Send to machine, Recall from machine, Export outputs, Mark complete, Add parts…​, Adapt/Compact…​, Split layout, et d’autres options utilisées pour gérer les instances de configuration.

Open in read-only mode for viewing
Ouvre la configuration sélectionnée en mode lecture seule.

Check-out the document for editing
Active la modification de la configuration sélectionnée.

Delete
Supprime la configuration sélectionnée.

View Report
Ouvre le rapport de configuration standard et le rapport spécifique aux étiquettes pour la configuration sélectionnée.

Send to Machine…​

Envoie la configuration sélectionnée à la machine et exporte les fichiers de sortie (fxlyt, NC, rapport, csv) vers l’emplacement de sortie de la tâche.

Add Parts…​

Ajoute davantage de pièces à une configuration mal remplie à l’aide de l’assistant de réempaquetage de configuration.

Adapt/Compact…​

Réimbrique la configuration sélectionnée pour compacter les pièces et libérer de l’espace utilisable.

Change LTT…​

Modifie la tôle assignée à la configuration sélectionnée.

Split Layouts…​

Divise la configuration sélectionnée en deux configurations distinctes ou plus.

Rename…​

Renomme la configuration sélectionnée.

Job / Prev / Next / Parts

Navigue vers la tâche parente, vers la configuration précédente ou suivante au sein de la tâche sélectionnée, ou vers les pièces contenues dans la configuration.

Sort and filter

Utilisez ces filtres pour afficher d’autres configurations partageant le même attribut que la configuration sélectionnée : Same Machine, Same Material, Same LTT, Same Priority, Same State, Same Sheet, Same Part, Same Remnant State, ou Same Rolling Direction.

Send to machine

  • Lorsqu’une imbrication est prête (remplie ou requise d’urgence), vous pouvez l’envoyer à la machine.

  • Effectuez un clic droit sur l’imbrication et sélectionnez Send to machine…​.

  • Un dossier est créé automatiquement, nommé d’après l’imbrication.

  • Les fichiers de sortie (fxlyt, NC, rapport, csv) sont exportés vers l’emplacement de sortie de la tâche (JOB).

  • Les imbrications envoyées à la machine sont affichées avec une coche bleue.

Une fois libérées, ces imbrications ne sont plus retentées pour le réempaquetage.

Recall from machine

  • Si la sortie nécessite une validation ou une mise à jour (par exemple, l’ajout de pièces supplémentaires) :

    • Effectuez un clic droit sur la configuration exportée.

    • Sélectionnez Recall from machine…​.

  • Les fichiers de sortie et le dossier (fxlyt, NC, rapport, csv) sont supprimés.

  • L’imbrication redevient modifiable.

  • Vous pouvez apporter des modifications et l’envoyer à nouveau à la machine.

Export outputs

  • Effectuez un clic droit sur toute configuration (imbrication) qui a été envoyée à la machine et cliquez sur Export outputs.

  • L’option Export Outputs exporte les fichiers NC, Report et Layout vers les dossiers de sortie machine respectifs.

  • Cette option régénère le fichier NC avec les réglages d’unités actuels pour la configuration.

Export Outputs n’est pas disponible pour les configurations terminées et les configurations en attente dans la file de réempaquetage.

Marquer comme terminé

  • Une fois l’imbrication traitée sur la machine, effectuez un clic droit sur l’imbrication et sélectionnez Mark complete…​.

  • Vous pouvez sélectionner plusieurs imbrications et les marquer comme terminées en même temps.

  • Lorsqu’une imbrication est marquée comme terminée :

    • Elle est grisée, déplacée à la fin de la liste et affichée avec une coche verte.

    • La configuration est retirée de la liste des configurations actives.

    • Les états des pièces et de la tâche sont mis à jour, et les quantités traitées passent à l’état terminé.

    • Les fichiers de sortie de cette configuration sont retirés de l’emplacement de sortie machine afin d’éviter toute utilisation en double.

Add parts…​

  • Utilisez cette option pour ajouter davantage de pièces à une configuration relativement mal remplie. Comme l’imbrication interactive, il s’agit d’une option guidée par un assistant qui peut être utilisée sur une ou plusieurs configurations en même temps.

  • TruSmartCAM affiche l’assistant de réempaquetage de configuration dans la zone de travail principale lorsque cette option est utilisée. Maintenez la touche Ctrl enfoncée et sélectionnez une ou plusieurs pièces à placer sur la ou les configurations, puis appuyez sur Next.

  • Les pièces sélectionnées sont affichées à l’étape suivante avec une colonne de quantité modifiable. Mettez à jour les quantités de pièces si nécessaire dans le champ Update Qty. Cliquez sur Next pour passer à l’imbrication. Notez que les quantités ne peuvent être qu’augmentées, pas réduites.

  • Toutes les configurations sont imbriquées séparément, et les résultats imbriqués sont affichés avec les pièces nouvellement placées. La sélection de la configuration affiche toutes les pièces existantes de la configuration. Le résultat est automatiquement abandonné si aucune nouvelle pièce n’est placée pendant le réempaquetage. Une configuration comportant plusieurs copies peut aboutir à des motifs différents après le réempaquetage.

Adapt/Compact…​

  • Cette commande basée sur un assistant peut être utilisée pour adapter une configuration d’une machine à une autre lorsque la machine d’origine est en panne ou lorsque la charge de travail des machines doit être équilibrée.

  • Elle peut être utilisée lorsque la tôle prévue est en rupture de stock et que la configuration doit être replanifiée sur une autre tôle disponible.

  • Vous pouvez fusionner des configurations empaquetées sur de plus petites tôles sur de plus grandes tôles pour utiliser la matière plus efficacement.

  • Vous pouvez diviser des configurations empaquetées sur de plus grandes tôles en tôles plus petites si les stocks de grandes tôles ne sont pas disponibles.

  • Vous pouvez améliorer l’efficacité d’empaquetage de plusieurs configurations (même provenant de machines différentes) en les fusionnant.

  • Pour l’utiliser, sélectionnez une ou plusieurs configurations et cliquez sur Adapt/Compact…​ pour ouvrir l’assistant dans la zone de travail.

  • Le volet de gauche affiche toutes les configurations sélectionnées et le volet Parts affiche les pièces de la configuration.

  • Sélectionnez la machine cible et la matière de la tôle, puis cliquez sur next pour effectuer la réimbrication.

  • Les nouveaux résultats d’imbrication sont affichés dans le volet des résultats.

  • Cliquez sur next pour enregistrer la configuration adaptée ou compactée.

Diviser une configuration

L’option Split layouts…​ vous permet de diviser une configuration existante en plusieurs configurations en modifiant les quantités, sans avoir à refaire l’outillage ou l’imbrication.

Cette fonctionnalité est particulièrement utile dans les scénarios suivants :

  1. Lorsque vous devez produire immédiatement une partie de la quantité totale tout en planifiant la quantité restante pour une production ultérieure.

  2. Lorsque les besoins de production doivent être répartis sur plusieurs équipes ou jours afin d’optimiser le flux de travail et l’utilisation des ressources.

  3. Lorsqu’une machine spécifique est temporairement indisponible ou occupée, et que vous devez ajuster la configuration pour tenir compte des contraintes de production actuelles.

Pour diviser une configuration, procédez comme suit :

  • Dans la vue Layouts, sélectionnez la configuration souhaitée.

  • Cliquez sur Split layouts…​.

  • Saisissez la valeur requise dans New Copies.

  • Cliquez sur OK.

La configuration sélectionnée est maintenant divisée en deux configurations avec des quantités ajustées.
