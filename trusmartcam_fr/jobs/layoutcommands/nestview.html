Vue de configuration

  • La sélection de l’option nests affiche la liste de toutes les imbrications de la tâche actuellement sélectionnée.

  • Double-cliquez sur une imbrication pour afficher une répartition détaillée de cette imbrication.

  • La répartition de l’imbrication affiche :

    • Les pièces utilisées dans l’imbrication.

    • Des informations détaillées telles que la matière utilisée, le temps de cycle et d’autres métriques.

  • Vous pouvez parcourir les différentes imbrications et cliquer sur n’importe quelle pièce pour effectuer les mêmes actions que celles disponibles dans la zone Parts.

  • Un clic droit sur une imbrication ouvre le panneau Layout.

    • Send to Machine…​ libère l’imbrication pour la production sur les machines, après quoi l’option d’imbrication passe à Recall from Machine.

    • Add Parts…​ permet d’ajouter des pièces supplémentaires à l’imbrication.

    • Adapt/Compact…​ permet de modifier par lot les matières ou les machines utilisées dans l’imbrication.

    • Change LTT…​ permet d’appliquer une technologie laser différente pour la matière et l’épaisseur sélectionnées dans l’imbrication.

    • Split Layouts…​ permet de transformer une imbrication comportant plusieurs répétitions en une nouvelle imbrication.

    • Rename…​ permet de renommer l’imbrication.
