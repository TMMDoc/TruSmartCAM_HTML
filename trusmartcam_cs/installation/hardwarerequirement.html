Požadavky na porty

TruSmartCAM Server : 7371

Server čeká na požadavky klientů na tomto TCP portu. Na serverovém počítači by měla být pro tento port povolena příchozí spojení.

Floating License Server : 5776

Floating License Server čeká na licenční požadavky na tomto portu. Na počítači serveru plovoucích licencí (TruSmartCAM Server) by měla být pro tento port povolena příchozí spojení.

Licenční připojení ke Cloudu : 7567

Tento port používá TecZone (software pro ohýbání) a Floating License Server k odesílání licenčních požadavků do Metamation Cloud. Pro aktivaci a obnovení licencí by proto mělo být na tomto portu povoleno odchozí spojení.

Požadavky na instalaci a podporu

  • Pro instalaci aplikace TruSmartCAM jsou vyžadována oprávnění správce.

  • Nástroje pro vzdálenou diagnostiku prostřednictvím dodavatelské VPN nebo zabezpečeného připojení.
