Instalace serveru

Postupujte podle pokynů k instalaci TruSmartCAM Serveru spolu se SQL.

Práva administrátora

Ke spuštění této instalace musí mít uživatel oprávnění správce.

  • Instalaci zahájíte spuštěním souboru Setup.TruSmartCAM.<version>.exe.

Verze je číslo.

  • Přečtěte si licenční smlouvu, zvolte I accept the agreement a poté klikněte na Next.

Krok 1 : Umístění instalace

  • Zadejte instalační adresář nebo přijměte výchozí instalační adresář C:\Program Files\TRUMPF\TMM\Praxis a klikněte na Next.

    • C:\Program Files\TRUMPF\TMM\Praxis - Instalační složka bude obsahovat následující složky: Bin, MetaCAM, Samples a Tracker.

    • C:\ProgramData\TRUMPF\TMM\Praxis - Datová složka bude obsahovat následující složky: TruSmartCAM, TecZone a MetaCAM.

Krok 2 : Výběr komponent

Typ instalace Komponenty

Full

Server + Desktop klient + Engine

Client

Desktop klient

Server

Server + Desktop klient

Station

Vybere všechny terminály stanic jako TecZone, MetaCAM, RightAngle (řídicí jednotka ohýbání), Vulcan (řídicí jednotka laserového stroje)

Custom

Vybere podle volby uživatele.

  • Zvolte Full Installation. Vyberte Code Senders a Bend Code Senders z TruSmartCAM Tools. Nyní se typ instalace změní na Custom. Klikněte na Next.

Krok 3 : Volba instalace SQL serveru

Instalace SQL Express 2022 je potřebná pouze pro TruSmartCAM Server. Tato možnost není dostupná pro instalace klienta a Sync. Rovněž je zaškrtnuta a instalována při prvním spuštění a poté ji lze ignorovat. Pokud je již SQL na serveru TruSmartCAM nainstalován, může uživatel Step 3 ignorovat.

  • V Select Additional Tasks: Klikněte na Install SQL Express a klikněte na Next.

  • V Ready to Install: Shrňte všechny instalační funkce a klikněte na Install.

Krok 4 : Instalace SQL serveru

Po instalaci komponent TruSmartCAM pokračuje instalační program instalací SQL serveru. Chcete-li pokračovat, přijměte licenční smlouvu a nainstalujte SQL express s výchozími možnostmi.

Po dokončení instalace klikněte na Close a dokončete instalaci.

V závislosti na verzi systému Windows může uzavření instalace SQL vyžadovat restart.

Krok 5 : Zástupci na ploše Windows

  • Pokud se po instalaci SQL systém nerestartuje, zaškrtněte políčko Launch TruSmartCAM a klikněte na Finish.

  • Pokud se systém restartuje, spusťte ikonu zástupce TruSmartCAM na ploše nebo zadejte TruSmartCAM v nabídce Start systému Windows a zvolte Run as administrator.

Server installation : Ikony zástupců TruSmartCAM a TruSmartCAM License jsou dostupné na ploše.
Client/SYNC Installation : Na ploše je dostupná pouze ikona zástupce TruSmartCAM.

Krok 6 : Registrace licence

  • Do pole Serial Number zadejte TruSmartCAM Serial key poskytnutý týmem Trumpf Metamation Service. Do pole "Registered to" zadejte <Company Name> a e-mail. Klikněte na OK.

V případě, že síťový firewall blokuje registraci licence nebo pokud na PC serveru TruSmartCAM není internet, provádí se licence TruSmartCAM offline aktivací. Odešlete e-mailem soubor Prax.request ze složky C:\ProgramData\TRUMPF\TMM\Praxis týmu Trumpf Metamation Service. Tým Trumpf Metamation poskytne soubor Prax.lock, který je třeba umístit do této složky.

Krok 7 : Počáteční jednorázová konfigurace

  • Zadejte název databáze a nastavte umístění úložiště dat. Zaškrtněte políčko Use SQL Server a vyberte název SQL serveru pro připojení k databázi. Klikněte na OK.

  • Otevře se TruSmartCAM Desktop klient a v dolní části zobrazí Database Connection Succeeded.

  • Konfigurační soubory TruSmartCAM, TecZone a MetaCAM byly vytvořeny s výchozími konfiguračními stroji nebo podle strojů licence TruSmartCAM. Stejná konfigurace bude sdílena mezi všemi klienty TruSmartCAM.

úvodní obrazovka zobrazí přihlašovací jméno uživatele Windows jako přihlášení a jméno TruSmartCAM. První uživatel TruSmartCAM je považován za Site Admin. Zadejte e-mail a heslo. Klikněte na OK .

Zaškrtnutím políčka Remember me uložíte přihlašovací údaje pro příště. Zrušení zaškrtnutí políčka Remember me vyvolá dialog pro přihlášení a heslo při každém spuštění aplikace TruSmartCAM.

Krok 8 : Přihlášení do TruSmartCAM

  • Zavřete TruSmartCAM a znovu jej otevřete. Systém vás vyzve k zadání přihlašovacích údajů TruSmartCAM.

  • Přihlášené uživatelské jméno se zobrazuje vedle ikony uživatele v záhlaví aplikace TruSmartCAM.

  • Když najedete kurzorem na ikonu uživatele, systém zobrazí:

    • Roli uživatele (například: Programmer, Admin).

    • Zástupce pro odhlášení: Ctrl+L.

  • Kliknutím na ikonu uživatele se otevře nabídka, která vám umožní:

    • Edit information…​ - Aktualizovat údaje vašeho profilu.

    • Change password…​ - Změnit heslo vašeho účtu.

    • Sign out - Odhlásit se z aplikace.

    • Cancel - Zavřít nabídku bez provedení jakýchkoli změn.

Krok 9 : Konfigurace strojů závodu

  • TruSmartCAM License [bit licence povolující všechny stroje] : Výchozí stroj a materiál TruSmartCAM jsou považovány za tovární konfiguraci.

  • TruSmartCAM License [žádné demo a povoleno několik bitů strojů] : Těchto několik strojů a výchozí materiál jsou považovány za tovární konfiguraci.

  • (Open → Import) nový díl ze složky C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts a ověřte, zda byl díl úspěšně importován.

Poznámka 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor s instalací Engine (práva Site admin):

    • TruSmartCAM Monitor s Engine spolu s právy Site Admin TruSmartCAM bude mít následující možnosti:

      1. Rozeslat konfiguraci TruSmartCAM, TecZone, MetaCAM všem klientům TruSmartCAM. Rovněž má práva vytvořit nové přihlášení uživatele TruSmartCAM.

      2. Show Agents zobrazí celkový počet dostupných engine pro provedení automatizačních úloh, který odpovídá licenci TruSmartCAM.

  • TruSmartCAM Monitor bez instalace Engine (práva bez Site Admin):

PC, na kterém běží aplikace TruSmartCAM, musí mít nainstalovanou komponentu Engine TruSmartCAM [PC serveru nebo v jakékoli klientské instalaci]. PC s nainstalovanou komponentou Engine TruSmartCAM by mělo běžet 24x7, aby provádělo všechny automatizační úlohy.
Note 2 : OpenGL

  • Aplikace TruSmartCAM se při otevírání okamžitě zavře a na hlavním panelu se rovněž nezobrazuje pmonitor.

  • To představuje problém s OpenGL.

  • Další způsob, jak to potvrdit: Otevřete C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts , který zobrazí chybový dialog o problému s OpenGL.

  • Aktualizace C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini , sekce options s hodnotou GLVersion=1 zajistí úspěšné otevření aplikace TruSmartCAM.

[Options]
GLVersion=1.0
