Import dílů

Import dílů

Před importem dílů se ujistěte, že formáty souborů jsou kompatibilní s TruSmartCAM. Další podrobnosti naleznete v podporované formáty souborů.

Pokud po importu nejsou k dílu namapovány materiál a tloušťka, přiřaďte materiál pomocí panelu dílu.

Metody importu

Existují tři metody importu dílů do knihovny dílů:

  1. Import prostřednictvím souboru

  2. Přetažení

  3. Watch folder

Import prostřednictvím souboru

Soubor 2D nebo 3D dílu lze importovat do knihovny dílů pomocí možnosti Import parts…​.

  • Klikněte na ikonu open na příkazovém panelu a vyberte možnost Import parts…​.

  • Zobrazí se dialog Open — vyberte libovolný soubor CAD (2D nebo 3D).

  • Zobrazí se náhled vybraného souboru CAD.

  • Vyberte požadovaný díl a klikněte na Open.

  • Systém automaticky nastrojí díl pro všechny dostupné stroje s aktualizovaným stavem nastrojení.

Přetažení

  • Přetáhněte soubor dílu přímo do knihovny dílů TruSmartCAM.

Sledovaná složka

Nastavení Watch vám umožňuje sledovat složku pro nové soubory a automaticky je importovat do knihovny dílů.

Ke konfiguraci viz stránka Nastavení sledování.

  • Použijte cestu UNC (Universal Naming Convention) \\192.168.1.11\<Folder path> nebo připojený disk M:\<Folder Path>.

  • PC, na kterém běží Engine, musí mít k této složce přístup pro čtení/zápis.

  • Nepoužívejte lokální cestu jako C:\<Folder Path>, protože služba Watch vyhledává soubory na PC s Engine — nikoli na lokálním PC.

Konfigurace importu

Use geometry comparison on same CAD revision

Při importu dílu se stejnou CAD revizí může TruSmartCAM porovnat geometrii souboru CAD s existujícím dílem.

  • Chcete-li to povolit, nakonfigurujte Revision lookup keys (například REV) v factory → settings →Import. Poté povolte možnost Use geometry comparison on same CAD revision.

Porovnání geometrie u stejné CAD revize funguje pouze tehdy, když jsou nakonfigurovány Revision lookup keys.

  • Nyní importujte díl do knihovny dílů s konkrétní revizí (například Revision 1).

  • Stejný díl je importován znovu se stejnou hodnotou revize.

  • TruSmartCAM porovná geometrii nově importovaného souboru CAD s existujícím dílem.

  • Pokud je zjištěn rozdíl v geometrii, TruSmartCAM zobrazí výzvu s dotazem, zda:

    • Replace nahradit existující díl novou geometrií při zachování stejné hodnoty revize.

    • Skip přeskočit import a zachovat existující díl a jeho geometrii.

To umožňuje uživatelům aktualizovat geometrii dílu bez změny hodnoty revize a zároveň si zachovat kontrolu nad tím, zda jsou existující díly nahrazeny.

Importované díly jsou automaticky přidány do knihovny pro další použití. Další informace naleznete v Knihovna.
