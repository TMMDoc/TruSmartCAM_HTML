Import úloh

Import z csv nebo xlsx

Úlohy můžete také importovat v běžných textových formátech

  • Klikněte na File → Open → Import Jobs, zobrazí se dialog Open Folder. Vyberte C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • Pokud všechny díly existují v umístění csv nebo v adresářích vyhledávacích složek, zobrazí se okno new job se seznamem všech dílů odpovídajících polím csv.

  • Chybějící díly jsou ignorovány a nezobrazují se v okně new job.

  • Zpočátku je stav dílu Nascent.

  • Klikněte na OK, nyní jsou díly importovány do knihovny dílů.

Create a blank part for the missing CAD files

Při importu úloh pomocí tabulky (.csv nebo .xlsx) můžete někdy mít řádky odkazující na soubory CAD, které nejsou v systému dostupné.

  • Chcete-li to ošetřit, přejděte na Factory → Settings → Job, v Spreadsheet import settings povolte Create a blank part for the missing CAD files

Když je tato možnost vybrána:

  • Pokud během importu úlohy chybí soubor CAD pro jakýkoli řádek, systém automaticky vytvoří prázdný díl namísto chybějícího souboru CAD.

  • V okně new job jsou tyto chybějící díly vizuálně zvýrazněny žlutě, aby označovaly, že přidružený soubor CAD chybí.

  • Chybějící díl bude stále mít svá namapovaná pole (jako název dílu, materiál, tloušťku, množství atd.) z CSV. Jeho stav dílu se však zobrazí jako Nascent, což znamená, že jde pouze o prázdný zástupný symbol bez skutečné geometrie.

Tím je zajištěno, že import úlohy může stále pokračovat bez chyb způsobených chybějícími soubory CAD — prázdný díl můžete později aktualizovat nebo nahradit správným souborem CAD, jakmile bude k dispozici.

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings→ Do not show the New Job dialog if the spreadsheet has no error

  • Když je toto políčko zaškrtnuto, systém automaticky vytvoří novou úlohu bez zobrazení dialogu New Job, pokud tabulka nemá žádné chyby (žádné chybějící díly, chybějící data nebo neplatná data).

  • Když je toto políčko zrušeno, dialog New Job se vždy zobrazí ke kontrole a potvrzení uživatelem, i když tabulka nemá žádné chyby.

Prefer raw-material column over material + thickness

factory → Settings → Job→Prefer Raw-Material column over Material + Thickness

  • Když je toto políčko zaškrtnuto, systém očekává, že tabulka použije sloupec Raw-Material (například Steel-20). To znamená, že typ materiálu a tloušťka by měly být zkombinovány do jedné hodnoty v jednom sloupci.

  • Když je toto políčko zrušeno, systém očekává, že tabulka bude mít samostatné sloupce pro Material a Thickness (například Steel a 2.00). Systém je během importu interně zkombinuje.

Sledovaná složka pomocí CSV/XLSX

  • V factory → Settings→ Watch settings zaškrtněte Enable 'Live Folder' a Watch sub-folders also.

  • Nastavte cestu ke složce Watch (UNC nebo připojený disk).

  • V Spreadsheet import settings zaškrtněte Import spreadsheet from 'Live Folder'.

  • Vyberte Import Jobs z možností Spreadsheet Import.

  • Zkopírujte C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv a vložte jej do složky Watch.

  • Systém zkontroluje CSV a pokusí se úlohu vytvořit automaticky.

  • Pokud soubor CAD chybí, žádná úloha se nevytvoří, protože požadovaná CAD data nebyla nalezena.

Vyhledávací adresář CAD a rekurzivní vyhledávání CAD - nenakonfigurováno

  • V factory → Settings → Job → Spreadsheet import settings, pokud není nastaven žádný CAD lookup directories a Use recursive CAD search se nepoužívá, systém nevyhledává soubory CAD automaticky.

  • Pokud je zaškrtnuto políčko Create a blank part for the missing CAD files, úloha se stále vytvoří, i když soubory CAD chybí.

  • V tomto případě budou všechny díly v úloze vytvořeny jako nascent (prázdné) díly — což znamená, že nemají žádnou geometrii, protože soubory CAD nebylo možné najít.

Vyhledávací adresář CAD a rekurzivní vyhledávání CAD - nakonfigurováno

Když je CAD lookup directories nastaven na (C:\Program Files\TRUMPF\TMM\Praxis\Samples) a Use recursive CAD search je povolen v factory → Settings → Job → Spreadsheet import settings:

  • Systém automaticky prohledá určenou složku a všechny její podsložky pro požadované soubory CAD uvedené v tabulce.

  • Create a blank part for the missing CAD files je rovněž povoleno, takže pokud některý soubor CAD stále není nalezen, systém vytvoří prázdný díl jako zástupný symbol.
