Import konstrukčních skupin

Konstrukční skupiny jsou skupiny souvisejících dílů zkombinovaných do jednoho celku, což umožňuje spravovat více dílů společně jako jednu entitu.

Konstrukční skupiny můžete importovat pomocí následujících metod:

  1. Import prostřednictvím souboru

  2. Přetažení

  3. Import z tabulky

Import prostřednictvím souboru

Konstrukční skupinu lze importovat do knihovny dílů pomocí možnosti Import Assemblies…​.

  • Klikněte na ikonu Open v příkazovém řádku a vyberte Import Assemblies…​, nebo použijte File → Open → Import Assemblies…​.

  • Zobrazí se dialog Open. Vyberte požadované soubory konstrukčních skupin.

  • Zobrazí se náhled vybrané konstrukční skupiny.

  • Kliknutím na Open konstrukční skupinu importujete.

  • Importované konstrukční skupiny jsou uvedeny v zobrazení Assemblies v knihovně dílů.

Přetažení

  • Přetáhněte konstrukční skupinu přímo do knihovny dílů TruSmartCAM.

Import z tabulky

  • Použijte File → Open → Import Assemblies…​ a vyberte soubor CSV, XLSX nebo XML, nebo soubor přetáhněte.

  • Před importem zkontrolujte a aktualizujte údaje a množství konstrukčních skupin. Pro úpravy použijte Add…​ nebo Remove…​.

  • Po importu lze konstrukční skupiny připravit a přiřadit jim statická rozmístění (Static Nests).
