Import

Import

Output settings

Save flat pattern - Povolte tuto možnost pro uložení rozvinutého tvaru importovaného dílu.

Format for flat pattern - Tato možnost se používá k výběru formátu souboru DXF nebo GEO.

Flat pattern destination - Toto je umístění, kam se rozvinutý tvar uloží.

Import settings

Units for DXF files - Toto je měrná jednotka, se kterou bude soubor DXF importován, uživatel si může vybrat mezi mm nebo palcem.

Material lookup keys - Pomocí oddělovače čárkou lze přiřadit více vyhledávacích záznamů. Když je díl importován, TruSmartCAM používá tyto klíče k vyhledání hodnot materiálu. Vyhledané hodnoty se poté použijí k rozlišení surového materiálu. Původní hodnoty jsou uloženy ve Misc Properties dílu.

Revision lookup keys - Když je díl importován, hodnota revize ze souboru surového dílu (importovaný soubor dílu) je porovnána se stávající hodnotou revize v repozitáři. Import je zrušen, pokud je revize stejná. Vlastní mapování polí je nyní také podporováno pro soubory DXF. U souborů DXF jsou data vlastního pole extrahována z textové vrstvy ve výkresu nebo z přílohy PPI.

Use geometry comparison on same CAD revision - Porovnává geometrii při importu dílu se stejnou CAD revizí a vyzývá uživatele k nahrazení nebo přeskočení importu, pokud jsou zjištěny rozdíly, viz Konfigurace importu pro více podrobností.

Part name keys - Tato možnost funguje podobně jako materiál a Revision lookup keys. Nastavte jeden nebo více Part name keys pro použití PPI Part name místo názvu souboru jako názvu dílu.

Thickness lookup keys - Pomocí oddělovače čárkou lze přiřadit více vyhledávacích záznamů. Když je díl importován, TruSmartCAM používá tyto klíče k vyhledání hodnot tloušťky. Vyhledané hodnoty se poté použijí k rozlišení tloušťky. Původní hodnoty jsou uloženy ve Misc Properties dílu.

Thickness comparison fudge - Toto se používá při vyhledávání surového materiálu při importu dílu. TruSmartCAM se pokouší rozlišit surový materiál po analyzování názvu materiálu a tloušťky. Pro více informací viz téma Tolerance tloušťky níže.

Identify shapes after a flat is imported - Když je díl importován, vnitřní tvary uvnitř dílu mohou být automaticky rozpoznány a identifikovány.

Shape identification fudge - Hodnotu fudge identifikace tvaru lze nastavit na:

  1. Globální úrovni - Tato hodnota se používá jako výchozí pro všechny tvary.

  2. Úrovni jednotlivého tvaru - Výchozí hodnotu lze přepsat nastavením hodnoty fudge na úrovni jednotlivého tvaru. Výběr tvaru v dialogu Shape Library zobrazí hodnotu fudge. Ve výchozím nastavení je nastavena na 0 a pro takové tvary se použije výchozí globální hodnota.

Rotate flat horizontally - Obecně jsou stoly řezácích strojů obdélníkové a širší. Pro zlepšení proveditelnosti nástrojení otočte díl podél šířky dílu po importu dílu.

Part rotation threshold - Nastavte toto jako minimální číslo pro povolení rotace. Jakýkoli díl menší než nastavená hodnota nebude otočen.

Misc settings

Enable pre-import external tools - Povolte možnost importu externích nástrojů před importem pro povolení Creo Reader. TruSmartCAM nahraje předem extrahované instance rodiny přetáhnutého dílu. Upozorňujeme, že extrakce instancí se provádí během nahrávání dílu (jako operace před importem), takže software Creo musí být nainstalován na počítači, ze kterého se díl nahrává.

Ignore drawing colors in Flat thumbnails for clarity - Povolte tuto možnost pro generování ostřejších miniátur ve stupních šedi. Barvy vrstev a textové entity jsou ignorovány kvůli přehlednosti obrazu.

Use only one Engine for all import tasks - Když je povoleno, pro důležité úkoly se používá pouze jedno jádro enginu.

Tolerance tloušťky

Thickness comparison fudge vybírá nejbližší hodnotu tloušťky plechu, když požadovaná tloušťka plechu není dostupná ve skladu, porovnáním hodnoty tloušťky plechů ve skladu.

Například předpokládejme následující:

  1. Máme díl s tloušťkou plechu 1,6 mm a materiálem ocel.

  2. Hodnota Thickness comparison fudge je 0,1 mm.

  3. Sklad má ocelové plechy s tloušťkou 1,5 mm, 1,55 mm a 1,7 mm.

TruSmartCAM vybírá plech s nejbližší hodnotou tloušťky po porovnání hodnoty Thickness comparison fudge (0,1 mm) s importovanou položkou (měřící 1,6 mm). V tomto případě bude výběrem 1,55 mm.
