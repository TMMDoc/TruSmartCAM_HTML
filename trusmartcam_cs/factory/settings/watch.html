Sledování

Watch Settings umožňují TruSmartCAM monitorovat určenou složku a automaticky importovat soubory do systému. To pomáhá automatizovat import dílů, úloh, konstrukčních skupin a zakázek bez ručního zásahu.

Watch settings

Enable 'Live Folder' - Umožňuje automatické monitorování zadané složky.

Watch this folder - Určuje složku, která má být monitorována pro příchozí soubory.

Watch sub-folders also - Zahrnuje všechny podsložky do procesu monitorování.

After file import

After import - Po importu souboru má uživatel dvě možnosti. Soubor lze z umístění smazat nebo přesunout do jiného umístění.

  • Delete imported file - Odstraní zdrojový soubor po úspěšném importu.

  • Move imported file - Přesune zdrojový soubor do složky zadané v Move files to this folder po úspěšném importu.

Move files to this folder - Určuje cílovou složku, kam mají být přesunuty úspěšně importované soubory, když je After import nastaveno na Move imported file.

Move spreadsheets with errors to this folder - Přesune neúspěšné importy do zadané složky chyb.

Spreadsheet import settings

Import spreadsheet from 'Live Folder' - Automaticky importuje soubory tabulek zjištěné ve složce watch.

Do not import spreadsheet with errors - Zabraňuje importu souborů obsahujících chyby validace.

Spreadsheet import option - Vybere typ dat k importu z rozevíracího seznamu. Podporované formáty tabulek mohou zahrnovat CSV, XLSX nebo XML. Dostupné možnosti jsou:

  • Import Jobs - Importuje data úloh z tabulky.

  • Import Orders - Importuje data zakázek z tabulky.

  • Import Assemblies - Importuje data konstrukčních skupin z tabulky.

  • Import Parts - Importuje data dílů z tabulky.

Další informace

  • Při konfiguraci složky watch použijte cestu UNC (\\ServerName\FolderPath) nebo mapovanou jednotku (M:\FolderPath). Nepoužívejte místní cesty jako C:\FolderPath.

  • Počítač, na kterém běží služba TruSmartCAM Engine, musí mít oprávnění ke čtení a zápisu do nakonfigurované složky watch. Bez dostatečných oprávnění nemusí být soubory úspěšně zjištěny, importovány, přesunuty nebo smazány.

  • Mapování tabulek musí být nakonfigurováno před povolením Watch Settings. Jinak TruSmartCAM nebude schopen zpracovat soubory tabulek zjištěné ve složce watch.
