nesting แบบโต้ตอบ

Interactive nesting สามารถใช้เพื่อสร้างแผน nest สำหรับชิ้นงานเดียว ชิ้นงาน บางชิ้นจาก job เดียวกัน job เดียว หรือหลาย job โดยสามารถเลือก เครื่องจักรและวัสดุ กำหนดพารามิเตอร์แผ่น และตรวจสอบผล nesting แบบโต้ตอบได้

คลิกขวาที่ชิ้นงานหรือ job และเลือก Plan Part…​/Plan Job…​ → Run Interactive Nesting…​

  • หน้าต่าง Interactive Nesting จะเปิดขึ้น

  • โดยค่าเริ่มต้น หน้าต่าง interactive nesting จะสลับไปที่หน้า Select Machine & Material

  • เครื่องจักรจะแสดงด้วยแถบสีที่บ่งบอกโหลดการผลิตที่มีอยู่:

    • แถบสีเขียว: ชั่วโมงที่จัดตารางไว้

    • แถบสีเทา: ชั่วโมงที่ว่างอยู่ (จากกะทิ 8 ชั่วโมง)

  • ภายใต้แต่ละเครื่องจักร ชิ้นงานที่เลือกจะถูกจัดกลุ่มตามวัสดุดิบ (ชิ้นงาน/จำนวนรวม)

  • หากชิ้นงานไม่มีโซลูชัน tooling ที่ถูกต้องสำหรับเครื่องจักร ชิ้นงานและ วัสดุนั้นจะถูกข้ามการประมวลผลสำหรับเครื่องจักรนั้น

  • หากเลือกวัสดุดิบสำหรับเครื่องจักรหนึ่งแล้ว วัสดุนั้นจะไม่สามารถใช้กับ เครื่องจักรอื่นได้

  • เมื่อกำหนดแผน nest ของเครื่องจักรแล้ว ให้เลือกแผ่นที่ต้องการและ กำหนดค่าพารามิเตอร์แผ่น เช่น Priority, Quantity, Margins เป็นต้น

  • คุณสามารถกรองแผ่นเพื่อแสดง All Sheets, Standard Sheets หรือ Remnant Sheets คลิก Next

ไม่สามารถเพิ่มจำนวนในขั้นตอนนี้ได้ คุณสามารถคงจำนวนเท่ากับ จำนวนสินค้าคงคลังแผ่น หรือลดลงและตรวจสอบผล nesting

  • Update Qty จะปรากฏในหน้าต่างแผน Interactive nesting

  • โดยค่าเริ่มต้น Pick All (F5) จะรวมชิ้นงานทั้งหมด สำหรับ nesting หรือคุณสามารถเลือกชิ้นงานตามลำดับความสำคัญด้วยตนเอง และปรับจำนวนชิ้นงาน คลิก Next

  • nesting จะเริ่มทำงาน และชิ้นงานที่ nest บนแผ่นจะอัปเดตเป็น สถานะสีน้ำเงิน

  • โหลดการผลิตของเครื่องจักรจะอัปเดตตามผล nest

  • layout ที่ nest แล้วจะถูกวาดตามมาตราส่วน และแสดงในแท็บ Nest Results

  • หากมีชิ้นงานบางส่วนที่ยัง nest ไม่ได้ ข้อความ Some parts remain unnested จะปรากฏขึ้น — ชิ้นงานเหล่านี้ จะคงอยู่ใน job เดิม

    • สาเหตุที่ไม่สามารถ nest ได้อาจเกิดจากไม่มีแผ่นสำหรับ nest

  • ผลลัพธ์ Interactive Nest จะมีคำนำหน้าตามที่กำหนดไว้ใน: factory → settings → Job→ Nest settings, Interactive sheet-name prefix

  • layout ของ interactive nest จะมีคำนำหน้าเป็นตัวอักษร L
