ชุดประกอบ

สร้าง static nest จากชุดประกอบ

สามารถสร้าง static nest สำหรับชุดประกอบได้โดยใช้ Interactive nesting wizard นี้เป็น layout ที่คงที่ซึ่งเชื่อมโยงเฉพาะกับชุดประกอบที่เลือกเท่านั้น

  • สลับไปที่มุมมอง assys

  • คลิกขวาที่ชุดประกอบที่ต้องการและเลือก Create Nests…​

  • Interactive Nesting wizard จะเปิดขึ้น

  • โดยค่าเริ่มต้น Interactive nesting wizard จะสลับไปยังหน้า Select Machine & Material

  • เครื่องจักรจะแสดงพร้อมแถบสีที่บ่งบอกโหลดการผลิตที่มีอยู่:

    • แถบสีเขียว: ชั่วโมงที่กำหนดไว้

    • แถบสีเทา: ชั่วโมงที่ว่างอยู่ (จากกะที่ 8 ชั่วโมง)

  • ภายใต้แต่ละเครื่องจักร ชิ้นงานที่เลือกจะถูกจัดกลุ่มตาม Raw-Material (ชิ้นงาน/จำนวนรวม)

  • หากชิ้นงานไม่มีโซลูชัน tooling ที่ใช้ได้สำหรับเครื่องจักร ชิ้นงานและ วัสดุนั้นจะถูกข้ามการประมวลผลสำหรับเครื่องจักรนั้น

  • หากเลือกวัสดุดิบหนึ่งให้กับเครื่องจักรหนึ่ง จะไม่สามารถใช้กับเครื่องจักรอื่นได้

  • เมื่อตั้งแผน nest ของเครื่องจักรเสร็จแล้ว ให้เลือกแผ่นที่ต้องการและ แทนที่ค่าพารามิเตอร์ของแผ่น เช่น Priority Quantity, Margins เป็นต้น

  • คุณสามารถกรองแผ่นเพื่อแสดง All Sheets Standard Sheets หรือ Remnant Sheets คลิก next

ไม่สามารถเพิ่มจำนวนในขั้นตอนนี้ได้ คุณสามารถคงจำนวนเท่ากับ จำนวนในคลังแผ่น หรือลดลงและตรวจสอบผลลัพธ์ nesting

  • Update Qty จะปรากฏในหน้าต่าง Interactive nesting plan

  • โดยค่าเริ่มต้น Pick All (F5) จะรวมชิ้นงานทั้งหมดสำหรับ nesting หรือคุณสามารถเลือกชิ้นงานที่มีลำดับความสำคัญด้วยตนเองและปรับจำนวนชิ้นงาน คลิก next

  • nesting เริ่มทำงาน และชิ้นงานที่ nest ลงแผ่นจะมีสถานะอัปเดตเป็นสีน้ำเงิน

  • โหลดการผลิตของเครื่องจักรจะอัปเดตตามผลลัพธ์ nest

  • หากมีชิ้นงานบางส่วนยังไม่ได้ nest ข้อความ Some parts remain unnested จะปรากฏขึ้น - ชิ้นงานเหล่านี้จะอยู่ ใน job เดิม

    • ชิ้นงานอาจยังไม่ได้ nest หากไม่มีแผ่นที่เหมาะสม

  • สามารถแก้ไข Static Nest เพื่อเพิ่มชิ้นงานที่ยังไม่ได้ nest:

    • เลือก layout ที่ต้องการแทรกชิ้นงานที่ยังไม่ได้ nest และเช็กเอาท์ เพื่อแก้ไข

  • TecZone จะเปิดขึ้น คลิก Pick หรือ Pick All เพื่อเลือกชิ้นงานที่ยังไม่ได้ nest จากชุดประกอบแม่

  • จัดเรียงชิ้นงานใน layout ตามที่ต้องการ

  • nest ที่สร้างขึ้นจะถูกตั้งชื่อตามชุดประกอบแม่โดยอัตโนมัติ เพื่อความ ง่ายในการระบุ

static nest ไม่สามารถมีชิ้นงานจากชุดประกอบอื่นได้ การอนุญาตให้ nest ผสมชุดประกอบจะทำให้ไม่สามารถปล่อยชุดประกอบหนึ่งโดยไม่ปล่อยชุดอื่น จึง ไม่อนุญาตการผสมโดยการออกแบบ

ส่วนประกอบที่ไม่ใช่แผ่นโลหะ

  • เมื่อนำเข้าชุดประกอบ ชิ้นงานแผ่นโลหะจะถูกดึงออกมาและเพิ่มลงใน ชุดประกอบภายในไลบรารีชิ้นงาน

  • ส่วนประกอบที่ไม่ใช่แผ่นโลหะจะถูกแยกออกและเพิ่มลงใน Components

  • ชุดประกอบจะถูกเพิ่มลงใน Assembly Library และ BOM (Bill of Materials) จะมีทั้งชิ้นงานและส่วนประกอบ

  • หากชิ้นงานถูกนำเข้ามาเป็นชิ้นงานแผ่นโลหะอยู่แล้ว ระบบจะอัปเดต รายการที่มีอยู่และลบรายการซ้ำออกจากไลบรารีชิ้นงาน

  • การเลือกชุดประกอบจะแสดงทั้งชิ้นงานและส่วนประกอบ โดยแสดงจำนวนส่วนประกอบ ไว้ใต้ภาพส่วนประกอบ (จำนวนส่วนประกอบของชุดประกอบที่เลือกและจำนวนส่วนประกอบทั้งหมด)

  • ทูลทิปของส่วนประกอบจะแสดงชื่อ วัสดุ และขนาด ส่วนประกอบจะถูกยกเว้นระหว่างการผลิต - จะไม่ถูก nest และไม่มีการ สร้างแผ่นสำหรับส่วนประกอบ

  • ตัวอย่างชุดประกอบและส่วนประกอบมีให้ใช้งานที่: C:\Program Files\TRUMPF\TMM\Praxis\Samples\Assys\Components, ซึ่งสามารถใช้ทดสอบการนำเข้าส่วนประกอบและขั้นตอนการทำงานชุดประกอบได้

การสร้าง job จากชุดประกอบ

  • คลิกขวาที่ชุดประกอบ คลิก New…​ แล้วคลิก Job

  • ในกล่องโต้ตอบ New Job กำหนดจำนวนชุดประกอบ คลิก OK จากนั้นอัปเดตรายละเอียด job (เช่น วันครบกำหนดและลำดับความสำคัญ) ตามที่ต้องการ

  • ระบบจะสร้าง job จากชุดประกอบและคัดลอก static nest เป็น job nest พร้อมทั้งอัปเดตจำนวนแผ่น nest ที่คัดลอกมาจะมีคำนำหน้าเป็น job ID

  • job nest สามารถแก้ไขหรือลบได้โดยไม่กระทบต่อ static nest เดิม

  • job nest สามารถจัดเรียงใหม่ได้โดยใช้ Adapt/Compact…​ หรือ Add parts…​

  • สำหรับขั้นตอนโดยละเอียด ดูที่ Adapt/Compact และ Add parts

หากชิ้นงานไม่ปรากฏใน nest ให้ตรวจสอบกล่องโต้ตอบแก้ไข nest — คุณสามารถ แทรกชิ้นงานที่ยังไม่ได้ nest ด้วยตนเองได้

ใช้การค้นหาและตัวกรองที่บันทึกไว้เพื่อค้นหาชิ้นงานข้ามหลายชุดประกอบได้อย่างรวดเร็ว

ใช้ชื่อชุดประกอบและ nest ที่ชัดเจนและสื่อความหมายเพื่อหลีกเลี่ยงความสับสน เมื่อคัดลอก nest เข้าสู่ job
