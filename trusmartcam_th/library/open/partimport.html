นำเข้าชิ้นงาน

ก่อนนำเข้าชิ้นงาน โปรดตรวจสอบให้แน่ใจว่ารูปแบบไฟล์เข้ากันได้กับ TruSmartCAM ดูรายละเอียดเพิ่มเติมได้ที่ รูปแบบไฟล์ที่รองรับ

หากวัสดุและความหนาไม่ได้ถูกแมปกับชิ้นงานหลังจากการนำเข้า ให้กำหนด วัสดุโดยใช้แผงข้อมูลชิ้นงาน

วิธีการนำเข้า

มีสามวิธีในการนำเข้าชิ้นงานเข้าสู่ไลบรารีชิ้นงาน:

  1. นำเข้าผ่านไฟล์

  2. ลากแล้ววาง

  3. โฟลเดอร์ที่เฝ้าดู

นำเข้าผ่านไฟล์

ไฟล์ชิ้นงานแบบ 2D หรือ 3D สามารถนำเข้าสู่ไลบรารีชิ้นงานได้โดยใช้ ตัวเลือก Import parts…​

  • คลิกไอคอน open จากแถบคำสั่ง และเลือกตัวเลือก Import parts…​

  • กล่องโต้ตอบ Open จะปรากฏขึ้น — เลือกไฟล์ CAD ใดก็ได้ (2D หรือ 3D)

  • ภาพตัวอย่างของไฟล์ CAD ที่เลือกจะแสดงขึ้น

  • เลือกชิ้นงานที่ต้องการและคลิก Open

  • ระบบจะจัดเครื่องมือให้กับชิ้นงานโดยอัตโนมัติสำหรับเครื่องจักรที่มีอยู่ทั้งหมด พร้อมอัปเดตสถานะ tooling

ลากแล้ววาง

  • ลากและวางไฟล์ชิ้นงานลงในไลบรารีชิ้นงาน TruSmartCAM โดยตรง

โฟลเดอร์ที่เฝ้าดู

การตั้งค่าการเฝ้าดูช่วยให้คุณเฝ้าดูโฟลเดอร์เพื่อหาไฟล์ใหม่ และนำเข้า ไฟล์เหล่านั้นเข้าสู่ไลบรารีชิ้นงานโดยอัตโนมัติ

เมื่อต้องการกำหนดค่า ดูหน้า การตั้งค่าการเฝ้าดู

  • ใช้เส้นทางแบบ UNC (Universal Naming Convention) \\192.168.1.11\<Folder path> หรือ ไดรฟ์ที่แมปไว้ M:\<Folder Path>

  • เครื่องคอมพิวเตอร์ที่รัน Engine อยู่ต้องมีสิทธิ์อ่าน/เขียนโฟลเดอร์นี้

  • อย่าใช้เส้นทางแบบโลคัล เช่น C:\<Folder Path> เพราะบริการ Watch จะค้นหาไฟล์บนคอมพิวเตอร์ Engine — ไม่ใช่คอมพิวเตอร์ท้องถิ่น

การกำหนดค่าการนำเข้า

Use geometry comparison on same CAD revision

เมื่อนำเข้าชิ้นงานที่มี CAD revision เดียวกัน TruSmartCAM สามารถเปรียบเทียบ เรขาคณิตของไฟล์ CAD กับชิ้นงานที่มีอยู่ได้

  • หากต้องการเปิดใช้งาน ให้กำหนดค่า Revision lookup keys (เช่น REV) ใน factory → settings → Import จากนั้นเปิดใช้งานตัวเลือก Use geometry comparison on same CAD revision

การเปรียบเทียบเรขาคณิตบน CAD revision เดียวกันจะทำงานได้ก็ต่อเมื่อมีการกำหนด Revision lookup keys ไว้แล้วเท่านั้น

  • จากนั้น นำเข้าชิ้นงานเข้าสู่ไลบรารีชิ้นงานด้วยค่า revision ที่ระบุ (เช่น Revision 1)

  • นำเข้าชิ้นงานเดียวกันอีกครั้งด้วยค่า revision เดิม

  • TruSmartCAM เปรียบเทียบเรขาคณิตของไฟล์ CAD ที่นำเข้าใหม่กับชิ้นงานที่มีอยู่

  • หากตรวจพบความแตกต่างของเรขาคณิต TruSmartCAM จะแสดงข้อความถามว่าต้องการ:

    • Replace ชิ้นงานที่มีอยู่ด้วยเรขาคณิตใหม่ โดยคงค่า revision เดิมไว้

    • Skip ข้ามการนำเข้า โดยคงชิ้นงานที่มีอยู่และเรขาคณิตไว้

สิ่งนี้ช่วยให้ผู้ใช้อัปเดตเรขาคณิตชิ้นงานได้โดยไม่ต้องเปลี่ยนค่า revision ขณะที่ยังคงควบคุมได้ว่าจะแทนที่ชิ้นงานเดิมหรือไม่

ชิ้นงานที่นำเข้าจะถูกเพิ่มลงในไลบรารีโดยอัตโนมัติเพื่อใช้งานต่อไป สำหรับข้อมูลเพิ่มเติม ดูที่ ไลบรารี
