นำเข้าออเดอร์

ออเดอร์สามารถสร้างหรือนำเข้าได้โดยใช้วิธีต่อไปนี้:

  1. นำเข้าออเดอร์จากไฟล์สเปรดชีต

  2. นำเข้าออเดอร์โดยอัตโนมัติผ่านการตั้งค่าการเฝ้าดู

  3. สร้างออเดอร์จากชิ้นงานที่มีอยู่ในไลบรารีชิ้นงาน

  4. สร้างออเดอร์จาก static nest ของชุดประกอบ

นำเข้าออเดอร์จากไฟล์สเปรดชีต

  • ไปที่ Open → Import Orders…​

  • รูปแบบสเปรดชีตที่รองรับได้แก่ CSV, XLSX และ XML

  • เลือกไฟล์สเปรดชีตที่ต้องการและคลิก Open

  • กระบวนการนำเข้าคล้ายกับขั้นตอนการนำเข้า Job/Assembly

คุณยังสามารถลากและวางไฟล์สเปรดชีตลงในหน้าออเดอร์โดยตรง เพื่อนำเข้าออเดอร์ได้

นำเข้าออเดอร์โดยใช้การตั้งค่าการเฝ้าดู

  • เปิดใช้งานตัวเลือก Import spreadsheet from 'Live Folder' ใน Watch settings

  • เลือก Import Orders ใน Spreadsheet import option

  • กำหนดตำแหน่งโฟลเดอร์ที่จะนำเข้าออเดอร์

  • ระบบจะเฝ้าดูโฟลเดอร์ที่กำหนดไว้อย่างต่อเนื่อง

  • ไฟล์สเปรดชีตที่เพิ่มเข้ามาใหม่จะถูกนำเข้าสู่ออเดอร์โดยอัตโนมัติ

สำหรับขั้นตอนการกำหนดค่าโดยละเอียด โปรดดูเอกสาร Watch settings

สร้างออเดอร์จากไลบรารีชิ้นงาน

  • เลือกชิ้นงานที่ต้องการจากไลบรารีชิ้นงาน

  • คลิกขวาและเลือก New…​ → Order เพื่อเปิดกล่องโต้ตอบ New Orders

  • กรอกรายละเอียดที่จำเป็น เช่น จำนวน วันครบกำหนด และลำดับความสำคัญ

  • คลิก OK เพื่อสร้างออเดอร์

  • ระบบจะสลับไปยังหน้าออเดอร์โดยอัตโนมัติ

  • ออเดอร์ที่สร้างจะแสดงในหน้า Orders Ready เพื่อสร้าง job

สร้างออเดอร์จากชุดประกอบ

  • คลิกขวาที่ชุดประกอบที่ต้องการ

  • เลือก New…​ → Order เพื่อเปิดกล่องโต้ตอบ New Orders

  • กรอก Assembly count ที่ต้องการ

  • คลิก OK เพื่อสร้างออเดอร์
