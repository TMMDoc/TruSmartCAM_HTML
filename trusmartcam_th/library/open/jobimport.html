นำเข้า job

นำเข้าจาก csv หรือ xlsx

คุณยังสามารถนำเข้า job ในรูปแบบข้อความทั่วไปได้

  • คลิก File → Open → Import Jobs กล่องโต้ตอบ Open Folder จะปรากฏขึ้น เลือก ifdef::PRAXIS[C:\Program Files\Metamation\Praxis\Samples\Jobs\C0\C0.csv.] C:\Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv.

  • หากชิ้นงานทั้งหมดมีอยู่ในตำแหน่งของไฟล์ csv หรือในไดเรกทอรีที่ใช้ค้นหา หน้าต่าง new job จะปรากฏขึ้นโดยแสดงรายการชิ้นงานทั้งหมด ที่ตรงกับฟิลด์ใน csv

  • ชิ้นงานที่หายไปจะถูกข้ามและไม่ปรากฏในหน้าต่าง new job

  • เริ่มแรกสถานะชิ้นงานจะเป็น Nascent

  • คลิก OK จากนั้นชิ้นงานจะถูกนำเข้าสู่ไลบรารีชิ้นงาน

Create a blank part for the missing CAD files

เมื่อนำเข้า job โดยใช้ไฟล์สเปรดชีต (.csv หรือ .xlsx) บางครั้งอาจมี แถวที่อ้างอิงถึงไฟล์ CAD ที่ไม่มีอยู่ในระบบ

  • เพื่อจัดการกรณีนี้ ให้ไปที่ Factory → Settings → Job ภายใต้ Spreadsheet import settings เปิดใช้งาน Create a blank part for the missing CAD files

เมื่อเลือกตัวเลือกนี้:

  • หากไฟล์ CAD หายไปสำหรับแถวใดระหว่างการนำเข้า job ระบบจะ สร้างชิ้นงานเปล่าขึ้นแทนที่ไฟล์ CAD ที่หายไปโดยอัตโนมัติ

  • ในหน้าต่าง new job ชิ้นงานที่หายไปเหล่านี้จะถูก ไฮไลต์ด้วยสีเหลืองเพื่อระบุว่าไฟล์ CAD ที่เกี่ยวข้องหายไป

  • ชิ้นงานที่หายไปจะยังคงมีฟิลด์ที่แมปไว้ (เช่น ชื่อชิ้นงาน วัสดุ ความหนา จำนวน เป็นต้น) จาก CSV อย่างไรก็ตาม สถานะชิ้นงานจะแสดง เป็น Nascent ซึ่งหมายความว่าเป็นเพียงตัวแทนเปล่าที่ยังไม่มีเรขาคณิตจริง

สิ่งนี้ช่วยให้การนำเข้า job ดำเนินต่อได้โดยไม่เกิดข้อผิดพลาดจากไฟล์ CAD ที่หายไป — คุณสามารถอัปเดตหรือแทนที่ชิ้นงานเปล่าด้วยไฟล์ CAD ที่ถูกต้อง ได้ภายหลังเมื่อมีไฟล์นั้นแล้ว

Do not show the new job dialog if the spreadsheet has no error

factory → Settings → Job → Spreadsheet import settings → Do not show the New Job dialog if the spreadsheet has no error

  • เมื่อเลือกช่องทำเครื่องหมายนี้ ระบบจะสร้าง job ใหม่โดยอัตโนมัติ โดยไม่แสดงกล่องโต้ตอบ New Job หากไฟล์สเปรดชีตไม่มีข้อผิดพลาด (ไม่มีชิ้นงานหายไป วันที่หายไป หรือข้อมูลไม่ถูกต้อง)

  • เมื่อล้างช่องทำเครื่องหมายนี้ กล่องโต้ตอบ New Job จะปรากฏขึ้นเสมอเพื่อ ให้ผู้ใช้ตรวจสอบและยืนยัน แม้ว่าไฟล์สเปรดชีตจะไม่มีข้อผิดพลาดก็ตาม

Prefer raw-material column over material + thickness

factory → Settings → Job → Prefer Raw-Material column over Material + Thickness

  • เมื่อเลือกช่องทำเครื่องหมายนี้ ระบบจะคาดหวังให้ไฟล์สเปรดชีตใช้ คอลัมน์ Raw-Material (เช่น Steel-20) หมายความว่าประเภทวัสดุ และความหนาควรรวมกันเป็นค่าเดียวในคอลัมน์เดียว

  • เมื่อล้างช่องทำเครื่องหมายนี้ ระบบจะคาดหวังให้ไฟล์สเปรดชีตมี คอลัมน์ Material และ Thickness แยกกัน (เช่น Steel และ 2.00) ระบบ จะรวมทั้งสองเข้าด้วยกันภายในระหว่างการนำเข้า

โฟลเดอร์ที่เฝ้าดูโดยใช้ CSV/XLSX

  • ใน factory → Settings → Watch settings ทำเครื่องหมายที่ Enable 'Live Folder' และ Watch sub-folders also

  • กำหนดเส้นทางของโฟลเดอร์ที่เฝ้าดู (UNC หรือไดรฟ์ที่แมปไว้)

  • ใน Spreadsheet import settings ทำเครื่องหมายที่ Import spreadsheet from 'Live Folder'

  • เลือก Import Jobs จากตัวเลือก Spreadsheet Import

  • คัดลอก ifdef::PRAXIS[C:\Program Files\Metamation\Praxis\Samples\Jobs\C0\C0.csv] C:Program Files\TRUMPF\TMM\Praxis\Samples\Jobs\C0\C0.csv และวางลงในโฟลเดอร์ที่เฝ้าดู

  • ระบบจะตรวจสอบ CSV และพยายามสร้าง job โดยอัตโนมัติ

  • หากไฟล์ CAD หายไป จะไม่มีการสร้าง job เนื่องจากไม่พบข้อมูล CAD ที่ต้องการ

ไดเรกทอรีสำหรับค้นหา CAD และการค้นหา CAD แบบเริเคิร์ซีฟ - ไม่ได้กำหนดค่า

  • ใน factory → Settings → Job → Spreadsheet import settings หากไม่ได้ตั้งค่า CAD lookup directories และ ไม่ได้ใช้ Use recursive CAD search ระบบ จะไม่ค้นหาไฟล์ CAD โดยอัตโนมัติ

  • หากเลือกช่องทำเครื่องหมาย Create a blank part for the missing CAD files ไว้ job จะยังคงถูกสร้างแม้ว่าไฟล์ CAD จะหายไป

  • ในกรณีนี้ ชิ้นงานทั้งหมดใน job จะถูกสร้างเป็นชิ้นงาน Nascent (เปล่า) — หมายความว่าไม่มีเรขาคณิตเนื่องจากไม่พบไฟล์ CAD

ไดเรกทอรีสำหรับค้นหา CAD และการค้นหา CAD แบบเริเคิร์ซีฟ - กำหนดค่าแล้ว

เมื่อตั้งค่า CAD lookup directories เป็น ifdef::PRAXIS[(C:\Program Files\Metamation\Praxis\Samples)] (C:\Program Files\TRUMPF\TMM\Praxis\Samples) และเปิดใช้งาน Use recursive CAD search ภายใต้ factory → Settings → Job → Spreadsheet import settings:

  • ระบบจะค้นหาไฟล์ CAD ที่ต้องการตามที่ระบุในไฟล์สเปรดชีตโดยอัตโนมัติ ในโฟลเดอร์ที่ระบุและโฟลเดอร์ย่อยทั้งหมด

  • Create a blank part for the missing CAD files ก็ เปิดใช้งานด้วย ดังนั้นหากยังคงหาไฟล์ CAD ไม่พบ ระบบจะสร้าง ชิ้นงานเปล่าเป็นตัวแทน
