นำเข้าชุดประกอบ

ชุดประกอบคือกลุ่มของชิ้นงานที่เกี่ยวข้องกันซึ่งรวมเข้าด้วยกันเป็นหน่วยเดียว ช่วยให้คุณจัดการชิ้นงานหลายชิ้นพร้อมกันเสมือนเป็นหน่วยเดียว

คุณสามารถนำเข้าชุดประกอบได้โดยใช้วิธีต่อไปนี้:

  1. นำเข้าผ่านไฟล์

  2. ลากแล้ววาง

  3. นำเข้าจากไฟล์สเปรดชีต

นำเข้าผ่านไฟล์

ชุดประกอบสามารถนำเข้าสู่ไลบรารีชิ้นงานได้โดยใช้ ตัวเลือก Import Assemblies…​

  • คลิกไอคอน Open ในแถบคำสั่ง และเลือก Import Assemblies…​ หรือใช้ File → Open → Import Assemblies…​

  • กล่องโต้ตอบ Open จะปรากฏขึ้น เลือกไฟล์ชุดประกอบที่ต้องการ

  • ภาพตัวอย่างของชุดประกอบที่เลือกจะแสดงขึ้น

  • คลิก Open เพื่อนำเข้าชุดประกอบ

  • ชุดประกอบที่นำเข้าจะแสดงอยู่ในมุมมอง Assemblies ในไลบรารีชิ้นงาน

ลากแล้ววาง

  • ลากและวางชุดประกอบลงในไลบรารีชิ้นงาน TruSmartCAM โดยตรง

นำเข้าจากไฟล์สเปรดชีต

  • ใช้ File → Open → Import Assemblies…​ และเลือกไฟล์ CSV, XLSX หรือ XML หรือลากและวางไฟล์

  • ตรวจสอบและอัปเดตรายละเอียดชุดประกอบและจำนวนก่อนนำเข้า ใช้ Add…​ หรือ Remove…​ เพื่อแก้ไข

  • หลังนำเข้า ชุดประกอบสามารถเตรียมการและกำหนด Static Nest ได้
