การตรวจสอบความถูกต้อง tooling

ส่วนนี้อธิบายวิธีเข้าถึงและแก้ไขข้อมูล tooling สำหรับชิ้นงานใน TruSmartCAM

  • คลิกขวาที่ไทล์ชิ้นงานใด ๆ เพื่อเปิดแผงชิ้นงานและเข้าถึง ตัวเลือก tooling

  • คลิก Toolings เพื่อสลับไปยังอินสแทนซ์ที่ทำ tooling แรก ที่มีอยู่

  • หรือคลิกที่อินสแทนซ์ที่ทำ tooling โดยตรงเพื่อดูรายละเอียดเครื่องจักร และตัวเลือก tooling

  • ใช้ เพื่อ Open in read-only mode for viewing

  • ใช้ เพื่อ Check-out the document for editing

  • อินสแทนซ์ที่ทำ tooling ที่เลือกจะเปิดขึ้นใน TecZone หรือ MetaCAM

  • ดำเนินการตรวจสอบ tooling ด้วยตนเองและทำการเปลี่ยนแปลงที่จำเป็น

  • เมื่อคุณพยายามบันทึก กล่องโต้ตอบ Unsaved Changes จะแสดงขึ้นเพื่อให้คุณ ยืนยันการแก้ไข

  • คลิก Yes เพื่อดำเนินการบันทึก

  • ระบบจะดำเนินการตรวจสอบ tooling อีกครั้งหลังบันทึก

  • หากไม่มีข้อผิดพลาด ตัวเลือกในการบันทึกการเปลี่ยนแปลงไปยัง TruSmartCAM จะปรากฏขึ้น

  • หากพบข้อผิดพลาดของ tooling จะมีข้อความแสดงข้อผิดพลาดปรากฏขึ้น

  • หลังบันทึก สถานะ tooling ของชิ้นงานจะถูกอัปเดตในไลบรารีชิ้นงาน

  • สีเขียวบนอินสแทนซ์ที่ทำ tooling แสดงว่าได้เช็คอินแล้ว

  • ผู้จัดทำของอินสแทนซ์ที่ทำ tooling จะถูกอัปเดตเป็นบุคคลล่าสุดที่แก้ไข

  • ฟิลด์ User-edited ระบุว่าอินสแทนซ์ที่ทำ tooling ถูกแก้ไขด้วยตนเองหรือไม่ เมื่อผู้ใช้เช็คเอาต์อินสแทนซ์และทำการเปลี่ยนแปลงใด ๆ ฟิลด์นี้จะถูกตั้งเป็น Yes โดยอัตโนมัติเมื่อบันทึก

  • หากชิ้นงานกำลังถูกแก้ไขอยู่ ไอคอนผู้ใช้จะปรากฏบนไทล์ของชิ้นงาน

  • เมื่อชี้เมาส์ไปที่ไทล์ จะแสดงว่าใครเป็นผู้เช็คเอาต์และเวลาที่เช็คเอาต์

  • ขณะที่ชิ้นงานถูกเช็คเอาต์อยู่ ตัวเลือก Check-out the document for editing จะถูกปิดการใช้งาน สำหรับอินสแทนซ์ที่ทำ tooling เดียวกัน และตัวเลือก Cancel Check-out จะถูกเปิดใช้งาน
