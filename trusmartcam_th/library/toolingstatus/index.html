สถานะ tooling

ใน TruSmartCAM ไทล์ชิ้นงานแต่ละรายการจะแสดงสถานะ tooling ของชิ้นงานนั้น สำหรับเครื่องจักรที่มีอยู่ทั้งหมดด้วยภาพ ซึ่งช่วยให้ผู้ใช้เห็นได้อย่างรวดเร็วว่าชิ้นงาน ถูกทำ tooling สำหรับเครื่องจักรใดบ้าง และ tooling นั้นพร้อมใช้งาน ต้องการการตรวจสอบ หรือขาดหาย

  • สถานะ tooling จะแสดงบนไทล์ชิ้นงานโดยตรงโดยใช้ไอคอนและ ตัวบ่งชี้สี

  • ไอคอนแต่ละตัวแทนเทคโนโลยีของเครื่องจักร (เช่น Bend, Laser)

  • สีของไอคอนแสดงสถานะ tooling ปัจจุบันสำหรับเครื่องจักรนั้น

ตารางด้านล่างอธิบายความหมายของไอคอนและสีแต่ละสี ซึ่งช่วยให้ผู้ใช้ ตีความสถานะ tooling ได้อย่างถูกต้อง

ข้อผิดพลาด tooling

ข้อผิดพลาด CAM (Computer-Aided Manufacturing) เกิดขึ้นระหว่างขั้นตอน การทำ tooling หรือการเตรียมการผลิต ข้อผิดพลาดเหล่านี้เกิดจากปัญหา เช่น การชนกันของเครื่องมือ tooling ที่ขาดหาย หรือเงื่อนไขการตัดที่ไม่ถูกต้อง

รูปต่อไปนี้แสดงตัวอย่างสถานะข้อผิดพลาด tooling ที่อาจ แสดงบนไทล์ชิ้นงานระหว่างการทำ tooling ส่วนต่อไปนี้อธิบายข้อผิดพลาดของ tooling แต่ละรายการและสาเหตุ

Bend tooling errors

  • Collisions detected และ Gripper error : การตั้งค่าการดัดทำให้เครื่องมือหรือ gripper ชนกัน ระหว่างการจำลอง

  • Tool Overload และ Narrow flange or hole too close : เครื่องมือดัดรับภาระเกิน หรือรูอยู่ใกล้เส้นดัดมากเกินไป ซึ่งอาจทำให้ชิ้นงานหรือเครื่องมือเสียหาย

  • Needs review และ Short Punch/Die span : การตั้งค่า tooling ต้องการ การตรวจสอบด้วยตนเอง หรือช่วงของดาย/พันช์ที่เลือกเล็กกว่าที่จำเป็น สำหรับชิ้นงาน

  • Tool Missing, Poor backguage หรือ Part too big for this machine : ไม่มีเครื่องมือดัดที่จำเป็น backgauge ตั้งค่าไม่ถูกต้อง หรือชิ้นงานมีขนาดใหญ่เกินไปสำหรับเครื่องจักรที่เลือก

Cut tooling errors

  • Missing cutting condition : ไม่ได้แมปเงื่อนไข การตัดกับวัสดุดิบ จึงไม่สามารถดำเนินการตัดได้

  • Untooled or partially tooled contours : มีบางรูปทรงหรือ ขอบที่ถูกข้ามไปหรือถูกทำ tooling เพียงบางส่วนในกระบวนการทำ tooling ทำให้ ชิ้นงานไม่สมบูรณ์สำหรับการตัด
