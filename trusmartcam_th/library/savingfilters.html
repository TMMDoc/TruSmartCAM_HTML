การบันทึกตัวกรอง

ตัวกรองที่บันทึกไว้ช่วยให้ท่านสามารถนำเกณฑ์ที่ใช้งานบ่อยกลับมาใช้ซ้ำใน Parts, Jobs และ Layouts ช่วยให้การทำงานของท่านราบรื่นขึ้น แต่ละโมดูลจะมี ตัวกรองเริ่มต้น แต่ Site Admins หรือ Programmers สามารถสร้างรายการตัวกรอง เพิ่มเติมได้ตามที่ต้องการ การนำตัวกรองที่บันทึกไว้กลับมาใช้ซ้ำช่วยประหยัดเวลา และช่วยรักษาความสอดคล้องของการค้นหา

  • คลิกที่ไอคอน เพื่อดูตัวกรองเริ่มต้น

ขั้นตอนในการบันทึกตัวกรอง

  • คลิกที่ไอคอน แล้วเลือกรายการตัวกรองใดๆ

  • จากเมนูแบบดรอปดาวน์ของรายการตัวกรองที่เลือก ให้เลือกตัวเลือก เครื่องหมายถูกต้อง จะปรากฏถัดจากเงื่อนไขที่เลือก

  • เมื่อต้องการใช้เงื่อนไข ให้คลิกที่ไอคอน แล้วเลือก Add Condition Ctrl++ คุณสามารถทำซ้ำ ขั้นตอนนี้เพื่อเพิ่มเงื่อนไขหลายรายการได้

  • หากต้องการบันทึกตัวกรองที่เลือกไว้พร้อมเงื่อนไข ให้คลิกที่ Save Filter…​ Ctrl+S

  • ป้อนชื่อ แล้วคลิกที่ Save

  • จากกล่องโต้ตอบ Save Filter คุณยังสามารถลบ ตัวกรองที่บันทึกไว้ก่อนหน้านี้ได้ด้วย

  • ตัวกรองเหล่านี้จะถูกบันทึกไว้ในรายการตัวกรองเริ่มต้น ในที่นี้ Material ถูกบันทึกไว้ในรายการเริ่มต้น

ตัวกรองที่สร้างโดย SiteAdmin และ Admin จะถูกแชร์ให้กับผู้ใช้ทุกคน ตัวกรองที่สร้างโดย Programmer และ Operator จะถูกแชร์เฉพาะ ผู้ใช้บทบาท Programmer และ Operator เท่านั้น

คำสั่งของตัวกรอง

คำสั่ง ไอคอน ทางลัด คำอธิบาย

Clear Selection

Ctrl+X

ยกเลิกการเลือกทั้งหมดที่เลือกไว้และรีเฟรชมุมมองรายการตัวกรอง

Select Highlighted

Ctrl+A

เลือกตัวเลือกทั้งหมดที่ได้ไฮไลต์ไว้ คำสั่งนี้จะถูกปิดใช้งานหาก การไฮไลต์รายการไม่สามารถใช้ได้กับฟิลด์ที่เลือก

Match All

&

แสดงเฉพาะรายการที่ตรงตามเงื่อนไขที่เลือกทั้งหมดเท่านั้น

Pin In/Out Menu

Ctrl+Down/Up

เมื่อปักหมุดไว้ เมนูแบบดรอปดาวน์จะเปิดค้างไว้แม้โฟกัสปัจจุบัน จะย้ายไปยังหน้าต่างอื่น

Close Menu

Esc

ปิดเมนูแบบดรอปดาวน์
