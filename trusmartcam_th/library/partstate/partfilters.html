ตัวกรองชิ้นงาน

ตัวกรองไลบรารีชิ้นงาน (Part Library Filters) ช่วยให้คุณค้นหาและระบุตำแหน่ง ชิ้นงานในไลบรารีได้อย่างรวดเร็วโดยการกำหนดเงื่อนไขที่เจาะจง ด้วยการจำกัดผลลัพธ์ ให้แสดงเฉพาะชิ้นงานที่ตรงตามเกณฑ์ของคุณ ตัวกรองเหล่านี้จึงช่วยให้การจัดการ และเข้าถึงชิ้นงานที่เกี่ยวข้องได้อย่างมีประสิทธิภาพ

State

  • ใช้ตัวกรอง State เพื่อค้นหาชิ้นงานตามสถานะ ปัจจุบัน

  • เมนูแบบดรอปดาวน์จะแสดงสถานะที่มีทั้งหมดตามชิ้นงานในไลบรารีที่มีอยู่

  • รายการสถานะจะเปลี่ยนแปลงแบบไดนามิกตามชิ้นงานที่เลือกและสถานะของชิ้นงานเหล่านั้น

  • ตัวอย่างเช่น เลือก Material Missing เพื่อดูชิ้นงานที่อยู่ในสถานะ วัสดุที่ยังไม่ได้รับการแก้ไข

Status

  • ใช้ตัวกรอง Status เพื่อค้นหาชิ้นงานตามสถานะ tooling

  • เมนูแบบดรอปดาวน์จะแสดงสถานะ tooling เป็นกล่องสี รวมถึงเครื่องจักร ทั้งหมดที่มีอยู่และข้อผิดพลาดที่เกี่ยวข้อง

  • กล่องสีแสดงสถานะต่อไปนี้:

    • สีขาว: tooling ปกติ

    • สีส้ม: tooling มีข้อผิดพลาด

    • สีเหลือง: tooling มีคำเตือน

    • สีเทา: tooling ถูกระงับ

  • หากชิ้นงานมีข้อผิดพลาด narrow flange หรือ tooling not assigned การเลือกเงื่อนไข เหล่านี้จะแสดงชิ้นงานที่เกี่ยวข้อง

  • ชิ้นงานที่มี tooling ถูกระงับบนเครื่องจักรที่เลือกจะแสดงโดยการคลิกที่กล่องสีเทา

Bend mounts

  • ใช้ตัวกรอง Bend mounts เพื่อค้นหาชิ้นงานตามเครื่องมือดัดที่ใช้

  • เมนูแบบดรอปดาวน์จะแสดงเครื่องมือดัดทั้งหมดที่มีอยู่ และสามารถกรองได้ตามชื่อเครื่องมือ ประเภท (punch, gooseneck, radius เป็นต้น) หรือคำอธิบาย

  • เลือกเครื่องมือหลายรายการและคลิก Match all เพื่อจัดเรียงเครื่องมือที่ใช้ เครื่องมือที่เลือกทั้งสองรายการ
