กำหนดค่าผู้ใช้

  • ไคลเอนต์ TruSmartCAM ที่มีบทบาทแตกต่างกันใช้เพื่อควบคุมการกำหนดค่า โรงงาน

    • เพิ่มเครื่องจักร วัสดุ และแผ่นใหม่

    • แก้ไขการกำหนดค่าเครื่องจักร

    • แก้ไขชิ้นงาน job และชุดประกอบ

    • แก้ไข/อัปเดต nest แผ่น วางแผน Job

    • เพิ่ม/แก้ไขผู้ใช้

  • พีซีที่ติดตั้ง Pserver จะถูกนับเป็นผู้ใช้ TruSmartCAM คนแรก

  • TruSmartCAM ใช้ข้อมูลรับรองของ Windows เป็นชื่อผู้ใช้ TruSmartCAM ซึ่งคือ Site Admin

  • คอมพิวเตอร์ที่ติดตั้ง TruSmartCAM Client ถัดไป กล่าวคือชื่อผู้ใช้คอมพิวเตอร์ จะถูกนับเป็น Programmer

เฉพาะ Site Admin เท่านั้นที่สามารถแก้ไขข้อมูลผู้ใช้คนอื่น และเปลี่ยนรหัสผ่านได้
