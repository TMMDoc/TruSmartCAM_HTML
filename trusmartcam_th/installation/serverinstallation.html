การติดตั้งเซิร์ฟเวอร์

ทำตามคำแนะนำเพื่อติดตั้ง TruSmartCAM Server พร้อมกับ SQL

Administrator Rights

ในการดำเนินการติดตั้งนี้ ผู้ใช้ต้องมีสิทธิ์ระดับผู้ดูแลระบบ

  • รัน Setup.TruSmartCAM.<version>.exe เพื่อเริ่มการติดตั้ง

Version เป็นตัวเลข

  • อ่านข้อตกลงอนุญาตใช้สิทธิ์ และเลือก I accept the agreement จากนั้นคลิก Next

ขั้นตอนที่ 1 : ตำแหน่งการติดตั้ง

  • ระบุไดเร็กทอรีการติดตั้ง หรือยอมรับค่าเริ่มต้นการติดตั้ง C:\Program Files\TRUMPF\TMM\Praxis แล้วคลิก Next

    • C:\Program Files\TRUMPF\TMM\Praxis - โฟลเดอร์ติดตั้งจะมี โฟลเดอร์ดังนี้ : Bin, MetaCAM, Samples และ Tracker

    • C:\ProgramData\TRUMPF\TMM\Praxis - โฟลเดอร์ข้อมูลจะมีโฟลเดอร์ดังนี้ : TruSmartCAM, TecZone และ MetaCAM

ขั้นตอนที่ 2 : การเลือกส่วนประกอบ (Components)

ประเภทการติดตั้ง ส่วนประกอบ

Full

Server + Desktop client + Engine

Client

Desktop Client

Server

Server + Desktop client

Station

เลือกเทอร์มินัลของทุก Station เช่น TecZone, MetaCAM, RightAngle(Bend Controller), Vulcan(Laser Machine Controller)

Custom

เลือกตามความต้องการของผู้ใช้

  • เลือก Full Installation เลือก Code Senders และ Bend Code Senders จาก เครื่องมือ TruSmartCAM จากนั้นประเภทการติดตั้งจะเปลี่ยนเป็น Custom คลิก Next

ขั้นตอนที่ 3 : เลือกติดตั้ง SQL Server

การติดตั้ง SQL Express 2022 จำเป็นเฉพาะสำหรับ TruSmartCAM Server เท่านั้น ตัวเลือกนี้ไม่มีสำหรับการติดตั้งแบบ Client และ Sync นอกจากนี้ ตัวเลือกนี้จะถูกเลือก (Checked ON) และติดตั้งในครั้งแรกเท่านั้น จากนั้นสามารถข้ามได้ หากติดตั้ง SQL ใน TruSmartCAM Server ไว้แล้ว ผู้ใช้สามารถข้ามขั้นตอนที่ 3 ได้

  • ใน Select Additional Tasks : คลิก Install SQL Express และคลิก Next

  • ใน Ready to Install : สรุปคุณสมบัติการติดตั้งทั้งหมด และคลิก Install

ขั้นตอนที่ 4 : การติดตั้ง SQL Server

เมื่อติดตั้งส่วนประกอบ TruSmartCAM เสร็จแล้ว ตัวติดตั้งจะดำเนินการ ติดตั้ง SQL Server ต่อ ให้ยอมรับข้อตกลงอนุญาตสิทธิ์เพื่อดำเนินการต่อ และติดตั้ง SQL Express ด้วยตัวเลือกเริ่มต้น

เมื่อการติดตั้งเสร็จสมบูรณ์แล้ว คลิก Close และดำเนินการติดตั้งให้เสร็จสมบูรณ์

ขึ้นอยู่กับเวอร์ชันของ Windows การปิดการติดตั้ง SQL อาจมีการ แจ้งเตือนให้รีสตาร์ตเครื่อง

ขั้นตอนที่ 5 : ทางลัดบน Windows Desktop

  • หลังติดตั้ง SQL หากระบบไม่รีสตาร์ต ให้เลือกช่องทำเครื่องหมาย Launch TruSmartCAM และคลิก Finish

  • หากระบบรีสตาร์ต ให้เปิดไอคอนทางลัด TruSmartCAM บนเดสก์ท็อป หรือพิมพ์ TruSmartCAM ใน Windows Start Program แล้ว Run as administrator

การติดตั้งเซิร์ฟเวอร์ : ไอคอนทางลัด TruSmartCAM และ TruSmartCAM License จะมีอยู่บนเดสก์ท็อป
การติดตั้งแบบ Client/SYNC : จะมีเฉพาะไอคอนทางลัด TruSmartCAM อยู่บนเดสก์ท็อป

ขั้นตอนที่ 6 : การลงทะเบียนไลเซนส์

  • ในช่อง Serial Number ให้พิมพ์ TruSmartCAM Serial key ที่ Trumpf Metamation Service Team จัดหาให้ พิมพ์ <Company Name> ในช่อง "Registered to" และ E-Mail จากนั้นคลิก OK

กรณีที่ไฟร์วอลล์ของเครือข่ายบล็อกการลงทะเบียนไลเซนส์ หรือไม่มีอินเทอร์เน็ตใน TruSmartCAM Server PC สามารถลงทะเบียนไลเซนส์ TruSmartCAM แบบออฟไลน์ได้ โดยส่งอีเมล ไฟล์ Prax.request จากโฟลเดอร์ C:\ProgramData\TRUMPF\TMM\Praxis ไปยัง Trumpf Metamation Service Team จากนั้น Trumpf Metamation Team จะส่งไฟล์ Prax.lock ซึ่งต้องนำมาวางไว้ในโฟลเดอร์นี้

ขั้นตอนที่ 7 : การกำหนดค่าครั้งแรกเพียงครั้งเดียว

  • พิมพ์ชื่อฐานข้อมูล (Database Name) และตั้งตำแหน่งที่จัดเก็บข้อมูล เลือก ช่องทำเครื่องหมาย Use SQL Server และเลือกชื่อ SQL server ที่จะเชื่อมต่อกับฐานข้อมูล คลิก OK

  • TruSmartCAM Desktop Client จะเปิดขึ้นและแสดง Database Connection Succeeded ที่ ด้านล่าง

  • ไฟล์การกำหนดค่าของ TruSmartCAM, TecZone และ MetaCAM จะถูกสร้างขึ้นพร้อม เครื่องจักรค่าเริ่มต้นตามค่าเริ่มต้น หรือตามเครื่องจักรตามไลเซนส์ TruSmartCAM โดยค่ากำหนดเดียวกันนี้จะถูกแชร์ไปยัง TruSmartCAM Client ทุกเครื่อง

หน้าจอต้อนรับจะแสดงชื่อผู้ใช้ที่ล็อกอิน Windows เป็นชื่อล็อกอินและชื่อของ TruSmartCAM ผู้ใช้ TruSmartCAM คนแรกจะถูกกำหนดเป็น Site Admin ให้กรอก Email และ รหัสผ่าน คลิก OK .

เลือกช่องทำเครื่องหมาย Remember me เพื่อบันทึกข้อมูลการเข้าสู่ระบบสำหรับครั้งถัดไป หากล้างช่องทำเครื่องหมาย Remember me ระบบจะแสดงกล่องโต้ตอบ ให้กรอกชื่อผู้ใช้และรหัสผ่านทุกครั้งที่เปิดแอปพลิเคชัน TruSmartCAM

ขั้นตอนที่ 8 : การเข้าสู่ระบบ TruSmartCAM

  • ปิด TruSmartCAM แล้วเปิดขึ้นใหม่ ระบบจะแจ้งให้คุณกรอกข้อมูลการเข้าสู่ ระบบ TruSmartCAM

  • ชื่อผู้ใช้ที่เข้าสู่ระบบจะแสดงอยู่ถัดจากไอคอนผู้ใช้ในส่วนหัวของ แอปพลิเคชัน TruSmartCAM

  • เมื่อนำเมาส์ไปวางเหนือไอคอนผู้ใช้ ระบบจะแสดง :

    • บทบาทผู้ใช้ (เช่น : Programmer, Admin)

    • ทางลัดสำหรับการออกจากระบบ : Ctrl+L

  • การคลิกไอคอนผู้ใช้จะเปิดเมนูที่ช่วยให้คุณสามารถ :

    • Edit information…​ - อัปเดตรายละเอียดโปรไฟล์ของคุณ

    • Change password…​ - เปลี่ยนรหัสผ่านบัญชีของคุณ

    • Sign out - ออกจากระบบ

    • Cancel - ปิดเมนูโดยไม่มีการเปลี่ยนแปลงใด ๆ

ขั้นตอนที่ 9 : การกำหนดค่าเครื่องจักรของโรงงาน

  • TruSmartCAM License [บิตไลเซนส์ที่เปิดใช้งานเครื่องจักรทั้งหมด] : เครื่องจักร TruSmartCAM และวัสดุเริ่มต้นจะถูกใช้เป็นค่าเครื่องจักรของโรงงาน

  • TruSmartCAM License [ไม่มีโหมดเดโมและเปิดบิตเครื่องจักรเพียงไม่กี่เครื่อง] : เครื่องจักรเหล่านั้นและวัสดุเริ่มต้นจะถูกใช้เป็นค่าเครื่องจักรของโรงงาน

  • (Open → Import) ชิ้นงานใหม่จาก C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts และตรวจสอบว่านำเข้าชิ้นงานสำเร็จหรือไม่

หมายเหตุ 1 : TruSmartCAM Monitor

  • TruSmartCAM Monitor ที่ติดตั้ง Engine (สิทธิ์ Site admin):

    • TruSmartCAM Monitor ที่มี Engine พร้อมสิทธิ์ Site Admin ของ TruSmartCAM จะมี ตัวเลือกต่อไปนี้ :

      1. Push การกำหนดค่า TruSmartCAM, TecZone, MetaCAM ไปยัง TruSmartCAM Client ทุกเครื่อง รวมถึงมีสิทธิ์สร้างการเข้าสู่ระบบของผู้ใช้ TruSmartCAM ใหม่

      2. Show Agents จะแสดงจำนวน Engine ทั้งหมดที่มีสำหรับงาน automation ตามที่กำหนดไว้ในไลเซนส์ TruSmartCAM

  • TruSmartCAM Monitor ที่ไม่ติดตั้ง Engine (สิทธิ์ Site admin):

  • TruSmartCAM Monitor ที่ไม่ติดตั้ง Engine (ไม่มีสิทธิ์ Site Admin):

PC ที่รันแอปพลิเคชัน TruSmartCAM จะต้องติดตั้งส่วนประกอบ Engine ของ TruSmartCAM [บน Server PC หรือบน Client เครื่องใดก็ได้] PC ที่ติดตั้งส่วนประกอบ Engine ของ TruSmartCAM ควรทำงานตลอด 24x7 เพื่อดำเนินงาน automation ทั้งหมด
หมายเหตุ 2 : OpenGL

  • แอปพลิเคชัน TruSmartCAM ปิดตัวเองทันทีขณะเปิดใช้งาน และ pmonitor ไม่แสดงที่ task bar

  • อาการนี้แสดงถึงปัญหา OpenGL

  • อีกวิธีหนึ่งในการยืนยัน : เปิด C:\Program Files\TRUMPF\TMM\Praxis\Samples\Parts ซึ่งจะแสดงกล่องโต้ตอบแจ้งข้อผิดพลาดเกี่ยวกับ OpenGL

  • อัปเดตไฟล์ C:\ProgramData\TRUMPF\TMM\Praxis\Prax.ini โดยในส่วน options กำหนด GLVersion=1 จะทำให้แอปพลิเคชัน TruSmartCAM เปิดขึ้นได้สำเร็จ

[Options]
GLVersion=1.0
