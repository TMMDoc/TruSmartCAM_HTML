ข้อกำหนดด้านพอร์ต

TruSmartCAM Server : 7371

เซิร์ฟเวอร์จะรอรับคำขอจากไคลเอนต์ผ่านพอร์ต TCP นี้ จึงควรอนุญาต การเชื่อมต่อขาเข้ามายังพอร์ตนี้บนเครื่องคอมพิวเตอร์เซิร์ฟเวอร์

Floating License Server : 5776

Floating License Server จะรอรับคำขอด้านไลเซนส์ผ่านพอร์ตนี้ จึงควรอนุญาต การเชื่อมต่อขาเข้ามายังพอร์ตนี้บนเครื่องคอมพิวเตอร์ floating license server (TruSmartCAM Server)

License connection to Cloud : 7567

พอร์ตนี้ถูกใช้โดย TecZone (ซอฟต์แวร์ดัดโลหะ) และ Floating License Server เพื่อ ส่งคำขอด้านไลเซนส์ไปยัง Metamation Cloud ดังนั้นควรอนุญาตการเชื่อมต่อขาออก บนพอร์ตนี้เพื่อการเปิดใช้งานและต่ออายุไลเซนส์

ข้อกำหนดด้านการติดตั้งและการสนับสนุน

  • ต้องมีสิทธิ์ระดับผู้ดูแลระบบ (administrative privileges) เพื่อติดตั้งแอปพลิเคชัน TruSmartCAM

  • เครื่องมือวินิจฉัยระยะไกล (remote diagnostic tools) ผ่าน Contractor VPN หรือการเชื่อมต่อที่ปลอดภัย
