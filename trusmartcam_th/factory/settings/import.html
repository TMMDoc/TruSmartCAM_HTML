นำเข้า

Output settings

Save flat pattern - เปิดใช้งานตัวเลือกนี้เพื่อบันทึก flat pattern ของชิ้นงานที่นำเข้า

Format for flat pattern - ตัวเลือกนี้ใช้เพื่อเลือก รูปแบบไฟล์ DXF หรือ GEO

Flat pattern destination - นี่คือตำแหน่งที่จะจัดเก็บ flat pattern

Import settings

Units for DXF files - นี่คือหน่วยวัดที่จะใช้นำเข้าไฟล์ DXF โดยผู้ใช้สามารถเลือกได้ระหว่าง mm หรือ inch

Material lookup keys - สามารถกำหนดคีย์ค้นหา หลายรายการโดยใช้เครื่องหมายจุลภาค (,) คั่นระหว่างกัน เมื่อนำเข้าชิ้นงาน TruSmartCAM จะใช้คีย์เหล่านี้เพื่อค้นหาค่าวัสดุ ค่าที่ค้นหาได้จะถูกนำไป ใช้เพื่อระบุวัสดุดิบ ค่าดั้งเดิมจะถูกจัดเก็บไว้ในส่วน Misc Properties ของชิ้นงาน

Revision lookup keys - เมื่อนำเข้าชิ้นงาน ค่า revision จากไฟล์ชิ้นงานต้นฉบับ (ไฟล์ชิ้นงานที่กำลังนำเข้า) จะถูก เปรียบเทียบกับค่า revision ที่มีอยู่ในคลัง การนำเข้าจะถูกยกเลิก หากค่า revision เหมือนเดิม ขณะนี้รองรับการแมป custom field สำหรับไฟล์ DXF ด้วย สำหรับไฟล์ DXF ข้อมูล custom field จะถูกดึงมาจากเลเยอร์ของ ข้อความในแบบดรออิงหรือไฟล์แนบ PPI

Use geometry comparison on same CAD revision - เปรียบเทียบ geometry เมื่อนำเข้าชิ้นงานที่มี CAD revision เดียวกัน และแจ้งให้ผู้ใช้เลือกว่าจะแทนที่หรือข้ามการนำเข้าหากตรวจพบความแตกต่าง ดูรายละเอียดเพิ่มเติมได้ที่ Import configuration

Part name keys - ตัวเลือกนี้ทำงานคล้ายกับ Revision lookup keys และวัสดุ กำหนด Part name keys หนึ่งคีย์หรือมากกว่าเพื่อใช้ PPI Part name เป็นชื่อชิ้นงานแทนชื่อไฟล์

Thickness lookup keys - สามารถกำหนดคีย์ค้นหา หลายรายการโดยใช้เครื่องหมายจุลภาคคั่นระหว่างกัน เมื่อนำเข้าชิ้นงาน TruSmartCAM จะใช้คีย์เหล่านี้เพื่อค้นหาค่าความหนา ค่าที่ค้นหาได้จะถูกนำไป ใช้เพื่อระบุความหนา ค่าดั้งเดิมจะถูกจัดเก็บไว้ในส่วน Misc Properties ของชิ้นงาน

Thickness comparison fudge - ใช้ในการค้นหา วัสดุดิบเมื่อนำเข้าชิ้นงาน TruSmartCAM จะพยายามระบุวัสดุดิบ หลังจากแยกชื่อวัสดุและความหนา สำหรับข้อมูลเพิ่มเติม โปรดดูหัวข้อ Thickness fudge ด้านล่าง

Identify shapes after a flat is imported - เมื่อ นำเข้าชิ้นงาน รูปทรงภายในชิ้นงานสามารถถูกรู้จำและระบุได้โดยอัตโนมัติ

Shape identification fudge - สามารถกำหนดค่า fudge ของการระบุรูปทรงได้ที่:

  1. ระดับส่วนกลาง (Global level) - ค่านี้ใช้เป็นค่าเริ่มต้นสำหรับทุกรูปทรง

  2. ระดับรูปทรงแต่ละรูป (Individual Shape Level) - สามารถแทนที่ค่าเริ่มต้นได้โดยกำหนด ค่า fudge ที่ระดับรูปทรงแต่ละรูป การเลือกรูปทรงในไดอะล็อก Shape Library จะแสดงค่า fudge โดยค่าเริ่มต้นจะถูกกำหนดเป็น 0 และรูปทรงเหล่านี้จะใช้ค่าส่วนกลางเริ่มต้น

Rotate flat horizontally - โดยทั่วไปโต๊ะเครื่องตัดมักจะ มีลักษณะเป็นสี่เหลี่ยมผืนผ้าและกว้าง เพื่อเพิ่มความเป็นไปได้ของการทำ tooling ให้หมุนชิ้นงานตามความกว้างหลังจากนำเข้าชิ้นงานแล้ว

Part rotation threshold - กำหนดค่านี้เป็น จำนวนขั้นต่ำสุดที่อนุญาตให้หมุนได้ ชิ้นงานใดที่เล็กกว่าค่าที่กำหนดจะไม่ถูกหมุน

Misc settings

Enable pre-import external tools - เปิดใช้งาน ตัวเลือกเครื่องมือภายนอกก่อนนำเข้า เพื่อเปิดใช้งาน Creo Reader TruSmartCAM จะอัปโหลด family instances ที่ดึงข้อมูลล่วงหน้าของชิ้นงานที่วางลง โปรดทราบว่าการดึงข้อมูล instance จะดำเนินการระหว่างการอัปโหลดชิ้นงาน (เป็นการดำเนินการก่อนนำเข้า) ดังนั้นจึงต้องติดตั้งซอฟต์แวร์ Creo บนคอมพิวเตอร์ที่ใช้อัปโหลดชิ้นงาน

Ignore drawing colors in Flat thumbnails for clarity - เปิดใช้งานตัวเลือกนี้เพื่อสร้างภาพย่อเฉดสีเทาที่คมชัดขึ้น สีของเลเยอร์และออบเจกต์ข้อความจะถูกละเว้นเพื่อความคมชัดของภาพ

Use only one Engine for all import tasks - เมื่อเปิดใช้งาน จะใช้ Engine core เพียงตัวเดียวสำหรับงานนำเข้าทั้งหมด

Thickness fudge

Thickness comparison fudge จะเลือก ค่าความหนาของแผ่นที่ใกล้เคียงที่สุดเมื่อความหนาแผ่นที่ต้องการไม่มีอยู่ในคลัง โดยเปรียบเทียบค่าความหนาของแผ่นที่มีในคลัง

ตัวอย่างเช่น สมมติตามต่อไปนี้:

  1. เรามีชิ้นงานที่มีความหนาแผ่น 1.6 mm และวัสดุเป็นเหล็ก

  2. ค่า Thickness comparison fudge คือ 0.1 mm

  3. คลังมีแผ่นเหล็กที่มีความหนา 1.5 mm, 1.55 mm และ 1.7 mm

TruSmartCAM จะเลือกแผ่นที่มีค่าความหนาใกล้เคียงที่สุดหลังจากเปรียบเทียบค่า Thickness comparison fudge (0.1 mm) กับ รายการที่นำเข้า (วัดได้ 1.6 mm) ในกรณีนี้จะเลือก 1.55 mm
