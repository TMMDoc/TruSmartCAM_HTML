Output settings

Save layout NC and reports - เปิดใช้งานตัวเลือกนี้เพื่อเก็บ ไฟล์ NC และรายงานของ layout

Save layout file - เปิดใช้งานตัวเลือกนี้เพื่อเก็บ ไฟล์ layout

Output simulation preview in reports - เปิดใช้งาน ตัวเลือกนี้เพื่อสร้างภาพตัวอย่างการจำลอง tooling พร้อมกับผลลัพธ์อื่น ๆ ซึ่งเป็นภาพเคลื่อนไหว GIF สั้น ๆ สำหรับ tooling แบบเลเซอร์/พันช์

Do not delete program outputs on layout/job completion - การเปิดใช้งานตัวเลือกนี้จะข้ามการลบ ผลลัพธ์โปรแกรมเมื่อ job/layout ถูกทำเครื่องหมายว่าเสร็จสิ้น

Nest settings

Mix parts from multiple Jobs - รองรับการ nesting แบบผสม ชิ้นงานจากหลาย job สามารถนำมา nest รวมกันได้ เพื่อเพิ่มประสิทธิภาพการจัดเรียง

Do not auto-release layouts - การตั้งค่านี้จะ หยุดไม่ให้ layout พร้อมสำหรับการผลิตจนกว่า layout ทั้งหมดจะอยู่ในสถานะ released

Re-nesting packing cut-off - ค่านี้ใช้เพื่อ ตัดสินใจว่า layout ที่ nest แล้วจะถูกเก็บไว้ในคิวการอนุมัติและจะถูกนำมา nest ใหม่เมื่อมีการวางแผนชิ้นงานใหม่ หรือจะถูกปลดสำหรับการผลิต และส่งออกผลลัพธ์ที่เกี่ยวข้องไปยังโฟลเดอร์เอาต์พุต

Interactive sheet-name prefix - ส่วนนี้ใช้ เพื่อรองรับ nesting แบบโต้ตอบ ซึ่งผู้ใช้สามารถควบคุมชิ้นงานที่กำลัง nest และผลลัพธ์ nest ได้มากขึ้น ใช้รูปแบบการตั้งชื่อที่แตกต่างจาก auto-nesting สำหรับ layout ที่ nest แบบโต้ตอบ

Update sheet inventory on nest (un)release - หาก เปิดใช้งานตัวเลือกนี้ คลังแผ่นจะอัปเดตเมื่อส่ง nest ไปยังเครื่องจักร นอกจากนี้ การเรียกคืน nest จากเครื่องจักรจะคืนแผ่นกลับสู่คลัง

Automate remnant inventory management - เมื่อเลือก ตัวเลือกนี้ ซอฟต์แวร์จะจัดการคลังเศษวัสดุโดยอัตโนมัติ หากไม่เลือก การจัดการเศษวัสดุจะเป็นแบบโต้ตอบ

Auto-refresh Out-of-date layouts - เมื่อ เลือก ซอฟต์แวร์จะรีเฟรชทุก ui:EGTag.SelectOutOfDate[Out-of-date Layouts] ที่เชื่อมโยงกับชิ้นงานหลังจากคำนวณโซลูชันการตัดเสร็จ

Automate twin-line nesting - เลือกตัวเลือกนี้เพื่อเปิดใช้ การทำงาน twin-line แบบอัตโนมัติ

Pull workflow settings

Use 'Pull workflow' - ตัวเลือกนี้มีประโยชน์ สำหรับผู้ใช้ที่ต้องการระบบการวางแผนและ nesting ที่ทำงานอัตโนมัติสูง เมื่อเปิดใช้งาน TruSmartCAM จะวางแผน nesting ตามความต้องการ

Nests per station - ค่านี้ใช้เพื่อกำหนดจำนวน layout ที่จะสร้างต่อสถานี

Maximum sheets per nest - ค่านี้ใช้เพื่อควบคุม จำนวนแผ่นสูงสุดต่อ nest หนึ่ง ๆ ตัวอย่างเช่น หากมีออเดอร์ที่มีชิ้นงานขนาดใหญ่ (ซึ่งเต็มทั้งแผ่น) และต้องการจำนวนมาก (เช่น 500 ชิ้น) TruSmartCAM จะไม่สร้าง nest เดียวที่มี 500 ชุดในโหมด pull อีกต่อไป แต่จะสร้าง 10 ชุดต่อ nest โดยที่ 10 คือค่าสูงสุด

Bend programs per station - ค่านี้ใช้เพื่อ กำหนดจำนวนโปรแกรมการดัดที่จะสร้างต่อสถานี

Mark the task completed, when the program outputs are removed - เปิดใช้งานตัวเลือกนี้เพื่อทำเครื่องหมาย layout เป็น Done เมื่อ ผลลัพธ์ถูกลบออกจากตำแหน่งปลายทางที่กำหนด

Spreadsheet import settings

CAD lookup directories - TruSmartCAM จะพยายาม โหลดรายการชิ้นงานที่ระบุไว้ในไฟล์ CSV ที่นำเข้าจากไลบรารีชิ้นงาน อย่างไรก็ตาม หากไม่มีชิ้นงานนั้นในไลบรารีชิ้นงาน ระบบจะพยายาม ดึงชิ้นงานจากไดเร็กทอรีที่ค้นหาตามลำดับของไดเร็กทอรีที่กำหนดไว้ในกล่องโต้ตอบนี้

Use recursive CAD search - เปิดใช้งานตัวเลือกนี้ เพื่อให้การค้นหาทำซ้ำกับผลลัพธ์ที่อยู่ถัดไป

Create a blank part for the missing CAD files - หาก ชิ้นงานไม่มีอยู่ในไลบรารี TruSmartCAM หรือไดเร็กทอรีที่ค้นหา TruSmartCAM จะสร้างชิ้นงานเปล่าสำหรับชิ้นงานที่ไม่มีเหล่านั้น

Do not show New Job dialog if the spreadsheet has no error - หากรายการใน CSV สมบูรณ์ กล่าวคือไม่มีข้อมูลที่ไม่ตรงกับ DB หรือทุกฟิลด์ระบุไว้อย่างถูกต้อง TruSmartCAM จะไม่แสดงหน้าต่างภาพรวม job และจะประมวลผล job ทันทีที่ CSV ถูกนำเข้าหรือวางลง

Prefer Raw-Material column over Material + Thickness - ชนิดสเปรดชีตที่รองรับ:

  1. รูปแบบ 1: PartName, Quantity, DueDate, Priority, RawMaterial

  2. รูปแบบ 2: PartName, Quantity, DueDate, Priority, Material, Thickness

  3. รูปแบบ 3: PartName, Quantity, DueDate, Priority, Material, Thickness, RawMaterial

หากไม่เลือกตัวเลือกนี้ ระบบจะถือว่ารูปแบบ 1 เป็นชนิดสเปรดชีต เริ่มต้น นอกจากนี้เรายังรองรับรูปแบบ 3 ในกรณีที่รูปแบบ CSV เป็นแบบรูปแบบ 3

หากเลือกตัวเลือกนี้และ CSV เป็นรูปแบบ 2 TruSmartCAM จะระบุวัสดุดิบ จากฟิลด์ Material และ Thickness ใน CSV

Spreadsheet output settings

Export Job/Layout completion report (.csv) - เลือกตัวเลือกนี้เพื่อเปิดใช้การส่งออก CSV เมื่อ Layout หรือ Job เสร็จสิ้น รายงานที่เสร็จสิ้นจะถูกบันทึกไว้ที่ตำแหน่ง Reports ที่กำหนดไว้ที่ Factory → Settings → Reports settings
