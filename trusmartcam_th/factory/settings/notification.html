การแจ้งเตือน

การแจ้งเตือนจะแจ้งให้ผู้ใช้ทราบเกี่ยวกับข้อผิดพลาด CAD และ tooling ที่เกิดขึ้นภายในระบบ ช่วยให้มั่นใจได้ว่าปัญหาต่าง ๆ จะถูกสื่อสารอย่างทันท่วงที เพื่อให้สามารถดำเนินการแก้ไขได้อย่างเหมาะสม

การแจ้งเตือนทางอีเมล

คุณสมบัติการแจ้งเตือนทางอีเมลช่วยให้ผู้ใช้กำหนดค่าและรับการแจ้งเตือน ทางอีเมลอัตโนมัติสำหรับข้อผิดพลาด CAD และ tooling เมื่อกำหนดค่าแล้ว ระบบจะส่งอีเมลไปยังผู้รับที่กำหนดโดยอัตโนมัติทุกครั้งที่เกิดเหตุการณ์ที่เกี่ยวข้อง เพื่อให้มั่นใจได้ว่าปัญหาจะได้รับการแก้ไขอย่างทันท่วงที

หากต้องการกำหนดค่าการแจ้งเตือนทางอีเมล ให้ไปที่: factory > settings > Notifications

หน้า Notifications ประกอบด้วยส่วนต่อไปนี้:

การตั้งค่าการแจ้งเตือน

ส่วน Notification settings ควบคุมวิธี การสร้างและส่งการแจ้งเตือนทางอีเมลไปยังผู้รับ

  • Enable email notifications - เปิดให้ ระบบส่งการแจ้งเตือนตามเงื่อนไขที่กำหนดไว้

  • Notification recipients - ระบุที่อยู่อีเมล ของผู้รับ สามารถเพิ่มผู้รับหลายคนได้โดยคั่นด้วยเครื่องหมายจุลภาค (,) หรือเว้นวรรค

  • Send messages in batch - รวมการแจ้งเตือน หลายรายการไว้ในอีเมลฉบับเดียว ข้อความที่สร้างขึ้นภายในช่วงเวลาที่กำหนดจะ ถูกจัดกลุ่มไว้ด้วยกัน ซึ่งช่วยลดปริมาณอีเมลและป้องกันความรกรุงรัง

  • Attach tooling simulation preview where applicable - แนบภาพตัวอย่างการจำลอง tooling ไปกับอีเมลแจ้งเตือนเมื่อ มีข้อมูล ซึ่งมีประโยชน์สำหรับการตรวจสอบปัญหาที่เกี่ยวข้องกับ tooling ได้โดยตรงจากอีเมล

การแนบภาพตัวอย่างการจำลองอาจทำให้ขนาดของอีเมล เพิ่มขึ้นอย่างมาก

Mail settings

ส่วน Mail settings กำหนดการกำหนดค่า เซิร์ฟเวอร์เมลขาออกที่ระบบใช้สำหรับส่งการแจ้งเตือนทางอีเมล การตั้งค่าเหล่านี้ต้องกำหนดให้ถูกต้องเพื่อให้สามารถส่งการแจ้งเตือนได้สำเร็จ

  • SMTP server - ระบุที่อยู่เซิร์ฟเวอร์ SMTP ที่ใช้สำหรับส่งอีเมลขาออก (เช่น smtp.gmail.com) โดยทั่วไปข้อมูลนี้ สามารถดูได้จากส่วนบัญชีหรือการตั้งค่าของโปรแกรมอีเมลของผู้ใช้

  • SMTP port - กำหนดหมายเลขพอร์ตที่เมล เซิร์ฟเวอร์ใช้ส่งอีเมลผ่านอินเทอร์เน็ต ค่าที่ใช้กันทั่วไปได้แก่ 465 (SSL) และ 587 (TLS)

  • Transport protocol - กำหนดโปรโตคอลที่ใช้เพื่อ ส่งอีเมลจากแอปพลิเคชันไปยังเมลเซิร์ฟเวอร์อย่างปลอดภัย (เช่น SSL หรือ TLS)

  • Server needs authentication - เปิดใช้ การยืนยันตัวตนสำหรับเซิร์ฟเวอร์ SMTP เมื่อเปิดใช้งาน ชื่อผู้ใช้และรหัสผ่านจะถูกตรวจสอบโดยเซิร์ฟเวอร์ก่อนส่งอีเมล

  • User-name - กำหนดบัญชีอีเมลที่ใช้ เพื่อยืนยันตัวตนกับเซิร์ฟเวอร์ SMTP และส่งการแจ้งเตือน

  • Password - กำหนดรหัสผ่านที่เชื่อมโยงกับบัญชี อีเมลที่ใช้สำหรับการยืนยันตัวตน

  • Sender address - กำหนดที่อยู่อีเมลผู้ส่งที่แสดง แก่ผู้รับเมื่อได้รับการแจ้งเตือน

  • Test…​ - ส่งอีเมลทดสอบเพื่อยืนยัน การกำหนดค่าเมลเซิร์ฟเวอร์

คลิก Test…​ เพื่อตรวจสอบการตั้งค่า หาก การทดสอบสำเร็จ จะมีข้อความยืนยันแสดงขึ้น มิเช่นนั้นจะมีข้อความแสดง ข้อผิดพลาดที่ระบุสาเหตุของความล้มเหลว

  • การแจ้งเตือนทางอีเมลจะไม่ทำงานในโหมดโต้ตอบ (เช่น ขณะ แก้ไขหรือบันทึกชิ้นงานด้วยตนเอง)

  • การส่งอีเมลจะดำเนินการในเบื้องหลังและอาจล่าช้าได้

  • การแจ้งเตือนอาจไม่ถูกส่งหากระบบหรือ engine หยุดทำงาน ก่อนที่การประมวลผลจะเสร็จสมบูรณ์
